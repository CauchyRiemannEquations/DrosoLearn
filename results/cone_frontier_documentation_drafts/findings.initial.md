# 같은 수정량 안에서 자기 수정과 도움을 더 살릴 수 있는가

작성일: 2026-10-20 (Asia/Seoul). 연구 ID `cone_frontier_v1`.

**저장된 수정들을 합치면, 균형 방향은 자기 수정과 기존의 도움을 조금 더 남겼다.** real/raw의
주 비교에서 기존 실제 방향을 100으로 놓으면 자기 수정은 **104.72**, 도움은 **110.67**이었다.
다만 모르는 문제에 준 방해도 늘었고, 매 수정마다 두 항이 함께 개선된 것은 아니었다.
새 방향으로 학습을 다시 돌린 결과나 정답률 개선은 아니다.

## 쉽게 설명하면

앞선 방식은 방해를 없애면서 나머지 영향의 비율까지 유지하려다 자기 수정과 도움을 크게
줄였다. 이번에는 “알고 있는 문제를 방해하지 않기”와 “같은 길이만큼 움직이기”를 지키면서
비율을 자유롭게 바꿨다. 자기 답만 가장 잘 고치는 방향과, 자기 답·알려진 도움을 함께
고려하는 방향을 따로 계산했다. **움직일 방향에는 개선 여지가 있지만, 어디에 힘을 쓸지의
절충과 아직 모르는 문제에 대한 위험이 남아 있다.**

## 실제 배선·원래 입력에서의 일곱 후보

아래 비율은 10개 계산 시드의 점수 질량을 합친 pooled 비율이다. 분모는 같은 저장 경로의
**이미 정규화된 실제 선택 억제 방향**이며, 직전 분석의 정규화 전 목표가 아니다. 100은 기존과
같다는 뜻이다. 방해는 다른 세 문제의 오답 방향 점수 변화 절댓값을 합친 뒤 시드 평균한 값이다.

| 같은 feedback 경로에 적용한 후보 | 자기 수정, 기존=100 | 기존 도움, 기존=100 | 방해 점수 질량 |
|---|---:|---:|---:|
| 저장된 실제 선택 억제 | 100.00 | 100.00 | 0.161141 |
| 공유 참고 | 1512.75 | 1517.95 | 19.001233 |
| 전체 번짐 억제 참고 | 158.81 | 약 0 | 약 0 |
| 관측 기반 자기 수정 최대 | 173.87 | 12.82 | 0.200294 |
| **관측 기반 균형 방향 — 주 비교** | **104.72** | **110.67** | **0.211764** |
| 전체 정답 참고·자기 수정 최대 | 158.81 | 약 0 | 약 0 |
| 전체 정답 참고·균형 방향 | 88.91 | 97.39 | 약 0 |

자기 수정 최대 방향은 자기 항을 **73.87%** 더 남겼지만 기존 도움은 **12.82%**만 남겼다.
따라서 자기 수정의 최댓값을 찾는 것만으로 두 기능을 함께 살릴 수는 없다. 공유 참고의 큰
값 역시 알려진 문제에 대한 방해를 허용한 대가이며, 새 안전 조건 안에서의 개선이 아니다.
표의 “약 0”은 실제로 작은 수치 잔차가 남은 값이다. 전체 수치는 원자료에 보존했다.

## 합계의 개선과 매번의 동시 개선은 다르다

주 균형 방향의 전체 pooled 비율은 자기 수정 **1.0471569894**, 도움 **1.1067124513**이다.
그러나 비영 수정 **1,941회** 중 두 항을 모두 나쁘게 하지 않고 하나 이상 개선한 수정은
**22회(1.13%)**였다. 모두 아직 보상을 덜 관측한 구간에서 나왔다. 네 부호를 모두 관측한 뒤의
**1,877회에서는 0회**였다. 따라서 “매번 자기 수정과 도움을 함께 늘리는 방법을 찾았다”고
말할 수 없다. 어떤 수정은 자기 항을 더 남기며 도움을 줄이고, 다른 수정은 반대 절충을 해도
전체를 합치면 두 합계가 모두 늘 수 있다.

| 주 균형 방향의 실제 관측 구간 | 자기 수정, 기존=100 | 기존 도움, 기존=100 | 위 동시 비악화·개선 수정 |
|---|---:|---:|---:|
| 부분 관측 | 124.85 | 108.37 | 22 / 64 |
| 네 보상 부호 모두 관측 | 101.10 | 111.09 | 0 / 1,877 |
| 전체 | 104.72 | 110.67 | 22 / 1,941 |

완전 관측 구간의 자기 비율은 `0.5599612309 / 0.5538628364 = 1.0110106585`, 도움 비율은
`0.5677609895 / 0.5111032720 = 1.1108537563`이다. 이는 **질량의 합을 나눈 비율**이며,
시드별 비율을 단순 평균한 값과 다르다. 마지막 보상 부호를 발견한 시행부터 완전 관측에
포함한다. 이 구간 비교는 시점·보상 경험·상태도 함께 달라지므로 정보 획득만의 인과효과가 아니다.

## 아직 모르는 문제에는 방해가 늘었다

주 방향은 실제로 알고 있는 보상 부호만 사용했다. 알려진 문제의 안전 조건 위반은 0이지만,
미관측 문제의 실제 방해 점수 질량은 기존 **0.1611405538 → 0.2117636162**로 **31.42%**
늘었다. 이 조건의 유의미한 방해는 모두 부분 관측 구간의 미관측 문제에서 발생했다.
평가자는 정답을 알고 이를 셌지만, 그 정답을 관측 기반 방향 선택기에 전달하지 않았다.

전체 정답 참고는 미관측 문제까지 안전 조건을 추가한다. 그래서 부분 관측 기반 방향보다
자기 수정 최댓값이 작을 수 있다. 정답을 더 안다는 이유만으로 모든 점수가 더 커지는 것이
아니며, 이 참고를 실제 보상만 쓰는 주 방법의 성적으로 대신하지 않는다.

## 여섯 배선·입력 조건을 모두 보존한 비교

모든 값은 각 조건의 기존 실제 방향을 100으로 놓은 전체 pooled 비율이다. 새 관측 기반
균형 방향은 여섯 조건의 합계에서 두 지표가 모두 100을 넘었지만, 실제 배선만의 우수성을
보여 주지는 않는다. 인공 이름표 입력의 결과로 원래 입력의 결론을 바꾸지 않는다.

| 배선 / 입력 | 자기 최대: 자기 / 도움 | 균형: 자기 / 도움 |
|---|---:|---:|
| 실제 / raw | 173.87 / 12.82 | 104.72 / 110.67 |
| 실제 / identity | 129.97 / 42.11 | 103.05 / 114.03 |
| 재배선 / raw | 174.18 / 10.76 | 103.34 / 110.87 |
| 재배선 / identity | 122.33 / 51.03 | 101.53 / 108.57 |
| 일반 신경망 / raw | 176.97 / 11.66 | 104.63 / 110.59 |
| 일반 신경망 / identity | 122.01 / 48.12 | 100.98 / 110.24 |

![같은 저장 경로와 단위 이동 상한에서의 자기 수정·도움 비교](../results/cone_frontier_figures_v1/cone-retention.png)

그림의 비율도 pooled 값이다. 완전한 절충 곡선을 탐색한 것이 아니라 사전에 고른 두 목적을
비교했다. 지표는 선택 전 점수 변화이며 정답률·학습 속도·새 입력 일반화가 아니다.

## 검증과 보존

6조건·10계산 시드의 **24,000개** 저장 시행(비영 수정 11,692개)에서 새 학습 없이 비교했다.
7후보·168,000개 후보 시행 기록·**672,000개** 목적지 영향 셀, **1,476개** 유일한 최적화
case, **15개 배열·1,260개 CSV 행**을 보존했다. 새 행동·출력 갱신·내부 시냅스 갱신·가치
갱신·난수·모델 생성은 모두 0회다. 후보 방향을 실제 출력 가중치에 적용하지 않았다.

독립 검산은 producer와 새 solver를 import하지 않고 제약·목적·영향을 다시 구성하고 원래
특징 공간에서 최적화를 다시 풀었다. 단위 이동 상한, 관측 정보 분리, 비음수 승수의 쌍대 상한,
구간 합계를 모두 통과했다. 최대 증거 잔차는 **1.71×10⁻¹⁴**, 이동 상한 위반 잔차는
**1.39×10⁻¹⁷**였다. 자동검사 **234개(신규 165 + 관련 기존 69)**가 통과했다.

기존 **18,812개 파일·2,105,281,712 bytes**의 Git blob hash 보존 검사를 통과했다.
이번 검사를 byte 전체 직접 비교라고 부르지 않는다. 이전의 직접 비교 receipt도 보존했다.
실패·기준·설정·소스는 결과에 맞춰 바꾸지 않았고 원래 충분한 습득 **0/10**과 두 미지지도
그대로 남았다. [계획](cone-frontier-protocol.md), [재현 안내](cone-frontier-reproduction.md),
[전체 요약](../results/cone_frontier_v1/summary.json), [독립 검산](../results/cone_frontier_v1/verification.json).

## 지금 말할 수 있는 것과 다음 후보

같은 저장 수정량 안에서 **비율 보존을 완화하면 합계상 더 남길 여지**는 있었다. 실제 계속
학습할 때도 도움이 되는지는 아직 모른다. 고정 내부 가중치·활성, 실제 학습 출력, 보상 기록과
이번 대안 계산을 구분한다. 네 인공 문자열의 계산 분석이며 생물학적 가소성, 새 일반화(Level 3),
인간 학습 유사성(Level 4), 공통 신경 기작(Level 5), 교육 효과를 추가 입증하지 않는다.

다음 후보는 균형 규칙을 실제 학습에 적용하는 별도 전향적 실험이다. 새 등록, 고정 예산,
정보·기억·계산 자원 대조와 미관측 방해 측정을 먼저 설계해야 한다. 이번 분석에서는 실행하지
않았다. 이전 실패와 닫힌 후속 게이트를 유지한다.

Five original MATLAB analysis payloads from immutable Git release c7c5d3a164425af3e65cc908ef0d41f01725984c, preserved without edits. Dataset metadata declares CC0; see the existing original [declaration](../stolz_2022_openneuro/dataset_description.json) and [official version](https://openneuro.org/datasets/ds004295/versions/1.0.0/download). Five payloads total 43,141 bytes. No additional participant, EEG or stimulus data is included.

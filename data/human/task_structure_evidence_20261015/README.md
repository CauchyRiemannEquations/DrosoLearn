# 공개 과제 코드의 원문 근거

Marković, Reiter & Kiebel (2022), DOI 10.3389/fnbeh.2022.962494의 과제 구조를
확인하기 위해 받은 작은 프로그램 텍스트와 공식 메타데이터다. 인간의 시행별
기록·성과·EEG·실행 바이너리는 포함하지 않는다. upstream 코드를 실행하지 않았다.

- OSF: https://osf.io/57wr8/ (상위 프로젝트 https://osf.io/h526v/).
  저작권자 Dimitrije Markovic, 2019. 공식 component가 명시한 CC BY 4.0에
  따라 원바이트를 재배포한다. osf_task_node.json의 license 관계와
  osf_task_license.json의 https://creativecommons.org/licenses/by/4.0/legalcode 를
  보존했다. MATLAB 파일은 모두 revision 1이다. 원문 변경은 없다.
- pybefit: Dimitrije Markovic, https://github.com/dimarkov/pybefit,
  고정 커밋 813aeb5ad2c7bbed90ecd7d947bce9fe981c9702. 두 formatter와
  원 MIT 고지 pybefit_LICENSE.md를 함께 보존한다. 원문 변경은 없다.
- 공식 API의 파일 목록·버전·권한 응답은 코드의 출처 및 바이트 검증 근거로
  보존한다. 관측 시각에 대한 스냅샷이며 미래 API 응답과 같다고 가정하지 않는다.

파일별 URL·버전/커밋·UTC 취득 시각·바이트·SHA-256은 source-manifest.json에
있다. OSF 텍스트 12개는 공식 파일 목록의 크기와 SHA-256에 일치하며,
GitHub 원문은 고정 커밋의 Git blob SHA-1도 확인했다.

논문 HTML은 외부 작업 캐시에만 있다. manifest의 external_review_sources는
그 열람 캐시의 출처만 기록하며 해당 본문을 이 폴더에 포함하지 않는다.
정확 실행판과 2018 원본의 연결은 미확인이다. 의미 판정과 한계는
docs/human-task-structure-sources.md에 있다.

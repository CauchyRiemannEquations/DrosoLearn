# Source and license

Christopher Stolz, Alan Pickering, Erik M. Mueller (2022), *Reward gain and punishment avoidance reversal learning*, OpenNeuro ds004295, version 1.0.0.

[Dataset DOI](https://doi.org/10.18112/openneuro.ds004295.v1.0.0) · [Official release and CC0 declaration](https://openneuro.org/datasets/ds004295/versions/1.0.0/download) · [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

The dataset's original `dataset_description.json` declares `License: CC0`. This collection preserves 31 original files, totaling 1,934,671 bytes: 26 event TSVs, the original README and two JSON metadata files, and two behavioral MAT files. It is a partial behavior/metadata collection, not the complete EEG/BIDS dataset. EEG recordings, stimuli and demographic tables are not included.

The original upstream files are unchanged. `source-manifest.json` records URLs, exact Git tag commit, byte lengths, SHA-256 and Git blob/annex bindings. The two MAT files are bound by the SHA256E objects in the same immutable Git release; their public S3 downloads match those objects. Local source collection and schema auditing are independent of the authors' scientific analyses.

Related article: Stolz, Pickering & Mueller, *Dissociable feedback valence effects on frontal midline theta during reward gain versus threat avoidance learning*, [10.1111/psyp.14235](https://doi.org/10.1111/psyp.14235), first published December 2022, volume 60 (2023). Its article license is separate from the dataset's CC0 declaration. Article text and figures are not redistributed here.

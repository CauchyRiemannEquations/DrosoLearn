# Phase 5 — 범위를 한정한 연구 종합의 실행 계획

2026-10-19. 연구 ID `phase5_synthesis_v1`. 사용자가 승인한 네 추가 연구를 순서대로 완료하고 검산한 뒤 종합한다. **이미 알려진 결과를 정리하는 회고적 종합**이며, 결과를 보지 않은 새 확증 실험의 사전등록이라고 표현하지 않는다. 종합 실행 전 소스·설정·선행 결과·문헌 검토·입력 증거를 고정하고 별도 결과 경로를 사용한다.

쉽게 말하면, 성공한 부분과 안 된 부분을 모두 같은 장부에 놓고 처음의 다섯 질문에 답한다. 검산 통과는 계산이 맞았다는 뜻이고, 학습·일반화·인간 유사성 가설의 지지는 별도다.

## 포함·제외 범위

기존 완료 태그의 24개 연구와 추가 연구 4개를 역사 순서로 모두 포함한다. 데이터 가용성 감사, 의미 대응의 미해결, 무학습 반례, 측정·정적 분석, 학습 개입, 인간 비교의 첫 난수 주소 오류와 별도 수정, 음성 결과를 제외하지 않는다. 원 `human_shell_v1`은 산술 검산 통과와 자율 비교 설계 한계가 공존하므로 `design_limited`로 보존한다. 수정판은 같은 사람 분할·학습률·판정 기준의 새 난수 주소 실행이며 원본을 대체 삭제하지 않았다.

새 학습 시행·새 난수 추출·인간 실험·효과 검정은 각각 0회다. 기존 문헌의 근거를 새로 재현했다고 세지 않는다. 문헌 조사에서 실제 본문·초록·접근 제한을 구분한 이전 감사도 그대로 포함한다. 새로운 외부 자료·비용·인간 실험은 이번 범위 밖이다.

## 기계 판독 증거 장부

설정 `studies`의 각 항목은 연구 ID·완료 태그·검산·읽기용 보고서·주 결과·역할을 포함한다. 연구별 독립 검산의 `passed=true` 또는 `status=pass/passed`와 빈 오류 목록을 확인한다. 명시적으로 `passed=false`인 모순 기록은 거부한다. 검산에 주 summary의 해시가 있으면 실제 바이트와도 대조한다. 이 작업은 과거 모든 학습을 새로 실행하는 작업이 아니며, 선행 검산·등록·산출물 해시와 최종 원본 보존 감사를 함께 사용한다.

`claims`에는 주장 ID, 원 연구 질문 번호, 주장 수준, 결과 상태, 쉬운 설명, 한계 및 원 JSON 포인터와 정확한 관측값을 남긴다. 모든 근거 파일을 등록의 `input_files` 또는 `parent_files`로 고정한다. RFC6901 포인터의 목록 좌표·이스케이프를 검사하고 JSON 중복 키·NaN·Infinity를 거부한다. 관측값은 canonical JSON으로 정확히 대조하며 숫자·문자열·bool을 섞지 않는다. 출처·측정 감사인 Level 0은 학습 주장 수준이 아니라 장부상의 별도 표시다.

상태는 supported, not_supported, bounded, not_assessable, design_limited, untested 중 하나다. 주장이 양성이어야 장부에 들어가는 구조를 사용하지 않는다. 이미 닫힌 습득·자료·공동학습 조건을 열지 않는다. 다섯 질문 각각의 주장 목록이 중복·누락 없이 대응해야 한다. Level 4 양성·Level 5·교육 효과·모든 Phase 2/3 과제 완료를 새로 선언하지 않는다.

## 산출물·검증

공통 실행기는 등록·metadata·수치 장부 NPZ·주장 CSV·summary·artifact hash를 새 `results/phase5_synthesis_v1/`에 생성한다. 수치 배열은 연구별 검산 통과 표시와 주장별 질문·수준·상태·관측 수다. 실제 연구의 시행 수를 사람·동물 개체 수로 더하지 않는다. 독립 검산기는 종합 생산자를 import하지 않고 근거 포인터·파일 해시·주장 연결·모든 배열·CSV·summary와 0회 계수를 재계산한다.

그 뒤 쉬운 한국어 최종 보고서, 자동 생성 증거 부록, 기존·신규 결과 그림, 출처·라이선스·재현 안내를 제공한다. 그림은 검산된 배열·요약의 기술적 표시이며 새 유의성 검정이 아니다. 모든 모델과 습득 미달을 표시하고, 간섭·순서는 자기 조건의 습득/공동학습 gate에 따라 해석한다. idle 상태 복제는 자연 시간 망각 실험이 아니다.

최종 보존 감사는 이전 `human-shell-comparison-v2`의 literal Git blob과 현재 파일을 비교한다. 변경 가능한 기존 파일은 README·로드맵·저장소 상태의 세 인덱스뿐이다. 네 추가 연구와 종합의 실행 전 원격 등록 바이트·시간 순서·소스/입력/결과 해시·태그 계보, 자동검사 수, 보고서 링크·그림 값도 대조한다. 완료 코드·원자료·실패·원 DrosoMem은 수정하지 않는다.

간섭·순서의 원 NPZ는 GitHub 단일 파일 제한을 47,300바이트 넘어 원본을 바꾸지 않고 두 연속 Git blob으로 보존했다. [저장 명세](result-storage.md)의 manifest와 두 조각도 종합 등록에 입력 해시로 동결한다. Phase 5의 새 모듈/독립 검산기에서만 정확히 이 부모 한 경로의 Git 바이트 검사를 조각 연결로 수행하며, 연결된 길이·SHA가 기존 원 artifact hash·등록 부모 hash·현재 원 NPZ와 모두 같아야 한다. 다른 파일은 원 공통 함수를 그대로 검사하고 종료 때 함수 참조를 복구한다. 새 clone 복원은 누락 파일만 `xb`로 만들며 기존 파일은 검증만 한다. 이 저장 보완에 합성 Git fixture·부분 누락/변조·순서·다른 부모 검사·덮어쓰기 방지 시험을 추가한다. 기존 과학 소스·결과는 바꾸지 않는다.

## 종료와 이후 연구

이 종합은 현재 승인된 유한 계산 연구의 첫 보고서다. 실제 시각 회로, 독립 커넥톰 반복, 새 인간 자료, 맥락/표현과 갱신의 분리, 더 넓은 규칙 계열은 후속 연구 질문으로 구분한다. 부족한 근거를 성공 가정이나 추가 시행으로 메우지 않는다. 자동 이어가기는 PAUSED를 유지하고, 네 추가 연구와 종합을 완료한 뒤 이번 연속 작업을 마친다.

## 알려진 합성 정책과 예정된 반례

8개의 새 계산 시드 16001..16008을 사용한다. 원 29개 일정×216시행에서 uniform(.5), 같은 조개 직전 행동을 .9로 반복하는 persistence(첫 방문 .5), Q(alpha=.1,beta=4)의 세 정책을 실행한다. 선택 난수는 `SeedSequence([2026101902,seed,numeric_participant_id])`이며 같은 칸의 조건들이 같은 uniform을 공유한다. Q는 자기 Go에서만 +1/0/−1을 받고 NoGo는 0이다. 숨은 상태·미래·NoGo 내용을 갱신 입력으로 주지 않는다. Q의 상태 가치 갱신과 신경망의 내부/출력 갱신을 구분한다.

정상 세 정책의 새 선택은 150,336회다. 별도로 **Q가 선택한 행동 테이프를 고정해 재생**하는 프로그램을 만든다. 테이프는 이미 계산한 Q 행동에서 구성되며, 재생 중 보상을 읽거나 가치를 학습하지 않는다. 같은 행동이므로 같은 세 요약 지표가 나오는 것은 **사전에 알려진 구성적 항등식**이다. 232개 테이프·696개 지표의 정확한 일치를 검산한다. 이 테이프는 원래 조건을 보고 만들었으므로 공정한 학습 성능 대조·인간의 실제 전략 후보·새로운 실험 발견으로 사용하지 않는다.

예정된 반증 대상은 “이 세 행동 요약만으로 보상 기반 학습이라는 기작을 유일하게 알아낼 수 있다”라는 강한 주장이다. 테이프와 학습자의 같은 요약이 확인되면 그 유일 식별 주장을 부정하는 계산 반례가 성립한다. 학습이 없었다거나 기존 인간 행동의 원인이 테이프라는 주장은 아니다.

추가로 잠재 Go 보상의 부호만 뒤집은 인공 환경에서 같은 초기값·uniform의 Q를 50,112회 실행한다. 원 인간 보상이나 기록은 수정하지 않는다. Q의 행동과 고정 테이프의 불일치 수를 기술한다. 테이프의 선택은 그대로이며 Q가 반응하는지 확인하되 사후 효과 기준이나 유의성 검정을 추가하지 않는다. 세 정책+부호 반전 Q의 **새 합성 선택은 총 200,448회**, 별도 테이프 재생 읽기는 50,112회다. 테이프 읽기를 새 학습 표본으로 세지 않는다.

# 균형 방향의 실제 출력 학습과 미관측 문제 방해

작성일: 2026-10-20 (Asia/Seoul). 연구 ID는 `balanced_learning_v1`이다.
완료 기준선은 `cone-frontier-v1`, commit
`56e1a31537083825e83d4402cfa9445e7e519b9b`다. 새 설정·소스·입력·계획을
동결하고 기존 비공개 원격에 게시한 뒤, 새 계산 시드에서 한 번의 정해진 실험을 실행한다.

## 쉽게 설명하면

앞선 계산은 저장된 한 번의 수정에 다른 방향을 대입한 참고였다. 자기 답을 고치는 힘과
다른 문제에 주는 도움을 조금 더 남길 수 있었지만, 아직 모르는 문제를 방해하는 양도 늘었다.
이번에는 **그 균형 방향을 실제로 매번 적용하여 이후 선택과 보상까지 달라지게 한다.**
마지막 성적과 모르는 문제에 준 방해를 별개로 검사한다. 성적이 좋아져도 방해까지 줄었다고
가정하지 않으며, 한 번 수정의 점수 개선을 전체 학습 성공으로 바꾸어 부르지 않는다.

## 선행 근거와 반증 가능성

원래 선택 억제 실험의 real/raw 주 방법은 기대 정답 선택 확률 56.78%였고 충분한 습득은
0/10이었다. 전체 번짐 억제보다 +0.32%p로, 사전 5%p 개선 기준에 미달했다. 약화 분석과
기하 분석을 통해 비율 보존 대신 안전한 방향을 고르는 후보를 정했지만, 그 분석은 실제
새 학습이 아니었다. 여기서는 이 실패와 후보 선택 과정을 모두 알고 출발한다. 기존 기록을
모르는 독립적인 발견이라고 주장하지 않는다. 이번 새 시드의 행동 집계는 동결 후 처음 수행한다.

기존 DrosoMem과 완료된 소스·설정·등록·실패·원자료·결과는 변경하지 않는다. 같은 등록의
실패를 예산 연장, 시드 교체, 균형 목적 가중치 변경, 유리한 배선·표현·시드의 선택으로
성공으로 바꾸지 않는다. 필요한 후속 질문은 별도 계획으로 남긴다.

## 과제·표현·배선·시드

입력은 기존의 네 인공 전체 문자열 `ABAB, BABA, ABBA, BAAB`이다. 앞 두 입력은 Go
선택 시 +1, 뒤 두 입력은 Go 선택 시 −1을 준다. NoGo 보상은 항상 0이며, 숨은 Go 보상의
부호나 정답 여부를 알려주지 않는다. 실제 시각 물체의 수량·LC11 경로를 모델링한 과제가 아니다.
분류해야 할 네 입력을 모두 훈련한다. 새 문자열·새 규칙 일반화 시험은 없다.

배선은 `real, rewired, ann`, 표현은 `raw, identity`의 6조합이다. 실제 배선은 고정된
FlyWire v783 왼쪽 mushroom body 부분 투사 자료를 사용한다. 이름표(identity) 표현은
인공적인 사전 입력이며 숨은 정답으로 만들지 않는다. 입력 catalog와 전처리 bytes, KC→MBON
원본 그래프, 출처 및 기존 인코더 규칙을 그대로 보존한다. ANN은 같은 투사 크기지만 초파리
실제 배선이 아닌 계산 대조다. 재배선이 동등한 모든 생물학적 특성을 보존한다고 주장하지 않는다.

새 계산 시드는 **17501..17510**, 시드·조건당 **400시행**이다. 체크포인트는
**0, 50, 100, 200, 400**이다. 입력 순서는 각 4시행 블록에 네 입력을 한 번씩 섞는다.
시드별 입력 순서와 행동 선택용 균등 난수는 모든 24조건에 공유한다. 실제 확률·행동·보상·
발견 시점은 방법별로 달라진다. 이전 17401..17410의 결과를 새 시드와 짝지어 검정하지 않는다.
난수 namespace는 `202610201`로 고정한다. 입력 순서는
`SeedSequence([namespace,seed,0])`, 행동 균등 난수는 `[namespace,seed,1]`을 사용한다.
기존 모델 생성 규칙의 encoder `seed+100000`, 재배선 `seed+110000`, ANN `seed+120000`을
그대로 쓴다. 두 종류의 행동 난수와 모델 생성 난수는 서로 다른 역할이다.
전체 실제 선택·피드백 기록은 **24×10×400=96,000개**, 체크포인트의 정적 입력 평가는
**24×10×5×4=4,800개**다. 정적 평가는 새 보상이나 가중치 갱신을 만들지 않는다.

## 네 방법과 실제 획득 정보

방법 순서는 `shared, isolated, feedback_selective, balanced`로 고정한다.

1. `shared`: 단위 특징의 현재 입력 방향으로 출력 계수를 바꾼다. 다른 입력으로 번짐을 허용한다.
2. `isolated`: 다른 세 입력의 점수 번짐을 억제하는 기존 단위 방향을 사용한다.
3. `feedback_selective`: 실제 관측한 보상으로 확인된 방해만 0으로 만들고 나머지 raw 영향의
   비율을 유지한 뒤 단위 길이로 줄이는 기존 방식이다.
4. `balanced`: 실제 관측한 문제를 방해하지 않는 안전 범위 안에서 자기 수정과 알려진 기존
   도움의 평균에 같은 목적 가중치를 주는 기존 기하 분석의 균형 방향을 사용한다.

모든 학습자는 출력 계수 외에 **4칸의 실제 획득 보상 부호 기록**을 0으로 시작한다. Go를
실제 선택해 얻은 +1 또는 −1만 현재 source 칸에 기록한다. 현재 Go 보상을 기록한 뒤 같은
시행의 방향을 정할 수 있다. NoGo 0은 미관측 부호를 채우지 않는다. 반복 관측은 발견 수를
늘리지 않으며, 상충하는 부호가 오면 무결성 실패다. 이 기록은 내부 KC→MBON 시냅스가 아니다.

선택은 항상 출력 계수로 계산한 sigmoid 확률을 따른다. 보상 기록을 직접 조회해 Go/NoGo를
결정하지 않는다. 공유·전체 억제도 같은 기록을 남기지만 방향에는 사용하지 않는다. 균형·선택
억제는 그 학습자 자신의 실제 기록만 받는다. 평가용 전체 정답표는 방향 선택기에 전달하지
않으며, 이번에 정답표를 미리 아는 oracle 학습자는 없다. 네 칸을 모두 채운 전후의 비교는
시점·보상·출력 상태도 함께 달라지는 기술 비교이며, 정보 획득만의 인과효과가 아니다.

## 균형 방향: 같은 안전 조건과 같은 목적

입력별 고정 단위 특징을 D, 현재 입력을 i, `M=D D^T`, 실제 기록을 k라 한다. 실제 비영
Go 갱신은 현재 부호를 관측한 뒤 실행하므로 `k[i] != 0`이다. 안전 조건은 다음과 같다.

```text
||w||_2 <= 1
(k[i]*k[j]*D[j]) @ w >= 0  모든 k[j] != 0인 j
H = {j != i : k[j] != 0, k[i]*k[j]*M[i,j] > 1e-8}
c = D[i]                                           H가 비었을 때
c = .5*D[i] + .5*mean(k[i]*k[j]*D[j] for j in H)     그 외
```

`c @ w`가 최대인 방향을 사용한다. 관측된 자기 입력도 안전 제약에 포함한다. 알려진 도움이
하나도 없으면 자기 수정 목적만 쓴다. 도움의 합이 아닌 평균을 쓰며 .5/.5를 바꾸거나 조건별로
탐색하지 않는다. 미관측 목적지에 평가 정답을 이용한 제약을 추가하지 않는다. 이 목적은 매번
자기 수정과 도움 둘 다 기존보다 클 것을 보장하지 않는다. 알려진 방해를 막되 미관측 문제에는
새 방해가 발생할 수 있다.

동결된 `cone_geometry.cone_direction`의 활성 부분집합 열거와 수치 증거를 재사용한다.
수치 허용 오차는 `1e-8`, SVD 상대 cutoff는 `1e-12`로 고정한다. 제약은 최대 4개다.
실제 행동 난수를 쓰기 전에 고정 특징의 full row rank 4·condition 1e6 이하를 검사하고,
기존 선택 억제의 가능한 부호 상태 81개×source 4개, 조합당 324방향을 전수 검사한다.
균형 최적화는 실제 비영 Go 시행에서 필요한 관측 상태만 계산하며, 같은 특징·source·
실제 관측 기록의 반복이면 해당 증거를 재사용한다. 실제 방향 선택은 그 시행의 관측 기록으로만
하며, 평가 정답에 맞춘 상태 캐시를 숨겨 제공하지 않는다. 증거·유한성·단위 길이·안전 조건
실패는 결과에 남기고 실행을 중단한다.
어려운 case를 다른 방법이나 다른 시드로 대체하지 않는다.

출력 갱신은 모든 방법에서 다음과 같다.

```text
p = sigmoid(D[i] @ head_before)
g = .1 * (actual_action - p) * obtained_reward
head_after = head_before + g*w
```

NoGo이면 `g=0`이다. 균형 최적화는 호출하지 않고 0방향·0갱신을 남긴다. 현재 시행을
알려진 부호로 만드는 것도 금지한다. 비영 Go 갱신에만 실제 균형 방향을 적용한다.

고정 내부 투사 가중치, 인코더, bias 및 같은 입력에 대한 내부 활성 반응은 바뀌지 않는다.
실제로 바뀌는 것은 출력 계수와 별도 보상 기록이다. 학습에 의한 출력 logit·선택 확률 변화는
고정 내부 활성의 변화와 구별한다. 내부 시냅스 및 가치 계수 갱신 횟수는 0이다.

## 같은 수정량 제한이 뜻하는 것

모든 방법의 방향은 길이 1 이하이고 학습률은 .1이다. 한 시행의 실제 출력 이동 상한은
`.1`, 400시행의 경로 길이 상한은 `40`, 제곱 이동 길이의 합 상한은 `4`다. 실제 이동 길이,
경로, 제곱합, 최종 출력 계수 길이를 방법·시드별로 보존한다. 최종 길이는 실제 경로 길이
이하여야 한다. 이 규칙을 지켜도 확률·선택이 달라 실제 g와 누적 비용이 같지는 않다.

따라서 “같은 제한 아래의 실제 성적 비교”라고 부른다. 저장된 부모 경로의 g를 재사용하거나
실현된 총 이동량을 사후에 똑같게 만드는 실험이 아니다. 균형 최적화·행렬 처리·별도 관측 기억의
추가 계산 비용까지 같다고 주장하지 않는다. solver 호출 수·검사 수·기억 갱신을 별도 보고한다.

## 미관측 문제에 주는 실제 방해

각 시행에서 **자기 출력 갱신 직전과 직후의 같은 상태**를 비교한다. 실제 정답 부호를 y라
할 때 평가 전용 점수 변화는 `y[j]*(logit_after[j]-logit_before[j])`, 정답 선택 확률은
`sigmoid(y[j]*logit[j])`다. 이것은 해당 단일 갱신의 직접 효과이며 이후 전체 학습 성적과
다른 양이다. 평가자는 전체 정답을 사용할 수 있지만 그 값은 보상 획득과 방향 선택에 역류하지 않는다.

미관측 집합의 주 정의는 현재 source를 제외한 `known_before[j]==0`이다. 이 집합에 대한
음수 점수 변화의 절댓값 합과 **정답 선택 확률 감소의 절댓값 합**을 각각 보존한다. 자기 입력은
별도로 기록한다. 후자의 확률 방해 질량을 주 안전 비교에 사용하고, 점수 방해 질량으로
대신 판정하지 않는다. 양수 도움과 음수 방해를 상쇄해 순합만 남기지 않는다.

`known_after`로 정한 미관측 집합도 보존한다. 현재 source만 새로 기록할 수 있으므로
**다른 입력의 전·후 미관측 mask는 항상 같다**. source까지 포함한 전체 미관측 개수는
달라질 수 있으므로 별도 기록과 감사에 사용한다. NoGo에서는 모든 관측 mask·logit·확률의
변화가 0이다. 이미 알려진 목적지의 음수 점수·확률 변화도 별도로 남겨 균형 안전 조건을 검사한다.

한 학습자의 400시행에서 다른 미관측 문제에 발생한 방해 질량을 모두 합친다. 주 비교는 그
학습자 단위 합계의 시드 평균이다. 분모를 고정하려면 400으로만 나누며 판정은 같은 합계로
한다. 미관측 노출 횟수는 방법에 따라 달라질 수 있으므로, 그 횟수·발견 시점·미관측 목적지당
기술적 평균을 따로 보고한다. 노출 수가 줄었다는 이유로 위험이 없어졌다고 부르거나,
사후에 유리한 분모로 주 지표를 바꾸지 않는다. 분모 0의 기술적 비율은 null이다.

## 사전 가설과 독립 판정

주 조건은 **real/raw/balanced**이다. 다른 배선·표현은 사전 기술 대조이며 주 조건을
대체하지 않는다. 평균과 시드별 값·표준편차·짝 차이를 모두 보고한다. 계산 시드 10개는
독립 초파리 개체나 인간 참가자 10명이 아니다. 이 작은 실험에서 모집단 동등성이나
통계적 유의성, 교육 효과를 주장하지 않는다.

**H_gain — 실제 성적의 실용적 개선.** 마지막 네 입력의 기대 정답 선택 확률 평균을 쓴다.
동일 새 시드에서 balanced−feedback_selective와 balanced−isolated의 평균 차이가
**각각 0.05 이상**이고, 각 비교에서 양수 차이인 시드가 **각각 8/10 이상**이어야 한다.
두 비교와 모든 무결성·수치·정보·예산 게이트가 통과해야 지지한다. 공유 방법과의 차이만으로
대신하지 않는다. 두 비교는 동결된 실용 기준이며 사후 유의성 검정을 추가하지 않는다.

**H_acquisition — 충분한 습득.** 주 조건에서 각 시드의 마지막 평균이 **0.8 이상**, 초기
평균 대비 향상이 **0.25 이상**, Go 정답 두 입력과 NoGo 정답 두 입력의 각 클래스 평균이
**각각 0.7 이상**이어야 한다. 이 세 조건을 모두 만족하는 시드가 **8/10 이상**이고 모든
게이트가 통과해야 지지한다. H_gain과 독립으로 판정하며 한쪽 성공으로 다른 쪽을 대신하지 않는다.

**H_unknown — 관측된 실험에서 미관측 방해가 더 나쁘지 않음.** 위에서 정한 400시행당
확률 방해 질량으로 balanced−feedback_selective의 평균 차이가 **1e-8 이하**, 같은 차이가
**1e-8 이하인 시드가 8/10 이상**이어야 한다. 모든 게이트도 통과해야 지지한다. 이는 주
조건·실제 관측한 계산 시드의 기술적 비악화 기준이며 모집단 비열등성 증명이 아니다.
미관측 문제에 준 방해가 정확히 0이라는 가설도 아니다. 점수 방해·노출당 방해·전체 알려진
문제의 안전 위반은 함께 보고하되 이 주 지표를 대체하지 않는다.

세 판정을 각각 보존한다. 성적 개선과 방해 비악화를 함께 주장하려면 H_gain과 H_unknown이
둘 다 필요하며, 충분한 습득을 말하려면 H_acquisition도 별도로 필요하다. 실패해도 시드,
노출 수, 예산·가중치·판정 문턱을 바꾸지 않는다. 무결성 실패는 과학적 미지지와 구별한다.

## 검증·기록·재현

별도 설정 `configs/balanced_learning_v1.json`, 계획(이 문서), 소스, 검사, 실제 입력 catalog,
그래프, 선행 완료 자료를 SHA-256으로 동결한다. 별도 등록과 게시 증거는
`results/registration_balanced_learning_v1.json`,
`results/balanced_learning_publication_proof.json`이다. 원격의 비공개 상태와 게시 원문 bytes를
확인한 시간이 실제 실행 시작보다 앞서야 한다. 실행 경로는 `results/balanced_learning_v1`로
배타적으로 만들며 이전 결과를 덮어쓰지 않는다.

모든 시행의 입력·확률·선택·획득 보상·관측 전후 기억·방향·갱신 스칼라·실제 출력 계수 이동·
logit과 정답 선택 확률의 전후 변화·미관측 mask·방해 질량·solver 증거를 남긴다. 체크포인트는
출력 계수·실제 관측 기억·logit·선택 확률을 포함한다. 입력·특징·내부 가중치 불변 증거,
모든 방법·배선·표현·시드의 결과, 실제 수정 비용과 보상 발견 시점을 함께 보존한다.

독립 검산은 새 producer와 새 balanced 학습자를 import하지 않고 새 시드의 실제 순서·난수·
환경·기억·방향·출력 갱신·평가를 처음부터 재구성한다. 동결 solver의 증거도 제약과 쌍대 상한으로
별도 확인한다. 모든 배열·CSV·집계·세 가설·예산·원본 hash와 게시·실행 순서를 검사한다.
모든 동적 방향은 단위 제한과 관측 정보 제한을 지켜야 한다. 알려진 문제의 수치 안전 위반을
미관측 방해로 옮기거나 작은 방해를 임의 삭제하지 않는다.

개발 검사는 새 실제 시드·그래프 집계를 쓰지 않고 작은 합성 특징과 허구의 fixture 시드만
사용한다. NoGo 무학습, 현재 획득 보상 순서, 정보 누출 거부, 보상 기록의 별도 상태, solver
호출 조건, 단위 제한, 자기·알려진 문제의 안전, 미관측 mask와 정확한 단일 갱신 효과를 검사한다.
검사 통과 후 소스·설정·입력을 동결하고 작은 고정 예산의 실제 실행을 한 번 수행한다.

## 해석의 한계

이 실험은 네 인공 문자열에서의 출력 학습(Level 2)이다. 내부 시냅스 학습, 실제 LC11 수량
회로, 수학적 이해, 새 입력 일반화(Level 3), 인간 행동 유사성(Level 4), 공통 신경 기작
(Level 5), 교육 효과를 추가 입증하지 않는다. 이전 인간 비교 미지지와 맥락별 공동 습득·
간섭·순서·일반화의 닫힌 선행 게이트를 유지한다. 과거 Phase 5 종합도 이 새 결과로 덮어쓰지 않는다.

결과는 쉬운 한국어 보고서, 재현 안내, 기계 판독 가능한 요약과 독립 검산, 검산된 학습 곡선·
미관측 방해 그림으로 보존한다. 이 사용자 요청에서는 이 등록 한 건만 수행하며 자동 반복을
재개하지 않는다.

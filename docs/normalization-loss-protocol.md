새로 훈련하지 않는다. 같은 시행의 기록을 서로 다른 계산 단계로 나누는 분석이다. 이동 길이를

## 세 단계의 점수 회계

입력별 단위 MBON 특징 행을 D, 부모의 공유 영향 행렬을 `M=D D^T`라 한다.
행은 수정하는 source, 열은 영향을 받는 destination이다. 시행 t의 source는 i, 실제 저장된
갱신 스칼라는 g, 정규화 전 목표 영향은 b, 실제 단위 방향의 영향은 a다.
평가용 정답 부호는 `y=[+1,+1,-1,-1]`이다.

```text
g = .1 * (actual_action - stored_probability_go) * obtained_reward
B[j] = y[j] * g * M[i,j]           원래 공유 영향 참고
P[j] = y[j] * g * b[j]             정규화 전 목표 참고
A[j] = y[j] * g * a[j]             실제 저장된 영향

suppression_loss[j] = B[j] - P[j]
normalization_loss[j] = P[j] - A[j]
total_loss[j] = B[j] - A[j]
total_loss = suppression_loss + normalization_loss
```

양수 점수는 그 destination의 정답 쪽 움직임, 음수는 오답 쪽 움직임이다. `loss`가 음수면 해당
단계가 방해를 덜어 정답 쪽 점수를 더 남겼다는 뜻이다. 따라서 단계별 signed loss 전체를
무조건 나쁜 변화로 읽지 않는다.

모든 단계는 **같은 실제 저장된 g**를 쓴다. B와 P는 별도 학습 정책의 경로가 아니다. 특히 P는
일반적으로 단위 이동 길이 예산을 넘는 정규화 전 방향에 해당한다. 그 값을 이용해 행동·보상을
다시 생성하거나 이후 확률을 갱신하지 않는다. NoGo에서 g=0이면 세 단계의 실현 점수 변화도
모두 정확히 0이다.

`shared`의 b는 원래 M의 source 행이고 길이 비율은 1이다. `isolated`의 b는 자기 항만 1인
단위벡터다. 두 선택 억제 방법의 b는 원래 M에서 자기 이외의 관측상 해로운 항만 0으로 바꾼다.
`feedback_selective`는 같은 시행의 실제 Go 보상 기록을 반영한 `known_after`를 쓰며,
`oracle_selective`만 별도 전체 정답표를 쓴다. 진단 대조의 실제 관측 기록도 처음에는 모두 0이다.

정규화 전 길이를 r, 실제 정규화 비율을 s라 하면 `s=1/r`이고 `a=s*b`다. 억제할 항이 없는
공유 끝점의 정확한 비율 1을 포함하여 수치 허용 오차 안에서 검증한다. 자기 raw 영향은 1로
유지되므로 r은 1 이상이고 s는 1 이하인 것이 부모 기하의 성질이다. 이 분석에서 새 방향을
최적화하거나 다른 제약으로 바꾸지 않는다.

이 값은 **출력 선택 전 점수(logit)의 변화**다. 약화율을 정답률의 감소나 %p 손실이라고 부르지
않는다. 점수에서 확률로의 변환은 비선형이고, 실제 방향을 바꾸면 이후 확률·행동·보상도 달라질
수 있다. 이번에는 새로운 확률 기여 회계나 반사실 학습 경로를 추가하지 않는다.

## 자기 수정·도움·방해·미관측의 범주

정적 cross 부호는 `y[i]*y[j]*M[i,j]`로 판단한다. 같은 정답끼리라도 M이 음수이면 방해일 수
있고, 정답이 반대라도 M이 음수이면 도움일 수 있다. `abs(value)<=1e-8`은 수치 중립으로
분류하되 아주 작은 값의 실제 점수 질량을 0으로 버리지 않는다. 실제 Go 갱신에서는 g의 부호가
source 정답 부호와 같으므로 이 기하적 부호가 실제 정답 쪽 영향의 도움·방해와 일치한다.

| 범주 | 포함하는 destination |
|---|---|
| `self` | 현재 source 자신 |
| `cross_helpful` | 다른 문제이며 정답 정렬 공유 영향이 +1e-8보다 큼 |
| `cross_harmful` | 다른 문제이며 정답 정렬 공유 영향이 −1e-8보다 작음 |
| `cross_neutral` | 다른 문제이며 위 두 부호 문턱 사이 |
| `cross_unknown` | 다른 문제이며 해당 학습자의 `known_after`에서 아직 보상 부호가 0 |
| `cross_same` | 다른 문제이며 정답 부호가 source와 같음 |
| `cross_opposite` | 정답 부호가 source와 다름 |
| `cross_all` | 다른 세 문제 모두 |
| `all` | 자기 문제와 다른 세 문제 모두 |

`self+cross_all=all`, `cross_helpful+cross_harmful+cross_neutral=cross_all`,
`cross_same+cross_opposite=cross_all`은 각각 완전한 분할이다. `cross_unknown`은 분석용
도움·방해·중립 집단과 겹친다. 아홉 범주를 전부 더하지 않는다. 평가자가 쓰는 y를 부모의
학습자에게 전달하거나 미관측 부호를 정답처럼 채우지 않는다.

## 실제 관측 단계와 비영 갱신

세 관측 구간은 `all`, `partial`, `full`이다. `full`은 **해당 시행의 `known_after` 네 칸이
모두 비영**인 경우다. 마지막 부호를 처음 획득한 발견 시행도 full에 포함한다. partial은 그
여집합이고 all은 전체다. 정답표 진단도 별도 특권 정보가 아닌 실제 획득 관측표로 구간을 나눈다.

단계가 바뀌기 전후는 보상 경험·시행 시점·출력 상태가 함께 달라진다. 따라서 이 구간 비교는
관측 경로의 기술이지 네 부호를 알아낸 것만의 인과효과가 아니다. 정답표 진단과 feedback이
동일한 방향 규칙을 쓰게 된 뒤에도 앞서 쌓인 출력 상태와 실제 g는 서로 다를 수 있다.

방향 자체의 길이 제한은 NoGo 시행에도 계산되어 저장됐다. `scale_mean_all`은 구간의 모든
시행에서 s를 평균하며, `scale_mean_updated`는 `g!=0`인 실제 비영 출력 갱신만 평균한다.
아주 작은 비영 g를 허용 오차로 지우지 않는다. 실제 점수 질량·약화율은 g가 곱해진 값이므로
NoGo의 0 영향이 포함되어도 비영 갱신의 합과 같다. 방향 평균과 실현 점수의 가중 비율을
서로 같은 수치라고 부르지 않는다.

## 합계·남은 비율·분모

각 조건·시드·관측 구간·범주에서 B, P, A의 양수 합을 helpful, 음수 절댓값 합을 harmful,
signed 합을 net으로 저장한다. 수치 중립 항도 실제 질량 계산에는 그대로 포함한다.

```text
helpful_loss = desired_helpful - actual_helpful
harmful_reduction = desired_harmful - actual_harmful
helpful_retention = actual_helpful / desired_helpful
harmful_retention = actual_harmful / desired_harmful
```

분모가 정확히 0이면 비율은 `null`이다. 0% 보존으로 채우거나 그 시드를 숨기지 않는다.
예를 들어 전체 번짐 억제의 cross 목표는 이미 0이므로, cross 도움은 정규화 전에 제거되었다.
그 경우 정규화 단계의 도움 보존율을 0이라고 보고하지 않는다.

시드별 비율의 평균·표준편차와 모든 시드의 질량을 합친 pooled 비율을 별도로 저장한다.
평균은 유효값 수와 전체 시드 수를 함께 남기며, 한 개 유효값의 표준편차는 0, 유효값이 없으면
평균·표준편차는 null이다. 표준편차는 `ddof=1`의 계산 시드 간 기술값이고 생물학적 개체의
불확실성이나 신뢰구간이 아니다. pooled 비율은 큰 실현 점수 질량의 시드에 더 무게가 있으므로
시드별 비율의 단순 평균과 같다고 가정하지 않는다. 보고할 때 어느 분모인지 명시한다.

각 범주의 방향 평균은 그 구간의 시행들로 계산한다. 같은 시행에 destination이 몇 개 속했는지에
따라 방향 평균을 중복 가중하지 않는다. 방향 통계가 범주 행마다 반복되는 것은 의도적이다.
셀 수는 선택된 시행×destination 수, 비영 셀 수는 그중 비영 갱신에 해당하는 수다.

## 수치 자격과 산출물

부모 CSV와 배열의 source·행동·실제 보상·관측 정보, 저장된 기하·방향·스칼라를 확인한다.
재구성 잔차는 다음 고정 순서의 12종이며 조건·시드마다 최대 절대 오차를 남긴다. 모든 값은
유한하고 `1e-8` 이하여야 한다.

1. 공유 Gram과 저장된 D의 곱.
2. 실제 방향×D와 실제 영향.
3. 방법·관측 정보로 다시 정한 b와 저장된 정규화 전 목표 영향.
4. `actual_influence=scale*desired_influence`.
5. 정규화 전 길이와 비율의 역수 관계.
6. 자기 점수 변화와 부모 기록.
7. 다른 세 문제 점수 변화 L2와 부모 기록.
8. 출력 이동 길이와 부모 기록.
9. 행동·확률·획득 보상으로 계산한 g와 부모 기록.
10. 실제 방향의 단위 길이.
11. 실제 저장 갱신을 더해 재구성한 점검 시점 점수.
12. B−A와 두 단계 손실의 합.

실제 보상 관측 순서·방법별 사용 정보와 부모 파일의 무결성은 선행 독립 검산과 새 검산에서
확인한다. 구간 `all=partial+full` 및 위 범주 분할의 가산 수량·질량도 검사한다. 평균·비율은
가산 항등식에 억지로 넣지 않는다. 실패하면 결과를 보존하고 해석을 멈춘다. 수치 문턱·시드·
입력·방향·예산을 바꿔 통과시키지 않는다.

새 배열은 세 단계 margin delta와 두 단계 signed loss 5종이
`(3,2,4,10,400,4)`, scale·raw norm·full 관측 표시·비영 갱신 표시 4종이
`(3,2,4,10,400)`이다. cross 분류 1종은 `(3,2,4,10,400,4)`,
재구성 잔차 1종은 `(3,2,4,10,12)`다.

CSV는 topology→representation→method→seed→phase→category 순서의
`24×10×3×9=6,480`행이다. 부모 96,000시행의 destination 셀 384,000개, 그중 cross 셀
288,000개를 분석한다. 이는 새 학습 시행이나 새 반복 표본이 아니다. 모든 조건·시드·구간·
범주의 통계와 무정의 비율을 보존한다.

## 동결·실행·독립 검산

정확한 소스 13개와 부모 10개의 경로·SHA-256, 설정, 프로토콜, source Git commit을 별도
등록으로 고정한다. 독립 검산과 자동검사 소스도 포함한다. 개발 검사는 작은 합성 행렬·가짜
저장 경로만 사용하며 새 동결 전 실제 부모의 새 약화 집계를 계산하지 않는다.
등록을 기존 비공개 원격 main에 게시하고 로컬과 동일한 원문 bytes를 실제로 확인한 게시
증거의 시간이 분석 시작보다 앞서야 한다. 결과 경로는 배타적으로 새로 만든다.

- 설정: `configs/normalization_loss_v1.json`.
- 등록: `results/registration_normalization_loss_v1.json`.
- 원격 게시 증거: `results/normalization_loss_publication_proof.json`.
- 배열·CSV·요약·메타데이터·등록 사본·해시: `results/normalization_loss_v1`.
- 독립 검산: `results/normalization_loss_v1/verification.json`.
- 검산을 통과한 값의 그림: `results/normalization_loss_figures_v1`.

```text
python scripts/run_normalization_loss.py register --config configs/normalization_loss_v1.json --out results/registration_normalization_loss_v1.json
python scripts/run_normalization_loss.py run --config configs/normalization_loss_v1.json --registration results/registration_normalization_loss_v1.json --publication-proof results/normalization_loss_publication_proof.json --out results/normalization_loss_v1
python scripts/verify_normalization_loss.py --config configs/normalization_loss_v1.json --registration results/registration_normalization_loss_v1.json --result-dir results/normalization_loss_v1 --publication-proof results/normalization_loss_publication_proof.json --out results/normalization_loss_v1/verification.json
```

독립 검산은 새 producer를 import하지 않고 부모 배열·CSV에서 기하 부호·실제 관측·스칼라·
단계별 영향·구간·분할·12잔차·6,480행·시드 및 pooled 통계를 별도로 재계산한다. producer
요약을 옮겨 적는 검사는 독립 산술 검산이 아니다. 등록·게시·시작·완료 순서와 파일 해시도
확인한다. 자동검사는 잘못된 부호·분모·행 축, 수치 중립 질량 삭제, 구간 발견 시행 경계,
NoGo의 방향 통계와 실제 점수 차이, 겹치는 미관측 범주, 전체 억제의 무정의 비율을 확인한다.

## 해석과 다음 작업의 경계

이 분석의 대상은 네 알려진 인공 전체 문자열의 출력 학습(Level 2)이다. 고정된 내부 시냅스·
입력 반응, 학습된 출력 계수, 별도 획득 보상 부호 기억을 구분한다. 인공 이름표와 보상 기록을
실제 시각 수량 회로·LC11 입력·수학 기호 이해라고 해석하지 않는다.

같은 실제 g로 비교한 점수 약화가 크더라도 학습 실패의 유일한 원인이라는 증거는 아니다.
정답표 진단은 추가 정보가 있는 대조이며 실제 보상만으로 배운 주 방법을 대신하지 않는다.
출력 차원·시행당 이동 상한이 같아도 관측 기억·정보·추가 계산·실현 총 이동 비용이 모두
같다는 뜻이 아니다. 실제 배선 우위를 전제로 하지 않는다.

새 문자열 일반화(Level 3), 인간 행동 유사성(Level 4), 공통 신경 기작(Level 5), 교육 효과를
추가 주장하지 않는다. 새 인간 실험·자료는 없다. 부모 미지지와 기존 인간 비교의 미지지,
맥락별 공동 습득·일반화·간섭·순서의 닫힌 선행 게이트는 그대로 유지한다. 새 예산·시드·
방향·표현·학습법을 시도할 필요가 보이면 이번 분석과 분리한 새 계획으로 제안한다.

## 매 수정의 정확한 확률·점수 장부

고정 단위 특징 D, 수정 전후 출력 계수 h, 실제 스칼라 g와 저장 방향 w를 사용한다.
source는 i, 평가할 destination은 j다.

```text
actual_delta_head = g*w
logit_before[j] = D[j]@head_before
logit_increment[j] = g*(D[j]@w)
aligned_margin_delta[j] = y[j]*logit_increment[j]
correct_probability_delta[j] = q_after[j] - q_before[j]
q_before[j] = sigmoid(logit_before[j])                  y[j]=+1
q_after[j] = sigmoid(logit_before[j]+logit_increment[j]) y[j]=+1
q_before와 q_after는 위 sigmoid의 1-값                     y[j]=-1
```

sigmoid는 부모의 고정 logit clipping 규칙을 그대로 사용한다. 확률 차이를 logit 차이나
국소 미분값으로 근사하지 않는다. 자기·알려진 다른 입력·미관측 다른 입력의 세 집합은
destination 네 개를 빠짐없이 한 번씩 분할한다.

여기서 “정확한 장부”는 이 비선형 원식을 쓰는 수학적 항등식과 고정 허용 오차 `1e-8`
안의 검산을 뜻한다. 출력 계수를 더한 뒤 다시 내적하는 부모의 연산 순서와 위 canonical
증분 연산은 부동소수점의 끝자리에서 다를 수 있다. 부모의 실제 저장 변화·체크포인트와
잔차를 대조하며 bytes 동일성이나 실수 연산의 무오차를 주장하지 않는다. 극히 작은 양수·
음수 셀도 해당 canonical 계산 그대로 남기되, 반올림 규모의 방해 개수를 생물학적 피해로
해석하지 않는다. 알려진 문제의 수치 안전 판정은 부모의 `1e-8` 허용 오차와 구별한다.

```text
own = {i}
known_other = {j != i : known_before[j] != 0}
unknown_other = {j != i : known_before[j] == 0}
```

각 집합에서 양수 도움 합, 음수 방해 절댓값 합, 부호 있는 순합을 각각 보존한다. 도움과
방해를 지워 순합만 남기지 않는다. 확률 질량·정답 정렬 logit 질량을 따로 계산한다.
부호 구분은 각각 `>0, <0, ==0`이며 작은 음수 효과를 임의 epsilon으로 지우지 않는다.
알려진 다른 문제에서의 양수 영향은 이미 관측한 연습 입력 간의 도움이며 새로운 사례로의
일반화를 뜻하지 않는다.

각 집합의 확률 순합을 모두 더해 4로 나누면 해당 수정의 네 입력 평균 기대 정답 확률
변화와 일치해야 한다. 모든 시행을 더하면 마지막 평균−초기 평균과 일치한다. 두 방법의
각 집합 합계 차이도 그 방법들의 최종 기대 정답 확률 차이와 정확히 합쳐져야 한다.
이 등식은 실제 기록의 수지 검산이며 원인의 유일성이나 뇌 기작의 증명이 아니다.

## 관측 전후 구간과 발견 시점

구간은 **현재 피드백을 받기 전** 실제 `known_before`의 비영 칸 수로 나눈다.
`partial`은 4개 미만, `full`은 정확히 4개다. 마지막 부호를 새로 발견한 시행도 partial에
속한다. 앞선 `known_after` 기준 분석과 포함 시점이 다르다는 점을 밝힌다.

현재 source만 새로 기록할 수 있으므로 다른 입력의 미관측 mask는 피드백 전후 같아야 한다.
source까지 포함한 전체 미관측 개수는 실제 새로운 발견 1개당 한 칸만 줄어야 한다. 관측
횟수·발견 횟수·완전 관측까지 걸린 시행을 각각 보존한다. NoGo 0이 미관측 정답을 채우는
일은 없다. 부분·완전 관측 구간의 차이는 시간·보상 경험·출력 상태도 달라지는 기술 비교이며
정보 획득만의 인과효과가 아니다.
첫 완전 관측 시행은 `known_after` 네 칸이 처음 모두 채워진 1기반 시행 번호로 남긴다.
끝까지 채워지지 않으면 sentinel 401(400+1)이며 실제 401번째 시행으로 세지 않는다.

## 다른 실제 경로의 수정 요소를 한 번만 교차 대입하기

선택 억제 S와 균형 B는 같은 시드·배선·표현·시행에서 source가 같다. 그러나 자신의 과거
행동 때문에 `head_before`, g, w와 실제 보상 기억은 서로 다르다. 저장된 두 경로의 요소를
한 번 교차 대입해 그 시행의 직접 확률 변화가 어떻게 달라지는지 계산할 수 있다.

이 계산은 이후의 선택·보상·기억을 갱신하지 않는다. 서로 다른 실제 경로에서 가져온 방향을
대입한 뒤 그 합을 새로운 학습 성적이라고 부르지 않는다. 교차 방향의 알려진 문제 안전
보장은 원래 그 방향을 선택한 학습자의 실제 관측 상태에만 해당한다. 상대 학습자의 기억
집합까지 안전하다고 가정하지 않는다.

교차 계산은 **두 방법 모두 실제 Go를 선택한 시행에만** 수행한다. 이때 현재 source의 보상
부호를 둘 다 실제 관측했으며 두 방향이 실제로 저장되어 있다. 두 수정 전 상태 모두에서
다음 네 조합을 사용한다.

```text
(gS,wS), (gS,wB), (gB,wS), (gB,wB)
```

따라서 상태 2개×스칼라 2개×방향 2개의 **8개 계산 셀**이다. 순서는 bit4=상태,
bit2=스칼라, bit1=방향이며 0은 S, 1은 B다. 각 셀은 같은 상태 h에서
`q(h+g*w)-q(h)`를 정확히 계산한다. 실제 S의 셀 000과 B의 셀 111은 각각 자기 실제
확률 변화와 일치해야 한다. 상태·스칼라·방향은 사후 장부의 요소이며 독립적인 무작위
개입 변수가 아니다.

세 요소의 교차 순서를 임의로 하나만 고르지 않고, 가능한 순서 모두에서 각 요소를 바꿀 때의
차이를 평균하는 **Shapley 장부 배분**을 사용한다. 요소 집합을 `K={state,scalar,direction}`,
어떤 요소 r을 바꿀 때 이미 B로 바꾼 다른 요소 집합을 T라 하면 목적지별 배분은 다음과 같다.

```text
phi[r] = sum_{T subset K\\{r}} |T|!*(2-|T|)!/3! * (f[T union {r}] - f[T])
phi[state]+phi[scalar]+phi[direction] = f[111]-f[000]
```

T가 빈 집합·원소 1개·원소 2개일 때 가중치는 각각 1/3·1/6·1/3이다. 이 배분은 선택한
단일 수정 함수의 차이를 정확히 나누는 수학적 규약이다. 독립적으로 확인된 원인 효과나
다른 배분법보다 유일하게 옳은 원인 비율이 아니다. 정답 선택 확률 변화와 그 음수 부분의
절댓값(방해)에 대해 각각 배분한다. 방해 배분은 음수일 수도 있으며, 요소를 바꾸자 방해가
줄어든 몫이라는 뜻이다.

NoGo에는 현재 source의 숨은 Go 부호를 추론해 균형 방향을 새로 구하지 않는다. 부모에
저장된 균형 NoGo 방향은 0이며 실제 g도 0이다. 한쪽만 Go·둘 다 NoGo인 시행에서는 교차
계산을 생략하고 0패딩·비대상 mask를 남긴다. 그 시행의 **실제 성과 차이**는 삭제하지 않고
행동 경우별 별도 나머지로 보존한다. 두 방법 모두 Go인 배분과 이 나머지를 합하면 전체
실제 성과 차이가 복원되어야 한다. 생략한 시행의 0패딩을 실제 계산 결과처럼 세지 않는다.

미관측 방해의 교차 비교에는 **두 실제 경로에서 동시에 미관측인 다른 목적지의 교집합**을
고정한다. 각 셀마다 새 관측 mask를 만들지 않는다. 둘 다 미관측·S에서만 미관측·B에서만
미관측·어느 쪽도 아닌 네 경우를 모두 남긴다. 교집합의 양쪽 실제 방해 차이와 B에만 있는
미관측 방해, S에만 있는 미관측 방해의 음수를 합하면 두 전체 방해 차이가 되어야 한다.
교집합 중 두 방법 모두 Go인 부분만 Shapley로 나누고 나머지를 정확한 장부 항으로 보존한다.
이 규칙으로 서로 다른 관측 집합의 효과를 방향 차이 하나로 잘못 돌리지 않는다.

## 균형 목적과 마지막 성적이 다른 이유를 읽는 범위

균형 방법은 같은 길이에서 자기 정답 정렬 logit과 **이미 알려진 기존 도움 평균**을
각각 .5로 두고 그 합을 최대화했다. 마지막 보고 점수는 네 입력의 정답 **선택 확률** 평균이다.
모르는 문제의 손실은 그 목적에 직접 포함되지 않았고, sigmoid의 같은 logit 변화가 만드는
확률 변화는 수정 직전 상태에 따라 달라진다. 방향을 바꾸면 이후 확률·실제 행동·보상·g도
달라질 수 있다. 이 목적 차이와 실제 장부를 함께 설명한다.

서로 다른 기록의 wS와 wB는 실제 관측 집합도 다를 수 있다. 같은 제약·같은 목적 안에서의
최적성 증거를 서로 다른 두 경로에 바로 적용하지 않는다. 균형 방식이 매번 자기 수정과
알려진 도움을 모두 더 남긴다거나, 기록의 차이 하나가 실패의 유일한 원인이라는 주장을
추가하지 않는다. 새로운 목적 가중치·보상 탐색·학습 예산의 실험은 별도 등록이 필요하다.

이를 구분하기 위한 별도 비교는 **두 방법 모두 현재 피드백 전 네 부호를 관측했고, 둘 다
실제 Go인 시행에만** 한다. 이때 같은 특징·전체 관측 부호·source로 H와 c를 구성하므로 두
방향을 같은 제약과 목적에 놓을 수 있다. 두 방향의 `c@w`, 자기 영향, 기존 도움 평균을
비교한다. 균형 목적값이 선택 억제보다 허용 오차를 넘게 작으면 무결성 실패다. 한편 같은
S의 수정 전 상태와 gS에서 wS를 wB로 바꾼 정확한 네 입력 평균 확률 변화 차이
`mean(f[001]-f[000])`는 음수일 수도 있다. 목적값 최적과 실제 확률 합계가 같은 대상이
아님을 이 별도 비교로 읽는다. 부분 관측에는 이 최적성 비교를 확장하지 않는다.

## 단위·집계·검산·산출물

주 설명은 real/raw의 균형−선택 억제 실제 경로 차이다. 나머지 5개 배선·표현과 공유·전체
억제 대조도 전부 보존한다. 조건·시드·구간·집합별 합계와 노출 수를 남긴다. 작은
분모를 가진 시드를 버리지 않는다. 분모 0의 기술적 비율은 null이며 0으로 바꾸지 않는다.
시드 평균·표준편차와 질량을 합친 비율은 구별한다. 계산 시드 10개는 동물이나 인간 10명이 아니다.

등록 `results/registration_balanced_pathways_v1.json`, 게시 증거
`results/balanced_pathways_publication_proof.json`, 설정 `configs/balanced_pathways_v1.json`,
결과 `results/balanced_pathways_v1`, 검산 `results/balanced_pathways_v1/verification.json`을
새 경로로 만든다. 기존 부모의 독립 검산·hash·선행 게이트를 재사용하되 부모 학습을 다시
실행하지 않는다. 새 등록의 source·parent 파일, 게시 원문 bytes와 게시→집계 시간 순서를 확인한다.

실제 확률·logit 변화, 세 집합·관측 전 구간, 첫 완전 관측 시행, 두 경로의 행동 경우·미관측
집합 관계, 비대상 0패딩을 포함한 8셀·세 요소 배분, 완전 관측 목적 비교를 **19개 배열**로
보존한다. 실제 bridge 대상 수는 저장 기록에서 결정하며 새로운 시행 수가 아니다. 교차
계산 목적지 셀 수는 `대상 시행 수×8×4`다. 요약 CSV는 배선→표현→방법→시드→관측
구간(partial/full)→집합(own/known_other/unknown_other)의 **1,440행**이다. 구간 시행 수는
집합별로 반복되지만 노출 수는 그 집합의 목적지 수이므로 합산 방법을 구별한다.

새 독립 검산은 producer를 import하지 않고 저장 방향·스칼라·출력 상태·관측 기록으로
장부를 다시 계산한다. 실제 단계의 점수·확률 차이, 집합의 빠짐없는 분할, 구간·집합별
합계, 최종 성적 telescoping 등식과 두 경로 차이, 교차 계산의 실제 셀 일치, NoGo 0방향의
의미, 입력·출력 해시·부모 보존을 검사한다. 허용 수치 잔차는 `1e-8`로 고정한다. 실패하면
그대로 보존하고 해석을 중단하며 다른 seed·예산·분모·집계 범위로 바꾸지 않는다.

결과는 쉬운 한국어 보고서·재현 안내·원자료와 기계 판독 요약·검산·검산된 그림으로 남긴다.
이 작업은 고정 내부 가중치와 활성, 부모의 실제 출력 학습(Level 2), 별도 보상 기록에 대한
기술 분석이다. 실제 초파리 시각 수량 인지·내부 시냅스 가소성·새 입력 일반화(Level 3)·
인간 행동 유사성(Level 4)·공통 신경 기작(Level 5)·교육 효과를 추가 입증하지 않는다.
이전 인간 비교 미지지·닫힌 습득 및 후속 게이트·Phase 5 첫 종합을 유지한다.

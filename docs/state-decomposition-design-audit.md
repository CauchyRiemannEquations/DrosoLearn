## 분석 범위와 재사용 자료

전체 10시드, 네 모델 `linear/real/rewired/ann`, 네 분기 `full/head_only/internal_only/frozen`, 반전 중 0·100·200·300·400 checkpoint, IID/OOD 각각128개 사례를 모두 포함한다. 기준 습득·반전 성공 여부나 이후 항의 부호를 보고 시드·분기를 제외하지 않는다. 새로운 학습·행동 표본·보상 표본·데이터 split·난수 경로는 만들지 않는다.

각 시드·모델의 공통 앞부분 마지막 snapshot을 기준으로 삼는다. 현재 snapshot은 같은 모델·시드·분기의 각 반전 checkpoint다. 저장된 `stimuli.npz`의 원 IID/OOD 배열을 양쪽 상태에 동일하게 넣는다. 공통 앞부분에서 사용한 TRAIN 활성이나 큰 수량을 기준으로 한 과거 점수를 기준값에 섞지 않는다. **모든 정적 조합은 동일한 작은 수량 선택 기준으로 평가한다.**

재사용의 중심은 저장된 상태와 이미 동결된 입력이다. 기존 분석에서 확인한 encoder·bias·pre/post·원 incoming normalizer·특징 척도·최초 가중치와 상한을 그대로 사용한다. 신규 분석 코드가 원래 학습자 구성이나 update를 호출할 필요는 없다. 원 상태나 원 계산 시드를 새 학습으로 재실행하지 않는다.

| 재사용 대상 | 이번 역할 | 피할 변경 |
|---|---|---|
| 부모 등록·summary·verification·artifact inventory | 완료·출처·정확 바이트 확인 | 과거 판정·해시·미달 수정 |
| 공통 학습 끝의 `readout_weights/internal_weights` | 기준 출력 h0와 기준 내부 W0 | 미학습 출력0 또는 `initial_internal_weights`로 대체 |
| 각 분기 checkpoint의 head·내부 가중치 | 현재 출력 ht와 현재 내부 Wt | 새 학습·재정규화·새 clipping 상한 |
| 저장된 encoder·bias·pre/post·scale | 동일 forward 계산 | 활성 KC/MBON만 추려 차원·순서 변경 |
| 원 IID/OOD counts·nuisance | 같은 사례에 대한 네 조합 평가 | 새 사례·새 수량 일반화로 해석 |

W0는 **공통 학습을 마친 실제 내부 가중치**다. anatomical 초기 가중치나 원 clipping 상한을 뜻하지 않는다. h0도 공통 학습을 마친 출력 계수이며 미학습 초기값0이 아니다. 기준과 현재의 나머지 고정 파라미터가 같은지를 먼저 확인해야 두 변화만의 식을 적용할 수 있다.

## 원점수의 정확한 대수식

각 후보의 정규화된 특징을 phi라 하고 `psi=phi_right−phi_left`라 쓴다. 모델의 오른쪽 선택 원점수는 `g=h·psi`다. 네 조합은 다음과 같다.

원점수는 모델이 선택 확률로 바꾸기 전 계산하는 중간 점수다. 같은 점수 증가도 처음부터 거의 확신하던 경우와 반반이던 경우에 선택 확률을 다르게 바꿀 수 있다.

| 코드 | 출력 | 내부 특징 | 원점수 |
|---|---|---|---|
| 00 | 공통 h0 | 공통 W0에서 계산한 psi0 | `g00=h0·psi0` |
| 10 | 현재 ht | 공통 W0에서 계산한 psi0 | `g10=ht·psi0` |
| 01 | 공통 h0 | 현재 Wt에서 계산한 psit | `g01=h0·psit` |
| 11 | 현재 ht | 현재 Wt에서 계산한 psit | `g11=ht·psit` |

`dh=ht−h0`, `dpsi=psit−psi0`로 두면 다음은 원점수 계산의 항등식이다.

```text
g11 − g00 = dh·psi0 + h0·dpsi + dh·dpsi
             출력 항    내부 항     교차 항
```

앞 두 항은 다른 부분을 공통 상태에 둔 정적 변화이고, 마지막은 두 변화의 곱에서 생기는 항이다. 음수 항은 이 사례의 기준 점수를 낮추는 수치이며 억제성 뉴런·망각·생물학적 손상을 뜻하지 않는다. 양수 항도 학습 성공이나 생물학적 협력을 뜻하지 않는다.

중요한 함정은 화면 좌우다. 입력은 작은 수량이 왼쪽과 오른쪽에 균형 있게 나타나므로 오른쪽−왼쪽 원점수를 그대로 평균내면 효과가 상쇄될 수 있다. 작은 수량의 정답 방향이 오른쪽이면 `target_sign=+1`, 왼쪽이면 `−1`로 정한다. **기준·현재의 네 원점수와 세 항, 총 원점수 변화에 모두 같은 sign을 곱한다.** 원 좌우 좌표의 값과 목표 방향으로 정렬한 값을 함께 보존하고, 그림·기술 평균은 작은 수량 방향으로 정렬한 값을 사용한다.

정렬 뒤에도 항등식은 성립한다. 사례별 잔차를 모두 확인하며 양수·음수 잔차가 평균에서 우연히 상쇄된 것으로 통과시키지 않는다. 기준과 현재가 같은 반전 trial0, frozen, 선형 내부0, 출력만/내부만 분기의 구조적 영항도 별도 검산한다.

## 확률은 원점수와 다른 양이다

원 구현의 오른쪽 선택 확률은 `sigmoid(clip(g,−40,40))`다. 작은 수량이 오른쪽이면 그 확률을, 왼쪽이면 `1−p_right`를 `p_rule`로 사용한다. 네 조합의 p_right와 p_rule를 따로 보존한다. clipping 여부는 `abs(g)>40`이며 정확히±40인 원점수는 clipping으로 바뀐 값이 아니다.

00과11의 재계산 확률은 부모 snapshot에 저장된 사례별 p_right와 절대 오차 `1e−12` 이내로 같아야 한다. 원점수 항등식의 `1e−10` 기준과 이 확률 일치 기준은 별개다.

확률에서도 `P11−P10−P01+P00`라는 네 값의 교차 차이를 계산할 수 있다. 그러나 이 값은 sigmoid와 clipping을 지난 뒤의 비선형 차이다. **원점수의 `dh·dpsi`와 같은 양이 아니다.** 원점수 교차 항이0이어도 sigmoid 때문에 확률 교차 차이가0이 아닐 수 있다. 반대로 포화 때문에 큰 원점수 변화가 작은 확률 변화로 보일 수 있다.

세 원점수 항의 단위는 계산 점수 차이이고, 확률 차이의 단위는 확률 또는 %포인트다. 둘을 합치거나 어느 항의 값을 전체 확률 향상의 기여율로 나누어 보고하지 않는다. 확률의 finite difference 항등식과 원점수의 bilinear 항등식을 별도 이름·열·잔차로 다룬다.

## 실제 학습 분기와 정적 조합을 혼동하지 않기

full 분기의 `10`은 **full에서 학습된 ht**를 공통 W0와 결합한 값이다. 실제 `head_only` 분기가 독자적인 선택·보상 경험으로 학습한 최종 head와 같다고 가정할 수 없다. `01`도 실제 `internal_only` 분기의 학습 결과가 아니다. 원 네 분기와 정적 네 조합을 같은 축 이름으로 붙이면 안 된다.

각 현재 분기의11과 공통 기준00은 저장된 실제 상태를 가리키지만, 10·01은 그 분기에서 지나오지 않은 상태 조합일 수 있다. 이 조합은 forward 함수 안에서 정의한 계산값이다. 이미 완료된 학습 경로를 보고 그 결과를 나누어 표현하는 것이며, 시간에 따른 학습의 인과 효과를 세 항에 배분한 것이 아니다. 이전 ablation 연구의 갱신 허용 개입과 이번 정적 재조합의 질문을 구분한다.

선형 모델에는 내부 연결이 없어 psi0와 psit가 같다. 따라서 내부·교차 원점수 항은0이며00=01,10=11이다. head가 고정된 분기는 출력·교차 항이0, 내부가 고정된 분기는 내부·교차 항이0이어야 한다. frozen에서는 모든 변화 항이0이어야 한다. 이는 구현·자료 일관성 대조이며 새 학습의 성공 기준이 아니다.

## 반증·무결성·그림

사례별 산술 잔차 허용 오차 `1e−10`은 고정된 계산 검산 기준이다. 학습 능력·성공·생물학적 유사성의 threshold가 아니다. 전체 평균이 커지거나 가설에 유리한 부호가 많이 나온 것을 새 주 가설 통과로 사용하지 않는다. 새로운 행동 가설·집단 검정·유의성 검정은0개다.

원 source·부모·선택 입력 NPZ 해시가 바뀌거나, 기준/현재의 고정 파라미터가 달라지거나, 전체 시드·모델·분기·사례가 빠지거나, 원점수/확률/영항의 독립 재계산이 허용 오차를 넘으면 무결성 실패로 남긴다. 잔차 기준이나 사례 범위를 사후 변경하지 않는다. 실제 학습의 습득·반전 실패도 원 source에서 지우지 않는다.

그림은 미리 정한 **full 분기·마지막 checkpoint·IID·전체 시드**만 사용한다. 다른 분기·시간·OOD를 보고 유리한 패널로 교체하지 않는다. 첫 PNG는 모델별 목표 방향 원점수의 출력·내부·교차 항과 총변화를, 둘째는 공통/현재 출력×공통/현재 내부의 네 정적 선택 확률을 보여 준다. 각 시드의 사례 평균을 점으로 보존하고 전체 시드 평균을 함께 표시한다. 그림은 학습 기여율·인과 경로·종간 비교를 나타내지 않는다.

새 그림은 독립 `passed`와 exact 입력 hash를 확인한 뒤 별도 sibling 폴더에 배타 저장한다. 검산 보고서는 summary·registration·config·primary artifact inventory 바이트를 가리키고, inventory는 그림에 쓰는 CSV와 원 metadata 등을 포함해야 한다. plotting source의 사전 동결 hash, 입력 hash, 두 PNG hash와 UTC를 별도 metadata로 남긴다. 기존 결과 폴더와 문서·코드를 다시 쓰지 않는다.

동일 source checkout에서 독립 검산이 완료된 뒤 다음처럼 그림만 재현한다. 결과와 그림 폴더는 같은 부모 아래에 두며 새 출력 폴더가 아직 존재하지 않아야 한다.

## 해석 범위와 종료

이 작업은 완료된 결과를 본 뒤 설계한 후속 기술 분석이다. 새로운 눈가림 확증 연구나 생물학적 가소성 실험이 아니다. 실제 점 그림의 수량 추출, 새 수량·새 규칙으로의 일반화, LC11/DAN 생리 회로, 사람과 초파리의 공통 신경 기작을 검사하지 않는다. 계산 시드는 독립 동물·사람이 아니며 Level4/5 또는 교육 효과를 주장하지 않는다.

# 조개 비교의 자율 선택 난수 주소 수정: 별도 실행 전 계획

작성일: 2026-10-19 (Asia/Seoul). 기존 `human_shell_v1`의 소스·설정·등록·완료 산출물을 수정하지 않는다. 이번 연구 ID는 `human_shell_rng_v2`이며 원 실패를 보존한 계산 설계 수정이다. 새 소스·설정·원본 결과 해시·프로토콜을 별도로 동결하고 등록을 원격 확인한 뒤 새 자율 실행을 한 번 수행한다.

## 왜 별도 수정이 필요한가

기존 자율 선택의 난수 주소는 `seed + 300000 + int(participant_id[1:])`였다. 서로 다른 seed·참가자 조합이 같은 합이 되는 대각선 충돌이 있었다. 5 seed × 29명 = 145개의 조합이 88개의 주소만 사용해 서로 독립적으로 지정하려던 행동 난수가 일부 공유됐다. 이 사실은 결과의 유불리를 보고 찾은 것이 아니라 실행 소스와 고정 설정만의 조합 검산에서 발견됐다. 발견 시점과 원래 진술은 [설계 문제 기록](../results/human_shell_rng_design_issue_v1.json)에 남긴다.

쉽게 말하면 서로 다른 시험에 사용할 추첨표를 일부 겹쳐 나눠 준 문제다. 원래 계산값을 지우거나 좋은 추첨을 골라 교체하지 않는다. 원본 전체를 보존하고, 추첨표를 나누는 주소만 바로잡아 별도 시험으로 기록한다. 기존 자율 결과의 교차 재표집 구간을 독립성이 확인된 최종 구간처럼 사용하지 않는다.

## 바꾸는 것과 고정하는 것

바꾸는 것은 자율 행동 난수 생성기의 주소 하나다.

```python
np.random.default_rng(
    np.random.SeedSequence([20261019, seed, int(participant_id[1:])])
).random(trials_per_person)
```

주소를 각 요소를 가진 튜플로 구분해 145개 seed·참가자 주소가 모두 다른지 **난수 추출 없이** 먼저 검증한다. 같은 seed·사람 안에서는 조건 간 같은 균등 난수를 공유하는 원 설계를 유지한다. 서로 다른 조건을 독립 표본으로 세지 않는다. 초기 배선·encoder 난수 주소와 가중치 초기값은 원본 그대로다. 일반적인 유사 난수열의 수학적 독립성까지 증명하는 연구는 아니다.

원래 calibration 20명·29명 test 분할, 세 후보 학습률·선택된 학습률, calibration 결과, 다섯 모델 초기화 seed, 원 조개 trace, 잠재 내용의 관측 마스크, 11조건, 처음/마지막 3회 창, ±.10 동등성 폭, 예측 개선 기준과 gain 기준, bootstrap 2,000회와 seed 14001은 모두 고정한다. 새 참가자 선택·학습률 재선정·가중치 warm-start·시행 연장·새로운 성공 기준을 허용하지 않는다.

## 새 실행과 원본 재사용

새로 실행하는 부분은 **자율 선택 344,520회**뿐이다: 11조건 × 5 seed × 29명 × 216시행. 원본 학습률 fit이나 사람의 과거를 사용한 조건부 예측을 다시 실행하지 않는다. 각 자율 궤적은 원래와 같은 초기 모델에서 시작한다. 모델이 Go한 때만 원 trace의 잠재 내용에 따른 +1/0/−1 보상을 받고, NoGo의 보상은 0이며 내용은 숨겨진다.

원본 `trajectories.npz` 각 배열의 conditional 축 `[0]`, conditional CSV 행, `conditional_*` witness 배열은 원래 값·dtype·원소 순서·바이트를 그대로 보존해 재사용한다. 원본 calibration 파일·선택 결과·등록·요약의 해시는 부모 증거로 동결한다. 새 결과 파일 컨테이너의 ZIP 압축 바이트가 원본 컨테이너와 같다는 뜻은 아니다. 재사용하는 배열 원소 바이트와 CSV 행의 원문 바이트를 확인한다. 원 파일 자체는 수정하지 않는다.

새 `produce_corrected` 함수는 원 API를 이용하는 명시적인 자율 실행 루프다. 원 함수를 동적으로 변형하거나 전역 난수기를 monkeypatch하지 않는다. 원 함수·규칙·측정 소스도 부모 버전과 함께 동결한다. 반환 스키마는 원본과 같은 두 경로 결합 배열·행·witness지만 conditional 경로는 다시 계산하지 않는다. 상세 witness는 원래와 동일하게 동결된 첫 test 참가자 A0021에 한한다.

## 검증과 보고

합성 자료의 두 seed·두 사람 교차 예에서 원 conditional 배열·행·witness·선택 설정이 불변인지, 새 자율 경로의 시행 수가 정확한지, 합 기반으로 충돌하던 서로 다른 조합이 새 주소에서는 다른지 확인한다. 실제 과학 seed의 사전 난수 추출은 하지 않는다. 자동검사에서는 짧은 합성 기록과 별도 seed를 사용한다.

원본에서 동결된 `summarize` 함수를 재사용해 새 자율 결과와 그대로 보존한 conditional 결과를 함께 요약한다. H_prediction과 conditional NLL/Brier는 원본과 정확히 같아야 한다. H_similarity·자율 gain qualification과 그림은 새 자율 결과에 따라 판정하며 원 결과를 덮어쓰지 않는다. 새 시도가 유사성을 지지하지 않아도 추가 seed나 재실행으로 결과를 바꾸지 않는다.

독립 검산은 새 원시 동결 파일에서 각 자율 궤적을 직접 다시 계산하고, 새 주소 145개와 모든 저장 선택·보상·업데이트·지표를 확인한다. 원 conditional/calibration 재사용과 H_prediction 불변도 별도로 확인한다. 원본 검산 결과와 새 수정 검산을 둘 다 보존한다. 새 동등성 결과는 이 조개 과제·등록한 세 행동 측정의 제한적 비교이며, 실제 초파리 학습·공통 신경 기작·수량 또는 수학 이해·교육 효과의 증거로 확대하지 않는다.

## 네 입력과 보상

| 정체성 | 문자열 | 목표 행동 | Go를 실제로 선택했을 때 보상 |
|---|---|---|---:|
| 0 | ABAB | Go | +1 |
| 1 | BABA | Go | +1 |
| 2 | ABBA | NoGo | -1 |
| 3 | BAAB | NoGo | -1 |

A=0, B=1이다. 모든 조건에서 NoGo의 획득 보상은 0이다.
NoGo를 선택했을 때 숨은 Go 보상이나 목표 종류를 학습자에게 주지 않는다.
학습자는 현재 입력·자신의 선택·획득 보상만 받으며, 분석용 목표 라벨은 환경과 평가에만 사용한다.

원 입력은 앞선 연구처럼 `[s0/3,s1/3,s2/3,s3/3,0,0,4/6]`의 7차원 벡터다.
이름표 입력은 **문자열의 사전식 순서**로 정한 네 정체성에 앞 네 좌표 중 서로 다른 한 좌표만
`sqrt(2)/3`을 주는 one-hot 벡터다. 마지막 길이 좌표는 원 표현과 같은 `2/3`이고 나머지는 0이다.
두 표현 모두 7차원이며 각 입력의 L2 길이는 `sqrt(2/3)`으로 같다.
원 문제 순서의 사전식 정체성 번호는 `[0,3,1,2]`다. 사전식 순서는 정답 종류를 사용하지 않는다.
전체 문자열을 인공적으로 제공하는 과제이며, 실제 시각 인식이나 순차 기억 학습이 아니다.

이전 입력 파일 `data/synthetic/pattern_rule_v1/input_catalog.json`은 원문 그대로 동결한다.
새 진단의 유한 입력 파일은 `data/synthetic/representation_update_v1/input_catalog.json`이다.
새 입력 파일에는 네 문제의 원 표현·정체성 표현·명세가 들어가며, 준비 과정에 신경망 성적이나
행동 RNG를 사용하지 않는다. 해시를 등록하고 런타임에서 누락 파일을 대신 만들지 않는다.
부모 파일에 남아 있는 미학습 문자열은 이번 성능 평가나 정규화에 사용하지 않는다.

## 사전에 아는 원 입력의 기하와 새로 검사할 내용

네 원 입력은 서로 다르지만 다음 관계를 만족한다.

`x_ABAB + x_BABA = x_ABBA + x_BAAB`

양의 종류 두 점과 음의 종류 두 점의 중간 지점이 같다. 따라서 원 입력에 선형·아핀 점수 하나만
붙여 네 문제를 모두 엄격하게 나누는 것은 불가능하다. 이것은 **입력 정체성의 소실이 아니라
선형 판독의 제약**이다. 고정 비선형 KC→MBON 변환 이후의 특징이 분류 가능한지는 별도 문제다.

원 벡터를 3배 하면 모든 좌표가 정수다. 정수 행 관계의 잔차 0, 3×3 소행렬의 행렬식 -1,
두 독립 차이 벡터의 2×2 소행렬식 1을 보존해 원 행렬 rank=3·아핀 차원=2를 확인한다.
가중치 `[1,-1,0,2,0,0,0]`는 3배 입력에서 점수 `[1,1,-1,3]`을 만들어 3/4를 맞춘다.
중간 지점의 공통성으로 4/4는 불가능하므로 원 선형 점수의 엄격한 판단 상한은 3/4다.
이 순수 대수 사실을 새 학습 실험의 발견이나 신경망 전체의 불가능성으로 부르지 않는다.

## 조건: 배선 3 × 표현 2 × 갱신 2

배선 T는 `real`, `rewired`, `ann`의 세 가지다. 원본은 고정된 FlyWire v783 왼쪽 MB 부분
투영의 512 KC·48 MBON·1,474 연결이다. `rewired`와 `ann`은 동결된 `build_graphs`의
대조 생성 규칙을 사용한다. 재배선은 차수 등 명시된 불변량을 보존하고, ANN은 기존 희소 무작위
대조다. 배선 간 모든 해부학적 특성이 같다고 주장하지 않는다.

표현 R은 `raw`, `identity`, 갱신 U는 `shared`, `projected`다. 총 12조건이다.
일차 비교는 **real/raw에서 projected−shared**다. real에서 identity/shared−raw/shared는
사전 지정한 표현 비교다. 다른 배선과 상호작용은 기술적 대조이며, 유리한 대조를 일차 조건으로
바꾸지 않는다. 실제 배선의 우수성을 전제하지 않는다.

모든 조건의 encoder·bias·KC→MBON 연결과 내부 가중치는 고정한다.
출력 계수는 48개이며 모두 0에서 시작한다. encoder는 model seed+100000,
재배선은 seed+110000, ANN은 seed+120000의 동결된 생성 규칙을 쓴다.
같은 seed에서는 표현·갱신 조건이 같은 초기 encoder를 사용한다.
내부 가소성, Q 값 학습, 자연적인 시간 망각은 이번 실험에 없다.

## 특징 정규화와 두 갱신의 정의

각 고정 신경망에 NoGo 영벡터와 Go 입력을 넣어 초기 MBON 차이 벡터를 구한다.
각 문제의 차이 벡터를 **그 벡터 자신의 L2 길이**로 나눠 단위 행벡터 d_i를 만든다.
이 네 행을 D라 한다. 이 과정은 네 훈련 입력만 사용하며 정답 종류·학습 성적을 사용하지 않는다.
원 차이 벡터의 길이도 남긴다. 전역 평균 크기만 맞췄던 기존 패턴 연구와 다른 새 진단이다.

출력 계수 h에서 Go 확률은 `logistic(d_i·h)`다. 확률 계산의 점수 clipping은 ±40이다.
학습률 eta=.1이며, 보상은 실제 획득한 r이다.

- shared: `delta_h = eta × (action−p) × r × d_i`
- projected: `delta_h = eta × (action−p) × r × u_i`

projected의 방향은 다음과 같이 성적을 보기 전에 정한 SVD 규칙으로 계산한다.

`C = pinv(D, rcond=1e−12)`

`P = D C`

`u_i = C[:,i] / P[i,i]`

SVD는 특이값이 `최대 특이값 × 1e−12`보다 엄격하게 큰 방향만 유지한다.
이는 rank가 부족할 때 성적을 보고 추가하는 대체법이 아니다.
모든 조건에 처음부터 같은 고정 절단 규칙을 적용한다.

같은 p·행동·보상에서 자기 문제의 원 점수 수정은 두 갱신 모두 `eta × (action−p) × r`다.
다른 문제의 반응은 다를 수 있다. 전체 점수 영향 행렬은 **행=고친 문제, 열=검사한 문제**로
shared는 `D Dᵀ`, projected는 `U Dᵀ`다. 실제 한 번의 갱신 영향에는 공통 계수
`eta × (action−p) × r`를 곱한다. 초기 Go·보상 ±1의 정적 영향도 함께 보존한다.

projected는 **유지한 SVD 반응 부분공간 안에서** 자기 점수 영향을 1로 맞추면서 다른 입력에
미치는 제곱 영향의 합을 최소화한다. v_i=1인 반응 벡터 v에 대해
`||v||² ≥ 1/P[i,i]`이고, `v=P[:,i]/P[i,i]`가 이 하한을 달성한다.
제외한 아주 작은 특이 방향까지 다시 허용한 전체 공간의 최소성은 주장하지 않는다.

rank가 네 개보다 작으면 다른 입력으로 번지는 영향이 남을 수 있다.
그러므로 이름은 projected이며, 모든 경우를 정확한 분리라고 부르지 않는다.
rank가 충분한 두 표현에서는 같은 입력 순서·행동 uniform에 대해 projected 행동 경로가
허용 오차 안에서 같아야 한다. 이것은 구성상 예상되는 수치 성질이며 독립적인 생물학적 발견이 아니다.

## 수치 조건과 분리 해석의 자격

행동 추출 전에 모든 seed·배선·표현의 기하를 계산한다.
각 원 특징 길이가 유한한 양수이고 P의 대각선도 유한한 양수여야 한다.
공유·투영의 자기 점수 영향 차이 최대값은 ≤1e−8이어야 한다.
이 필수 수치 조건이 깨지면 과학 행동 시행을 시작하지 않고 무결성/수치 실패를 보존한다.

**정확한 분리라는 강한 해석**은 유지 rank=4, D의 전체 행 조건수 ≤1e6,
자기 영향 잔차와 비대각 영향 최대값 ≤1e−8일 때만 자격이 있다.
이 자격이 닫혀도 필수 수치 조건을 통과한 사전 지정 projected 경로는 실행하며,
남은 영향과 닫힌 자격을 그대로 보고한다. 사후 cutoff 변경·정칙화·다른 seed로 교체하지 않는다.

엄격한 부동소수점 rank 기준 `max(shape) × float64 epsilon × 최대 특이값`과 유지 rank를
구분해 기록한다. 특이값·행 길이·조건수·P·방향·영향·잔여 간섭을 함께 남긴다.
rank가 낮다는 사실만으로 특정 라벨의 선형 분리가 불가능하다고 단정하지 않는다.
정의되지 않는 조건수는 보고서의 null과 명시적 정의 여부로 남기며 무한대를 유한 측정값처럼 저장하지 않는다.

## 선형 판독 가능성의 분석 대조

원 입력 및 신경 특징에서 라벨 y=[1,1,-1,-1]에 대해 `y_i × d_i·h ≥1`을 만족하는
출력 해가 있는지 분석한다. 네 제약 중 비어 있지 않은 15개 활성 집합을 모두 조사한다.
각 집합의 최소 L2 등식 해를 같은 고정 SVD cutoff로 계산하고, 활성 등식 잔차 ≤1e−8과
모든 부호 있는 점수 ≥1−1e−8을 요구한다. 가능한 후보 중 L2가 가장 작은 것을 보존한다.

이는 정답 라벨을 받은 **분석용 용량 진단**이며 보상으로 학습한 출력이 아니다.
후보·잔차·margin·선택 집합·L2를 보존한다. 수치 탐색에서 가능한 후보가 없다는 것은
`고정 cutoff와 허용 오차 아래에서 후보를 찾지 못함`이며, 순수 수학적 불가능의 증명이 아니다.
라벨은 이 분석에만 사용하며 입력·정규화·갱신 방향 계산으로 역류하지 않는다.

## 고정 예산·난수·기록

새 계산 seed는 **17101..17110**의 10개다. seed마다 네 문제를 한 번씩 섞은 100 block,
총 **400회** 선택·피드백을 모든 조건에 제공한다. 난수 주소는
`SeedSequence([202610193,seed,0])`가 순서, `[202610193,seed,1]`가 행동 uniform이다.
seed를 더해 주소를 만들지 않는다. 모든 12조건이 해당 seed의 순서와 uniform을 공유한다.
이후 실제 선택·획득 보상은 경로에 따라 달라질 수 있다.

checkpoint는 **0,50,100,200,400**이다. 각 시점에 네 훈련 문제를 추가 행동 추출·보상·갱신 없이
평가한다. 전체 예산은 **12조건 ×10seed ×400 =48,000회 실제 피드백**과
**12×10×5×4 =2,400개 정적 probe**다. 기하·분석 후보 수를 새 행동 시행 수로 세지 않는다.
계산 seed는 동물이나 사람의 수가 아니다.

모든 시행의 문제·확률·행동·획득 보상·출력 갱신 호출·실제 new-minus-old L2 변화와 비영 여부를
기록한다. NoGo의 0 변화와 호출 자체를 구분한다. 모든 checkpoint의 출력 계수·원 점수·확률,
초기 내부 가중치·encoder·bias·배선·KC/MBON 특징·행별 척도를 보존한다.
고정 특징과 내부 가중치의 변화는 0인지 확인하고, 출력 가중치 변화와 활성 상태를 구별한다.

두 갱신의 출력 좌표 수는 같지만 projected에는 특징 지향별 추가 고정 계수와 SVD 계산이 필요하다.
원 모델에서 추가 방향 계수는 배선·표현별 4×48개다. 실제 유효 좌표와 L2 변화도 보고한다.
한 배선·표현·seed마다 방향용 SVD 1회, 원/정규화 기하 진단 2회, 분석용 활성 집합 15회를 사용하며,
두 입력 표현의 분석용 30회를 더해 전체 producer SVD 호출은 1,110회다. 이 중 분석 진단은
정답 학습이나 추가 보상 시행으로 세지 않는다.
자기 문제의 원 점수 수정 폭을 맞췄다는 사실이 전체 가중치 L2·수치 조건·계산 비용·자율 행동
경로까지 같다는 뜻은 아니다. 모든 학습 자원이 같거나 생물학적으로 구현됐다고 주장하지 않는다.

## 사전 가설과 판정

일차 지표는 네 문제에서 정답 행동을 선택할 **기대 확률의 평균**이다. 실제로 뽑힌 행동의 정답률과
획득 보상률은 별도 기록이다. seed별 습득은 마지막 평균 ≥.80, 처음 대비 증가 ≥.25,
두 종류 각각의 평균 ≥.70을 모두 요구한다. 해당 조건의 10seed 중 8개 이상이 통과해야
연구 단위 습득을 지지한다. 실패 seed를 빼고 성공률을 계산하지 않는다.

일차 H_update는 real/raw의 projected−shared 최종 평균 차이에 대해 다음을 모두 요구한다.

1. 10seed 평균 차이 ≥.10.
2. 양의 차이가 8/10seed 이상.
3. real/raw/projected의 습득 통과가 8/10seed 이상.
4. 모든 조건의 필수 자기 영향 수치 조건 통과.
5. real/raw에서 shared의 평균 비대각 제곱 영향 합이 projected보다 엄격하게 큼.

H_repr은 real의 identity/shared−raw/shared에서 평균 차이 ≥.10,
양의 차이 8/10 이상, identity/shared 습득 8/10 이상, 모든 조건의 필수 수치 조건 통과를 요구한다.
이는 사전 지정한 추가 표현 비교다. 실용 기준을 통계적 유의성·생물학적 경계로 부르지 않는다.
사후 p값에 따라 가설이나 일차 조건을 바꾸지 않는다.

표현×갱신의 차이의 차이, 세 배선의 결과, 선형 해의 크기와 간섭 행렬은 기술적으로 보고한다.
이 연구에서 배선 우위·일반적인 모든 수열 학습·고급 수학 이해를 지지하는 별도 성공 판정을 만들지 않는다.

원 신경 특징의 분석적 해가 확인되고 shared가 습득하지 못하지만 projected가 습득한다면,
이 새 조건에서 입력의 완전한 정보 소실보다 갱신 기하가 병목일 수 있다는 제한된 근거다.
정체성 표현이 개선돼도 규칙 이해나 일반화의 증거는 아니다.
여러 개입이 함께 필요하거나 효과가 작거나 모든 학습이 실패하면 그 결과를 그대로 보존한다.
같은 등록의 실패를 학습률·시드·표현·예산 변경으로 성공으로 바꾸지 않는다.

## 실행 전 동결과 재현 명령

새 envelope는 완료한 `prospective.py`의 고정 소스 목록을 수정하지 않는 별도 구현이다.
설정의 **소스 20개·부모 증거 11개·그래프 파일 4개·입력 파일 2개**를 SHA-256과 Git commit으로
정확하게 동결한다. 부모 검산·완료 상태와 기준선 원문을 확인한다.
합성 검사는 실제 과학 seed와 예산을 사용하지 않으며 `integration_test`는 연구 등록이 거부된다.

먼저 모든 소스·설정·입력과 부모 증거가 commit된 상태에서 등록한다.

```text
python scripts/run_representation_update.py register --config configs/representation_update_v1.json --out results/registration_representation_update_v1.json
```

등록을 commit·push한 뒤 원격의 같은 등록 bytes를 확인하고, source commit·published commit·
등록 hash·확인 UTC를 `results/representation_update_publication_proof.json`에 보존한다.
원격 확인이 실제 계산 시작보다 앞서야 한다.

```text
python scripts/run_representation_update.py run --config configs/representation_update_v1.json --registration results/registration_representation_update_v1.json --publication-proof results/representation_update_publication_proof.json --out results/representation_update_v1
```

기존 결과 경로를 덮어쓰지 않는다. 실행 실패 시에도 실패 metadata와 만들어진 파일의 hash를 보존한다.
검증되지 않은 결과를 연구 완료나 성공으로 보고하지 않는다.

## 독립 검산과 해석 범위

독립 검산은 새 producer와 기하 helper를 import하지 않는다.
원 그래프·encoder·두 입력·행 정규화·SVD cutoff·방향·정적 영향·15개 분석 후보·난수 주소·
전체 행동과 보상·실제 출력 변화·checkpoint·습득·가설을 별도 산술로 다시 구성한다.
파일 hash·등록/원격 확인/계산 시작/완료의 시간 순서·예산과 모든 고정 상태도 확인한다.
옮겨 적은 요약 숫자만 맞추는 검사는 독립 검산으로 세지 않는다.

이 연구의 최대 범위는 유한 인공 입력의 판독 가능성(Level 1)과 경험으로 출력 계수가 변하며
성적이 달라지는 과정(Level 2)의 구분이다. **미학습 문제의 일반화는 검사하지 않는다.**
새 인간 자료나 인간 대상 실험이 없고 실제 초파리의 문자·수량 인식, 생물학적 내부 가소성,
인간과의 학습 유사성, 공통 신경 기작, 교육 효과를 새로 주장하지 않는다.
완료 후 기존 Phase 5 종합과 구별되는 후속 결과로 보존한다.

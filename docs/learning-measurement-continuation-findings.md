# 이어서 완료한 두 단계 — 기록의 뜻에서 실제 측정까지

작성일: 2026-10-15 (Asia/Seoul).

**두 단계 모두 실제 실행과 독립 검산을 마쳤다.** 이번 성과는 사람과 모델의 선택 기록을 믿을 수 있게 측정하는 기반을 만들었다는 것이다.

1. **기록의 뜻을 확인했다.** 논문·저자 과제 코드·변환 코드를 대조하고 원본25개에서 선택·상태·정오 코드가 일관됨을 검증했다. 같은 조건에서 사용한 일정도 일치했다. 카드 좌우 배치와 정보 요청 가능 여부를 혼동하지 않도록 고쳤다. [첫 단계 결과](human-task-structure-findings.md).
2. **실제 선택의 유지·전환을 셌다.** 사람25,000시행과 기존 모델112,000시행을 처리했다. 사람은21,530개의 원 이웃 쌍, 모델은111,720쌍에서 실제 피드백 뒤 같은 선택을 했는지 기록별로 계산했다. 사람의 제외3,445쌍도 이유와 함께 보존했다. [두 번째 단계 결과](feedback-transition-findings.md).

쉽게 말하면 ‘좋은 결과를 받고 같은 선택을 되풀이하는가’를 관찰할 자를 만든 셈이다. 다만 사람은 카드로 확률적 돈의 이득·손실을 경험했고, 모델은 입력에 이미 주어진 작은/큰 수량에 결정적 보상을 받았다. **같은 자로 잴 수 있다는 것만으로 같은 방식으로 배운다고 말할 수는 없다.** 이번에 사람과 모델의 우열·유사성·학습 속도 차이를 검정하지 않았다.

인공 자료 시험은 첫 단계46개, 두 번째234개로 총280개가 통과했다. 실제 자료도 각각 다른 프로그램으로 다시 계산해 일치했다. 두 단계 모두 계산 전에 기준·코드·입력 해시·설정을 private GitHub에 고정했다. 새 모델 학습을 돌리지 않고 이미 완료한 기록을 분석했으며, 기존 연구의 실패·원자료·코드와 DrosoMem은 보존했다.

현재 한계는 과거 정확한 실행 프로그램 버전 연결, 원본 미대응49행, 미해결 OpenNeuro 코드 의미, 사람과 모델의 과제·보상·선택 수 차이다. 이번 결과는 공통 신경 기작이나 인간 수학 학습의 교육 효과를 입증하지 않는다.

다음 연구는 작은 계산 대조 실험으로 보상 방식·선택 편향·반전 일정이 이 측정값을 어떻게 바꾸는지 구분하는 것이다. 그 뒤에 사람 학습에 대해 반증 가능한 비교 가설을 세운다. 새로운 인간 실험이나 인간과 같은 신경 기작을 먼저 가정하지 않는다.

원 자료 처리 결과는 [기록별 수치](../results/feedback_transition_v1/metrics.json), [모든 원 인접쌍과 제외 내역](../results/feedback_transition_v1/ledger.csv), [독립 검산](../results/feedback_transition_v1/verification.json)에 있다. 완료 버전은 `human-task-structure-v1` 및 `feedback-transition-v1` 태그로 구분한다.

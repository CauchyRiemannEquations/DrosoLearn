# DrosoLearn 연구 로드맵

단계의 완료는 코드가 존재한다는 뜻과 가설이 지지되었다는 뜻을 분리해 판단한다. smoke 실행은 파이프라인 점검이며 확증 결과가 아니다. 다음 단계로 넘어가기 위해 성공 사례만 고르거나 훈련 예산을 무제한 늘리지 않는다.

2026-10-14 후속 상태: 별도10시드의 **학습 이력·출력 초기화 진단**을 실행했고 [결과와 해석](reversal-findings.md)을 보존했다. 이는 최초 확장 설정의 무조건적 확증이나 전체 Phase2/3 완료가 아니다. 인간 S1/S6 공개 자료도 실제 확보·구조 검증했으며 [자료 준비 상태](human-data-readiness.md)에 비교 가능한/불가능한 지표를 구분했다. 인간/모델의 Level4 비교와 생물학적 Level5는 미실행이다.

입력 표현 후속도 별도10시드·6모델·2실제 학습 조건·48,000시행으로 실행했다. [쉬운 결과 해석](encoding-findings.md), [별도 프로토콜](encoding-protocol.md), [원자료](../results/encoding_v1/report.md)를 보존한다. 순서 제공 입력의 새 수량 성적은 학습으로 향상했으나 재배선·ANN에서도 비슷했다. 720개 임의 이름표의 완전 미학습15쌍 평균50%는 사전 증명된 대칭이며 새 실패로 세지 않는다. 일반 신경망 출력 전용의 연습 습득 실패2/10도 제외하지 않았다.

순서를 유지한 입력 간격 진단도 별도10새시드·6모델·24,000시행으로 실행·독립 검산했다. [쉬운 해석](spacing-findings.md)에 같은5대7의 간격 축소로 정답 선택 확률이 낮아졌지만 결정적 선택 방향은 유지된 결과를 구분했다. 1/4간격의75% 확률 기준은 모든 모델0/10이며 주 쌍 greedy100%로 이 실패를 구제하지 않는다. 연습 습득 실패2개도 남겼다. 이것은 입력 기하와 선택 함수에 대한 진단이며 새 생물학적 원리나 전체 Phase3 완료가 아니다.

## Phase 0 — 근거와 재사용 범위 확정

1. DrosoMem의 commit, 파일별 해시, 재현 조건, 코드·데이터의 서로 다른 라이선스를 고정한다.
2. v783 데이터가 공개된 부분집합인지 전체 회로인지 확인하고 KC·MBON·DAN·APL·LC11의 실제 식별 정보와 연결 범위를 분리해 기록한다.
3. M10·M11 및 후속 가소성 연구의 사전 기준, 음성 결과, 대조 배선과 신경 반응 검증을 검토한다.
4. 초파리 수량 구별, mushroom body 가소성, 인간 수량·학습 문헌의 직접 관찰과 DrosoLearn의 가정을 나눠 정리한다.
5. 첫 실험 설정과 성공·실패 기준을 실행 전에 저장한다.

산출물: 저장소 감사, 데이터 provenance, 기술 설계, 문헌 검토, 연구 질문, 실험 프로토콜. 실제 시각 입력 경로가 확인되지 않으면 Phase 1을 추상적 벤치마크로 유지한다.

## Phase 1 — 최소 추상 수량 보상 학습

실제 공개 부분집합의 512 KC/48 MBON 사이 KC→MBON 연결 1,474개를 사용하는 작은 Python 파이프라인을 실행한다. 이 경로에서 489 KC와 29 MBON이 연결에 참여하고 19 MBON은 입력이 없어 출력이 0이다. 전체 reservoir 대신 선택한 feedforward 경로를 사용한다. 두 후보 각각의 `n/8` 및 인공 nuisance descriptor를 고정된 무작위 encoder로 KC에 입력한다. 2 대 4에서 높은 수량에 보상을 주는 습득 단계와 낮은 수량으로 바뀌는 반전 단계를 분리한다. side bias, nuisance 단서, 입력 중복, 평가 중 학습 등으로 성능이 설명되지 않는지 검사한다.

고정 커넥톰과 출력층 학습, 제한된 내부 가소성, 동일한 학습 규칙의 재배선 대조, 희소 일반 인공 신경망을 비교한다. 배선과 가소성의 효과를 분리할 수 있도록 고정/가소성 × 실제/재배선 조건 및 ANN의 고정/가소성 조건을 사용한다. 양쪽의 출력층에는 같은 선택 행동·scalar reward에 의한 policy-gradient update를 적용한다. 무학습, 행동과 독립적인 Bernoulli(.5) 무작위 보상, 출력층을 고정한 내부 전용 학습도 비교한다. ANN 대조는 MBON별 indegree와 incoming weight multiset을 보존하지만 KC outdegree는 보존하지 않는다. 가소성 모델의 추가 내부 파라미터·업데이트 수는 같다고 가정하지 않고 수치로 보고한다. 외부 전역 보상 gate는 실제 DAN 발화가 아니다.

습득용 평가와 미관측 nuisance 조건 평가를 분리한다. 동일한 수량의 새로운 nuisance 조건에 성공한 결과는 숫자 외삽이나 새 규칙 전이로 해석하지 않는다. 습득 기준을 통과한 뒤 1 대 3, 3 대 4, 4 대 8의 2차 진단을 해석하되, `n/8` 입력이 이미 순서를 제공한 사실을 명시한다. 분석적 기준 모델로 과제 자체가 해결 가능한지 확인한다. 모든 seed와 실패도 결과에 포함한다.

산출물: 자동 테스트, 시행별 보상·행동·정확도, 학습 곡선, 고정 probe 활성, 내부/출력 가중치 변화, 재배선 무결성, 실행 metadata. 초기 smoke는 3 seed·단계당 400시행·평가 128시행·100시행 간격 checkpoint다. 1차 지표는 확률적 정책의 정답 선택 확률을 평가 사례에 평균한 `expected_reward`이며 greedy 정확도는 별도 진단이다. 습득의 사전 기준은 최종 IID 정답 선택 확률 ≥.75와 초기 대비 향상 ≥.15를 모두 요구하며 OOD ≥.70 및 반전 후 ≥.75 기준은 습득 통과 이후에만 해석한다. 첫 threshold checkpoint는 지속 습득 기준이 아닌 진단이다. 높은 초기 수행으로 gain 기준을 못 통과하는 결과도 보존한다. 3 seed smoke 뒤 확증을 하려면 사전에 고정된 별도 10 seed 프로토콜을 실행한다. smoke 결과를 보고 수정했으면 새 버전과 그 이유를 저장한다.

다음 단계 조건: 데이터·평가 무결성이 통과하고, 사전 기준으로 습득이 가능한지 결정할 수 있어야 한다. 습득 실패 시 원인 진단과 실패 보고는 완료된 산출물이며, 일반화 성공으로 대체하지 않는다.

## Phase 2 — 제한된 내부 가소성 검증

Phase 1의 가소성 코드는 계산적 후보 규칙이다. 생물학적 대응을 확대하려면 실제 KC→MBON 연결, compartment, DAN/MBON의 식별 정보와 응답 적합성을 먼저 확인한다. 동일 probe에 대한 활성 변화, 내부 가중치 변화, 출력층 변화의 기여를 분리한다.

검토할 진단은 보상 차단, 보상 섞기, 출력층 고정, 가소성 차단, 시간 순서 교란, 허용되지 않은 연결 변경 검사다. 외부 보상 스칼라를 특정 DAN의 활동으로 바꾸려면 그 경로와 baseline 응답을 검증해야 한다. 신경 반응 gate가 실패하면 과제 성능만으로 생물학적 기작을 주장하지 않는다.

산출물: 후보 가소성 규칙의 근거·가정, 2×2 배선/가소성 비교, 학습 자원 통제, 보상 의존성·안정성·신경 반응 검증. 대조 배선이 같거나 더 좋은 경우도 연구 결과로 보존한다.

## Phase 3 — 일반화·규칙·학습 이력

습득이 확인된 과제부터 난이도를 높인다.

1. 새로운 수량·차이·비율로의 반응을 기존 nuisance 일반화와 구분해 검사한다.
2. 반복·주기·홀짝·등차 과제의 식별을 시작하고, 규칙 식별·규칙 적용·다음 항 예측을 따로 평가한다.
3. 훈련하지 않은 시작값, 규칙 조합, 규칙 계열의 전이를 분리한다.
4. 복사·빈도·마지막 항·표면 배열 대조로 과제의 지름길을 검출한다.
5. 학습 순서, 반복, 보상 반전, 간섭, 다른 과제 이후와 지연 이후 변화를 비교한다.

모든 단계에서 습득 gate를 먼저 평가한다. 새로운 수량에 대해 scalar 또는 log 인코딩이 이미 순서를 주는 경우 인코딩의 귀납 편향을 따로 비교한다. 기호 과제는 인공 신경망 과제로 표시한다. 망각은 활성 상태 소실, 가중치 decay, 새로운 학습에 의한 간섭을 분리한다.

훈련2·4의 입력값을 고정하고 새5·7의 순서·중간값을 유지하는 코드 간격 변화는 [별도 프로토콜](spacing-protocol.md)로 실행했다. 학습 전을 보정한 간격 민감도 기준은6모델 모두 통과했으며 확률과greedy를 구분했다. 주 쌍 밖에서는 간격과중간값이 함께 바뀔 수 있다. ratio·difference별 성적을 인간 수량 감각으로 읽기 전에 scalar 간격·잡음·과제 난이도의 기여를 확인한다.

연습한2·4의 별도 출력 점수로만 맞춘 **선형 참조 함수의 설명 범위**도 새10시드·6모델·24,000시행으로 실행·독립 검산했다. [사전 계획](linearity-protocol.md)과 [쉬운 결과](linearity-findings.md)를 보존한다. 완전 미학습15쌍·네 간격의 시행별 확률 오차는 모델별 평균0.369–1.122%포인트로 주H-L 기준6/6통과였다. 습득 미달3개도 주 평균에서 제외하지 않았다. 원래 모델 점수를 받은 참조는 독립 보상 학습자가 아니며, 초기부터 오차가 작았다. 가소성 조건의 확률 오차는 작아도 원시 점수 차이 오차는 더 커 ‘더 선형적인 기작’으로 해석하지 않는다.

모델 점수를 받지 않는 **독립 보상 선형 학습자**도 새10시드·9조건·36,000시행으로 실행했다. [사전 계획](reward-linear-protocol.md)과 [쉬운 결과](reward-linear-findings.md)를 보존한다. 훈련 입력만으로 초기 특징 차이 RMS를 맞춘 선형은 연습96.85%·완전 새15쌍96.01%, 습득과습득후전이각10/10이며 H-R/H-G가 통과했다. 원래 척도의 선형은64.71%·71.16%로사전gate0/10이지만 결정적 새입력선택은100%였다. 무작위 보상 평균47.98%와 두보조조건의습득미달20건도 보존한다. 정답순서는입력이제공하며 결정적두선택보상은라벨동등정보다. 초기출력0·척도를바꾼별도연구이므로과거성적개선효과로읽지않는다. 척도·예산을맞춰도전체학습자원은같지않다.

독립 단순 학습자를 포함한 **보상 반전·학습 이력 비교**도 새10시드·7실제조건·4이력으로 실행했다. [사전 계획](bandit-reversal-protocol.md)과 [쉬운 결과](bandit-reversal-findings.md)를 보존한다. 실제196,000보상갱신과 정답 정보를 쓰는 별도조건부기대참조28,000갱신을 분리했다. 단순모델의 처음부터96.96%/반전44.51%/출력초기화96.96%, 끝점비용52.45%포인트로 주H-B통과였다. 반전기준은2/10이며 전체조건의반전미달40건을남겼다. 반전도3.03%→44.51%로회복했으므로 무학습으로읽지않는다. 초기수행·gain·raw/보정AUC를구분하고 intrinsic 학습속도차나생물학적기억으로확대하지않는다. 기대참조의 평균곡선오차1.41pp와개별경로오차6.29pp·큰변이를구분하며 정확한ensemble기대값이라고하지않는다.

같은 학습 이력에서 **출력 계수를 일부 줄이는 진단**도 새10시드·7모델·공유prefix/5경로로 실행했다. [사전 계획](head-attenuation-protocol.md)과 [쉬운 결과](head-attenuation-findings.md)를 보존한다. 실제168,000회/별도참조24,000회를 구분했으며 선형 그대로 59.51%·1/4 96.54%로 주H-A 통과였다. 끝점 차이 안의 즉시 경계 이득 26.74%p와 이후gain차이 10.28%p를 분리했다. 미달 33건을 보존하며 confidence-only·intrinsic속도·자연망각·생물학적기작으로 확대하지 않는다.

**인간 공개 시행별 자료의 가용성 감사**를 실행하고 [계획](human-trial-data-protocol.md)·[출처](human-trial-data-sources.md)·[쉬운 결과](human-trial-data-findings.md)를 보존했다. CC0 OpenNeuro 31파일에서 사건44,262행·선택14,568개를 확인했고 완전 연결 후보13,954개와 모호한614개를 구분했다. 구조 표시1,720건을 독립적인 실패 시행 수로 읽지 않는다. MAT23행의 참가자 연결은 미확정이다. 수량 예제4ID×250시행과 반전 후보74행에서도 중복·피드백·추가 선택·권한의 제약을 확인했다. 새 합성테스트121개와 주 자료의 독립 재검산이 통과했다. 자료를 일부 미리 본 탐색적 감사이며 인간/모델 유사성 검정은 아직 하지 않았다.

**익명 기록 사이의 대응 감사**도 [별도 계획](human-trial-linkage-protocol.md)으로 실행·독립 검산했다. [쉬운 결과](human-trial-linkage-findings.md)를 보존한다. 26×23의598조합에서 두 과제 전체 피드백이 양방향 유일하게 일치한 후보23쌍을 찾았고 s5/7/9는 미대응으로 남겼다. 12,880관측 구간 중 엄격 대조12,334/보류546개이며 좌우→1/2 코드 불일치6,114개와 기대+3 불일치4,135개를 고치지 않고 보존했다. 피드백 일치가 원 시행·도형·기대의 의미까지 보증하지 않음을 실제 확인했다. 새126개+기존 의존58개 테스트가 통과했다. 공식 OSF 메타데이터14개로 원 데이터 component의 CC BY4 관계도 새로 확인했으나 GitHub 가공 CSV와의 동일성·권한 이전은 미확정이다.

**코드 의미 진단과 공식 OSF 원본 재현을 연속 실행**했다. [두 단계 결과](human-data-continuation-findings.md)를 보존한다. 고정 183경로·97포인터를 조사하고 기존 12,334개 코드 대조의 전체·46그룹 교차표를 독립 검산했으나, 새로운 원 변환 근거를 확보하지 못해 의미 게이트는 미해결이다. 공통 숫자 치환을 선택하지 않았다. 별개 OSF 자료에서는 전체 74행의 가용성을 성과 계산 전에 고정하고, 찾은 main 25행(regular 15/irregular 10)의 원본에서 3배열×1000위치×25=75,000항목을 결측까지 재현해 0불일치·독립 검증 통과였다. 미대응 49행은 미검증이며, 폴더 Pilot이라는 이름을 집단 판정에 쓰지 않았다. 새 합성 테스트 109개(57+52)도 통과했다. 이것은 25행의 변환 검증이며 사람의 학습 효과가 아니다.

다음 후보는 **확인된 원본 범위에서 카드 선택·정보 요청·확률적 피드백·시행 구획의 뜻을 확인하고 공통 관측량을 설계하는 작업**이다. 미해결 OpenNeuro 열을 자동 합치지 않는다. 25개 부분 검증을 전체 자료·독립 참가자·모든 필드의 검증으로 확대하지 않고, 두 선택 모델과 정보 요청이 있는 인간 과제의 차이를 먼저 기록한다. 적합한 범위가 확인된 뒤에만 공통 측정 지표·분모·성공/실패 조건을 사전 정의한다. 모델 확률과 사람의 실제 선택을 그대로 같은 관측량으로 읽지 않는다. 새로운 인간 대상 실험이나 교육 효과 주장으로 건너뛰지 않는다.

산출물: 과제별 사전 프로토콜, 규칙 습득/일반화/전이의 분리 결과, 실패한 가설, 오류·순서·망각 분석.

## Phase 4 — 인간 학습과의 정량 비교

이 단계는 장기 핵심 목표이며 Phase 0부터 문헌과 지표를 준비한다. 기존 공개 자료만 사용한다. 초파리 모델과 인간이 같은 문제를 풀지 못하더라도, 비율별 구별, 반복에 따른 향상, 오류 분포, 학습 전이, 보상 수정, 간섭 같은 과제 구조가 비교 가능한지 먼저 검토한다.

초기 지표 후보는 비율에 따른 정확도·psychometric slope, chance/ceiling을 고려한 학습 곡선, 습득 기준 도달 시행 수, 반전 비용, 일반화 손실, 간섭 비용이다. trial 길이·보상·입력·상한·연령·과제 난이도 차이를 기록한다. 공개 숫자가 없는 논문의 그림을 독립 원자료처럼 취급하지 않는다.

유사성은 사전 정의한 지표에서 판단하고 차이·불확실성·단순 대조 모델도 함께 비교한다. 유사한 결과가 동일 신경 기작을 뜻하지 않는다. 인간 대상 새 실험이나 교육 효과 주장은 초기 범위에 포함하지 않는다.

산출물: 출처별 비교 가능성 표, 공개 데이터 가용성, 맞출 수 있는/없는 지표, Level 4 가설의 성공·실패 결과, 후속 생물학·인간 연구로 반증할 수 있는 가설.

## Phase 5 — 독립 연구 종합

원본 DrosoMem을 수정하지 않은 독립 보고서로 실제 검증 결과, 실패, 구현 가정, 추가로 필요한 자료를 정리한다. 실행 명령·설정·환경·seed·원본 해시·프로토콜 버전·코드 버전과 결과 파일 해시를 남긴다. 계산 반복을 초파리 개체 수로 표기하지 않으며 결과별 Level 1–5 주장 수준을 명시한다.

완료 기준은 성공적인 수학 문제 풀이가 아니라, 재현 가능한 관찰과 검증 가능한 다음 가설이 남아 있는 것이다.

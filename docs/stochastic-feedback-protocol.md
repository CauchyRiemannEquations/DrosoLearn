# 확률적 보상 학습 — 독립 선형 검증과 배선 확장 사전 계획

작성일: 2026-10-16 (Asia/Seoul). 이 계획은 새 과학 시드 10001–10010 및 11001–11010을 실행하기 전에 작성한다. 기존 소스·설정·등록·결과·실패를 덮어쓰지 않는 두 후속 연구다. [재사용 감사와 설계](stochastic-feedback-design.md)의 제안 중 아래에 고정한 조건만 실행한다. 이후 수치·예산·시드·평가 기준을 결과에 맞춰 변경하지 않는다. 실행 전 비공개 Git 원격 동결은 외부 공인 공개 사전등록을 뜻하지 않는다.

## 쉽게 설명하면

모델이 좋은 선택을 해도 가끔 보상을 놓치고, 나쁜 선택을 해도 가끔 보상을 받게 만든다. 이런 환경에서도 경험을 통해 선택이 바뀌는지 먼저 간단한 모델로 확인한다. 처음 400번은 큰 수량을 고르면 보상이 잘 나오고, 다음 400번은 작은 수량을 고르면 보상이 잘 나온다.

아무것도 배우지 않는 대조와 선택에 상관없이 보상이 무작위인 대조를 함께 둔다. 간단한 모델이 첫 규칙을 충분히 배웠고 독립 검산도 통과했을 때만 새로운 시드로 실제 배선·재배선·일반망을 비교한다. 반전의 성공을 미리 가정하지 않으며, 실패도 같은 예산의 결과로 보존한다.

수량은 점 그림이 아니라 `n/8`이라는 숫자로 이미 주어진다. 사람 자료와 보상이 조금 비슷해져도 같은 과제가 되는 것은 아니다. 이번 연구는 사람·초파리의 능력이나 신경 기작 비교가 아니다.

## 두 등록과 확장 gate

| 단계 | 설정 | 전체 시드 | 모델 조건 | 실제 선택·보상 표시 |
|---|---|---|---|---:|
| 독립 선형 검증 | [linear 설정](../configs/stochastic_feedback_linear_v1.json) | 10001–10010 | `linear`, `frozen` | 48,000 |
| 배선·가소성 확장 | [network 설정](../configs/stochastic_feedback_network_v1.json) | 11001–11010 | 아래 여덟 조건 | 192,000 |

각 모델은 세 환경에서 모두 high400→low400을 실행한다. fresh low, head reset, head 감쇠, 추가 반복 학습 조건은 이 연구에 포함하지 않는다. 같은 시드의 각 조건은 독립된 초기 상태에서 시작하며 환경 사이에 학습 상태를 이어받지 않는다.

두 설정·공통 소스·이 프로토콜은 선형 검증 전에 고정할 수 있다. **배선 단계의 실제 등록과 실행은 선형 단계의 H-L 지지 및 독립 검산 통과를 확인한 뒤에만 허용한다.** 배선 등록에는 선형 등록·최종 summary·독립 verification의 바이트 해시와 gate 판정을 보존한다. 설정 파일을 먼저 만들었다는 사실을 실제 배선 실행 완료나 gate 통과로 기록하지 않는다.

선형 H-L 미지지는 과학 결과다. 이 경우 시드를 교체하거나 예산을 연장해 기존 등록을 살리지 않고 배선 단계는 미실행으로 남긴다. 무결성 실패와 과학적 미지지를 구분한다. 반전의 미달은 확장 gate가 아니다. 첫 규칙을 배울 수 있었는지를 확인한 뒤 다른 구조에서 같은 과정을 관찰하는 순서다.

## 환경·선택·보상

TRAIN 수량쌍은 2대4다. phase1의 보상 우세 선택은 큰 수량4, phase2의 보상 우세 선택은 작은 수량2다. 원 시행 1–400과 401–800 사이에 한 번만 환경을 바꾸며 모델 상태는 초기화하지 않는다. 선택지는 매 시행의 좌우 후보이고, 지속적인 선택 정체성은 수량2/4다.

| 환경 | 보상 우세 선택의 reward1 확률 | 다른 선택의 reward1 확률 |
|---|---:|---:|
| `deterministic` | 1 | 0 |
| `probabilistic` | .8 | .2 |
| `uninformative` | .5 | .5 |

각 시행에서 `p=p_right`로 실제 행동 `a=int(u_action<p)`를 먼저 뽑는다. 선택한 후보가 해당 phase의 지정 방향에 맞으면 `q=q_optimal`, 아니면 `q=q_other`로 정하고 실제 보상 `r=int(u_reward<q)`를 뽑는다. 학습자는 `inputs, a, r`만 받는다. 학습 함수에 환경 정답, q, 다른 선택의 잠재 보상, 평가 성적을 전달하지 않는다. 별도의 정답 접근 기대 갱신 참조나 teacher 점수는 계산하지 않는다.

무정보 환경은 두 선택에 보상 우세가 없다. phase별 ‘지정 방향’은 지표를 같은 축으로 기록하기 위한 기준이며 그 방향의 높은 확률을 참 규칙 습득으로 해석하지 않는다. 모든 환경에서 평가 기호는 **`p_rule`**, 즉 해당 phase의 기준 수량 선택 확률로 통일한다. 결정적·정보 있는 확률적 환경에서는 이 기준이 보상 우세 선택이지만 무정보 환경에서는 비교용 기준일 뿐이다. 결정적 환경의 두 선택과 보상은 정답을 복원할 수 있는 정보이지만, .8/.2 환경의 개별 보상은 항상 정답을 알려주지 않는다.

## 모델·척도·갱신

`linear`는 기존 `reward_linear.LinearLearner`를 재사용한다. 모든 초기 출력 계수는 0, head 학습률은 .1이다. 초기 phase1 TRAIN 입력만으로 후보 특징 차이의 RMS `g=sqrt(mean(sum((z_right-z_left)^2)))`를 계산하고 `phi=z/g`를 두 phase 내내 유지한다. `g`는 양의 유한값이어야 한다. phase2·eval·정답·보상·학습한 가중치로 다시 계산하지 않는다. 이는 초기 400개 입력의 무보상 batch 전처리이며 미래 입력을 전혀 보지 않는 엄격한 온라인 모델이 아니다.

`frozen`은 동일한 초기 선형 모델을 만들고 실제 선택·보상은 기록하지만 update 호출을 생략한다. 출력·내부 counter는 0, head와 모든 평가 확률은 각각 0과 .5를 유지해야 한다. 이 불변은 구현 검증이며 무정보 학습 조건의 확률을 .5로 강제하는 규칙이 아니다.

배선 단계는 다음 여덟 조건을 모두 실행한다.

| 조건 | 특징과 연결 | 학습 가능한 부분 |
|---|---|---|
| `linear` | 원래 7차원 인공 입력 | 출력 계수7개 |
| `fixed`, `plastic` | 실제 KC→MBON 부분집합 | 출력 슬롯48개 / 출력과 내부 가중치1,474개 |
| `rewired_fixed`, `rewired_plastic` | 차수 보존 재배선 | 같은 출력 / 출력과 내부 가중치 |
| `ann_fixed`, `ann_plastic` | 무작위 희소 일반망 | 같은 출력 / 출력과 내부 가중치 |
| `frozen` | 초기 선형 상태 | 없음 |

신경망은 기존 `NormalizedLearner`를 재사용하며 encoder·bias와 KC ReLU는 고정한다. 실제 투영은 [고정 원자료](../data/flywire_783_mb_left_kc512_s701/provenance.json)의 nominal512 KC·48 MBON, 활성489 KC·29 MBON, KC→MBON 1,474쌍이다. 연결 없는 MBON19개 슬롯도 그대로 보존한다. 재배선은 KC outdegree·MBON indegree·MBON별 incoming weight multiset을 보존하고 KC outgoing strength·type/compartment 구조는 보존하지 않는다. 일반망은 MBON별 입력 수·입가중치 multiset을 보존하며 KC outdegree는 같다고 가정하지 않는다. 고정/가소성 쌍은 초기 encoder·bias·내부 상태·척도가 같아야 한다.

선형·신경망의 head 갱신은 `f=(a-p)*(r-.5)`, `head += .1*f*(phi_right-phi_left)`다. 내부 가소성은 갱신 전 head를 이용하여 `eligibility=old_head[post]*(KC_right-KC_left)[pre]/g`, `weights=clip(weights+.01*f*eligibility,0,2*initial_weights)`로 고정한다. anatomical mask 밖의 연결은 추가하지 않는다. .5는 고정 보상 중심화이며 학습한 보상 예측 오차나 실제 DAN 신호가 아니다.

`NormalizedLearner.update`는 부모의 학습 플래그만 바꿔도 head를 갱신하므로 `frozen`은 update 호출 자체를 생략한다. 초기 출력0인 가소성 모델의 첫 내부 step이 0이어도 update 호출 counter와 실제 가중치 변위를 구분해 기록한다. 내부·출력 가중치 변화와 활성 변화는 별도 항목이다.

같은 시행 수·초기 RMS를 맞춰도 계수 수·특징 방향·상관·학습 자원은 같지 않다. 가소성 조건은 추가 내부 가중치를 사용한다. 배선 단계의 주 목적은 지정된 조건의 학습 과정과 차이를 기술하는 것이며, 실제 커넥톰의 우수성·추가 자원과 무관한 생물학적 인과 효과를 판정하는 가설은 두지 않는다.

## 입력·난수·평가 누출 방지

모든 후보 입력은 `n/8`과 기존 교차 설계의 여섯 인공 nuisance 좌표다. 원 `make_dataset`을 재사용해 수량·좌우·nuisance를 균형화한다. 각 phase TRAIN은400행, IID와 nuisance OOD는 각각128행이다. 모든 split의 방향 독립 fingerprint 교집합을 실제 검사한다. 구조적 수량 oracle은 1, 각 nuisance-only 기준은 .5여야 한다.

| stream | NumPy `default_rng` seed | 길이 |
|---|---|---:|
| phase1 TRAIN | `seed*100+51` | 400 |
| phase2 TRAIN | `seed*100+54` | 400 |
| IID / OOD | `seed*100+52` / `seed*100+53` | 각각128 |
| phase1 / phase2 행동 | `seed+510000` / `seed+520000` | 각각400 |
| phase1 / phase2 보상 | `seed+530000` / `seed+540000` | 각각400 |
| 재배선 / ANN / encoder | `seed+550000` / `seed+560000` / `seed+570000` | 모델별 고정 |

한 시드의 phase별 입력·행동 uniform·보상 uniform 배열을 모든 환경·조건에 공유한다. 행동과 보상 stream은 독립 생성한다. 시행마다 해당 위치를 하나씩 사용하며 선택·보상·조건 수에 따라 다른 RNG 호출 수를 사용하지 않는다. 공유 uniform이 같은 실제 선택·보상을 보장하지는 않는다. 정책과 선택의 q가 달라질 수 있다. 이 결합은 짝지은 계산 조건이며 독립된 생물학적 표본을 만들지 않는다.

checkpoint는 각 phase 시행0·100·200·300·400이다. 두 phase 사이의 물리적 상태는 동일하고 phase2 trial0은 평가의 목표 방향만 바뀐다. IID/OOD 입력을 두 phase에서 고정해 사용하되 학습·early stop·hyperparameter 조정에 쓰지 않는다. 평가에서 action/reward RNG를 소비하지 않는다. 평가 전후 가중치·encoder·bias·척도·counter와 난수 상태가 모두 같아야 한다. 개발 fixture는 두 과학 시드 구간 밖에서만 실행한다.

## 주 가설 H-L과 실패 기준

선형 단계의 주 가설 **H-L**은 `.8/.2` 보상만으로 첫 큰 수량 선택 규칙을 사전 수준으로 습득하고, 선택과 무관한 보상 대조보다 높은 최종 지정 방향 확률을 보이는가다.

시드별 습득은 정보 있는 환경에서 phase1 최종 IID `p_rule≥.75`와 phase1 시작 대비 증가 `≥.15`를 모두 충족할 때다. 설정의 `acquisition_accuracy`·`adaptation_accuracy`는 이 선택 확률의 고정 threshold 이름이며 실측 정답률을 뜻하지 않는다. H-L은 다음 두 조건을 모두 요구한다.

1. `linear`·`probabilistic`에서 습득한 시드가 전체10개 중8개 이상이다.
2. 같은 시드의 `linear` phase1 최종 IID `probabilistic−uninformative` 차이를 계산한 **전체10시드 평균이 .15 이상**이다.

두 번째 기준에 별도 양수 시드 개수 조건을 추가하지 않는다. 습득 미달 시드를 gap 평균에서 제외하지 않는다. .75, .15와8/10은 이 계산 진단의 실용 기준이며 생물학적 임계값이나 유의성 검정이 아니다. 조건 하나라도 미달하면 H-L은 미지지다. 결정적·다른 모델의 성공이나 phase2의 좋은 결과로 바꾸지 않는다.

배선 단계에서는 각 조건·환경의 기준 충족 개수와 모든 개별 시드 결과를 같은 산술 정의로 보고한다. 무정보 환경에도 같은 flag를 계산한다면 우연한 **기준 방향 threshold 충족**이며 실제 규칙 습득의 증거가 아니라고 표시한다. 새 선형 시드에서 H-L 수치를 재계산하더라도 독립 반복의 기술 결과이며 선형 단계의 gate 판정을 소급 변경하지 않는다. 실제 배선이 재배선·일반망보다 우수하다는 통과 기준은 없다.

## 반전과 보조 측정

phase2에서는 최종 IID 작은 수량 선택 확률≥.75를 목표 기준으로 기록하고, **같은 조건·환경의 phase1 습득과 동시에 충족했는지**를 별도 표시한다. 새 규칙 phase2 시작점은 이미 작은 수량 확률이 낮아진 상태일 수 있으므로 시작 대비 gain≥.15를 추가 성공 조건으로 삼지 않는다. 무정보 환경은 보상 규칙이 구별되지 않으므로 기준 방향 수치는 기술값이며 습득·수정 성공으로 해석하지 않는다.

각 시드·조건·환경에서 다음을 모두 보존한다.

- phase1·phase2 시작점·끝점·gain, IID/OOD `p_rule`, 큰/작은 수량 선택 확률, greedy 기준 방향 선택률과 사례별 `p_right`.
- phase2 다섯 checkpoint의 사다리꼴 적분/400인 raw AUC와 `raw AUC−phase2 trial0`인 출발점 조정 AUC.
- phase2 IID≥.75인 최초 **관측 checkpoint**. 미도달은 null이며 실제 최초 시행·지속 성공을 뜻하지 않는다.
- 실제 선택의 지정 방향 비율과 실제 받은 보상률. 평가 확률·greedy 점수와 다른 지표로 기록한다.
- 출력·내부 가중치의 누적/시행별 변위, KC/raw MBON/정규화 활성 변화와 clipping 경계 비율, head/internal update counter.
- 모든 미달 시드와 초기 습득을 확인한 뒤의 phase2 미달을 구분한 실패 내역.

모든 환경의 평가 기대 보상은 `expected_reward=q_other+(q_optimal-q_other)*p_rule`로 별도 기록한다. 정보 있는 확률적 환경에서는 `.2+.6*p_rule`이므로 기준 선택 확률1도 기대 보상률.8이다. 무정보 환경에서는 `p_rule`과 관계없이 기대 보상이.5다. 실측 보상률을 선택 확률이나 정확도라고 바꾸어 부르지 않고 무정보 `p_rule`을 최적 선택 확률·정답률이라고 부르지 않는다.

환경 차이는 같은 시드의 phase1/phase2 끝점·시작점·gain·AUC를 짝지어 기술한다. 배선 단계는 각 환경에서 plastic−fixed, rewired−real, ANN−real 차이를 해당 가소성 수준별로 모두 보고한다. 유리한 조합만 고르지 않고 평균·표본 SD·개별 시드·자원 차이도 함께 남긴다. errorbar는 신뢰구간이 아니다.

반전 끝점이 좋아졌더라도 phase1의 확신과 보상 잡음·선택 이력이 함께 달라진다. 출발점 조정만으로 학습 속도 자체를 분리한 인과 효과를 얻었다고 주장하지 않는다. fresh low 대조가 없으므로 이전 연구의 fresh−reverse endpoint cost를 새 수치처럼 계산하거나 총 경험을 통제한 비교라고 하지 않는다.

stay/switch를 파생 보고할 경우 같은 phase의 원 인접 시행에서 실제 선택한 수량2/4와 t의 실제 피드백을 사용한다. 좌우 이동을 선택 전환으로 세지 않고 경계400→401을 제외한다. 각 원800시행에서 후보799쌍·유효798쌍, phase별399쌍이며 분자·분모·정의되지 않은 비율(null)을 남긴다. 높은 stay 또는 feedback별 차이만으로 학습을 정의하지 않는다. [학습 없는 측정 대조](metric-calibration-protocol.md)의 해석 제한을 유지한다.

## 예산·원자료·동결

선형 단계는 `10시드×2조건×3환경×800=48,000`회의 실제 행동·피드백 표시다. `linear` head update는24,000회, `frozen`은0회이고 내부 update는0회다. 배선 단계는 `10×8×3×800=192,000`회 표시, frozen을 제외한 일곱 모델의 head update168,000회, 세 가소성 모델의 내부 update72,000회다. head와 internal을 모두 갱신한 한 시행을 별개의 두 선택 경험으로 세지 않는다. 정답 접근 기대 갱신은 두 단계 모두0회다. 평가·무보상 척도 계산·경계 저장은 실제 reward update에 더하지 않는다.

각 raw trial에는 stage·seed·environment·condition·phase·원 시행 번호·family·좌우 수량·선택 수량·action·실제 reward·갱신 전 p·행동/보상 uniform·선택 q·update 호출 여부·optimizer factor·가중치/활성 변화·counter를 남긴다. 환경이 q를 계산하는 정보와 learner가 받은 세 인자를 분리한다. 원 입력·공유 uniform·topology·모든 checkpoint·자원·등록·Git commit·환경·실행 시작/종료 UTC·재현 명령·전체 output SHA-256을 보존한다. 결과 경로는 배타 생성하며 덮어쓰기하지 않는다. 예외가 발생하면 실패 메타데이터와 이미 생성한 부분 로그를 보존한다.

최종 소스 동결 목록은 공통 구현·독립 검산·시험·두 설정·이 프로토콜·실제 import한 기존 소스·투영 원자료·manifest·license·환경 잠금 파일을 포함한다. 선형 과학 실행 전에 source commit과 등록 파일을 원격에 보존하고 원격 바이트 해시와 UTC 확인을 기록한다. 배선 등록은 gate 증거를 추가로 동결한다. gate 확인 후 결과에 맞춰 조건·시드를 바꾸지 않는다. 기존 소스 전체를 새 해시에 맞춰 수정하지 않으며 각 완료 태그의 별도 checkout에서 재현한다.

## 자동 시험과 독립 검산

작은 인공 fixture는 보상 임계값의 `<` 비교, 세 q 환경, 실제 선택 뒤 보상 생성, 학습 인자 분리, 공유 stream 위치, 첫 내부 step과 update counter 구분, 동결 update0, TRAIN-only 고정 척도, split disjointness, 고정/가소성 초기 동일성, 평가 상태·RNG 비변경, 단계 경계, 모든 시드와 미달 보존, H-L 경계값과 네트워크 gate 거부를 검사한다. 과학 시드로 사전 smoke를 돌리지 않는다.

독립 검산은 producer learner·보상 생성·요약 함수를 호출하지 않고 고정 입력·uniform·초기화에서 선택, 실제 보상, RMS 척도, 출력/내부 갱신과 전체 checkpoint 확률·AUC·판정을 재계산한다. source/input/output 해시·전체 coverage·graph 불변량·자원/counter·gate 증거·동결 선행 시각을 확인한다. NaN·불허 상태변화·누출·보상/선택 불일치·해시 불일치는 무결성 실패로 남긴다. 기준 미달과 혼동하지 않는다.

## 해석 범위와 기존 연구 보존

고정 중심화 갱신의 현재 상태에서 기대 계수는 자체 대수식 `p*(1-p)*(q_right-q_left)`다. .8/.2에서 결정적1/0 대비 크기는.6배이고 .5/.5에서는0이지만 유한 경로는 우연히 이동한다. 이것을 실제 생물학적 가소성이나 전체 확률 학습 경로의 정확한 기대값이라고 주장하지 않는다. clipping 구간에서 모든 상태의 정확한 기울기라고도 주장하지 않는다.

LC11·실제 DAN 조절·APL·재귀 회로·시각적 수량 추출·생리학적 시간은 구현하지 않는다. 계산 시드는 초파리 개체나 인간 참가자가 아니다. 확인 가능한 범위는 인공 입력의 보상 경험에 따른 변화인 Level2이며, 이번에 새 수량쌍 일반화 Level3을 검사하지 않는다. 기존 결정적 연구의 실패·M11 규칙 습득 실패를 새 성적으로 대체하지 않는다.

사람 과제에는 카드·금전·정보 요청·다른 확률 일정이 있고 이 모델에는 인공 수량·이진 선택·한 번의 고정 반전이 있다. 인간 학습의 장기 비교 목표는 유지하되, 이번 결과로 Level4의 정량 유사성·Level5의 공통 신경 기작·인간 수학 교육 효과를 주장하지 않는다. 학습 없는 대조에서 나타나는 지표와 실제 가중치 변화의 차이를 먼저 구분하고, 이후 별도 등록한 반증 가능한 비교 가설을 만든다.

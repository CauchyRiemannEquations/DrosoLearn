# 두 단계를 이어서 진행한 결과

작성일: 2026-10-15 (Asia/Seoul).

**코드 차이 확인을 마친 뒤, 독립적으로 진행할 수 있는 원본 재현 검사까지 이어서 실행했다.** 사람과 모델의 학습 성적을 비교한 단계는 아직 아니다.

| 단계 | 실제로 한 일 | 결과와 의미 |
|---|---|---|
| 1. 코드 의미 확인 | 공개 출처를 추가 조사하고 기존 대조 기록을 고정된 표로 집계 | 코드 불일치는 그대로 남음. 현재 대응에서 모든 파일에 공통인 숫자 치환 하나로 해결되지 않으며 실제 원인은 미해결 |
| 2. 원본→가공 자료 재현 | 공식 원본 25개에 저자의 변환 규칙을 적용해 기존 가공 표와 전 항목 대조 | **75,000항목이 결측 위치까지 일치**, 독립 검증도 통과. 확인 못 한 49행은 미검증으로 보존 |

쉽게 말하면, 첫 자료의 ‘숫자 사전’은 아직 완성하지 못했다. 대신 다른 자료에서는 ‘원래 기록을 정리해서 이 표를 만든 과정’을 직접 재현했다. 한 자료에서 막혔다고 값을 추측해서 메우지 않고, 확인할 수 있는 다른 작업을 계속 진행했다.

새 합성 테스트는 **총 109개(57+52)** 통과했다. 두 단계 모두 기준·코드·자료 해시를 고정하고 원격 기록을 확인한 뒤 실제 집계를 수행했다. 기존 결과·불일치·실패와 DrosoMem은 변경하지 않았다.

자세한 근거와 실행 방법은 [코드 차이 결과](human-semantics-findings.md), [공식 원본 재현 결과](human-osf-origin-findings.md)에 있다.

다음은 검증된 원본 범위에서 카드 선택·정보 요청·피드백의 뜻을 확인하고 **사람과 모델에 같은 뜻으로 적용할 지표를 정하는 작업**이다. 자료 재현 성공이 인간과 초파리 모델의 같은 학습 원리, 수학 이해 또는 교육 효과를 뜻하지 않는다.

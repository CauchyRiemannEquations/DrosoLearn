# 첫 실행에서 확인한 점과 실패 — smoke v1

2026-10-14, Asia/Seoul. 결과를 본 후 추가한 해석 문서다. 실행 전에 동결한 [프로토콜](experimental-protocol.md), 코드·설정 및 성공 기준은 바꾸지 않았다. 모든 원자료는 [smoke_v1](../results/smoke_v1/report.md)에 있고 10시드 확장 설정은 **미실행**이다.

## 실제 수행 범위

Python 3.12.10, NumPy 2.2.6, Matplotlib 3.10.3에서 3개 계산 시드·9조건·2단계 각400시행, 총 **21,600 학습 시행**을 실행했다. 정확한 runtime/platform은 [metadata.json](../results/smoke_v1/metadata.json)의 기록이 우선이다. 별도 구현이 21,600개 시행 갱신·270 checkpoint·1,350 평가 curve행·69,120 평가 case·289개 artifact hash를 검증했고 **passed=true**였다. [검증 기록](../results/smoke_v1/verification.json)

자동 검증 75개가 통과했다. 데이터 해시/ID, 누출, crossed cue, 재배선 불변량, finite-difference gradient, fixed/frozen mask와 평가 불변성, 설정·등록 drift, 기존 결과 덮어쓰기 거부, 독립 replay, byte/semantic tamper 검출, CLI 상대경로를 검사했다. Matplotlib–Pyparsing의 API deprecation warning 14건이 있었으며 테스트 실패는 없었다. 작은 테스트 fixture는 실제 연구 결과와 구분했다.

평가 case/시행/checkpoint 건수는 계산 및 기록을 검증한 횟수다. 같은 자극의 여러 조건·시점 평가와 crossed family 내 대응 사례가 포함되므로 독립 표본수나 통계적 검정력을 뜻하지 않는다. 생물학적 개체는 실험하지 않았다.

## 습득은 일부 성립했지만 반전은 실패했다

지표는 결정론적 최대점수 선택이 아니라 **확률적 정책의 정확한 정답 선택 확률 평균**이다. 원래 고정 회로는 평균0.4988→0.8096, 가소성 회로는0.4988→0.9371이었다. 원래 fixed는2/3시드, plastic은3/3시드가 습득 기준을 통과했다. fixed seed303의0.747861은 기준0.75 미달이므로 실패로 보존했다. 반올림으로 성공으로 바꾸지 않는다.

OOD 인공 descriptor 조건은 original fixed2/3·plastic3/3이 습득+일반화 gate를 통과했다. 이는 실제 새로운 점 배치를 보고 수량을 추출한 결과가 아니라 이미 제공된 n/8을 사용하는 선택 정책의 descriptor shift 견고성이다.

**보상 반전은 모든 조건에서 사전 기준 미달**이다. 원래 fixed의 반전 후 평균0.5077, plastic0.5563으로0.75에 도달하지 못했다. 최초 습득 실패 시드의 반전은 습득조건부 해석 대상에서도 제외한다. 400시행 뒤 기존 선호가 줄었다는 변화와 새 규칙 습득 성공을 구분한다. 학습 횟수를 늘려 이 등록을 성공으로 만들지 않았다.

## 가소성 개선과 배선 고유성은 다르다

재배선 plastic 평균0.9432, ANN plastic0.9443도 습득했고 original plastic0.9371보다 수치상 약간 높았다. fixed/plastic 비교의 향상은 세 구조에서 모두 나타났다. 원래 배선 우위를 지지하는 결과는 확보하지 못했다. 3시드의 작은 차이로 어느 배선이 우월하거나 동등하다는 통계적 결론도 내리지 않는다.

가소성은1,474개의 추가 trainable parameter를 가진다. 같은48개의 readout과 시행을 사용해도 총 학습 자원은 고정 조건과 다르다. 내부만 갱신한 internal_only는 평균0.5015로 습득 기준을 **0/3** 통과했다. 내부 가중치와 MBON 활성은 변화했지만 그것만으로 이 고정된 초기 readout에서 행동 학습이 충분하지 않았다. 이 결과를 내부학습 일반의 불가능성이나 실제 초파리의 결함으로 해석하지 않는다.

frozen은 동일 성능·내부/출력 불변을 유지했고 random_reward는 평균0.4908로 정답 규칙을 습득하지 않았다. 이 대조들은 구현의 기대된 방향을 점검하지만 인공 모델의 생물학적 타당성을 검증하지 않는다.

## 허용되는 주장과 다음 연구

현재 근거는 특정 oracle 입력을 구별하고 보상에 따라 모델이 변한 Level1/2, 습득 gate를 통과한 경우의 제한된 입력 일반화 Level3이다. 새 수량쌍에 높은 성능이 있어도 입력 scalar가 순서를 이미 주므로 수학적 규칙의 발견으로 해석하지 않는다. LC11 시각 회로, DAN 구획 modulation, 실제 시냅스 기작, 인간 공개 자료의 정량 비교, Level4/5는 실행하지 않았다.

다음 실험은 반전 실패를 먼저 별도 가설로 다룬다. 처음부터 작은 수량에 보상하는 새 모델, 학습→반전 모델, 동일 시행의 무반전 모델을 비교해 초기 confidence·출력 학습·내부 clipping·학습 자원이라는 대안을 분리할 수 있다. 이는 **이번 결과에서 제안하는 새 가설**이며 검증된 원인이 아니다. 고정 decoder 크기 및 내부/출력 갱신 자원의 대조를 먼저 등록한다. 입력 표현·활성 sparsity가 차이를 만드는지도 별도 변인으로 시험한다.

기초 학습/수정의 재현성을 확보하기 전 mod-11이나 고난도 수열로 확대하지 않는다. 기존 M11 실패는 유지한다. 인간 비교는 [공통 지표 체계](human-learning-comparison.md)의 공개자료 schema/라이선스 확인과 원 분석 재현부터 진행하며 교육적 권고는 하지 않는다.

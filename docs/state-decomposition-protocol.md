## 네 정적 조합의 뜻

같은 모델·분기의 기준 출력을 `h0`, 기준 내부 가중치를 `W0`, 대상 checkpoint의 값을 `h1`, `W1`이라고 한다. W0는 원래 미학습 가중치가 아니라 **공통 첫 학습이 끝난 가중치**다. encoder·bias·연결 위치·최초 clipping 상한·incoming 정규화·특징 척도는 모든 상태에서 정확히 같아야 한다.

| 정적 조합 | 출력 계수 | 내부 가중치 |
|---|---|---|
| `00` | 기준 h0 | 기준 W0 |
| `10` | 현재 h1 | 기준 W0 |
| `01` | 기준 h0 | 현재 W1 |
| `11` | 현재 h1 | 현재 W1 |

이 조합 이름은 실제 학습 분기 이름과 다르다. 예를 들어 full 분기의 정적 10은 full에서 얻은 현재 출력을 기준 내부와 조합한 값이며, 실제 `head_only` 학습 분기의 결과가 아니다. 01도 실제 `internal_only` 학습과 동일시하지 않는다. 교차 상태는 실제 경험한 경로 밖의 조합일 수 있다.

각 정적 조합은 같은 평가 사례에서 계산한다. 기준 00도 원래 첫 단계의 큰 수량 목표가 아니라 **같은 작은 수량 목표**로 표시한다. 목표 방향 변경을 가중치 변화의 효과에 섞지 않는다.

## 원점수 분해

고정 입력 x에서 KC 활동은 고정 encoder와 bias의 ReLU다. MBON은 고정 연결 위치에서 가중치 선형합이며, 최초 TRAIN에서 정한 정규화 척도 g를 계속 쓴다. 오른쪽과 왼쪽 특징 차이를 ψ(W)라고 하면 선택 원점수 차이는 `d(h,W)=h·ψ(W)`다. 두 상태 차이는 다음과 같다.

```text
Δh = h1-h0
Δψ = ψ(W1)-ψ(W0)
d11-d00 = Δh·ψ(W0) + h0·Δψ + Δh·Δψ
           출력 변화 항   내부 특징 변화 항   교차항
```

`d11-d10-d01+d00`와 교차항도 일치해야 한다. 각 사례의 양쪽 항등식 절대 잔차가 **1e-10 이하**여야 한다. 평균 잔차가 작다는 이유로 큰 개별 오류를 무시하지 않는다. NaN·무한대·필드 누락·위치 불일치·상태 변경·해시 불일치는 무결성 실패다.

원점수 d는 오른쪽−왼쪽이다. 좌우를 균형화한 입력에서 그대로 평균하면 효과가 상쇄될 수 있으므로 작은 수량이 오른쪽이면 `s=+1`, 왼쪽이면 `s=-1`로 두고 네 점수와 세 항·전체 변화를 모두 `s*값`으로 정렬한 열도 저장한다. 해석과 그림은 이 **목표 방향 정렬 값**을 사용한다. 원래 오른쪽−왼쪽 값도 그대로 보존한다. 원점수는 선택 확률이나 보상률이 아니다.

선형 모델에는 내부 연결이 없으므로 내부 특징 변화 항과 교차항은 0이어야 한다. 실제 head_only 분기는 내부 변화 항·교차항이, internal_only 분기는 출력 변화 항·교차항이 0이어야 한다. frozen과 t0에서는 모든 변화가 0이어야 한다. 비활성 성분의 원 배열 동일성과 산술 0을 함께 확인한다.

## 확률·포화는 따로 본다

각 조합에서 `p_right=sigmoid(clip(d,-40,40))`를 계산하고, 작은 수량이 오른쪽이면 p_right, 왼쪽이면 `1-p_right`를 `p_rule`로 저장한다. 00과 11은 부모에 저장된 사례별 p_right와 **절대 오차 1e-12 이하**로 일치해야 한다.

`p11-p10-p01+p00`를 오른쪽 선택 확률과 목표 선택 확률 각각에서 기록한다. sigmoid와 clipping 이후 확률은 이중선형이 아니므로 이 상호작용은 원점수 교차항과 다른 값이다. 어느 항이 전체 변화의 몇 퍼센트를 인과적으로 만들었다는 비율을 계산하지 않는다. 양·음 항이 상쇄되거나 전체 변화가 0인 경우도 그대로 보존한다.

`abs(d)>40`인 조합별 사례를 clipping으로 표시한다. 정확히 ±40이면 clipping 표시는 0이다. clipping 비율과 확률의 포화 가능성을 기술하되 실제 생물학적 확신이나 신경 포화로 확대하지 않는다.

## 결과 분모·그림·검산

사례 좌표는 `10×4×4×5×2×128=204,800`, 네 조합 정책 값은 **819,200개**다. 이는 계산 평가 수이며 새 선택 경험·보상 갱신 수가 아니다. 추가 학습 갱신·학습자 구성·데이터 생성·난수 추출은 모두 0이다. 이미 기록된 첫 습득·반전 성공 여부로 시드·분기·사례를 제외하지 않는다.

시드별 CSV에 모든 사례·family·좌우 수량·작은 수량 목표·원점수 네 조합·세 분해항·정렬 값·잔차·정책 확률·clipping 표시를 남긴다. 모델·분기·시간·평가 split별로 모든 시드와 사례를 요약한다. 원점수/확률 단위와 사례 내 변이/시드 간 표본 SD를 구분한다.

그림 범위는 모든 네 모델·full 분기·반전 최종 checkpoint·IID·전체 10시드로 미리 고정한다. 첫 그림은 목표 방향 정렬 원점수의 세 항과 총변화, 둘째는 네 정적 조합의 목표 선택 확률이다. 나머지 분기·시점·OOD도 전체 CSV와 summary에 보존한다. 표본 SD는 신뢰구간이 아니며 유리한 하위집단을 추가 선택하지 않는다. 독립 검산 통과와 입력·검산·코드 해시 연결 뒤 별도 sibling 폴더에 그림을 배타 생성한다.

독립 검산은 producer·학습자 forward·요약을 호출하지 않고 이전 독립 감사의 수학 helper만 명시 재사용한다. 실제 부모 입력과 상태에서 네 조합·세 항·정렬·모든 정책 값·잔차·요약을 다시 계산하고, 원 입력/소스/Git/부모 gate/coverage/출력 해시와 비활성 대조를 검사한다. 개발 시험은 기존 완료된 시드 17/18·8시행 fixture를 복사해 정적 계산만 실행한다. 기존 원 파일 142개를 바이트 그대로 묶은 ZIP·파일별 manifest·출처 표시를 `data/engineering_fixtures/`에 함께 보존해 별도 checkout에서도 로컬 임시 경로 없이 시험할 수 있게 한다. 묶음 SHA와 각 원 파일 SHA를 확인하고 경로를 안전하게 복원하며, 새 학습을 fixture 준비에 사용하지 않는다. 재해시 후 의미 변조·분모 누락·기준 목표 혼동도 거부해야 한다.

실패 시 부분 로그와 실패 metadata를 보존하고 결과를 덮어쓰지 않는다. 완료된 코드·원자료·실패·이전 문서 정정을 소급 수정하지 않는다. DrosoMem은 그대로 보존한다.

## 해석과 종료 범위

이 분석은 현재 모델의 계산 구조와 저장된 상태의 관계를 기술한다. 같은 최종 행동도 출력 계수·내부 특징·확률 변환의 여러 조합에서 나올 수 있어 행동만으로 내부 학습을 단정하지 않는 데 도움이 된다. 새 수량·수학 규칙의 습득이나 일반화를 검사하지 않는다.

입력에 수량 순서가 이미 제공되며 실제 시각적 수량 인지·LC11/DAN 회로·동물 가소성을 재현하지 않는다. 계산 시드는 독립 동물이나 인간 참가자가 아니다. 인간 학습 비교라는 장기 목표를 유지하되 이번 산술 분해를 Level4 정량 유사성·Level5 공통 신경 기작·교육적 효과로 확대하지 않는다. 이번 결과·검산·재현 자료를 저장하면 작업을 종료하며 자동으로 다음 연구에 착수하지 않는다.

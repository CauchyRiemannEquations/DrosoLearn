# 확률적 보상 학습 — 재사용 감사와 후속 실행 설계

작성일: 2026-10-16 (Asia/Seoul). 이 문서는 기존 소스를 읽어 정리한 **실행 전 설계 제안**이다. 실제 과학 시드 실행 결과가 아니며, 새 설정·별도 프로토콜·소스 동결·등록을 대신하지 않는다. 최종 예산과 판정은 각 후속 실행의 등록 파일에 하나의 값으로 고정한다.

## 쉽게 설명하면

앞선 모델에서는 정해진 답을 고르면 항상 보상을 받았다. 이번에는 좋은 선택도 가끔 보상을 받지 못하고, 나쁜 선택도 가끔 보상을 받는 환경을 만든다. 예를 들어 처음에는 4개 선택이 80%, 2개 선택이 20%의 확률로 보상을 받는다. 이후 이 관계를 바꾼다. 모델은 자신이 실제로 받은 결과만으로 선택을 바꿔야 한다.

먼저 아무것도 배우지 않는 선택 규칙만으로도 ‘보상 뒤 같은 것을 고르는 비율’이 얼마나 달라지는지 확인한다. 그다음 단순 학습자로 과제가 풀리는지 확인하고, 학습이 성립한 경우에만 같은 과제를 실제 배선·재배선·일반망으로 확장한다. 성적이 낮다는 이유로 연습 횟수나 시드를 바꿔 성공을 만드는 순서는 아니다.

입력에는 이미 수량을 나타내는 `n/8`이 주어진다. 따라서 물체를 보고 개수를 알아내는 능력이나 인간의 수학 이해를 시험하지 않는다. 사람 자료와 보상 조건이 조금 비슷해져도 같은 과제가 되지는 않는다.

새 모듈에서 기존 클래스를 import할 수 있다. 기존 연구의 소스·설정·등록·결과·해시를 최신 구현에 맞춰 갱신하지 않는다. 과거 재현은 각 완료 태그의 별도 checkout에서 수행한다. 새 등록에는 실제로 의존하는 기존 소스의 바이트 해시도 포함한다.

**동결 대조의 주의점:** `NormalizedLearner.update`는 부모의 `learning`이나 `head_learning` 플래그를 확인하지 않고 출력 계수를 갱신한다. `LinearLearner` 역시 update를 호출하면 갱신한다. 따라서 flag만 바꿔 동결했다고 가정하면 안 된다. 새 동결 wrapper는 update를 호출하지 않아야 하며 출력·내부 가중치와 update counter가 처음 상태를 유지함을 검사한다. 초기 출력이 모두 0이면 이 동결 대조의 모든 입력 선택 확률은 정확히 .5다. 실제 행동·보상 표시는 가능하되 학습 호출 수는 0이다.

## 보상 환경과 중심화

현재 단계에서 보상을 더 자주 받는 후보를 `optimal`, 다른 후보를 `other`라 부른다. `optimal`은 평가용 환경 정의이고 학습 함수의 입력이 아니다. 행동을 먼저 뽑은 뒤 해당 선택의 확률 `q`와 별도 보상 uniform `v`로 `reward=int(v<q)`를 생성한다.

| 환경 | `P(reward=1|optimal)` | `P(reward=1|other)` | 역할 |
|---|---:|---:|---|
| 결정적 | 1 | 0 | 이전 환경과의 구조 대조; 새 시드의 별도 실행 |
| 정보 있는 확률적 | .8 | .2 | 주 학습 환경 |
| 정보 없는 확률적 | .5 | .5 | 선택 방향에 대한 정보가 없는 대조 |

처음 400시행의 optimal은 큰 수량, 다음 400시행은 작은 수량이다. 정보 없는 환경에서 이 `optimal`은 보상 우세 후보를 뜻하지 않는다. 동일한 평가 축을 유지하기 위해 지정한 기준 방향일 뿐이다. 이 환경의 높은 끝점 확률을 참 규칙 습득으로 해석하지 않는다.

재사용하는 갱신은 `factor=(action-p_right)*(reward-.5)`다. .5는 고정 중심화 기준이다. 새로 학습하는 보상 예측값, 생물학적 도파민 신호, 검증된 보상 예측 오차가 아니다. 선택과 받은 이진 보상만 `update(inputs, action, reward)`에 전달한다. 현재 정답, 보상 확률 `q`, 잠재 반대 행동의 결과, eval 값은 전달하지 않는다.

현재 상태와 입력을 고정하면 다음 자체 대수식이 성립한다.

`E[(action-p_right)*(reward-.5)] = p_right*(1-p_right)*(q_right-q_left)`

따라서 .8/.2 환경의 기대 갱신 방향 크기는 결정적 환경의 .6배이며, .5/.5에서는 기대 방향이 0이다. 그러나 유한한 선택·보상 경로에서 .5/.5 학습자의 계수와 평가 확률은 우연히 움직일 수 있다. 무정보 대조를 매 시행 .5 선택으로 강제하지 않는다. 이 한 단계 조건부 기대식을 반복한 궤적도 실제 확률적 학습 전체의 정확한 평균 경로는 아니다. 정답을 쓰는 기존 `ExpectedLinear` 참조를 실제 보상 학습 조건에 섞지 않는다.

## 실행 단계를 나누는 방법

1. **측정 대조:** 고정 선택 편향·고정 반복 성향과 보상 방식만으로 생기는 stay/switch 지표를 계산한다. 학습 전후의 변화나 내부 가중치 변화가 없는 자료임을 표시한다. 시행별 실제 선택과 실제 보상으로 측정하고, 확률을 행동처럼 세지 않는다.
2. **단순 학습 검증:** `linear_normalized`의 세 보상 환경과 update 없는 동결 대조를 끝까지 실행한다. 새 과학 시드 후보는 10001–10010이다. 과학 시드를 개발 fixture·학습률 선택에 사용하지 않는다. 무정보 학습 대조는 .5/.5 환경 자체이며, 같은 역할의 이름만 다른 대조를 독립 표본처럼 중복 집계하지 않는다.
3. **배선·가소성 확장:** 단순 학습 검증의 정보 있는 환경에서 사전 습득 gate를 충족하고 무결성 검산도 통과한 경우 새 등록으로 확장한다. 조건은 `linear_normalized`, `fixed`, `plastic`, `rewired_fixed`, `rewired_plastic`, `ann_fixed`, `ann_plastic`의 일곱 모델이다. 그중 그래프 모델은 여섯이다. 확장의 독립성을 높이려면 새 시드 11001–11010을 별도 등록한다. 같은 수치 시드 재사용을 택한다면 선택·보상·입력 stream의 관계와 이전 결과를 보고 확장했음을 명시한다.

실행 가능 여부와 연구 가설의 지지를 구분한다. NaN·해시 불일치·누출·불허 상태 변화는 무결성 실패이며 수리 전에 기존 실패 기록을 보존한다. 반면 규정 예산에서 습득 기준 미달은 과학적 미지지다. 미지지일 때 배선 모델에서 성공 예를 찾는 확장을 자동으로 진행하지 않는다. 추가 진단 질문·새 예산은 후속 별도 프로토콜로 만든다. 반전 성공을 배선 확장의 전제와 혼동하지 않는다. 먼저 첫 규칙 학습이 성립하는지를 gate로 삼는 것이다.

최소 주 이력은 high400→low400이다. 반전 비용을 주장하려면 새 규칙 low400을 처음부터 받는 `fresh_low` 대조도 권장한다. fresh는 같은 초기 phase1 TRAIN 입력으로 무보상 척도만 계산하고, 동일 phase2 입력·행동·보상 uniform을 사용한다. 같은 규칙 반복·head reset·감쇠 수준을 추가할 경우 실행 전에 별도 조건과 예산을 명시한다. 이전 감쇠의 유리한 수준을 새 기본 조건으로 조용히 옮기지 않는다.

## 공유 난수와 누출 방지

- 입력 split은 이전과 같은 2대4 교차 자료를 새 시드로 만들되 phase1 TRAIN, phase2 TRAIN, IID128, nuisance OOD128을 분리한다. 여섯 nuisance 좌표가 수량·좌우 위치에 교차하도록 보존한다. 모든 split의 방향 독립 fingerprint 교집합이 공집합인지 실제 검사한다. 수량 oracle은 1, 각 nuisance-only는 .5여야 한다.
- 초기 특징 차이의 RMS 척도 `g`는 **초기 phase1 TRAIN 입력만**으로 구해 고정한다. 미래 phase2 입력, 평가 입력, 정답, 보상, 학습된 가중치로 맞추지 않는다. fresh에도 같은 무보상 전처리 자료를 허용했음을 명시한다. 엄밀히 미래 입력을 전혀 보지 않는 온라인 모델이라는 표현은 쓰지 않는다.
- 행동 uniform과 보상 uniform은 서로 독립된 stream으로 만든다. 예를 들어 phase1 행동 `seed+480000`, 보상 `seed+490000`, phase2 행동 `seed+500000`, 보상 `seed+510000`처럼 이전 실행과 구별한 offset을 등록한다. 실제 offset은 최종 설정에 고정한다.
- 같은 시드·phase·원 시행 번호의 행동 uniform과 보상 uniform을 모델·환경·이력 사이에 공유한다. 각 시행에서 선택과 관계없이 각 uniform 위치를 하나씩 사용한다. 선택별로 다른 RNG 호출 수를 쓰거나 fresh 생략·분기 수에 따라 phase2 stream이 밀리면 안 된다.
- stream 공유는 같은 실제 행동·보상을 보장하지 않는다. 정책이 다르면 행동이 달라지고, 선택의 보상 확률도 다르다. 환경 사이에 같은 보상 uniform을 쓰는 것은 재현 가능한 짝지음이며 환경 표본을 독립 관측으로 만드는 장치가 아니다.
- 평가는 잠근 probe 입력에서 `p_optimal`, `p_large`, `p_small`, greedy와 각 사례 `p_right`를 계산한다. 평가에서는 행동·보상 RNG를 소비하거나 학습하지 않는다. 가중치·encoder·bias·척도·counter와 난수 상태가 바뀌지 않아야 한다. 반복 평가 결과로 학습률·예산·gate를 조절하지 않는다.

## 평가 기준 제안

checkpoint는 단계별 0·100·200·300·400시행으로 고정한다. `p_optimal`은 환경이 정한 현재 우세 선택을 할 확률의 사례 평균이고 **실측 보상률과 다르다**. .8/.2 환경에서 이 선택 확률이 1이어도 기대 보상률은 .8이다. 기대 보상은 `.2+.6*p_optimal`로 별도 기술할 수 있으나 실제 받은 보상은 시행 로그에서 계산한다. .5/.5의 방향 평가는 `p_designated`처럼 명확한 이름을 쓴다.

단순 학습의 사전 gate 후보는 다음을 모두 요구하는 것이다. 최종 등록에서 기준을 채택하거나 다른 하나의 값을 정하고, 과학 실행 뒤 바꾸지 않는다.

- 정보 있는 .8/.2 환경 phase1의 IID `p_optimal≥.75` 및 시작 대비 gain≥.15인 시드가 8/10 이상이다.
- 같은 시드의 정보 있는 환경−무정보 학습 환경의 phase1 최종 지정 방향 확률 차이를 모든 시드에 대해 보존한다. 전체 평균≥.15 및 엄격한 양수 시드 8/10 이상을 정보 사용의 별도 기준으로 둘 수 있다.
- 동결 대조는 가중치·counter·평가 확률 .5 불변을 무결성으로 확인한다. 과학 gate의 성적이 정확히 .5라는 뜻과 무정보 **학습** 경로가 평균 .5 근처라는 뜻은 구분한다.

phase2 수정은 phase1 습득을 확인한 뒤 `p_small≥.75`인 시드를 별도로 센다. 모든 시드의 phase2 시작점·끝점·gain·raw AUC·시작점을 뺀 AUC·최초 관측 .75 checkpoint(미달 null)를 보고한다. 습득 미달 시드를 전체 평균에서 지우지 않는다. 확률적 환경의 반전 끝점이 결정적 환경보다 좋아도 이전 규칙의 확신이 덜 강한 출발점, 보상 잡음과 경험한 선택 이력이 함께 바뀐다. 결과 하나로 학습 능력 자체가 빨라졌다고 주장하지 않는다. fresh가 있으면 endpoint cost를 추가하되 .8/.2와 결정적 환경의 총 경험·시작점도 함께 표시한다.

stay/switch는 같은 phase의 원 인접 두 시행 모두 유효한 실제 이진 선택일 때만 계산한다. 선택 정체성은 왼쪽/오른쪽이 아니라 **선택한 수량 2/4**로 맞춘다. 좌우가 바뀌어도 같은 수량은 stay다. 경계를 건너거나 평가·반사실 확률을 실제 선택으로 세지 않는다. 기존 공통 지표의 식을 재사용하더라도 새로운 모델 로그 적용은 새 입력 해시·출력 경로·등록을 가진다.

재배선은 KC outgoing strength, type/compartment 구조를 보존하지 않는다. 일반망은 KC outdegree도 보장하지 않는다. zero-output 슬롯19개와 사용 가능한 추가 내부 가중치까지 자원 보고에 남긴다. 고정/가소성 쌍은 같은 encoder·bias·초기 내부 상태·척도에서 출발한다. 초기 출력0, head 학습률.1, internal 학습률.01을 기존 구현에서 재사용할 수 있다. 내부 변화는 갱신 전 head를 이용하고 기존 anatomical mask와 `[0,2*initial_weights]` 범위에 제한한다. 이 규칙은 단순화된 계산 규칙이다.

공유 시행 수·고정 RMS만으로 선형과 네트워크의 계수 수·특징 방향·상관·표현 용량이 같아지지는 않는다. 내부 가소성의 효과와 추가 자원의 효과도 완전히 분리하지 못한다. 실제 배선의 우수성을 성공 목표로 삼지 않는다. LC11·실제 DAN 조절·APL·재귀 연결·실제 시간·살아 있는 동물을 구현하지 않는다.

## 원자료·보존과 독립 검산

로그에는 환경·모델·시드·이력·phase·원 시행 번호·stimulus family·좌우 수량·선택한 수량·갱신 전 확률·행동 uniform·보상 uniform·선택의 보상 확률·실제 reward·학습 호출 여부·갱신 계수·출력/내부 step 크기를 남긴다. 환경의 정답과 `q`는 검사 가능한 원자료일 뿐 학습자 인자에서 분리한다. 모든 checkpoint에서 내부 가중치·출력 계수·KC/raw MBON/정규화 활성과 counter를 구분해 보존한다.

물리적 선택·피드백 표시 수, 실제 head/internal update 호출 수, 평가 사례 수, 기술 참조 계산 수를 따로 집계한다. 동결의 reward 표시를 update 수에 더하지 않는다. 과학 실행은 고정된 전체 시드·예산을 끝까지 실행하고 실패·예외·부분 로그도 새 경로에 남긴다. 이전 M11·기존 독립 보상·반전·감쇠의 실패를 새 성공으로 대체하지 않는다.

독립 검산은 producer의 learner·reward 함수·summary를 호출하지 않고 저장 입력·uniform·초기 상태에서 행동, 실제 보상, 고정 척도, head/internal 갱신, 모든 probe 확률, 판정을 다시 계산한다. graph 불변량·split fingerprint·동결 상태 불변·전체 coverage·원자료 해시·등록 후 소스 불변과 원격 동결→실행의 UTC 순서를 확인한다. fixture는 과학 시드가 아닌 작은 인공 자료에서 경계값·모든 reward 모드·보상 uniform의 임계값·동결·위치 반전·누출·평가 상태 비변경을 검증한다.

이번 설계는 새로운 신경과학 문헌 주장을 추가하지 않는다. 기존 소스와 자체 대수식에 근거한 계산 실험이다. 인간 자료의 카드·금전·정보 요청·확률 일정과 모델의 수량·이진 선택·한 번의 반전은 여전히 다르다. 사람이 실제로 푼 과제를 재현하거나 Level4의 정량 유사성, Level5의 신경 기작, 인간 수학 교육 효과를 주장하지 않는다. 이 대조를 통해 측정값이 어떤 계산 조건에 민감한지 먼저 파악한 뒤 새로운 비교 가설을 세운다.

# 시간 혼합 반례의 독립 검산 설계

작성일: 2026-10-19 (Asia/Seoul). 연구 ID `time_mixture_v1`. 이 문서는 과학 설정 실행 전의 독립 검산 계획이다.

## 쉽게 설명하면

시간표에 따라 선택 습관과 결과의 확률을 함께 바꾸면, 보상을 보고 배우지 않아도 좋은 결과 뒤와 나쁜 결과 뒤의 행동 통계가 달라질 수 있다. 이번 검산은 같은 숫자를 서로 다른 두 계산법으로 얻는지 확인한다. 주 코드는 바로 이웃한 두 선택의 경우를 세고, 독립 코드는 가능한 **전체 선택·결과 경로**를 모두 세어 그 경로들에서 이웃한 선택을 다시 모은다.

이는 과거 사람이나 모델의 차이가 시간 혼합 때문에 생겼다는 증거가 아니다. 현재 선택·상태를 나눴다는 이유만으로 시간과 이력에 관한 모든 대안 설명이 없어지지는 않는다는 논리 반례다. 인간 자료의 정확한 과거 실행판 미확인과 직접 비교 게이트는 그대로 유지한다.

## 다른 계산법과 측정량

주 코드는 각 원 인접쌍의 현재 선택·다음 선택·현재 피드백에 대한 8개 국소 사건 확률을 `Fraction`으로 계산한다. 독립 코드 `scripts/verify_time_mixture.py`는 이 함수를 불러오거나 주 모듈을 import하지 않는다. 표준 라이브러리만 사용한다.

독립 방법은 9개 선택 비트와 첫 8개 시행의 피드백 비트가 만드는 `2^(9+8)=131,072`개 전체 경로를 **조건마다** 모두 열거한다. 확률을 10분의 정수 가중치로 옮겨 각 경로의 가중치를 정수 곱으로 계산한다. 공통 분모는 `10^17`이다. 모든 경로의 합이 정확히 1이 되는지 확인하고, 각 경로에서 원래 시간 `t`의 선택·피드백과 `t+1` 선택을 세어 사건별 가중치를 합한다. 4조건 총 524,288개는 가능한 경로의 계산 수이며 실제 표본 시행·사람·동물 수가 아니다.

그 뒤 선택·피드백별 기대 유지 횟수 `E[S]`, 기대 전환 횟수, 기대 분모 `E[D]`를 정수 합에서 `Fraction`으로 변환한다. 주 지표는 **`E[S]/E[D]`**다. 난수로 얻은 경험 비율의 평균 `E[S/D | D>0]`을 계산하거나 같은 값으로 주장하지 않는다. 분모가 0이면 비율과 해당 차이는 `null`이다. 0으로 채우지 않는다. 확률 0인 사건도 삭제하지 않는다.

전체 시간을 섞은 값과 원 시간별 값을 모두 확인한다. 원 시간·현재 선택을 고정하면 피드백별 유지율 차이는 정의되는 경우 정확히 0이다. 선택 확률 고정, 피드백 확률 고정, 둘 다 고정한 세 대조 조건도 정의되는 차이가 정확히 0인지 검산한다. 시간 혼합 조건의 사전 예상은 선택 0에서 `9/56`, 선택 1에서 `-9/56`이다. 이는 시간표가 제공하는 반례의 산술 예측이며 인간 또는 초파리의 관찰값이 아니다.

## 바이트와 선행 게이트

독립 검산은 숫자만 비교하지 않는다. 별도 등록의 설정·코드·시험·프로토콜·고정 의존성 전체와 실제로 실행된 verifier의 SHA-256을 확인한다. 두 부모 연구의 원 등록·설정·완료 metadata·독립 검산·전체 10개 주 산출물을 각각 확인하고 등록과 검산의 연결을 검증한다. 인간 과제 구조의 원 결과·등록·독립 검산도 연결하며 `direct_human_model_similarity_allowed=false`가 유지돼야 한다. 실제 인간 MAT나 과거 모델 시행을 새로 분석하지 않는다.

현재 출력은 등록 사본·metadata·전체 국소 사건·전체 지표의 정확한 목록과 SHA-256을 대조한다. 누락·중복·추가 사건, 시간 좌표 변경, 분자·분모·비율·가설 플래그 변경, 자원 수 변경과 UTC 순서 위반은 실패다. 원격 등록의 실제 게시 바이트와 Git 이력은 root의 별도 보존 검증이 담당한다. 이 독립 코드만으로 원격 게시를 확인했다고 주장하지 않는다.

## 실행 전 시험 범위와 결과의 의미

자동 시험은 2–3시행의 인공적인 짧은 시간표만 사용한다. 과학 설정의 9시행 반례는 등록·원격 동결이 끝나기 전에 실행하지 않는다. 짧은 producer 결과와 전체 경로 독립 계산의 일치, 수작업 분수, 확률 0 사건, 분모 0, 정확한 시간 조건화, 세 고정 대조, 분수의 정규 표현, 경로 탈출·중복 JSON·UTC·덮어쓰기 방지 및 재해시 후 의미 변조를 검사한다.

검산 통과는 논리 반례와 처리의 산술 정합성을 뜻한다. 독립 검산의 통과, 사전 반례 가설의 지지, 실제 인간–모델 비교 가능성은 서로 다른 판정으로 기록한다. 추가 학습 갱신·학습자 구성·표본 시행·난수 추출은 모두 0회다. Level 4 인간 유사성·Level 5 공통 신경 기작·교육 효과를 주장하지 않는다.

# 인간의 시행별 기록을 실제로 확인한 결과

작성일: 2026-10-15 (Asia/Seoul). 완료 보존 태그: `human-trial-data-audit-v1`.

## 먼저 쉽게 설명하면

**사람이 한 번씩 무엇을 골랐는지 기록한 공개 자료를 확보하고, 읽고 검사하는 도구까지 실행했다.** 이전의 연습 전후 성적표보다 자세한 기록이다. 다만 그 기록만으로 사람과 모델이 같은 방식으로 배우는지 판단할 준비가 끝난 것은 아니다.

예를 들어 화면 왼쪽을 골랐다는 기록은 있어도, 도형 위치가 매번 바뀌면 어떤 도형을 계속 고른 것인지 알 수 없다. 정답에 유리한 도형을 골라도 확률적으로 보상을 받지 못할 수 있다. 따라서 ‘왼쪽 선택’, ‘좋은 피드백’, ‘정답 선택’을 구분해야 한다. 이번에는 이 구분과 자료의 빈틈을 확인했다.

## 주 자료에서 실제로 확인한 수치

[OpenNeuro ds004295 v1.0.0](https://openneuro.org/datasets/ds004295/versions/1.0.0/download)의 작은 행동·사건 기록 부분만 보존했다. 원자료는 CC0다. EEG 신호, 인구통계, 자극 그림은 이번 수집에 포함하지 않았다.

| 항목 | 확인 결과 | 의미 |
|---|---:|---|
| 원본 파일 | 31개 / 1,934,671바이트 | 사건 TSV 26개, 메타데이터 3개, 행동 MAT 2개 |
| 사건 기록 | 44,262행 | 한 행이 문제 한 번은 아님 |
| 관측된 선택 사건 | 14,568개 | 전부 새 CSV에 보존; 원 예정 시행 번호는 아님 |
| 엄격한 연결 규칙을 통과한 묶음 | 13,954개 | 같은 과제 안에서 선택–기대 보고–피드백을 순서대로 연결한 후보 |
| 불완전하거나 모호한 선택 묶음 | 614개 | 삭제하거나 정답·오답으로 바꾸지 않음 |
| 구조 문제 표시 | 1,720건 | 서로 독립된 시행 수나 사람의 실패 횟수가 아님 |
| MAT의 기록 단위 | 변수마다 23개 cell × 280값 | 26개 사건 파일과 참가자 대응을 가정하지 않음 |

**13,954개는 ‘정상 학습 시행’으로 확정한 분석 표본이 아니다.** 정해 둔 보수적인 사건 연결 규칙을 통과했다는 뜻이다. 기대 보고가 여러 번 찍히거나 중단 표시가 짝을 이루지 않으면 연결을 유보했다. 하나의 경계 문제가 여러 후속 사건에 문제 표시를 남길 수도 있다. 원 연구의 참여자 제외 기준을 새로 적용하거나 잘 연결되는 파일만 골라 결과를 계산하지 않았다.

구조 문제의 내역은 다음과 같다. 겹치는 원인이 있으므로 합계를 독립 문제 수로 해석하지 않는다.

| 고정 파서가 남긴 표시 | 건수 |
|---|---:|
| 선택과 연결되지 않거나 과제 맥락이 다른 기대 보고 | 394 |
| 같은 선택에 여러 기대 보고 | 241 |
| 피드백 연결 완료 전 다음 선택 | 374 |
| 짝이 맞지 않는 중단 경계 | 2 |
| 일치하는 활성 과제 밖의 선택 | 347 |
| 선택과 연결되지 않거나 과제 맥락이 다른 피드백 | 360 |
| 연결 완료 전 과제 종료 | 1 |
| 선택 연결 도중 중단 경계 | 1 |

사건 파일 25개에서 한 건 이상의 표시가 있었다. `sub-s2`에 1,127건, `sub-s5`에 281건이 집중되었다. 이 숫자로 참가자 능력이나 원자료의 과학적 가치를 평가하지 않는다. 현재 파서가 원 사건 순서와 경계를 어떻게 처리했는지 보여 주는 진단이다. 이번 버전의 결과는 그대로 보존하며 향후 다른 연결 규칙을 검토한다면 별도 버전과 검증으로 진행한다.

별도 MAT는 큰 파일의 변수 10개와 작은 파일의 변수 4개를 확인했다. 공통된 행동·피드백 변수 4개는 정확히 같았다. 둘을 독립 참가자로 더하지 않았다. 전체 cell의 수치는 유한했으며 MAT의 기대 코드 `3–6`도 직접 선택 확률로 해석하지 않았다.

## 다른 후보도 실제 파일까지 점검했다

| 후보 | 확인된 구조 | 다음 비교를 막는 조건 |
|---|---|---|
| Cochrane / TEfits 수량 예제 | 4개 ID × 250시행 = 1,000행, 6열; 시행 순서와 정오 코드 정합성 확인 | 실제 피드백·세션·반전·정확한 두 수량이 없음. 추가 s1 파일 250행은 이미 포함된 자료의 완전 중복 |
| Marković / pybefit 반전 자료 | main 50행 + pilot 24행, 각 1,000시행; 선택·결과·정오 코드를 예정 상태와 대조한 불일치 0 | pilot 행 8/9와 11/12가 각각 완전 중복. main의 제3선택은 정보 요청. 데이터의 별도 권한과 포함 기준을 확정해야 함 |
| Hofmann et al. 수량 학습 | 원 논문의 자료 제공 방식을 확인 | 공개 파일 대신 저자 요청 방식. 저자에게 연락하지 않음 |
| Cheng et al. 수량 지각 | 논문과 OSF 연결을 확인 | 정상 공개 파일 접근이 반복 timeout해 실제 파일·권한 검증에 이르지 못함 |

수량 예제의 4개 ID를 원 연구 전체 참가자 수로 읽지 않는다. 반전 자료의 74개 행도 74명의 독립 참가자라고 부르지 않는다. 중복을 자동 삭제하지 않았다. TEfits와 pybefit 원자료는 저장소 밖 캐시에 두고, 고정 URL·해시·정적 읽기 도구와 구조 결과만 이 저장소에 남겼다. 패키지의 MIT 선언과 원 연구 전체 자료의 별도 사용 조건을 구분했다. 자세한 일차 출처는 [선정 기록](human-trial-data-sources.md)에 있다.

## 지금 비교할 수 있는 것과 남은 것

| 항목 | 현재 판정 |
|---|---|
| 원 사건과 새 선택 묶음의 대응 | 원 행 번호와 시각을 포함해 검사 가능. 불완전 묶음은 별도 표시 |
| 인간의 수량 과제 시행 순서 | TEfits의 작은 예제 범위에서 확인. 전체 학습 과정·피드백은 부족 |
| 인간의 정답률·반전 비용 | 이번 감사에서 계산하지 않음. 주 자료의 도형·원 시행 대응을 먼저 검증해야 함 |
| 기대 보고와 모델 선택 확률의 일치 | 확인되지 않음. 네 단계 평정을 보정된 확률로 취급할 근거 없음 |
| 사람과 모델의 학습 속도·오류 곡선 | 공통 측정 단위·예산·대조 조건을 별도 사전 정의한 다음 검토 |
| 수학 학습·같은 신경 기작·교육 효과 | 이번 자료 감사로 지지되지 않음 |

원 논문에는 예정 반전 시점과 70/30 확률 구조가 있다. 그러나 **예정 반전 시점을 관측 선택 번호에 바로 붙일 수는 없다.** 연습·누락·실제 시행 번호와 도형 좌우 대응의 검증이 더 필요하다. 논문에 계획이 없다고 주장하는 것과, 현재 파일에서 개별 시행의 정답을 복원하지 못한 것은 다르다. [원 논문 Methods 2.5](https://onlinelibrary.wiley.com/doi/full/10.1111/psyp.14235).

다음 작업은 **원 시행·도형·참가자 파일 사이의 대응 근거와 후보 자료의 사용 조건을 더 확인하는 것**이다. 확인하지 못한 지표는 보류한다. 그 뒤에만 공통 지표와 성공·실패 조건을 별도 등록해 인간과 모델을 비교한다. 이번 결과는 Level 4 또는 Level 5의 증거가 아니다. ‘비슷하지 않다’는 결과를 얻은 것도 아니다. 아직 그 질문을 시험하지 않았다.

## 검증과 보존

새 도구의 합성 자료 테스트 **121개가 19.94초에 통과**했다. 실제 사람의 성적을 보고 테스트나 파서를 조정하지 않았다. 이번 검사는 새 도구 범위이며 기존 모든 계산 실험의 테스트를 다시 실행한 것으로 표시하지 않는다. 구성과 소스 해시는 [테스트 기록](../results/test-validation-human-trial-data.json)에 있다.

원본을 다시 읽는 독립 검증기는 주 파서를 불러오지 않고 31개 원본, 동결 파일 39개, 주 산출물 해시 4개, 사건 44,262행 및 모든 선택 묶음을 다시 확인해 통과했다. [독립 검증 결과](../results/human_trial_data_v1/verification.json), [구조 감사](../results/human_trial_data_v1/structure-audit.json), [원 행 대응 CSV](../results/human_trial_data_v1/observed_choices.csv)를 보존했다. 다른 후보 15개 파일의 해시·코드 의미 감사와 두 MAT의 스키마 검사도 [별도 결과 폴더](../results/human_trial_candidates_v1/)에 보존했다.

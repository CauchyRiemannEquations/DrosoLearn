# 독립 보상 반전의 계산적 배경

2026-10-14, Asia/Seoul. 이 문서는 기존 관찰, 확인한 문헌과 이번 설계의 자체 수학적 도출을 구분한다. 새 시드의 성공이나 실패를 미리 가정하지 않는다.

## 이전 결과에서 남은 질문

[독립 보상 학습](reward-linear-findings.md)에서 초기 입력 차이의 전체 크기를 맞춘 7계수 선형 정책은 teacher 점수 없이도 높은 수량 선택을 습득했다. 반면 과거 [보상 반전 진단](reversal-findings.md)은 서로 다른 초기 수행을 포함하는 곡선 면적 차이를 관찰했다. 그 차이만으로 학습 능력 자체가 느려졌다고 결론내릴 수 없다. 두 연구는 head 초기값·특징 척도·시드가 달라 같은 실험으로 합치지 않는다.

이번 질문은 내부 학습이 없는 단순 정책에서도 반대 규칙 경험 뒤 고정 예산의 수정 비용이 나타나는지다. 단순 모델이 같은 효과를 보이면 복잡한 내부 회로나 생물학적 메커니즘을 가정하기 전에 선택 함수·기존 출력 계수·갱신식을 검토할 수 있다. 보상 반전은 현재 모델 안의 계산적 조작이며 실제 초파리나 인간 실험의 재현이라고 부르지 않는다.

## 문헌 확인 범위

Williams (1992), *Simple statistical gradient-following algorithms for connectionist reinforcement learning*, Machine Learning 8, 229–256, [공식 출판 페이지와 DOI 10.1007/BF00992696](https://link.springer.com/article/10.1007/BF00992696)의 서지와 초록을 2026-10-14에 다시 확인했다. 논문은 확률적 단위의 연결망에서 기대 보상 기울기를 따르는 REINFORCE 계열을 제시한다. 유료 본문 전체는 이번에 확인하지 않았다. 현재 이진 보상 factor·정규화·반전 이력·clipping과 아래 참조식은 DrosoLearn 구현에 대한 자체 설계·대수이며 논문이 초파리 수량 학습을 입증한 것으로 인용하지 않는다.

KC→MBON 가소성의 생물학적 출발점은 기존 [선행연구 검토](literature-review.md)의 Huang et al. (2024), Hige et al. (2015), Aso & Rubin (2016) 확인 범위로 유지한다. 실제 연구의 시간 순서·구획·DAN/MBON 상호작용과 달리 여기서는 fixed encoder·한 단계 KC→MBON·scalar 보상 갱신만 사용한다. Huang의 Nature 본문을 이번에 다시 열려 한 조회는 로그인 redirect로 실패했으며 새로 전체 본문을 확인했다고 표기하지 않는다. 새 생물학적 주장이나 동일 기작 해석을 추가하지 않는다.

## 단순 정책의 보상 갱신

7차원 특징을 초기 훈련 차이 RMS `g`로 나눠 `φ=x/g`, 후보 차이를 `Δφ=φ_right−φ_left`로 둔다. head는 0에서 시작하고 `p=P(right)=sigmoid(clip(head·Δφ,−40,40))`다. 행동 `a=1[u<p]`, 정답 선택 보상 `r∈{0,1}`에서 실제 갱신은 `head←head+.1(a−p)(r−.5)Δφ`다.

선택과 즉시 받은 결정적인 0/1 보상으로 정답쪽을 복원할 수 있다. `r=1`이면 선택한 쪽이 정답, `r=0`이면 반대쪽이 정답이다. optimizer에 정답 라벨을 직접 주지 않지만 보상에는 라벨과 동등한 정보가 있다. 드문·지연 보상에서 수량 개념을 발견하는 탐색이라고 해석하지 않는다.

정답이 오른쪽(`y=1`)일 때 오른쪽 행동의 factor는 `.5(1−p)`, 왼쪽 행동의 factor는 `.5p`다. 확률 `p`와 `1−p`로 평균하면 `p(1−p)`이다. 정답이 왼쪽(`y=0`)이면 같은 크기에 음수 부호가 붙는다.

`E_action[f | head,input,y]=(2y−1)p(1−p)`

이는 현재 이진 보상 구조의 자체 도출이다. `p(1−p)`는 p=.5에서 .25이며 p가 0 또는 1에 가까우면 작다. 옛 선택을 확신하는 상태가 반전 직후 작은 조건부 기대 factor를 갖는 대안 설명을 제공한다. 실제 변화는 특징 방향·크기, head, 내부 가소성과 clipping에도 의존하므로 scalar factor 하나를 전체 원인으로 선언하지 않는다. clipped 확률로 행동하되 clipping의 미분을 적용하지 않는 현재 갱신을 모든 상태에서 정확한 기울기라고 부르지 않는다.

## 조건부 기대갱신을 반복하는 참조

별도 참조는 현재 참조 head로 확률을 계산해 위 행동 평균 factor를 적용한다. 정답쪽을 직접 사용하므로 실제 보상 학습자와 같은 정보의 대조가 아니며, 학습된 모델 점수를 받아 재적합하는 설명식도 아니다. 같은 입력 stream·정규화·학습률·초기값과 경계 조작에서 결정적 기술 경로를 계산한다.

이 식은 **한 시점의 상태를 고정했을 때** 행동 평균 갱신을 정확히 준다. 이를 여러 시행 반복한 참조가 확률적 head의 전체 기대 경로가 되지는 않는다. 비선형 확률 때문에 `E[p(random_head)(1−p(random_head))]`와 `p(E[random_head])(1−p(E[random_head]))`는 일반적으로 같지 않다. 현재 참조는 자신의 상태에서 계산한다. 따라서 정확한 stochastic ensemble 평균·닫힌 형태 해라는 표현은 피한다.

각 시드의 실제 선형 경로와 참조 경로, checkpoint별 정답 선택 확률 차이·절대오차를 기술적으로 비교한다. 시드 평균 곡선의 차이와 개별 경로의 오차를 구분한다. 10시드에는 입력과 척도 차이도 있으므로 행동만 반복한 동일 입력 ensemble가 아니다. 가까운 곡선은 이 단순 갱신 설명의 제한된 적용 가능성을 보이며 원인을 완전히 증명하지 않는다. 차이가 크면 유한 행동 경로·nuisance·상태 비선형과 참조 근사의 한계를 기록한다. 참조를 위한 성공 임계값이나 추가 학습 예산은 없다.

## 출발점과 수정 비용

높은 규칙을 잘 배운 모델은 반전 직후 작은 쪽을 고를 확률이 낮다. 처음부터 낮은 규칙을 배우는 제로 head 모델은 .5에서 출발한다. 이 출발 차이는 학습 이력의 효과이며 곡선 전체 높이에 들어간다. AUC가 낮다고 새로운 규칙의 습득 능력이 본질적으로 느려졌다고 말할 수 없다. 높은 규칙을 400시행 연습한 뒤 낮은 규칙에 또 400시행을 사용하는 것과 처음부터 낮은 규칙 400시행은 총 경험도 다르다.

그래서 주 질문은 같은 **새 규칙 400시행** 뒤의 끝점 차이로 제한한다. 출발 확률·회복량·AUC·최초 관측 도달·raw margin과 반복 대조를 함께 남긴다. 큰 회복량은 낮은 출발점에서 생길 수 있다. 계속 낮은 규칙을 연습하는 `low_to_low`는 이미 잘하는 출발점 때문에 15%포인트 추가 향상이 어려울 수 있어 2단계 성공에 그 gain을 요구하지 않는다.

head reset 이후 선형·고정 내부 모델은 처음부터 배우는 경우와 같은 선택·보상 경로를 가져야 한다. 가소성 모델은 앞서 내부가 바뀌었으므로 차이가 남을 수 있다. reset은 컴퓨터 안의 계수 조작이며 실제 기억 삭제가 아니다. 차이는 내부 상태와 새 head의 상호작용이고, 내부 시냅스가 생물학적 기억을 저장한다는 독립 근거가 아니다.

## 인간 학습 비교에 남기는 가설

장기 목표는 기초 수량·규칙 학습에서 인간과 비교 가능한 계산 가설을 만드는 것이다. 이번 후보 지표는 반대 규칙 경험 뒤의 출발 선택 편향, 고정 예산 끝점 비용, 회복량, 기준 도달 시행, 오류의 방향이다. 인간 자료에서 동일 지표를 정의하려면 연습량·피드백·시행별 선택·초기 성적·평가 지표를 먼저 확인해야 한다. 모형 확률과 사람의 한 번씩 뽑힌 선택은 같은 관측값이 아니다.

현재 확보한 인간 원자료는 전후 요약이라 이번 반전 궤적과 직접 비교할 수 없다. 새 인간 실험을 하지 않고, 대응하는 기존 공개 자료가 확인되면 별도 계획을 등록한다. 비슷한 수정 곡선이 같은 신경 기작을 뜻하지 않으며, 초파리 연결 구조의 우수성이나 인간의 고등학교 수학 교육 효과를 이번 결과에서 주장하지 않는다. 실패·반대 방향·단순 정책이 설명하는 부분도 장기 연구의 결과로 보존한다.

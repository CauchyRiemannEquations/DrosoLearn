# 전체 목표 U와 현재 확률 P의 실제 경로를 나누는 분석

작성일: 2026-10-21 (Asia/Seoul). 연구 ID는 `objective_pathways_v1`이다.
완료 기준선은 `objective-learning-v1`, commit
`b96a6c9d88a9f83cbe4e093272eea0ca77f245fe`다. 새 분석 소스·설정·계획·검사와
부모 입력을 고정하고 비공개 원격의 동일 bytes를 확인한 뒤 실제 새 집계를 한다.

## 쉽게 설명하면

앞선 실제 학습에서 네 문제 전체를 고르게 돕는 U는 기존 균형 B보다 약 0.1871%p
낮았고, 현재 정답 확률도 고려한 P는 B보다 약 0.0682%p 높았다. 이번에는 그 기록을
**고칠 방향, 실제 수정 크기, 수정 직전 상태, 선택과 보상 경로**로 나눠 살핀다.

같은 순간에 두 방법 모두 실제로 답을 고쳤다면, 각자의 상태·수정 계수·방향을 하나씩
가져온 8가지 한 번 수정 계산을 비교할 수 있다. 한쪽만 고쳤거나 둘 다 고치지 않은
순간도 별도로 남겨 마지막 성적 차이까지 장부가 맞는지 확인한다.

이 배분은 기록의 차이를 읽는 정해진 계산법이다. 어느 요소가 유일한 원인이라고
증명하거나, 그 요소 하나만 바꾸어 다시 학습한 성적을 예측하는 새 실험은 아니다.
새 학습·보상 획득·난수·방향 최적화를 실행하지 않는다.

## 이미 아는 결과와 새 분석의 성격

부모 `objective_learning_v1`의 주 real/raw 최종 정답 선택 확률은 U 58.26715%,
P 58.52238%, 전환형 B 58.45421%였다. U/P의 실용 개선과 충분한 습득은 미지지,
충분한 습득은 각각 0/10, 미관측 다른 연습 입력의 운영상 보호는 둘 다 통과했다.
P−U의 별도 실용 추가 효과도 미지지다. 이 결과를 이미 알고 이번 질문을 정한다.

집계 전 계획을 고정하지만 결과를 모르는 독립 효과 검정이라고 부르지 않는다.
새 성공 문턱·유의성·최적 비율·유리한 시드 선택을 추가하지 않으며, 부모의 모든 판정과
실패·시드·400시행 예산·설정·소스를 보존한다. 보호 통과와 충분한 학습을 구별한다.

## 원자료와 새 실행 0회

부모의 세 배선 `real, rewired, ann`, 두 표현 `raw, identity`, 여덟 방법
`shared, isolated, feedback_selective, balanced, gated_balanced, gated_self_blend,
gated_uniform, gated_probability`, 계산 시드 `17801..17810`, 각 400시행을 읽는다.
전체 480 실제 경로·192,000시행·768,000목적지 효과를 모두 재구성해 보존한다.
이전 17701번대나 고정 상태 대입 연구의 경로를 새 대조로 가져오지 않는다.

입력은 네 인공 전체 문자열 `ABAB, BABA, ABBA, BAAB`다. Go 보상 부호는
`+1,+1,−1,−1`, NoGo 획득 보상은 0이다. 모든 입력을 연습했으며 미관측은 그중
아직 실제 Go 보상 부호를 얻지 못한 입력이다. 새로운 입력·규칙과 구별한다.
계산 시드 10개는 초파리 10마리 또는 사람 10명이 아니다.

새 행동·보상 획득·출력 계수 갱신·내부 가중치 갱신·가치 갱신·학습자·그래프·입력
특징 구성·난수·방향 최적화는 각각 **0회**다. 저장된 고정 단위 특징 D와 실제 스칼라 g,
방향 w의 누적 합으로 실제 출력 계수 prefix를 읽어 계산한다. 이 재구성을 새 학습으로
세지 않는다. 부모의 원 학습·그래프·최적화 전수 검산은 고정된 통과 증거로 연결한다.

## 세 비교와 공통 전환

비교 순서는 아래로 고정한다. 각 순서에서 candidate를 N, control을 C라 한다.

1. `gated_uniform − gated_balanced` (U−B).
2. `gated_probability − gated_balanced` (P−B).
3. `gated_probability − gated_uniform` (P−U).

주 설명은 real/raw의 세 비교다. 여섯 배선·표현의 18비교·180짝 경로를 모두 남긴다.
같은 경로를 비교마다 사용하므로 독립 시드 180개가 아니다. 다른 다섯 조건의 유리한
수치로 주 조건을 바꾸지 않는다.

B/U/P 세 방법 자신의 피드백 전 기억 `known_before` 네 칸이 모두 채워진 시행을
공통 후반(post)으로 삼는다. 세 mask와 최초 전환 시행이 같음을 검산한다. 네 번째
보상을 처음 얻는 시행은 전반(pre)이며 다음 시행부터 후반이다. 공통 전반의 상태·선택·
보상·수정·정답 확률 효과가 같고 최종 차이의 전반 기여가 0인지도 대조한다.
전환이 없는 허구 경로는 최초 후반을 N+1로 남기고 후반을 빈 집합으로 보존한다.

교차 계산은 공통 후반에서 **두 방법 모두 실제 Go를 선택한 시행**만 수행한다.
C만 Go, N만 Go, 둘 다 NoGo인 후반 시행의 실제 기여도 끝까지 더한다. NoGo의
숨은 Go 보상이나 잠재 방향을 새로 추론하지 않는다. 저장된 0방향에 상대의 비영 g를
곱해 방향 효과로 세지 않는다. 비대상의 셀·배분·진단 0패딩은 실제 계산 대상 수에서 제외한다.

모든 방법에서 NoGo의 g와 실제 이동은 0이다. 일부 기존 방법은 NoGo에도 고정 방향의
진단값을 저장했으므로 원래 배열의 방향 자체가 항상 0이라고 가정하지 않는다. 이번
세 비교의 완전 관측 후 NoGo 방향 0과, 다른 방법의 기존 진단 방향 재사용을 구별한다.

## 정확한 한 번 수정 8셀과 대칭 배분

각자 실제 수정 전 네 logit 점수 z, signed scalar g, 방향 영향 f=D@w를 읽는다.
평가용 참 부호 y는 새 학습자나 방향 선택기에 전달하지 않는다. 각 목적지의 정답 선택
확률 변화는 미분 근사가 아닌 부모의 정확한 sigmoid 원식으로 계산한다.

```text
F(state, scalar, direction) = y*(sigmoid(z_state + g_scalar*f_direction)-sigmoid(z_state))
```

bit4=상태, bit2=스칼라, bit1=방향이며 0은 C, 1은 N이다. 000/111셀은 각자의 실제
단일 수정 효과와 일치해야 한다. sigmoid의 ±40 clipping을 부모와 같게 쓴다.
혼합 셀에서는 저장된 g를 그대로 가져오며 바꿔 넣은 z에서 다시 계산하지 않는다.
따라서 일부 혼합은 실제 상태·행동·보상의 학습 관계를 동시에 만족하지 않을 수 있다.
이후 선택·보상·기억을 발생시킨 새 정책이나 실현 가능한 독립 개입이 아니다.

세 요소를 바꾸는 모든 순서를 대칭적으로 평균한 Shapley 장부를 쓴다.

```text
phi[r] = sum_T |T|!*(2-|T|)!/3! * (F[T union {r}]-F[T])
sum_r phi[r] = F[111]-F[000]
```

T는 r 외에 이미 N으로 바꾼 요소다. T 크기 0/1/2의 가중치는 1/3, 1/6, 1/3이다.
네 목적지별 배분을 현재 source인 자기(own)와 다른 세 입력(other)으로 나눈다.
순효과, 각 셀의 양수 부분, 음수 부분 절댓값을 **각각 먼저** 구한 뒤 배분한다.
순배분=양수 질량 배분−음수 질량 배분과 세 요소의 효율 합계를 검산한다.

양수 질량에 배분된 몫도 음수일 수 있다. 이는 도움 감소 몫이며 실제 새 피해라는 뜻이
아니다. 음수 질량의 음수 배분은 방해 감소 몫이다. 배분한 순효과에 뒤늦게 max를 적용해
도움/방해 배분을 대신하지 않는다.

세 요소 뒤에는 `control_only_Go, candidate_only_Go, neither_Go`를 잇는다.
C만 Go이면 실제 C의 순/양수/음수 효과에 각각 −1을 곱하고, N만 Go이면 실제 N을
더한다. 둘 다 NoGo이면 모두 0이다. 여섯 성분의 own/other 합은 실제 후반 차이,
전반을 더한 값은 최종 네 입력 평균 정답 선택 확률 차이로 돌아와야 한다.

## 같은 실제 대상에서 읽는 방향·크기·상태

후반 양쪽 Go인 같은 대상에 C/N 순서로 다음 12진단을 남긴다.

1. 현재 source의 정답 정렬 수정 전 logit `y[i]*z[i]`.
2. 현재 source의 정답 선택 확률.
3. 로지스틱 민감도 참고 값 `p*(1-p)`.
4. 실제 스칼라 절댓값 `abs(g)`.
5. 실제 출력 계수 이동 길이 `abs(g)*||w||`.
6. 방향 자체의 source 영향 `D[i]@w`.
7. 다른 세 입력의 부호 정렬 방향 영향 평균 `mean(y[i]*y[j]*(D[j]@w),j!=i)`.
8. 방향 길이 `||w||`.
9. 실제 획득 보상.
10. 현재 source의 Go 확률 p.
11. 실제 source의 정답 정렬 점수 변화 `y[i]*g*(D[i]@w)`.
12. 다른 세 입력의 실제 정답 정렬 점수 변화 평균 `mean(y[j]*g*(D[j]@w),j!=i)`.

기록 이름과 순서는 `aligned_source_logit_before, correct_source_probability,
logistic_sensitivity_value, abs_update_factor, head_step_l2, own_unit_direction_influence,
other_unit_aligned_influence_mean, direction_l2, observed_reward, source_Go_probability,
own_aligned_margin_step, other_aligned_margin_step_mean`다.

단위 방향 상한, 방향 점수, 실제 g, 실제 이동 길이와 실제 확률 변화를 구별한다.
평균 민감도·평균 크기·평균 방향을 곱해 평균 실제 효과라고 부르지 않는다. 상태 배분이
음수여도 상태 자체가 나쁘다는 뜻은 아니다. 이미 좋은 확률에서 같은 수정의 개선 여지가
줄어드는 효과도 들어갈 수 있다. 민감도는 참고 값이며 실제 효과는 항상 원식으로 계산한다.

## 실제 선택·보상 경로

모든 여덟 실제 방법에서 저장 source·공통 균등 난수 u·자신의 Go 확률 p로
`action=(u<p)`를 검산한다. 저장된 실제 reward는 Go일 때 source 부호,
NoGo일 때 0이며 g는 `.1*(action-p)*obtained_reward`와 맞아야 한다.
확률·선택·보상이 달라지는 과정을 미리 동일하게 맞춘 실험이라고 부르지 않는다.

세 비교의 모든 시행과 전반/후반에서 실제 행동 네 경우의 수, 최초 행동 불일치,
각자의 Go/NoGo 수, 양/음 보상 수와 누적 획득 보상, 실제 수정량을 남긴다.
최초 불일치가 없으면 null을 보존한다. 공통 난수에서도 각자의 p가 다르면 선택이
갈릴 수 있다. 불일치 시 p_C/p_N 사이에 같은 u가 놓이는지 확인한다.

선택·보상 장부는 각 배선·표현·방법·시드의 all/pre/post에 대해
source 4개×실제 action 2개×획득 reward 3값(−1,0,+1)의 모든 칸을 남긴다.
각 칸에는 정수 분모·실제 선택/보상 합·|g| 합·실제 길이 합·정답 확률 변화 합을 적는다.
불가능한 조합·빈 칸도 0개로 남기고, 평균의 분모가 0이면 null을 쓴다. source별
최종 기대 정답 확률, source/action/reward별 칸에서 실제 Go/NoGo 때의 확률 평균,
전후 누적 보상/수정도 함께 둔다.
획득 보상합·선택 성적·정답 선택 확률·이동 길이는 서로 다른 단위다.

별도 `expected_obtained_reward_sum=sum(p*y[source])`은 평가자가 참 부호와 실제
수정 전 확률로 계산한 기대 보상 참고 값이다. 실제 획득 보상합과 구별한다. NoGo의
실제 획득 보상은 여전히 0이며 이 참고 값을 학습자·기억·방향 선택기에 주거나, 하지
않은 Go의 피드백 기록으로 채우지 않는다.

양쪽 실제 Go의 같은 source에서는 action=1이고 실제 reward=k[source]가 같으므로
`g=.1*(1-p)*k[source]`다. 따라서 이 대상의 g 차이가 자신의 p 차이와 일치하는지
검산한다. 이 항등식은 두 경로의 상태·보상·선택이 독립 원인이라는 설명을 막는다.
한쪽만 Go인 경우에는 실제 수정의 나머지로 남기며, 하지 않은 선택의 보상을 만들어
새 정책 효과를 계산하지 않는다. 경로 차이와 상관을 고유한 인과 비율로 해석하지 않는다.

## 단위·산술 검사·전체 기록

목적지 확률 변화 합을 4로 나누면 최종 네 입력 평균에 대한 기여다. %p 표시 때
100을 곱한다. 누적 도움/방해 질량, 순기여, 최종 확률, 방향 점수, 보상, 실제 이동 길이는
서로 다르다. 누적 질량이 100%p를 넘는 것을 최종 성적이 100%를 넘었다고 읽지 않는다.

모든 시드를 보존하고 짝 차이의 10시드 평균은 같은 비중으로 계산한다. 시행을 합친
pooled 평균과 시드 평균을 구별한다. 대상 0개·후반 0개인 경로도 삭제하지 않고
0합계/0개와 정의되지 않은 진단평균 null을 남긴다. 부호는 `>0,<0,==0`으로 구분하며
작은 부호를 임의 epsilon으로 삭제하지 않는다.

허용 오차는 1e-8이다. canonical `z+g*f`와 계수를 더한 뒤 내적하는 부모 연산 사이의
부동소수점 잔차를 보존한다. 실제 확률/정답 정렬 점수 변화·출력 prefix·체크포인트·
기억의 전후 기록·비용 상한·미관측 효과와 대조하고 최종 확률까지 회계가 돌아오는지
검산한다. 원래 mode 전환과 부모 가설 판정은 상위 원학습 검산 증거로 함께 고정한다.
무오차 실수 항등식을 주장하지 않는다.

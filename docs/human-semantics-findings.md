# 코드 차이를 더 확인한 결과

작성일: 2026-10-15 (Asia/Seoul). 보존 태그: `human-semantics-v1`.

## 먼저 쉽게 설명하면

**숫자가 다른 위치를 전부 표로 정리했지만, 원인을 확정할 새 변환 코드는 찾지 못했다.** ‘잘 맞게 숫자를 바꿔 놓는 것’은 하지 않았다. 같은 사건 코드가 여러 MAT 코드와 함께 나타나므로, 현재 대응 위치에서 모든 파일에 공통인 단순 숫자 치환 하나로 차이를 전부 없앨 수는 없다. 참가자별 규칙·정렬·저장 과정 중 무엇이 원인인지는 이 표만으로 알 수 없다.

이는 사람의 오답이나 학습 실패를 측정한 결과가 아니다. 사람이 보고한 값이 두 기록에 어떻게 저장됐는지 확인하는 자료 처리 문제다. 이 의미가 해결되지 않은 열을 사용한 사람/모델 비교는 보류한다. **독립적으로 확인할 수 있는 다른 원자료의 출처 검증은 계속 진행한다.**

## 고정한 표의 결과

부모 결과 태그 `human-trial-linkage-v1`의 파일 7개를 Git 원바이트와 대조했다. 연결 후보 23쌍의 관측 구간 12,880개 중 기존 엄격 비교 대상 **12,334개**만 집계했고, 나머지 **546개**는 비교 불가로 그대로 남겼다. 대상·숫자 변환·행열 순서를 바꾸지 않았다. 전체와 기록쌍×과제의 46개 표를 모두 보존했다.

기대 코드의 행은 이미 `+3`이 적용된 사건 코드, 열은 원 MAT 코드다. 아래 표의 숫자는 해당 코드 조합의 **기록 수**다.

| 사건 코드+3 ＼ MAT 코드 | 3 | 4 | 5 | 6 |
|---|---:|---:|---:|---:|
| 3 | 557 | 105 | 89 | 58 |
| 4 | 106 | 2,108 | 1,039 | 326 |
| 5 | 97 | 1,048 | 3,812 | 438 |
| 6 | 69 | 342 | 418 | 1,722 |

대각선 합은 8,199, 나머지 합은 **4,135**다. 예를 들어 사건 코드+3이 `3`이어도 MAT 코드가 `3/4/5/6` 모두로 나타난다. 이것이 모든 파일에 공통인 한 개의 숫자 치환으로 완전 일치를 만들 수 없다고 말하는 근거다. 새로운 치환을 탐색하거나 채택한 결과는 아니다. 서로 다른 사람·과제의 표를 합친 것이므로 개인별 원인이나 신경 기작을 뜻하지 않는다.

## 원인을 어디까지 조사했는가

고정 공개 저장소의 잘리지 않은 Git tree에서 **183개 파일 경로와 97개 annex 포인터**를 확인했다. 포인터는 실제 큰 파일의 위치·해시를 가리키는 짧은 기록이다. 원 과제 실행 파일·원 로그·새 변환 코드는 이 tree의 경로 목록에서 찾지 못했다. 포인터의 원 payload 97개를 받은 것은 아니다.

원 논문의 보충 DOCX는 정상 요청에서 403이었고 실제 내용을 확인하지 못했다. 저자 기관의 공개 기록에서도 별도 부록 링크를 확보하지 못했다. 다른 곳에도 코드가 존재하지 않는다고 결론 내리지 않는다. 자세한 범위·한계·일차 출처는 [출처 검토](human-semantics-source-review.md)에 남겼다. [원 논문 Methods](https://onlinelibrary.wiley.com/doi/full/10.1111/psyp.14235)의 과제 설명만으로 실제 저장 변환을 추정하지 않았다.

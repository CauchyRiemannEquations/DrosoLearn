# 추가 연구와 Phase 5까지의 승인된 진행 범위

2026-10-19 (Asia/Seoul). 사용자는 추천한 추가 연구를 1번부터 순서대로 수행하고 간섭·순서를 포함한 후 Phase 5로 진행하도록 승인했다. 이 계획은 범위를 고정하며, 각 연구의 상세 가설·예산·설정은 해당 연구의 별도 실행 전에 등록한다. 기존 완료 결과와 원 DrosoMem은 변경하지 않는다.

1. **shell_credit_v1**: 한 조개에 대한 갱신이 다른 조개의 판단으로 번지는 정도와 실제 자기 조개 수정 크기를 분리한다. 고정 특징과 출력 갱신의 계산적 대조를 사용한다. 원 인간 과제의 예산을 연장한 재시험으로 해석하지 않는다. 내부 가소성·생물학적 원인·Q 우위의 전체 원인을 해결했다고 가정하지 않는다.
2. **shell_behavior_v1**: 저장한 인간·모델 기록의 조개별·보상별·이전 행동별 반응을 기술적으로 분석하고, 알려진 합성 정책에서 기존 세 지표가 구분하는 것과 구분하지 못하는 것을 확인한다. 이미 본 인간 평가 자료의 탐색적 후속이며 새 인간 유사성 확증이나 약물 효과를 주장하지 않는다.
3. **pattern_rule_v1**: 한 가지 최소 반복·주기 규칙 과제에서 습득과 미학습 사례 적용을 별도로 검증한다. 기호 빈도·마지막 기호·복사 지름길을 통제하고 과거 입력의 인공적 표현을 명시한다. 습득 실패를 일반화 성공으로 대체하지 않는다.
4. **interference_order_v1**: A→B/B→A/단독 및 학습 후 A/B 유지 검사를 비교한다. 각 과제의 습득과 관측·갱신 예산을 명시하고, 단순 휴지·다른 과제에 의한 간섭·명시적 감쇠를 구분한다. 선행 습득 조건이 닫히면 실행 가능한 구조 검증과 실패를 보존하며 후속 성적을 간섭 효과라고 해석하지 않는다.
5. **phase5_synthesis_v1**: 기존과 신규의 모든 성공·미지지·무결성 문제·미검증 범위를 다섯 연구 질문과 Level 1–5에 연결해 독립 보고서·기계 판독 증거 표·재현 명령으로 종합한다. 수량·수학 이해·인간 공통 기작·교육 효과를 미리 가정하지 않는다.

각 단계는 새로운 프로토콜·설정·소스/입력 해시·등록·결과 경로를 사용하고 실행 전 원격 등록 바이트를 확인한다. 선행 단계의 산술 검증은 필수이며, 과학적 가설 미지지는 다음에 독립적으로 가능한 연구를 영구 차단하지 않는다. 무결성 실패나 해석에 필요한 습득 조건을 건너뛰지 않는다. 정한 시행·시드·조건을 끝내면 결과의 유불리와 관계없이 해당 연구를 마친다.

같은 인간 49명을 재분할해 새로운 눈가림 평가라고 부르지 않는다. 계산 시드는 인간이나 초파리 개체가 아니다. 한 커넥톰 부분집합의 결과를 종 전체로 일반화하지 않는다. 새 인간 실험·추가 지출·실제 LC11/DAN 회로 구현은 이번 범위에 포함하지 않는다. 이전 자동 이어가기 설정을 재활성화하지 않고 이번 승인된 연속 작업을 수행한다.

# DrosoLearn의 연구 질문

영문 부제: **Exploring the Foundations of Mathematical Learning Through a Drosophila Connectome**

## 연구 목적

인간과 초파리의 뇌가 같은 방식으로 수학을 학습한다는 전제 없이, 공개 초파리 커넥톰에서 제약을 가져온 계산 모델의 학습 과정에 어떤 특징이 나타나는지 조사한다. 장기 목표는 수량 감각, 반복 학습, 보상 수정, 일반화, 간섭 등에서 인간의 기초 학습 연구와 비교할 수 있는 관찰 지표를 만들고, 독립적인 연구로 검증할 수 있는 가설을 제안하는 것이다. 실제 살아 있는 초파리나 새로운 인간 참가자를 대상으로 실험하지 않는다.

커넥톰 모델의 성능 우수성은 목표도 전제도 아니다. 신경망의 연결 구조, 입력 표현, 출력층 학습, 제한된 내부 가소성을 각각 연구 변수로 다룬다. 학습 실패, 배선 효과 없음, 대조 모델과의 차이 없음도 보존할 결과다.

## 기존 DrosoMem과의 관계

[DrosoMem](https://github.com/CauchyRiemannEquations/DrosoMem)은 완료된 별도 연구다. DrosoLearn은 원본 저장소의 코드·기록·결과를 수정하지 않으며, 재사용한 공개 자료의 버전·해시·출처·라이선스를 별도로 보존한다. 정확한 재사용 범위와 이후 연구까지 포함한 확인 결과는 `drosomem-audit.md`를 참조한다.

이 연구의 출발점에는 다음 제한이 포함된다.

- 고정 모델에서 과거 입력 정보가 읽혔다는 결과는 내부 시냅스가 학습했다는 결과가 아니다.
- 실제 배선이 모든 대조 배선보다 낫다는 근거는 확보되지 않았다.
- M11의 mod-11 규칙 습득과 일반화는 사전 정의한 기준을 통과하지 못했다. 습득 실패를 일반화 성공으로 대체해서 해석하지 않는다.
- 이후 가소성 실험이 존재하더라도, 가소성 규칙을 구현한 사실과 학습 기작이 검증된 사실을 구분한다. 음성 결과와 반응 적합성 실패를 새 프로젝트에서 지우지 않는다.

## 다섯 가지 핵심 질문과 반증 조건

| 질문 | 초기 검증 가능 범위 | 주장을 제한하거나 반증하는 결과 |
|---|---|---|
| Q1. 경험에 의해 수량 관련 선택을 학습할 수 있는가? | 인공 수량 표현을 받은 정책이 선택한 행동의 보상만으로 성능을 바꾸는가? | 습득 기준 실패, 초기 정책과 차이 없음, 보상 없는 대조군과 차이 없음, 표면 단서 대조군으로 같은 결과 설명 가능 |
| Q2. 무엇이 학습 중 변하는가? | 출력층 파라미터, 허용된 내부 시냅스, 동일 probe에 대한 활성 변화를 각각 측정 | 고정 내부 가중치에서 활성 변화만 발생; 가소성 조건에서 내부 변화가 있어도 습득 향상 없음; 내부 변화가 보상과 무관 |
| Q3. 습득한 반응이 새로운 사례에도 유지되는가? | 습득을 먼저 판정한 뒤 고정된 미관측 입력 조건에서 평가 | 습득 실패; 훈련과 평가 입력 중복; 미관측 조건 성능 기준 실패; 새로운 수량에 대해서는 제공된 인코딩 자체로 성공 설명 가능 |
| Q4. 보상·반복·순서·간섭·망각은 결과에 어떤 영향을 주는가? | Phase 1의 보상 반전, 이후 반복·학습 순서·다른 과제에 의한 간섭·지연 검사 | 반전 후 성능 회복 없음; 재설정 또는 평가 중 추가 학습에 의한 가짜 회복; 간섭과 단순한 활성 소실 구분 불가 |
| Q5. 인간의 기초 수량·수학 학습과 정량적으로 비교할 특징이 있는가? | 공개 문헌·데이터에서 비율 효과, 학습 속도, 오류, 전이, 보상 수정의 지표 조사 | 과제 구조·측정 단위가 서로 맞지 않음; 입력 차이를 통제하면 유사성이 사라짐; 유사성이 단순 정책의 결과로도 설명됨 |

## 첫 과제의 경계

첫 실험은 **인공 수량 입력을 사용하는 추상적 보상 학습 벤치마크**다. 실제 공개 부분집합에서 얻은 512 KC/48 MBON의 KC→MBON 연결 1,474개를 사용한다. 이 투사에서는 489 KC가 하나 이상의 MBON에 연결되며 29 MBON이 입력을 받는다. 나머지 19 MBON의 출력은 이 모델에서 항상 0이다. DrosoMem의 전체 reservoir를 그대로 재현하는 모델이 아니라 허용할 내부 연결을 좁힌 feedforward 모델이다. 두 후보 각각의 `n/8`과 인공 nuisance descriptor를 고정된 무작위 encoder로 KC에 입력한다. 물체 수를 알고 있는 시뮬레이터가 수량 표현을 제공하므로 이 입력은 숫자를 시각에서 추출하는 oracle 역할을 한다. 초파리의 시각 처리나 LC11 회로를 구현한 것이 아니며, 수량의 순서를 인코딩이 이미 제공한다. 모델이 수량 개념을 스스로 발견했다고 해석하지 않는다.

1차 과제는 2 대 4의 높은 수량 보상 습득, 미관측 nuisance 조건에서의 성능 유지, 낮은 수량 보상으로의 반전 적응을 구분한다. 기존 수량의 새로운 nuisance 조건 결과를 새로운 수량·새로운 규칙으로의 전이라고 부르지 않는다. 1 대 3, 3 대 4, 4 대 8은 습득 gate를 통과한 뒤에만 해석할 2차 수량 외삽 진단이다. 이것도 이미 순서를 제공한 입력에서의 정책 반응이며 수량 개념의 증거는 아니다. 실제 데이터로 확인한 커넥톰 연결에 제한적 가소성을 넣어도, 외부에서 만든 전역 보상 스칼라는 실제 DAN dynamics가 아닌 인공적 보상 조절 모델로 표시한다.

첫 실험의 표본 수·seed·성공 기준·분할·훈련 예산은 `experimental-protocol.md`와 실행 설정을 따른다. 설정 또는 코드 변경 후의 결과는 새로운 실행으로 보존하며, 실패한 실행의 성공 기준을 바꾸지 않는다.

## 관찰 결과의 주장 수준

| 수준 | 허용되는 주장 | 추가 근거 |
|---|---|---|
| Level 1 | 특정 정보가 계산 모델에서 구별되거나 읽힌다. | chance·누출·단순 단서 대조 |
| Level 2 | 학습 경험으로 성능 또는 모델 상태가 변한다. | 학습 전후·보상 대조·변화 위치의 분리 |
| Level 3 | 습득 후 미관측 입력으로의 일반화가 관찰된다. | 습득 통과·분할 무결성·고정 평가·일반화 종류의 명시 |
| Level 4 | 실제 초파리 또는 인간 연구와 특정 행동 지표의 유사성이 확인된다. | 비교 가능한 과제와 정량 지표·차이와 대안 설명 보고 |
| Level 5 | 동일하거나 관련된 신경 기작이 독립적 생물학적 증거로 뒷받침된다. | 별도의 회로·가소성·생리학 검증 |

Level 4만으로 Level 5를 주장하지 않는다. 현재 최소 모델과 smoke 실행만으로 실제 초파리 수량 인지, 인간의 수학 개념 습득, 고등학교 수학교육 효과를 입증할 수 없다. 인간 비교의 측정 계획과 출처는 `human-learning-comparison.md`, 문헌의 직접 근거와 새 가설의 구분은 `literature-review.md`에 남긴다.

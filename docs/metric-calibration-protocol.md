# 학습 없는 정책으로 선택 유지율의 성질을 확인하는 계획

작성일: 2026-10-16 (Asia/Seoul). 기존 사람·모델 자료와 그 결과를 수정하지 않는 별도 합성 실험이다. 아래 기준·설정·코드·시험을 전향적으로 고정한 뒤 과학 실행을 시작한다.

## 쉽게 설명하면

어떤 선택을 계속한다는 사실만으로 새 규칙을 배웠다고 말할 수는 없다. 처음부터 한쪽을 자주 고르는 기계도 좋은 결과 뒤와 나쁜 결과 뒤의 선택 유지율이 다르게 나올 수 있다. 반대로 아무것도 배우지 않고 직전 선택을 반복하는 기계는 두 경우 모두 높은 유지율을 보일 수 있다.

이번에는 **보상을 받아도 선택 방법을 전혀 바꾸지 않는 기계**를 만든다. 이 기계에 앞서 마련한 측정법을 적용해, 유지율 중 어느 부분이 학습 없이도 생기는지 확인한다. 사람이나 커넥톰 모델의 성능을 다시 집계하거나 비교하는 실험은 아니다.

## 질문과 고정된 반례

1. 한쪽 선택지를 선호하는 고정 정책에서 실제 피드백별 유지율 차이가 생길 수 있는가?
2. 직전 선택을 90% 확률로 반복하는 고정 정책은 학습 없이 높은 유지율을 보이는가?
3. 보상 규칙이 중간에 바뀌어도 정책이 변하지 않으면, 전체 비율만으로 그 사실을 놓칠 수 있는가?
4. 현재 측정 구현이 위 예의 정확한 분자·분모와 경계 제외를 보존하는가?

이는 측정의 성질을 확인하는 실험이다. `유지율 차이 = 학습` 또는 `높은 유지율 = 좋은 학습`이라는 해석에 대한 반례를 먼저 정한다. 반례가 확인되어도 기존 인간·모델 기록에 학습이 없었다고 결론 내리지 않는다.

## 정책: 보상에 따라 바뀌지 않는 세 가지 선택법

선택지는 지속적인 정체성을 가진 `0/1`이다. 화면 좌우·자극 수량·인간 카드에 대응시키지 않는다.

| 정책 | 초기 선택과 다음 선택 | 바뀌지 않는 값 |
|---|---|---|
| `iid_fair` | 매 시행 독립적으로 선택 1의 확률 0.5 | `p1=0.5` |
| `iid_biased` | 매 시행 독립적으로 선택 1의 확률 0.8 | `p1=0.8` |
| `sticky` | 첫 선택은 공평하게 정하고, 이후 직전 선택을 확률 0.9로 반복 | `p_stay=0.9` |

`iid`는 직전 선택과 무관하게 같은 확률로 다시 뽑는다는 뜻이다. `sticky`는 반복 성향만 있으며, 피드백을 입력으로 받지 않는다. 초기 선택을 0.5로 뽑아 sticky 정책의 두 선택지 비중이 처음부터 정상분포 `(0.5,0.5)`가 되도록 한다. 학습 가능한 가중치·보상에 따른 확률 갱신·정책 탐색·선택한 시드만의 재실행이 없다.

## 환경과 일정

상태 0에서 선택별 실제 이진 피드백 1의 확률 `q=(q0,q1)`을 네 가지로 고정한다. 상태 1에서는 두 선택지의 확률을 맞바꾼다. 피드백 0은 이 합성 실험에서 단지 이진 결과 0이다. 사람의 금전 손실과 동일시하지 않는다.

| 환경 | 상태 0의 `(q0,q1)` | 상태 1의 `(q0,q1)` |
|---|---|---|
| `probabilistic` | `(0.8,0.2)` | `(0.2,0.8)` |
| `deterministic` | `(1.0,0.0)` | `(0.0,1.0)` |
| `uninformative` | `(0.5,0.5)` | `(0.5,0.5)` |
| `swapped` | `(0.2,0.8)` | `(0.8,0.2)` |

각 기록은 800시행이며, 두 일정 모두 시행 1–400은 `phase1`, 시행 401–800은 `phase2`다. `fixed`에서는 모든 시행이 상태 0이고, `reversal`에서는 phase1은 상태 0, phase2는 상태 1이다. 반전이 있어도 정책 상태를 초기화하거나 선택 확률을 바꾸지 않는다. uninformative 환경도 고정된 반전 일정을 유지하되 두 선택지의 결과 확률은 달라지지 않는다. 이를 구별할 수 있는 학습을 주장하지 않는다.

시드는 9001–9010을 모두 사용한다. 정책 3개 × 환경 4개 × 일정 2개 × 시드 10개로 고정하며 성공한 조합만 고르지 않는다. 시드는 계산 반복이며 사람·초파리 개체가 아니다.

한 시드의 선택 난수와 피드백 난수는 분리한다. 선택 난수는 NumPy `default_rng(seed+410000).random(800)`, 피드백 난수는 `default_rng(seed+420000).random(800)`로 고정한다. 두 배열을 모든 정책·환경·일정에 재사용한다. 같은 정책·시드의 실제 선택 배열이 모든 환경·일정에서 바이트 또는 값 수준으로 동일한지 확인한다. 피드백 난수는 각 시행에서 선택된 선택지의 확률에 적용한다. iid는 `u_action < p1`을 선택 1로 사용하고, sticky는 첫 시행에 `u_action[0] < 0.5`를 선택 1로 사용하며 이후 `u_action[t] < 0.9`이면 이전 선택을 유지한다. 난수 결합 때문에 여러 조건은 독립 표본이 아니며 이를 독립 표본 검정에 사용하지 않는다. 실제 난수 생성기·배열 생성 순서·상태는 코드·실행 메타데이터에서 고정한다.

## 기존 지표의 사용과 경계

기존 `feedback_transition.measure_stream`의 정의를 그대로 사용한다. 현재와 다음 시행의 실제 선택 및 현재 피드백이 이진이며 원 시행에서 인접한 쌍만 센다. 합성 기록에는 정보 요청·결측·probe·시행 간격이 없다. 이 단순 조건을 이유로 기존 사람·모델의 제외 기록을 변경하지 않는다.

두 일정 모두 후보 799쌍 중 400→401의 단계 경계 한 쌍을 제외하여 유효 798쌍이다. reversal에서는 그 한 쌍에 상태 경계도 겹치지만 총 제외는 한 번이다. fixed에도 같은 단계 경계를 두어 일정 간 유효 쌍 예산을 맞춘다. 경계를 제외하면서 선택 과정 자체를 초기화하지 않는다. 전체 `all`과 별도로 사전에 정한 `phase1` 및 `phase2`를 보고한다. 각 단계 내부는 399쌍이며 전체 분자·분모는 두 단계의 합과 같아야 한다.

이 실험에서 상태는 이진 피드백 확률을 정하는 등록된 환경 상태다. 피드백 0/1이 전환되었다는 사실로 상태 경계를 새로 만들지 않는다. 단계와 상태는 별도 필드이며, 단계가 바뀌었다는 사실만으로 fixed의 결과 확률이 바뀌었다고 해석하지 않는다.

## 정확한 기대값과 실제 비율을 구분하기

선택의 정상분포를 `pi[a]`, 같은 선택을 반복하는 전이확률을 `T[a,a]`라 쓴다. iid 정책은 `pi=(1-p,p)`, `T[0,0]=1-p`, `T[1,1]=p`이고, sticky 정책은 `pi=(0.5,0.5)`, `T[0,0]=T[1,1]=0.9`다.

상태 `s`에서 실제 피드백 `f`의 확률을 `q_f(a,s)`라 정의한다. `f=1`이면 설정의 q, `f=0`이면 `1-q`다. 해당 보고 구간에서 상태 s 안의 유효 인접쌍 수를 `m_s`라 하면 정확한 기대 횟수는 다음과 같다.

```text
E[D_f] = sum_s m_s * sum_a pi[a] * q_f(a,s)
E[S_f] = sum_s m_s * sum_a pi[a] * q_f(a,s) * T[a,a]
E[X_f] = E[D_f] - E[S_f]
analytic_count_ratio_f = E[S_f] / E[D_f]
```

여기서 `D_f`는 피드백 f 뒤 유효 쌍의 분모, `S_f`는 유지 횟수, `X_f`는 전환 횟수다. 기대 분모가 0이면 analytic 비율도 `null`이다. 반전 경계를 제외했으므로, 경계를 가로지르는 전이확률을 이 식에 섞지 않는다.

**기대 횟수의 비율 `E[S]/E[D]`는 반복 실행마다 얻은 비율의 평균 `mean(S/D)`와 다른 양이다.** 분모는 확률적으로 달라지며 인접 쌍끼리 선택을 공유한다. 실제 출력에는 각 시드의 정수 분자·분모·비율, 합산 분자의 합/분모의 합, 비율의 시드별 평균과 정의된 시드 수, 정확한 기대 횟수와 기대 횟수의 비율, 양자의 차이를 각각 이름을 달리하여 남긴다. 비율 미정의 시드를 0으로 채우지 않는다. 조건끼리 합치거나 인간/모델 지표와 합쳐 평균을 내지 않는다.

## 실행 전에 계산으로 고정한 예상

아래는 상태 0의 구간에서 기대 횟수의 비율이다. 차이는 `stay|feedback1 − stay|feedback0`다. 이는 사람 자료·기존 모델 결과를 보고 정한 값이 아니다.

| 정책·환경 | 피드백 1 뒤 유지 | 피드백 0 뒤 유지 | 차이 |
|---|---:|---:|---:|
| iid fair, 모든 환경 | 0.5 | 0.5 | 0 |
| iid biased, probabilistic | 0.5 | 13/17 ≈ 0.76470588 | −9/34 ≈ −0.26470588 |
| iid biased, deterministic | 0.2 | 0.8 | −0.6 |
| iid biased, uninformative | 0.68 | 0.68 | 0 |
| iid biased, swapped | 13/17 ≈ 0.76470588 | 0.5 | 9/34 ≈ 0.26470588 |
| sticky, 모든 환경 | 0.9 | 0.9 | 0 |

상태 1에서는 확률을 맞바꾼다. probabilistic·deterministic·swapped 환경의 biased 정책은 위 차이의 부호가 반대다. 두 상태의 유효 쌍 수가 399씩인 reversal 전체에서는 두 피드백 조건의 기대 횟수 비율이 iid biased 정책에서 모두 0.68로 같아진다. 전체만 보면 각 구간에서 부호가 반대인 차이가 사라질 수 있다. sticky는 모든 구간에서 0.9, fair는 0.5다.

따라서 피드백별 유지율 차이는 보상이 선택 방법을 바꾼다는 인과적 증거가 아니다. 이번 biased 정책에서는 피드백이 어떤 선택을 했는지에 대한 단서가 되고, 두 선택지의 원래 선택 확률이 다르기 때문에 차이가 생긴다. 이것이 이번에 검증할 대안 설명이다.

## 통과·반증·실패 기준

수식 확인과 실행 무결성을 주 기준으로 삼는다.

- **H1:** fixed 일정의 iid biased + probabilistic 환경에서 정확 기대 횟수의 유지율 차이는 음수이며 절댓값이 0.2 이상이다. 예상은 `−9/34`다. 반례의 크기 기준은 Monte Carlo 시드별 차이에 적용하지 않는다.
- **H2:** sticky의 정확 기대 횟수 유지율은 모든 환경·일정·단계에서 두 피드백 모두 0.9다. 높은 유지율에 학습이 필요하다는 해석에 대한 반례다.
- **H3:** reversal 일정의 iid biased + probabilistic 환경에서는 phase1/phase2 차이가 크기가 같고 부호가 반대이며, 전체 차이는 0이다. 각 단계의 예상은 `−9/34`, `+9/34`다. 이것은 집계로 차이가 상쇄될 수 있음을 보이는 고정 반례다.

1. 분자·분모의 정확 기대값을 위 닫힌 식과 `(현재 선택, 다음 선택, 현재 피드백)`의 가능한 8개 경우를 완전 합산하는 독립 계산에서 확인한다. 부동소수점 수치 허용 오차는 `1e-12`로 고정한다.
2. fair·sticky·uninformative의 위 기대값과 biased 정책의 부호가 있는 반례가 성립해야 한다. 위 수식과 다른 결과가 나오면 그 반례를 확인했다고 쓰지 않고 analytic 또는 구현 실패를 보존한다.
3. 각 실제 기록에서 후보=유효+제외, `D0+D1=유효`, `S_f+X_f=D_f`를 정확히 확인한다. 두 일정 모두 전체 유효 798쌍·단계별 399쌍이며 경계는 한 번만 제외해야 한다. 단계별 정수 횟수의 합이 전체 횟수와 일치해야 한다.
4. 동일 정책·시드의 선택 경로가 환경·일정 사이에서 같아야 한다. 정책이 피드백 또는 보상 난수를 받아 갱신되지 않는지 독립 검산한다. 불일치는 학습이 발견된 결과가 아니라 실험 무결성 실패다.
5. 모든 사전 지정 시드·정책·환경·일정을 보존한다. 기존 파일의 해시·원본성·등록 선행 시각·코드 버전·입력/출력 무변경 검사를 통과해야 한다.

Monte Carlo(난수로 반복한 실행)의 실제 비율이 정확 기대 횟수 비율과 완전히 같을 것을 요구하지 않는다. 이번 시드별 비율의 우연 변동을 보고 사후 허용 오차·시드 수·성공 기준을 바꾸지 않는다. 시뮬레이션 수치의 유의성 검정이나 10개 시드의 결과를 사람 모집단에 적용하는 추론은 하지 않는다. 예상값과 실제 값의 차이는 숨기지 않고 전부 기술한다.

## 동결·재현·후속 해석

주 실행 전에 새 설정·이 문서·주 코드·독립 검산·합성 시험·직접 사용하는 기존 지표 코드와 환경 명세의 SHA-256 및 Git 버전을 등록한다. 등록은 실제 과학 시드의 선택·피드백을 생성하지 않는다. 등록 문서의 원격 바이트 확인을 기록한 후에만 새 결과 경로에서 실행한다. 독립 검산은 주 생성·기대값·집계 함수를 부르지 않고 같은 고정 설정의 배열과 분자·분모를 다시 구성한다. 기존 결과 경로는 덮어쓰지 않는다.

구체적인 CLI와 동결 파일 목록은 설정 및 구현 완료 뒤 같은 소스 고정에 포함한다. 재현 시 최초 완료 태그의 별도 checkout을 사용한다. 현재 코드로 과거 등록을 다시 고치지 않는다.

통과하면 다음 비교 연구는 유지율 자체를 학습의 정의로 쓰기 전에 선택 편향·반복 성향·확률적 결과·과제 일정 차이를 통제해야 한다는 설계 근거를 얻는다. 이 합성 반례는 생물학적 개체·초파리 커넥톰·수량 인지 실험이 아니며, Level 4의 인간 학습 유사성 또는 Level 5의 공통 신경 기작을 뒷받침하지 않는다.

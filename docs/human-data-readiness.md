# 인간 공개 자료의 비교 준비 상태

검토일: 2026-10-14 (Asia/Seoul). 이 문서는 공개 자료 확보와 구조 검증 결과다. 인간과 DrosoLearn의 유사성 검증 결과가 아니며, Level 4 또는 Level 5를 판정하지 않는다.

## 먼저 쉽게 설명하면

사람과 컴퓨터 모델의 학습을 비교하려면 같은 뜻의 점수를 비교해야 한다. 이번에 확보한 사람 자료는 **아이 56명의 연습 전 성적표와 연습 후 성적표**에 가깝다. 어떤 수량 비율에서 어려워했는지, 훈련 뒤 점수가 얼마나 달라졌는지는 살펴볼 수 있다. 하지만 연습을 한 번씩 할 때의 답변 기록은 없다. 따라서 몇 번째 연습에서 익혔는지, 보상 규칙이 바뀌자 얼마나 빨리 적응했는지를 이 자료에서 계산할 수는 없다. 이 구분을 먼저 해야 겉으로 비슷한 숫자를 보고 같은 학습 원리라고 성급하게 결론 내리지 않는다.

## 자료 구조와 측정

두 파일에 각각 `T1`, `T2` 시트가 있다. 각 시트의 2–57행은 56명의 참가자이며, 두 시점 및 두 과제 사이에서 ID와 집단 코드가 일치한다. 코드 1·2·3의 인원은 각각 19·19·18명이다. 단위는 **사람 × 측정 시점 × 조건별 정답 비율**이다. 한 행을 한 시행이나 한 학습 세션으로 읽으면 안 된다.

| 파일·범위 | 열 | 뜻 또는 확인된 범위 |
|---|---|---|
| S1, `T1!A1:O57`, `T2!A1:O57` | A `Sujet`, B `Groupe`, C `Moyenne` | 숫자 참가자 ID, 숫자 집단 코드, 전체 정답 비율 |
| 동일 | D–K `1/2 A`, `1/2 B`, `2/3 A`, `2/3 B`, `3/4 A`, `3/4 B`, `4/5 A`, `4/5 B` | 네 수량 비율마다 A/B로 집계된 정답 비율. 각각 0, .25, .5, .75, 1 값을 가진다. A/B의 의미를 직접 설명하는 파일 내 범례는 없다. |
| 동일 | L 빈 열, M `Z-SCORE`, N `MOYENNE`, O `ECART-TYPE` | L은 빈 구분 열. M–O는 집단별 전체 점수의 z점수·평균·표본 표준편차를 계산하는 원본 수식과 저장된 값 |
| S6, `T1!A1:I57` | A `Sujet`, B `Groupe`, C `MOYENNE`, D `Diff 1`, E `Diff 2` | 같은 ID·집단 코드, 덧셈 전체 및 두 난이도 조건별 정답 비율 |
| S6, `T2!A1:I57` | C `MOY ACC`, D `Diff 1 ACC`, E `Diff 2 ACC` | T1과 같은 측정 역할이며 헤더 표기는 다름 |
| S6, 두 시트 | F 빈 열, G `Z-score`, H `MOYENNE`, I `Ecart-type` | F는 빈 구분 열. G–I는 원본 요약 수식과 저장된 값 |

원 논문 Methods에서 수량 비교는 큰 집합을 선택하는 32문항, 비율 1:2·2:3·3:4·4:5, 시각 단서 일치/불일치 조건을 사용한다. 덧셈은 12문항의 두 선택지 과제다. 훈련 프로그램은 10회였지만 이 파일에는 10회별 응답이 없다. [원 논문 Methods](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0166685).

원문은 비기호·기호·통제 훈련을 설명하지만 XLSX에는 숫자 집단 코드의 범례가 없다. 두 수량 훈련 집단은 모두 19명이므로 파일의 나열 순서만으로 1과 2에 훈련명을 확정하지 않았다. A/B가 어떤 시각 단서 조건인지, Diff 1/2의 구체적 난이도 대응도 파일 자체로 확정하지 않았다. 후속 비교에서 이 대응을 사용할 때에는 별도의 근거를 먼저 고정해야 한다. 현재 감사 결과는 원 코드와 원 헤더를 그대로 사용한다.

## 결측과 최소 재현 검증

[schema-audit.json](../data/human/honore_noel_2016/schema-audit.json)에 모든 열의 헤더, 결측 수, 수치 범위, 수식 수와 검증 오차가 기록돼 있다.

- ID, 집단, 전체 정확도, 조건별 정확도의 결측은 네 시트 모두 0개다. 의도적인 구분 열 S1 L/S6 F는 각 56개가 비어 있다.
- S1 전체 정확도는 각 참가자의 D–K 8조건 평균과 정확히 일치했다. S6 전체 정확도는 D–E 평균과 최대 약 `1.1e-16`의 계산 오차 내에서 일치했다.
- 원본의 집단 평균·표본 표준편차·z점수를 표준 라이브러리로 독립 계산했다. 저장된 수식 결과와 `1e-12` 이내로 일치했다. 원본 수식은 실행하거나 고치지 않았다.
- 원 논문의 제외 규칙은 과제별로 자기 집단 평균보다 2표준편차 아래인 T1 또는 T2 점수가 있으면 참가자를 제외하는 것이다. 전체 집단으로 한 번 계산한 원본 표본 표준편차를 사용하면 S1 3명, S6 1명이 제외된다. 논문에 보고된 제외 인원과 일치한다. [원 논문 Results, Analyses](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0166685).

제외 ID는 S1 `155, 108, 225`, S6 `225`다. 이들의 점수는 원본에서 지우지 않았다. 감사 JSON의 원 코드별 기술 통계는 **제외 전 전체 56명**의 값이며 원 논문의 분석 표본 또는 ANOVA 재현 결과로 제시하지 않는다. 반복측정 ANOVA, 다중비교 보정, 논문 표·그림 전체의 재현은 수행하지 않았다. 제외 인원과 집계 정합성의 일치는 제한된 재현 확인이다.

## 지금 가능한 비교와 아직 불가능한 비교

| 후보 지표 | 자료의 준비 상태 | 다음 분석에서 필요한 조건 |
|---|---|---|
| 사람별 훈련 전·후 전체 정확도 변화 `p(T2)−p(T1)` | 계산 가능 | 원 코드와 훈련명 대응을 확정하고 원 논문의 분석을 먼저 재현. 인간의 관측 정답 비율과 모델의 정답 선택 확률을 구분하여 보고 |
| 네 비율에서의 정확도 및 전후 변화 | A/B를 평균한 비율별 지표는 계산 가능 | 네 비율을 모두 사전 선정. 유사하게 보이는 비율만 고르지 않음. 절대 수량과 시각 입력 차이를 별도로 명시 |
| 시각 단서 일치/불일치 비용 | 아직 의미 확정 전 | A/B 코드북 근거 필요. 개별 자극의 면적·밀도·배치 값은 이 자료에 없음 |
| 수량 비교 향상과 덧셈 점수 변화의 분리 | ID로 대응 가능 | 두 과제의 제외 규칙과 분석 표본을 따로 보존. 과제 변화의 비교를 모델의 산술 전이 성공으로 해석하지 않음 |
| 시행에 따른 학습 곡선, 습득까지 시행 수 | 불가능 | 훈련 시행별 또는 세션별 추가 공개 자료 필요 |
| 보상 반전 비용·간섭·망각·미학습 수량의 일반화 | 이 두 파일로는 불가능 | 해당 조작과 분할을 가진 별도의 공개 연구 자료 필요 |
| 반응 시간 | 사용 불가 | 원 논문이 터치스크린 문제와 아동 반응 변동 때문에 분석에서 제외. 파일에도 RT가 없음 |

현재 DrosoLearn은 수량 값을 인공적으로 제공받는다. 아이들은 물체를 보고 비교했다. 이 지각 단계의 차이를 인정한 상태에서 이후 학습 변화 지표를 맞춰야 한다. 사람 56명과 모델의 난수 시드는 서로 다른 반복 단위다. 이들을 하나의 표본으로 합치거나 모델 반복을 독립적인 초파리 개체로 세지 않는다.

이 점검에서는 어느 인간 패턴이 모델과 닮았는지를 검정하지 않았다. 후속 인간 비교 가설과 성공·실패 기준은 모델 결과를 보고 맞추기 전에 별도 프로토콜로 고정해야 한다. 기본 비교 원칙은 [human-learning-comparison.md](human-learning-comparison.md)를 따른다.

## 재현 방법

저장소 루트에서 다음을 실행하면 원본 두 파일의 SHA-256, 참가자 키, 결측, 집계 점수 및 제외 인원 검증을 다시 수행한다. Python 표준 라이브러리만 사용하며 원본 XLSX를 변경하지 않는다.

```powershell
python scripts/audit_human_source.py
```

새 JSON을 저장하려면 새 출력 경로를 지정한다. 기존 파일 덮어쓰기는 거부한다.

```powershell
python scripts/audit_human_source.py --output work/human-source-audit.json
```

최초 구조 점검은 스프레드시트 스킬과 번들 Artifact Tool의 read-only import/inspect로 수행했고, 별도의 Python 읽기로 교차 확인했다. 보존된 최종 감사 스크립트는 이에 의존하지 않는다. 원본을 다시 내려받는 경우 manifest의 출판사 URL과 해시를 사용한다. 해시가 바뀌면 같은 버전의 자료라고 자동 처리하지 않는다.

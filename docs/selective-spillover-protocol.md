## 실제 획득 보상을 기억하는 규칙

모든 조건은 자기 입력별 관측 부호 `k∈{−1,0,+1}^4`를 모두 0에서 시작하여 기록한다.
0은 아직 실제 Go 보상을 관측하지 않았다는 뜻이다. 현재 문제 i에서 행동을 먼저 선택하고
실제 보상 r을 얻은 다음, Go를 선택했으면 `k_i=sign(r)`를 기록한다.
이 기록은 같은 시행의 출력 갱신 방향 계산에 바로 사용할 수 있다. NoGo이면 기록을 바꾸지 않는다.
각 조건의 기록은 자기 경로의 관측만 쓴다. 결정적인 이 과제에서는 같은 입력에서 나중에 Go 보상을
다시 관측해도 부호는 같지만, 그것을 미리 알고 기억을 초기화하지 않는다.

입력 식별자에 붙은 네 관측 부호는 **출력 가중치와 별도의 학습 자원**이다.
모든 학습자는 이 관측 상태 네 칸을 따로 기록한다.
기록을 저장·조회하고 pseudoinverse를 쓰는 추가 계산도 필요하다. 공유·전체 억제 조건도 관측
기록을 남기지만 방향에는 사용하지 않는다. feedback만 현재 보상 반영 뒤의 관측 부호로 선택
억제하며, oracle는 아래의 별도 전체 정답표로 선택 억제한다. 같은 출력 차원과 이동 상한만으로
모든 정보·계산·저장 자원을 같게 맞췄다고 주장하지 않는다. 이는 알려진 네 문제를 보상으로
식별하는 추상 모델이며, 생물학적 보상 신호나 시냅스 기작의 사실적 구현이 아니다.

정답표 진단 조건만 방향 선택용 별도 부호 `[+1,+1,−1,−1]`를 초기부터 받는다. oracle의 실제
획득 관측 기록도 0에서 시작하며, 추가 정답표와 구분하여 저장한다. 이 추가 정답 정보가 있는 조건을
보상만으로 정답 부호를 알아낸 학습자라고 부르지 않는다. 환경·평가의 정답표는 다른 학습자의
방향 계산이나 초기 관측 기록에 전달하지 않는다.

## 방향 계산: 먼저 해로운 항을 0으로, 다음 이동 길이를 1로

고정 MBON Go−NoGo 특징 차이를 입력마다 정규화한 단위 행벡터를 d_i, 네 행을 D라 한다.
정규화와 SVD는 정답이나 관측 부호를 사용하지 않는다. 기존 cutoff 규칙의 pseudoinverse를 C라 한다.

```text
C = pinv(D, rcond=1e-12)
M = D D^T                        행=수정 source, 열=영향 destination
```

현재 source i의 관측 부호와 destination j의 관측 부호가 모두 0이 아니고,
`k_i*k_j*M[i,j] < −1e-8`이면 그 다른 문제 항을 해로운 것으로 분류한다. 자기 항은 제외한다.
아주 작은 음수는 고정 수치 허용 오차 안에서 그대로 남긴다. 부호가 모르는 항은 해롭거나
이롭다고 추정하지 않고 원래 raw 영향 그대로 둔다. 같은 정답끼리만 돕는다고 가정하지 않는다.
음의 raw cross 영향도 두 정답 부호에 따라 도움 또는 방해가 될 수 있다.

```text
b = M[i,:] 복사
b[j] = 0                        관측상 해로운 off-input 항에만 적용
u = d_i + C @ (b-M[i,:])
w = u / ||u||
```

원래 방향 d_i에서 raw 목표 영향 b를 만족시키는 가장 짧은 수정이 `C@(b-M[i,:])`다.
full row rank 아래에서 정규화 전 `u D^T=b`이며 자기 영향과 나머지 raw 영향은 보존된다.
자기 영향이 약 1로 유지되므로 Cauchy–Schwarz에서 `||u||≥1`이다.
정규화 후 `w D^T=b/||u||`이므로 해로운 0은 남지만 자기·도움·미관측 항의 크기는 공통 비율로 줄어든다.
따라서 도움의 부호·상대 비율을 남기며 크기 자체는 정확히 보존하지 않는다.
억제할 항이 없으면 재정규화 없이 원래 공유 단위 방향을 그대로 쓴다.

전체 번짐 억제 대조는 부모와 같은 `C[:,i]/(D C)[i,i]`를 단위 길이로 정규화한 방향이다.
이 유한 선택 규칙이 모든 가능한 단위 방향 중 최적이거나, 도움이 되는 번짐을 가장 크게 남기는
최적화라고 주장하지 않는다. 각 관측 tuple의 실제 필요 시점에 방향을 계산하며 정답표를 사용한
미리 채운 feedback 방향 캐시는 만들지 않는다. 고정 label-free C만 재사용한다.

## 사전 수치 자격과 실제 갱신

실제 선택을 추출하기 전에 60개 배선·표현·seed 특징 그룹의 기하를 모두 확인한다.
유지 rank=4, D 전체 행 조건수 ≤1e6, 유한한 양수 길이, 기존 budget 자격과 정확한 전체 분리
자격, `D C−I` 최대 절대 잔차 ≤1e-8을 모두 요구한다. 닫히면 과학 행동 전에 멈추고 보존한다.
rank 부족을 정답별 분류 불가능 증명이라고 부르지 않는다.

이후 실제 행동 난수를 소비하기 전에 정답표 없이 **가능한 관측 부호 3^4=81가지 전부**와
source 네 가지를 각 기하에 적용한다. 81×4×60=19,440개 방향 검사는 실제 정답 조합만 고르는
검사가 아니며 행동·보상·학습을 만들지 않는다. 이 검사를 feedback의 정답별 사전 방향 캐시로
재사용하지 않는다. 관측 부호가 일부 결정적 환경과 맞지 않는 상태도 빠짐없이 검사한다.

동적 선택 방향도 정규화 전 목표 영향, 정규화 재구성, 단위 길이, 정규화 후 목표 영향,
자기 raw 영향 보존, raw 길이 1 하한, 선택한 해로운 항 0 잔차를 각각 1e-8 이내로 요구한다.
실패하면 결과를 보존하고 멈춘다. cutoff·시드·방향 규칙·학습 예산을 바꾸어 통과시키지 않는다.
label-free 기하 생성에는 기존 방식의 SVD 그룹당 3회, 총 180회를 쓴다. 시행별 새 SVD는 없다.
실제 실행 중 두 선택 억제 조건의 방향 계산은 2×60×400=48,000회이며, 출력 스칼라가 0인
시행도 포함한다. 사전 19,440개 방향 검사와 구분하여 센다.

현재 확률은 `p=sigmoid(clip(d_i·h,−40,40))`이다. 공통 uniform으로 행동 a를 추출하고
실제 보상 r을 받은 뒤 관측 기록을 반영하여 다음을 한 번 계산한다.

```text
g = .1 × (a−p) × r
h_new = h_old + g × w
```

모든 방향 길이는 1이다. 같은 g에서는 같은 L2 이동 길이지만, 자율 경로의 확률·선택·보상이
달라지므로 실제 총 이동량까지 같다는 뜻이 아니다. 시행당 L2 상한 .1, 400회 경로 상한 40,
제곱 이동량 합 상한 4, 최종 출력 길이≤누적 경로 길이, 실제 변화와 `g*w`의 일치를 1e-8
허용 오차로 검증한다. 이 수학적 길이는 뇌의 생물학적 에너지 비용이 아니다.

관측 기록 전후·현재 source·행동·실제 보상·확률·사용 방향·선택 억제 마스크·자기 및 cross
점수 변화·출력 L2와 비영 갱신을 기록한다. 관측 기록 변화 횟수와 출력 갱신을 별도로 센다.
내부 가중치·encoder·bias·입력 특징의 초기/최종 일치도 검사한다.

## 고정 예산·난수·평가

새 계산 seed는 **17401..17410**의 10개다. 네 문제를 한 번씩 섞은 block 100개로 seed마다
**400회** 선택·획득 피드백을 준다. 같은 seed의 24조건은 source 순서와 행동 uniform을 공유하되
다른 조건의 실제 행동·보상을 강제로 맞추지 않는다. 두 난수 스트림은 새 namespace **202610196**의
`SeedSequence([202610196,seed,0])`와 `SeedSequence([202610196,seed,1])`로 따로 만든다.

checkpoint는 **0,50,100,200,400**이다. 추가 행동·보상·학습 없이 네 연습 입력을 정적으로 평가한다.
총 **24×10×400=96,000회** 선택·획득 피드백과 **24×10×5×4=4,800개** 정적 평가다.
계산 seed는 동물 개체나 인간 참가자가 아니다. seed를 교체·추가하거나 결과를 보고 예산을 연장하지 않는다.

일차 점수는 네 연습 입력에서 정답 행동을 선택할 **기대 확률 평균**이다. 추출된 실제 행동의 정답률·
획득 보상·관측 속도·학습 곡선·출력 이동 비용은 따로 보고한다. 다른 표현·배선·oracle 결과를
일차 조건으로 바꿔 성공을 보고하지 않는다.

별도의 단순 과제 점검으로, 각 조건이 실제로 쌓은 checkpoint 관측 부호만 읽는 **정적 조회 참고**도
기록한다. 관측 부호 +1이면 Go 확률 1, −1이면 0, 미관측 0이면 .5로 정하고 네 문제의 정답
확률을 계산한다. 이 참고는 출력 h를 쓰거나 새 행동·보상을 만들지 않는다. 원래 head 정책은
항상 `sigmoid(d_i·h)`이며 관측표를 직접 조회해 행동하지 않는다. 참고가 잘되면 그 시점까지
획득한 정보로 네 유한 문제를 기억하는 단순 정책이 가능한지 보여 줄 뿐이다. 조회 정책을 처음부터
자율 실행했을 때의 선택·학습 성적은 아니며, head 학습의 성공·규칙 일반화를 대신하지 않는다.
정적 조회 참고도 24×10×5×4=4,800개를 따로 기록한다. 이는 위 head 정적 평가 4,800개와
다른 종류의 계산이며 새 학습 시행은 0회다.

## 사전 가설과 반증 기준

**H_selective**는 real/raw 보상 관측 기반 선택 억제가 다음을 모두 만족해야 지지한다.

1. 공유 대조보다 마지막 기대 정답 확률 평균이 10seed 평균에서 .05 이상 높다.
2. 전체 번짐 억제 대조보다 같은 평균 차이가 .05 이상 높다.
3. 각 대조와의 차이가 양수인 seed가 각각 8/10 이상이다.
4. 모든 조건의 필수 기하·동적 방향·실제 출력 이동·관측 정보 제한 검사가 통과한다.

이는 비교 방법보다 실용적으로 나아졌는지의 문턱이며 충분한 습득을 필수로 섞지 않는다.
**H_acquisition**은 같은 real/raw 주 조건에서 seed별 마지막 평균≥.80, 처음 대비 증가≥.25,
Go 정답 두 문제와 NoGo 정답 두 문제 각각 평균≥.70을 모두 만족하는 seed가 8/10 이상이며
모든 수치·정보 제한 검사를 통과해야 지지한다. H_selective 지지를 요구하지 않는다.
두 가설을 따로 보고한다. .05·8/10·습득 문턱은 실용적 사전 기준이지 통계적 유의성이나
생물학적 학습 경계가 아니다.

oracle 결과는 추가 정답 정보가 있는 진단이다. oracle만 잘되면 보상 관측 기반 가설은 그대로
미지지다. 모든 조건·seed의 기대 확률·습득·기록·비용을 남긴다. 미지지를 효과가 정확히 0이거나
모든 선택 억제 방법이 불가능하다는 결론으로 확대하지 않는다.

## 등록·실행·검산과 해석 경계

새 설정의 정확한 소스·부모 증거·그래프·입력 파일 집합을 SHA-256과 source commit으로 동결한다.
이번 정확한 고정 집합은 소스 28개·부모 증거 8개·그래프 4개·입력 2개이며 전체 상대 경로는
`configs/selective_spillover_v1.json`에 열거한다. 새 경로는 아래와 같다.

- 등록: `results/registration_selective_spillover_v1.json`.
- 원격 등록 확인: `results/selective_spillover_publication_proof.json`.
- 과학 결과: `results/selective_spillover_v1`.
- 독립 검산: `results/selective_spillover_v1/verification.json`.

```text
python scripts/run_selective_spillover.py register --config configs/selective_spillover_v1.json --out results/registration_selective_spillover_v1.json
python scripts/run_selective_spillover.py run --config configs/selective_spillover_v1.json --registration results/registration_selective_spillover_v1.json --publication-proof results/selective_spillover_publication_proof.json --out results/selective_spillover_v1
python scripts/verify_selective_spillover.py --config configs/selective_spillover_v1.json --registration results/registration_selective_spillover_v1.json --result-dir results/selective_spillover_v1 --publication-proof results/selective_spillover_publication_proof.json --out results/selective_spillover_v1/verification.json
```

개발 검사는 만든 작은 행렬과 가짜 저장소만 사용하며 등록 전 실제 그래프·새 연구 seed의 결과를
미리 집계하지 않는다. 등록 commit을 비공개 원격 main에 게시하고 같은 원문 bytes를 실제로
확인한 proof의 시간이 과학 계산 시작보다 앞서야 한다. 새 결과 경로는 배타적으로 생성한다.

독립 검산은 새 producer·선택 기하 helper를 import하지 않고 입력·신경망·단위 특징·SVD·
전체 억제 방향·관측 부호 기록·선택 억제 규칙·모든 확률/행동/보상/방향/출력 변화·checkpoint·
비용·습득·두 가설을 다시 계산한다. 등록·게시·시작·완료의 시간 순서, 정보 제한, 고정 상태와
파일 해시도 확인한다. producer 요약을 옮겨 적은 검사는 독립 산술 검산이 아니다.

최대 범위는 네 알려진 인공 문제의 출력 학습과 별도 획득 부호 기억(Level 2)이다.
내부 시냅스 학습·새 문자열 일반화(Level 3)·인간 행동 유사성(Level 4)·공통 신경 기작(Level 5)·
실제 초파리의 문자나 수량 이해·교육 효과를 주장하지 않는다. 새 인간 실험·자료는 없다.
기존 인간 비교의 미지지와 맥락별 공동 습득·일반화·간섭·순서의 닫힌 선행 게이트를 보존한다.
후속 연구는 결과를 정직하게 보고한 뒤 별도 계획·등록으로 진행한다.

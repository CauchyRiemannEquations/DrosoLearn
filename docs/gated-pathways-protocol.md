## 쉽게 설명하면

앞선 실험은 아직 답을 모르는 다른 문제에 주는 방해를 막았지만, 충분한 학습에는 이르지

네 보상 부호를 모두 확인한 다음 시행이다. 다만 다른 방식이 그 시점에 무엇을 알고 있었는지는
따로 읽는다. 같은 시간 구간이라고 다른 방식의 보상 경험까지 같다고 가정하지 않는다.

새 학습·예산 연장·시드 교체·새 방향 계산은 하지 않는다. 실제 기록의 합계가 마지막 성적에
맞는지 검산하고, 다음 실험을 위해 좁힐 수 있는 질문과 여전히 모르는 원인을 구분한다.

## 공통 시간 구간과 각자의 지식은 구별한다

각 배선·표현·시드 조합에서 gated의 실제 `known_before` 네 칸이 모두 비영인지로
**공통 전환 전(pre)·전환 후(post)**를 정한다. 같은 조합의 나머지 네 방법에도 이 시간
mask를 그대로 적용한다. 네 번째 보상 부호를 처음 얻은 시행은 pre이며 다음 시행부터
post다. 게이트가 열린 NoGo도 post이지만 실제 출력 수정은 0이다.

최초 완전 관측 시행은 gated `known_after`가 처음 네 칸이 된 1기반 시행 번호다. 첫
post 시행은 그 다음이다. 끝까지 완전 관측하지 못하면 401 sentinel, 마지막 400시행에서
완전 관측하면 첫 post도 401이며 실제 추가 시행으로 세지 않는다. post가 비어도 기록을
삭제하거나 더 학습하지 않는다.

각 방법의 자체 완전 관측 여부는 **그 방법 자신의 known_before**로 따로 구한다.
공통 pre인데 자체 완전 관측인 시행, 공통 post인데 자체 부분 관측인 시행을 각각 센다.
각자의 최초 완전 관측 시행과 gated 기준 차이도 남긴다. 공통 시간 경계가 같다는 것을
보상 관측 횟수·지식 집합·출력 상태까지 같은 대조라고 해석하지 않는다.
요약의 `own_full_trial_difference`는 **gated 최초 완전 관측 시행−대조의 최초 완전 관측
시행**이며, 완전 관측 상태로 보낸 시행 수의 차이가 아니다. 401 sentinel이 포함된
경우 그 차이를 실제 관측된 사건 간 대기 시간으로 해석하지 않는다.

## 실제 확률·점수 변화의 세 집합

source i는 현재 연습 입력이며, destination j는 그 수정의 영향을 받는 네 입력이다.
각 방법의 실제 `known_before`로 목적지를 다음과 같이 빠짐없이 한 번씩 나눈다.

```text
own = {i}
known_other = {j != i : own_method_known_before[j] != 0}
unknown_other = {j != i : own_method_known_before[j] == 0}
```

source는 그 부호가 아직 미관측이어도 own에 속한다. 마지막 새 부호 발견 시행도 같은
규칙을 쓴다. 현재 source만 보상 기억을 바꿀 수 있으므로 다른 목적지의 미관측 여부는
현재 피드백 전후 같아야 한다. 평가자가 전체 정답 부호 y를 써서 효과를 측정하지만,
새 학습자·전환 판정·방향 선택을 실행하거나 그 부호를 전달하지 않는다.

고정 단위 특징 D와 실제 저장 g·방향 w로 출력 계수 prefix를 재구성한다. 한 시행의
정답 정렬 logit 변화와 정답 선택 확률 변화는 다음과 같다.

```text
z_before = D @ head_before
increment = g * (D @ w)
aligned_margin_delta = y * increment
correct_probability_delta = y * (sigmoid(z_before+increment)-sigmoid(z_before))
```

sigmoid의 clipping은 부모와 같다. 국소 미분으로 근사하지 않는다. 이 canonical 증분
계산과 부모의 실제 출력 계수를 더한 뒤 내적하는 연산 순서는 부동소수점 끝자리에서
다를 수 있다. 부모의 저장 변화·체크포인트와 고정 허용 오차 `1e-8` 안에서 대조한다.
“정확한 장부”는 비선형 원식과 이 허용 오차 안의 항등식 검산을 뜻하며 무오차 실수 연산이나
bytes 동일성을 모든 산술 값에 요구하는 말이 아니다.

각 공통 구간·각 목적지 집합의 양수 도움 합, 음수 방해 절댓값 합, 부호 있는 순합을
정답 확률과 정답 정렬 logit에서 각각 남긴다. 부호 분류는 `>0, <0, ==0`이며 tiny 음수나
양수를 임의 epsilon으로 지우지 않는다. 반올림 규모의 부호 개수를 생물학적 피해나 허용
오차를 넘는 알려진 문제 방해로 확대하지 않는다. 도움으로 방해를 상쇄한 순합만 보고하지 않는다.

## 마지막 성적과 맞아야 하는 장부

각 학습자의 공통 pre/post × own/known_other/unknown_other의 **2×3 순확률 합계**를
각각 4로 나누면 네 입력 평균 성적에 대한 기여가 된다. 여섯 항을 합하면 마지막 평균
기대 정답 확률−초기 평균과 일치해야 한다. 두 방법의 여섯 항 차이도 마지막 두 성적의
차이와 일치해야 한다. 양수 합−음수 합=순합도 별도로 검산한다.

주 설명은 real/raw의 gated−balanced 실제 경로 차이다. gated−isolated는 보호를 계속한
방식과의 보완 비교다. gated−feedback_selective와 gated−shared도 기술 비교로 보존한다.
다른 5개 배선·표현, 전체 30조건·300개 조건·시드 조합의 장부를 모두 남기고 유리한 입력 표현으로
주 결론을 바꾸지 않는다. 이 차이는 실제 경로의 수지이며 특정 손실 항을 제거한 새 학습의
성적 예측이나 유일한 인과 원인 분해가 아니다.

## 같은 구간에서 실제로 쓴 수정량

각 학습자의 공통 pre/post에서 시행 수, 실제 Go 수, 비영 출력 이동 수, 출력 이동 경로의
L2 합, 제곱 이동 길이 합을 각각 센다. 전후 합은 부모의 전체 시행 수·획득 보상 횟수·
실제 경로·제곱합과 일치해야 한다. NoGo·모드 활성·실제 비영 출력 수정은 구분한다.

기술적 비율 `gain_per_Go`는 각 집합의 확률 순합/4인 endpoint 기여를 그 공통 구간의
실제 Go 수로 나누고, `gain_per_path`는 같은 기여를 구간의 실제 경로 길이로 나눈다.
구간 비용 요약에서는 세 집합의 기여를 합한 구간 전체 기여를 사용한다. 0분모는 JSON
null·CSV 빈칸으로 남기며 임의의 작은 수를 분모에 더하지 않는다. 비영 구간만 골라 시드나
실패를 삭제하지 않는다. 같은 상한에서 실제 비용은 달랐으며, 비용당 비율을 인과적 학습 효율이나
최적 자원 배분의 증거로 부르지 않는다. CPU·최적화·기억·전환 처리 비용을 맞췄다고
주장하지 않는다. 시드 평균, 시드 표준편차, 합친 질량의 pooled 비율도 구별한다.

최적화를 하지 않는다. 같은 상태의 저장 실제 효과만 나눈다. 부모의 H_gain 미지지,

## 동결·기록·독립 검산

설정 `configs/gated_pathways_v1.json`, 계획(이 문서), 소스·검사·부모 원자료를 SHA-256으로
별도 등록한다. 등록 `results/registration_gated_pathways_v1.json`, 게시 증거
`results/gated_pathways_publication_proof.json`, 결과 `results/gated_pathways_v1`과
독립 검산 `results/gated_pathways_v1/verification.json`을 새 경로로 만든다. 게시 원문
bytes와 시간 확인이 새 실제 집계보다 앞서야 하며 완료 결과를 덮어쓰지 않는다.

시행별 실제 확률/logit 변화, 공통 시간 구간, 각 방법의 목적지 집합·자체 관측 상태와
공통 경계의 불일치, 최초 완전 관측·첫 전환 시행을 남긴다. 조건·시드·공통 구간·집합별
합계는 **30×10×2×3=1,800개·24열 집계 행**이며, 구간 시행 수·Go·비영 수정·경로·
제곱합 비용이 집합별로 반복되므로 목적지 노출 수와 구별한다. 양음수 확률/logit의 원래
질량과 endpoint 기여·비율을 다른 열로 남긴다. 구간별 비용은 별도 요약 장부에도 보존한다.

실제 확률·logit 변화, 각자의 목적지 집합과 완전 관측 여부, 공통 gated 구간, 각자의 첫
완전 관측과 기준 첫 전환, 재계산 이동 길이·제곱합 및 원 시드·순서·정답 사본을 **12개
배열**로 보존한다. 여섯 배선·표현에서 gated를 네 대조와 비교한 **24개 경로 대비**도
시드별로 남긴다. 평균 비율은 정의된 시드별 비율의 같은 비중 평균이며 모든 시드에서
정의되지 않으면 null이다. 0분모 시드의 원래 경로·비용 기록 자체를 삭제하지 않는다.

독립 검산은 새 producer를 import하지 않고 부모의 저장 D·g·w·실제 보상 기억·행동·
계수 경로로 모든 산술을 다시 계산한다. 같은 공통 경계의 적용, 마지막 발견 시행의 pre,
각자의 지식에 따른 세 집합 분할, 부호·양음수 합과 최종 성적 telescoping, 비용 전후
합계·분모·null·관측 불일치·출처/출력 해시·등록→게시→집계 순서를 검사한다.
수치·무결성 실패는 남기고 해석을 중단하며 시드·표현·분모를 바꾸어 통과시키지 않는다.

개발 검사는 작은 손으로 만든 저장 경로와 허구 시드만 사용한다. 공통 전환 후에도 다른
방법이 일부 보상을 모르는 합성 반례, 빈 구간, 0수정/0분모, 마지막 발견 경계와 양음수
잔차를 포함한다. 실제 새 장부 집계를 보고 기준을 조정하지 않는다.

검산된 학습 장부·수정량·관측 상태 그림, 쉬운 한국어 보고서와 재현 안내를 남긴다.
고정 내부 연결·활성, 실제 부모 출력 계수 학습(Level 2), 별도 획득 보상 기억을 구분한다.
내부 생물학적 가소성, 실제 시각 수량·LC11/DAN 회로, 새 입력 일반화(Level 3), 인간

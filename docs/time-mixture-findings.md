# 배우지 않는 기계에서도 나타난 피드백 차이

2026-10-19 (Asia/Seoul), `time_mixture_v1`. [실행 전 계획](time-mixture-protocol.md)과 [독립 검산 설계](time-mixture-independent-audit.md)를 먼저 동결한 뒤 실제 계산했다.

## 먼저 쉽게 설명하면

초반에는 선택 0을 자주 고르고 결과도 좋게 나오며, 후반에는 선택 0을 덜 고르고 결과도 덜 좋게 나오는 기계를 만들었다. 이 기계는 보상 결과를 보지 않고 미리 정한 시간표만 따른다. 그래도 초반과 후반을 합치면 **좋은 결과 뒤와 나쁜 결과 뒤에 같은 선택을 유지하는 비율이 달라졌다.** 같은 현재 선택끼리 나누어도 차이는 남았다.

따라서 이런 통계 차이 하나를 곧바로 ‘보상을 보고 배운 정도’라고 읽을 수 없다. 이번 반례는 실제 사람이나 기존 모델에 학습이 없었다는 뜻도, 그 결과가 시간 혼합으로 생겼다는 뜻도 아니다.

## 실제 계산 결과

9개 원 시행의 8개 인접쌍을 네 조건에서 정확한 분수로 계산했다. 외부 시계의 4→5 변화도 원 인접쌍에 포함했다. 유리한 선택은 끝까지 0이며 과제 상태나 단계가 반전되지 않았다.

| 함께 변한 조건의 현재 선택 | 피드백 1 뒤 유지율 | 피드백 0 뒤 유지율 | 차이 1−0 |
|---|---:|---:|---:|
| 0 | 41/70 ≈ 58.57% | 17/40 = 42.50% | 9/56 ≈ **+16.07%p** |
| 1 | 23/40 = 57.50% | 103/140 ≈ 73.57% | −9/56 ≈ **−16.07%p** |

선택 확률만 고정한 대조, 보상 확률만 고정한 대조, 둘 다 고정한 대조에서는 두 현재 선택의 차이가 모두 정확히 0이었다. 원 시간까지 따로 나누면 네 조건 모두 피드백별 차이가 정확히 0이었다. 사전에 둔 다섯 산술 예측이 모두 성립했다. [전체 분수·시각별 결과](../results/time_mixture_v1/metrics.json).

표는 **기대 유지 횟수 / 기대 분모** `E[S]/E[D]`다. 실제 유한 표본의 비율을 여러 번 평균한 값 `E[S/D]`는 계산하지 않았다. 경험 자료의 학습률·통계적 유의성·사람 성적도 아니다.

주 계산은 32개 원 인접쌍의 256개 국소 사건을 합산했다. 독립 계산은 조건마다 131,072개, 네 조건 총 **524,288개 가능한 전체 경로**를 정수 가중으로 열거했다. 모든 사건·시간 좌표·분수·null·대조·합계가 정확히 일치했다. 이 경로 수는 실제 사람·초파리·표본 시행 수가 아니다. 학습 갱신, 학습자 구성, 표본 시행 생성, 난수 추출은 모두 0회다. [독립 검산](../results/time_mixture_v1/verification.json).

## 무엇을 확인했고 무엇을 확인하지 않았는가

앞선 무학습 교정은 서로 다른 현재 선택을 합치는 문제를 다뤘다. 이번에는 현재 선택·상태·단계를 고정한 뒤에도 시간에 따른 두 변화가 남을 수 있음을 별도로 확인했다. 같은 선택으로 나누는 처리는 필요할 수 있지만 그것만으로 모든 대안 설명을 제거하지는 않는다.

기존 확률적 모델은 단계 안에서 보상 확률을 고정했다. 이번 합성 반례는 보상 확률까지 시간에 따라 바꾸므로 **그 모델의 실제 차이를 이번 시간표로 설명하지 않는다.** 실제 사람 자료의 원인도 검정하지 않았다. 향후 인과적인 보상 학습 효과를 추정하려면 시간·이력·선택·환경에 대한 별도의 통제와 설계가 필요하다.

이것은 측정량을 해석하는 산술 연구다. 시각 수량 추출·LC11 회로·DAN 활동을 재현하지 않으며, Level 4 인간 유사성·Level 5 공통 신경 기작·교육 효과는 미검증이다. 기존 학습 결과와 실패는 그대로 남긴다.

# 모델과 인간 자료에 같은 행동 지표를 적용하기 위한 인터페이스

검토일: 2026-10-15 (Asia/Seoul). 기존 모델 소스·문서·실제 CSV 헤더와 행 수만 읽었다. 사람 또는 모델의 새로운 정답률·조건별 성적·연속 선택 지표를 집계하지 않았고, 모델을 새로 학습시키지 않았다. 이전 파일은 변경하지 않았다.

쉽게 말하면, **보상을 받은 다음에도 같은 선택을 하는지, 다른 선택으로 바꾸는지**는 사람과 모델 양쪽에서 셀 수 있다. 다만 여기서 ‘같은 선택’이 왼쪽인지, 같은 카드인지, 더 많은 수량인지 먼저 정해야 한다. 지금 모델은 왼쪽과 오른쪽 중 하나를 뽑는다. 물체 수량이 좌우로 바뀌므로 같은 쪽을 누르는 것과 같은 수량을 고르는 것은 다르다.

## 선택·피드백·식별키의 뜻

| 원래 필드 | 확인한 의미 | 공통 형식에 옮길 때의 조건 |
|---|---|---|
| `action` | 실제 표본 추출한 선택. **0은 왼쪽, 1은 오른쪽** | 고정 카드 ID나 선택 확률로 바꾸어 부르면 안 됨 |
| `reward` | 방금 뽑힌 선택이 현재 수량 규칙의 정답쪽이면 1, 아니면 0 | 실제 받은 이진 피드백. 0을 무응답·결측으로 처리하지 않음 |
| `p_right` | 이번 선택을 뽑기 직전의 오른쪽 선택 확률 | 실제 행동을 대체하지 않음. 반올림하거나 큰 쪽을 골라 실제 선택을 다시 만들지 않음 |
| `left_count`, `right_count` | 그 시행에 왼쪽·오른쪽에 인공적으로 제공한 수량 | 수량 선택 지표를 쓰려면 실제 action이 가리킨 수량을 여기에서 찾아야 함 |
| `seed` | 계산 난수 시드 | 인간 참가자나 초파리 개체가 아님 |
| `condition` | 모델 종류 | 모델 종류를 나타내는 키. `family_id`와 다름 |
| `history` | 학습 이력 또는 분기 이름 | 다른 이력의 마지막·첫 행을 이어 붙이지 않음 |
| `phase` | `phase1`, `phase2` | 경계에서 연습 입력 stream·규칙·모델 조작이 달라질 수 있음 |
| `trial` | 단계 안의 실제 연습 순서, 1–400 | 기록 순서가 행동의 시간 순서. 평가 checkpoint의 0과 구분 |
| `family_id` | 같은 수량·인공 비수량 좌표를 교차시킨 **자극 묶음**의 ID | 모델 종류·독립 시행 주체·카드 ID가 아님. 이 열로 정렬하거나 묶으면 원래 시행 순서가 깨짐 |

실제 소스는 `p_right`를 계산한 다음 난수와 비교하여 action을 뽑고, 해당 action과 현재 정답쪽을 비교해 reward를 만든다. 그 뒤 `model.update(x, action, reward)`를 호출한다. 즉 로그의 피드백과 선택은 같은 시행에 대응한다. `optimizer_factor`와 가중치 변화 크기는 그 갱신의 계산 기록이며 별도의 보상·사람의 확신 점수가 아니다. KC·MBON·decision의 시행별 크기는 갱신 전에 계산되고, step 크기는 갱신 전후의 차이다. [반전 학습 시행 기록 코드](../src/drosolearn/bandit_reversal.py#L272), [계수 축소 시행 기록 코드](../src/drosolearn/head_attenuation.py#L278), [학습자 갱신 인터페이스](../src/drosolearn/reward_linear.py#L61).

## ‘유지·전환’의 좌표를 먼저 고정해야 한다

최소 세 종류를 구분한다.

- **화면 쪽 유지:** 직전과 이번 action이 모두 왼쪽 또는 모두 오른쪽이다.
- **수량 범주 유지:** 직전과 이번 모두 더 많은 수량을 골랐거나, 모두 더 적은 수량을 골랐다. 이 연구의 연습은 2개 대 4개이므로 그 범위를 벗어난 수량 범주 일반화로 해석하지 않는다.
- **고정 카드 유지:** 화면 위치가 바뀌어도 같은 카드 정체성을 골랐다. 현재 모델 CSV에는 그런 카드가 없다.

예를 들어 직전에는 4개가 오른쪽에 있고 이번에는 왼쪽에 있을 수 있다. 계속 4개를 고르면 화면 쪽은 바꾸었지만 수량 범주는 유지했다. 화면 쪽의 유지율을 인간의 같은 카드 유지율과 같은 측정이라고 자동 처리하면 안 된다. 좌우 위치와 카드 정체성의 대응을 인간 자료에서 먼저 확인해야 한다.

원래 선택의 좌표는 `screen_side`다. 아래 후속 계획에서는 실제 action과 두 수량을 사용해 `smaller_larger_quantity_category`로 변환하며, 화면 쪽의 유지와 같은 집계에 섞지 않는다. 현재 모델을 `persistent_card`로 표시할 근거는 없다. 선택 좌표만 바꾼 결과를 새 모델의 학습 결과로 부르지도 않는다.

수량 범주를 이진 코드로 보존한다면 0=적은 수량, 1=많은 수량처럼 단계와 무관한 대응을 먼저 정한다. 현재 보상 규칙의 정답/오답을 선택 ID로 바꾸지 않는다. 규칙이 반전될 때 선택 ID의 뜻까지 바뀌면 같은 선택의 유지·전환을 측정할 수 없다.

## 후속 실제 집계에 고정할 모델 범위

후속 등록 계획의 모델 자료는 **`bandit_reversal_v1`의 실제 `trials.csv` 중 phase2 전체**다. 시드 7001–7010, 일곱 모델 조건, 네 이력 모두를 포함한다. 구조상 280개 구간이며 각 400행, 총 112,000행이다. 이는 자료 선택·크기 계획이고 행동 비율 계산 결과가 아니다. `phase1`, `expected_updates.csv`, `head_attenuation_v1`의 자료는 이 계획에서 제외한다. 실제 실행 전에 대상 파일 해시와 전체 구간 목록을 별도 설정·등록에 고정한다.

선택 좌표는 **0=더 적은 수량, 1=더 많은 수량**이다. 좌우 action이 가리킨 실제 수량을 `left_count`, `right_count`에서 찾아 변환한다. phase2의 목표 상태는 더 적은 수량으로 고정되어 있으므로 같은 구간 안에서 규칙 반전은 없다. 같은 연구·시드·조건·이력의 phase2 안에서 원 trial이 바로 이어지는 두 행만 후보로 삼는다. 각 구간 첫 시행 앞에 phase1의 마지막 시행을 붙이지 않으며, 계수 초기화 자체를 한 시행으로 만들지도 않는다.

이 선택은 공유된 선행 경험을 여러 번 집계하거나 단계 경계를 넘는 쌍을 만드는 문제를 피한다. 각 phase2는 실제 따로 기록된 학습 구간이지만, 같은 시드의 조건·이력이 입력과 행동 난수 stream을 공유한다는 의존성은 남는다. 따라서 구간별 기술만 허용하며 독립 참가자 표본처럼 합치지 않는다. 인간 자료의 카드 정체성과 모델의 수량 범주는 별개의 선택 좌표다. 둘이 같은 자극·경험이라고 주장하거나 두 비율이 비슷하다는 사실을 종간 유사성으로 해석하지 않는다.

일부 구간은 단순한 상관을 넘어 **행동 기록이 정확히 같은 관계**다. 기존 독립 검산은 내부 가소성이 없는 `linear_normalized`, `fixed`, `rewired_fixed`, `ann_fixed`에서 `fresh_low`와 `high_to_low_reset_head`의 phase2가 history 열을 제외한 모든 시행 값까지 같아야 함을 검사한다. [기존 중복 경로 검산 코드](../src/drosolearn/bandit_reversal_audit.py#L532)가 이 관계를 명시한다. 두 이력은 서로 다른 개입 설명을 가지므로 계획한 구간별 기록을 모두 보존하지만, 이를 독립 기록 두 개로 해석하거나 독립 표본의 합산 추정에 사용하지 않는다. 이 문서에서는 실제 기록을 다시 비교하거나 중복 개수를 새로 집계하지 않았다.

## 경계와 공유 학습 이력

반전 연구의 이력은 다음과 같다. `fresh_low`에는 1단계 실제 학습 행이 없고 2단계만 있다. 나머지 세 이력은 단계당 400회다.

| 이력 | 1단계 보상 규칙 | 경계 조작 | 2단계 보상 규칙 |
|---|---|---|---|
| `fresh_low` | 실제 학습 생략 | 초기 상태 | 적은 수량 |
| `high_to_low` | 많은 수량 | 없음 | 적은 수량 |
| `high_to_low_reset_head` | 많은 수량 | 출력 계수만 0으로 초기화 | 적은 수량 |
| `low_to_low` | 적은 수량 | 없음 | 적은 수량 |

계수 축소 연구는 실제 많은 수량 1단계를 `history=shared_prefix`, `phase=phase1`로 **한 번만** 학습·기록한다. 같은 종료 상태를 복사하여 `gamma_0`, `gamma_025`, `gamma_05`, `gamma_1`의 네 2단계 분기를 만든다. `fresh_low`는 처음 상태에서 시작하는 별도 2단계다. 네 분기에서 head를 각각 0·1/4·1/2·1배로 바꾸며 내부 연결과 다른 상태를 보존한다. 이 조작은 보상을 받은 한 시행이 아니다. [분기 생성 코드](../src/drosolearn/head_attenuation.py#L300).

따라서 공유 1단계 행을 네 번 복제한 뒤 독립 학습 경험 네 개로 세면 안 된다. 네 분기의 마지막·첫 행을 서로 연결해서도 안 된다. 필요하면 `boundary.json`의 `shared_prefix_path`, `shared_prefix_sha256`, `gamma`, 전후 상태 변화로 부모·분기 관계를 명시한다. `fresh_low`에 공유 1단계를 붙이는 것은 잘못된 이력이다. 다른 반전 연구에서 실제 따로 실행·기록한 동일 초기 이력도 같은 난수 stream을 공유하므로 독립 인간 표본처럼 취급하지 않는다.

첫 공통 지표의 보수적인 연속 구간 키는 **연구 ID·seed·condition·history·phase**다. 그 안에서 `trial`이 정확히 1 증가하는 두 행만 잇는다. 각 구간의 첫 행, 단계 전환, 계수 초기화·축소, 분기 시작은 새 경계로 둔다. 단계를 넘어선 전환을 나중에 분석하려면 경계 조작과 규칙 변경을 별도 표시하는 새 기준이 필요하다. 이미 관찰한 결과에 맞추어 경계 정책을 바꾸지 않는다.

## 확률·참조 계산·결측을 실제 행동과 구분한다

`expected_updates.csv`에는 `action`, `reward`가 없다. 현재 정답쪽 `target`을 직접 사용하는 기대 갱신 기술 참조다. 이 파일에서 실제 보상 뒤 유지·전환을 만들 수 없다. `learning_curves.csv`의 `p_target`, `p_larger`, `p_smaller`, `greedy_accuracy`도 평가 요약이다. 연속 실제 선택 대신 사용하지 않는다. [기대 참조 범위](../docs/bandit-reversal-protocol.md), [평가 지표 구현](../src/drosolearn/reversal.py#L92).

실제 시행 CSV에는 `valid`, `missing`, `nonfinite`, 정보 요청 여부를 뜻하는 전용 열이 없다. 모델은 매 시행 두 쪽 중 하나를 뽑으며 사람처럼 응답 제한시간·제3의 정보 요청 선택을 구현하지 않는다. reward 0은 정상 피드백이고, 크기 0인 활성·가중치 변화도 자동 결측이 아니다.

후속 변환기는 새 값을 집계하기 전에 action·reward가 각각 정수 0/1인지, p_right가 유한한 0–1인지, 시행 번호·키가 중복 없이 이어지는지 확인해야 한다. 수량은 서로 다른 양의 정수인지 확인한다. 비어 있는 셀·NaN·무한대·예상 밖 코드는 유효 행동으로 대체하거나 조용히 삭제하지 않는다. 잘못된 행을 지우고 그 전후를 바로 이어 붙이면 실제로 연속하지 않았던 선택이 한 쌍이 된다.

기존 실행 코드는 비유한 가중치를 검사하고 실패 시 metadata에 실패를 기록한다. 기존 독립 검산은 시행별 유한 수치, 실제 선택·보상과 난수 stream을 검사한다. 다만 실행 완료 표시 하나를 새 변환기의 행별 유효성 검사로 대체하지 않는다. 입력 해시와 기존 검산 결과를 연결하여 보존한다. [반전 독립 검산](../src/drosolearn/bandit_reversal_audit.py#L266), [계수 축소 독립 검산](../src/drosolearn/head_attenuation_audit.py#L133), [유한 수치 파서](../src/drosolearn/encoding_audit.py#L52).

| `feedback` / `feedback_kind` | 원 reward, `deterministic_correctness_reward` |
| `barrier_before` | 새 구간·분기·개입 경계면 참 |
| `valid_choice` / `valid_feedback` | 원 열의 유효성 검사 결과. 원 로그에 이미 존재하는 열인 것처럼 설명하지 않음 |
| 선택적 자극 정보 | left_count·right_count·family_id. 시간 순서나 주체 구분을 대신하지 않음 |

유지·전환은 선택 t와 선택 t+1을 비교하고, 조건을 나누는 피드백은 **t의 실제 피드백**이다. t+1의 보상으로 직전 행동을 분류하면 다른 질문이 된다. 분모는 유효한 연속 두 선택과 t의 유효 피드백을 모두 가진 쌍이다. 어떤 피드백 조건의 분모가 0이면 비율은 계산 불가로 남겨야 하며 0%로 채우지 않는다. 실제 자료에 적용할 제외·경계·집계 단위와 보고 범위는 별도 프로토콜에서 고정한다.

## 지금 가능한 작업과 후속 과제 정합

**기존 로그를 읽는 변환기와 같은 지표의 순수 계산 함수를 만드는 데에는 새 모델 학습이 필요하지 않다.** 위 인터페이스로 인공 두 선택·피드백·경계·결측 예제를 검증할 수 있다. 이 문서는 그 실제 지표를 아직 계산하지 않았다.

사람과 모델의 결과를 학습 현상으로 정량 비교하려면 다음 과제 차이를 먼저 맞추거나 분리해야 한다.

- 현재 모델은 2개 대 4개와 여섯 인공 비수량 좌표를 후보마다 직접 받는다. 점 이미지에서 수량을 알아내는 시각 단계가 없다. [입력 코드](../src/drosolearn/data.py#L15)는 수량 1좌표와 인공 좌표 6개를 만든다. 네 교차 사례를 만든 뒤 순서를 난수로 섞으므로 자극 묶음별로 다시 정렬하면 안 된다.
- 모델 reward는 현재 수량 규칙에 따른 결정적 정답 보상 0/1이다. 인간의 확률적 카드 보상·금전 손익·정오 표시는 서로 다른 의미일 수 있다. 같은 0/1 형식이 같은 피드백 생성 과정을 뜻하지 않는다.
- 현재 모델은 400회씩 두 단계와 한 번의 정해진 규칙 변경 또는 인공 계수 조작을 사용한다. 인간 자료의 여러 반전·잠재 상태·정보 요청 선택·응답 누락·연습 횟수·휴식과 직접 같지 않다. 계수 축소를 사람의 심리적 확신 조작으로 동일시하지 않는다.
- 모델들끼리도 출력 계수가 선형 7개와 네트워크 48개로 다르고, 가소성 조건에는 내부 가중치 1,474개가 추가된다. 같은 연습 횟수만으로 모든 학습 자원이 동등하지 않다. [자원 설정 근거](../docs/bandit-reversal-protocol.md).
- 같은 시드의 조건·이력은 입력과 행동 난수 stream을 공유한다. 모델 조건·분기·단계의 행들을 독립 참가자처럼 합치지 않는다. 계산 시드와 사람 참가자는 다른 반복 단위다.

따라서 다음 학습 실험이 필요해지면 안정된 선택 정체성, 입력 표현, 피드백 확률과 종류, 반전 일정, 정보 요청 처리, 연습 예산과 학습 가능한 자원을 먼저 설계·등록해야 한다. 현재 학습자 API가 입력·실제 행동·보상을 받는다는 사실은 재사용 가능성의 근거지만, 인간의 카드 과제를 그대로 구현했다는 근거는 아니다. 이번 단계의 산출물은 측정 인터페이스이며 사람과 초파리 모델의 정량적 유사성 또는 공통 신경 기작에 관한 Level 4·5 결과가 아니다.

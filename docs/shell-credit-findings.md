# 한 조개 학습이 다른 조개의 판단에 번지는 효과

2026-10-19. 첫 추가 연구 `shell_credit_v1`의 정해진 10,800회 선택·피드백과 별도 독립 재계산을 완료했다.

쉽게 말하면, 한 문제의 답을 고칠 때 다른 문제의 답도 함께 흔들리는 계산 구조를 시험했다. 규칙이 바뀌지 않는 별도 과제에서 자기 문제에 대한 첫 수정 폭은 맞추고, 다른 문제로 번지는 갱신만 계산적으로 분리했다.

| 조건 | 최종 유리한 선택 확률 평균 | 사전 습득 기준 통과 |
|---|---:|---:|
| 공유 출력 갱신 | 61.90% | 0/5 계산 시드 |
| 조개별 영향을 분리한 갱신 | 84.29% | 5/5 계산 시드 |
| 무학습 균등 선택 | 50.00% | 0/5 계산 시드 |

분리−공유의 평균 차이는 +22.38%포인트이며 다섯 시드 모두 양수였다. 평균 ≥10%포인트·양수 4/5 이상·분리 조건 습득 4/5 이상이라는 사전 H_credit이 지지됐다. 이 수치는 실제 표본 선택의 정답률과 구분되는 고정 여섯 입력의 기대 선택 확률이다.

정적 행렬에서 공유 갱신은 다른 조개 점수에도 영향을 줬다. 분리 조건은 자기 조개의 같은 상태 수정 폭을 유지하면서 다른 조개에 대한 영향을 수치 허용 오차 안에서 제거했다. 여섯 특징의 rank는 전 시드 6, Gram 조건수는 55.66~164.95로 사전 수치 조건을 통과했다. 이는 같은 원 특징으로 여섯 반응을 구분하는 계산 해가 존재함과 갱신 방향의 차이를 보여 주며, 원 입력이 모든 정보를 잃었다고 해석하지 않는다.

모든 내부 가중치와 KC·MBON 특징은 고정했다. 실제 출력 갱신 호출은 7,200회이며 내부 갱신은 0회다. 출력 좌표 수는 둘 다 48이지만 실제 활성 특징 좌표는 29다. 분리 조건에는 288개의 추가 고정 계수와 행렬 풀이가 필요했고, 출력 갱신 L2나 이후 자율 선택·보상 경로까지 같지는 않다. 계산적 개입의 전체 경로 효과이며 생물학적 학습법의 우위를 증명하지 않는다.

또한 초기 한 Go·±1 경험에서 actor의 평균 자기 점수 변화는 .05, 원 설정의 Q 산술 참조는 .4였다. 학습률 숫자가 같다고 같은 행동 수정 크기는 아니다. Q를 이 새 과제에서 추가 학습하거나 전체 Q 우위를 검정한 것은 아니다.

이 정지 과제는 사람의 원 216시행과 다른 720시행·여섯 정지 보상 이름표 환경이다. 앞선 인간 유사성 미지지를 대체하지 않는다. 내부 가소성, 반전, 인간의 사전 연습이나 학습률 선정 목적의 차이는 이번에 인과적으로 분리하지 않았다. 원 사람 과제 실패 전체의 원인이 공유 갱신이라고 확정할 수 없다.

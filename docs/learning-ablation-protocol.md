# 동일 학습 상태에서 내부·출력 갱신을 끄는 대조

작성일: 2026-10-16 (Asia/Seoul). 연구 ID `learning_ablation_v1`.

## 목적과 선행 근거

앞 연구에서 확률적 보상의 첫 규칙은 학습했으나 반전 적응은 조건별로 달랐다. 고정망과 가소성망은 첫 학습의 최종 상태도 달랐으므로 그 비교만으로 반전 중 내부 갱신의 역할을 분리할 수 없었다. 이번에는 **하나의 첫 학습 상태를 복제한 뒤 반전 중 갱신 허용 여부만 바꾸는 계산 개입**을 한다. 더 큰 모델·더 긴 예산·성공 시드 선택으로 이전 실패를 대체하지 않는다.

선행 조건은 `stochastic_feedback_network_v1`의 완료와 독립 검산 통과다. 그 summary, verification, registration, config, artifact inventory의 SHA-256과 발표 커밋을 설정에 고정한다. verifier의 summary/registration/config 해시 및 artifact inventory의 summary 해시가 같은 바이트를 가리켜야 한다. 이전 반전의 성공 개수나 이번 새 prefix의 습득 성공을 실행·분석 대상 선택 gate로 쓰지 않는다.

이번 가설·분모·설정·입력 생성·소스·시험을 과학 시드 실행 전에 private Git에 고정하고 원격 동일 바이트 확인 뒤 실행한다. 과거 결과를 참고한 후속 진단이며 공인 또는 눈가림 확증 사전등록이 아니다. 새 과학 시드는 고정된 **12001–12010**이며 개발 fixture는 17/18만 쓴다.

## 모델과 네 분기

입력은 2 대 4의 인공 수량 순서 `n/8`과 여섯 교차 nuisance 좌표다. 선형 모델과 KC→MBON 실제 부분 배선, 차수 보존 재배선, 일반 희소망 네 모델을 사용한다. 원 graph·초기화·TRAIN-only 특징 차이 RMS 정규화·출력 0 초기값·head 학습률 .1·internal 학습률 .01은 기존 검증된 구현과 같다. 생물학적 가소성 대신 기존 단순화된 계산 규칙을 검사한다.

각 시드·모델에서 큰 수량에 유리한 확률적 보상으로 400회 한 번 학습한다. 네트워크의 prefix는 내부와 출력 모두 학습하고 선형은 출력만 학습한다. prefix 최종 상태를 완전히 복제하여 다음 네 분기에서 작은 수량에 유리한 보상으로 각각 400회 실행한다.

| 분기 | 반전 중 출력 갱신 | 반전 중 내부 갱신 |
|---|---|---|
| `full` | 허용 | 네트워크에서 허용 |
| `head_only` | 허용 | 차단 |
| `internal_only` | 차단 | 네트워크에서 허용 |
| `frozen` | 차단 | 차단 |

선형 모델에는 내부 학습 파라미터가 없으므로 `internal_only`와 `frozen`은 상태·확률·실제 선택·보상 경로가 같아야 한다. 선형 `full`과 `head_only`도 같아야 한다. 같은 prefix를 네 번 학습한 것으로 세지 않는다.

복제에는 head, 현재 내부 가중치, 최초 가중치와 상한, incoming 정규화, encoder, bias, pre/post, 특징 척도와 최초 RMS, 누적 counter가 포함된다. prefix 가중치로 상한이나 척도를 다시 맞추지 않는다. `internal_only`는 학습된 출력 계수를 그대로 유지하며 0으로 재설정하지 않는다. phase2 시작점의 19개 기존 상태 배열은 prefix 끝과 같고 새 phase-local counter만 0이다. npz 컨테이너 바이트의 동일성과 배열 값의 동일성을 혼동하지 않는다.

## 실제 보상과 선택적 갱신

매시행 현재 정책의 오른쪽 선택 확률 `p`에서 `a=int(u_action<p)`를 뽑는다. 해당 phase의 기준 수량이면 보상 확률 .8, 다른 수량이면 .2이며 `r=int(u_reward<q)`로 실제 이진 보상을 생성한다. 학습 갱신에는 입력, 실제 선택, 실제 보상, 고정 갱신 마스크만 전달한다. 정답 방향·q·다른 선택의 잠재 보상을 전달하지 않는다.

`f=(a-p)*(r-.5)`이고 허용된 경우만 `head += .1*f*(phi_right-phi_left)`를 실행한다. 내부 갱신이 허용된 네트워크에서는 **갱신 전 head**를 써 `e=old_head[post]*(KC_right-KC_left)[pre]/scale`, `weights=clip(weights+.01*f*e,0,2*initial_weights)`를 실행한다. 마스크를 끈 부분은 수치·counter 모두 변하지 않아야 한다. 모든 부분을 끈 분기도 선택과 보상을 실제 기록한다.

기존 update 함수는 출력 학습 플래그를 완전히 따르지 않으므로 새 명시적 갱신 함수로 구현한다. full 1-step은 기존 수식과 일치해야 한다. 초기 출력 0 때문에 첫 내부 변위가 0인 경우에도 호출 횟수와 실제 변위를 구분한다. .5는 고정 보상 중심화이며 실제 DAN 신호나 학습된 보상 예측 오차가 아니다.

## 입력·난수와 평가

| 항목 | NumPy default_rng seed |
|---|---|
| prefix / reversal TRAIN | `seed*100+61` / `seed*100+64` |
| IID / nuisance OOD | `seed*100+62` / `seed*100+63` |
| prefix / reversal 행동 uniform | `seed+610000` / `seed+620000` |
| prefix / reversal 보상 uniform | `seed+630000` / `seed+640000` |
| 재배선 / 일반망 / encoder | `seed+650000` / `seed+660000` / `seed+670000` |

TRAIN은 phase별 400개, IID/OOD는 각각 128개, probe는 IID 앞 8개다. 모든 split의 방향 독립 fingerprint가 겹치지 않아야 하며 구조적 수량 oracle은 1, nuisance-only 기준은 각각 .5여야 한다. 모든 모델·분기는 같은 시드의 입력과 phase별 두 uniform 배열을 공유한다. **같은 난수가 같은 선택·보상을 강제하지는 않는다.** 정책이 달라지면 선택과 선택한 보상의 확률도 달라질 수 있다.

각 phase의 0·100·200·300·400 checkpoint에서 같은 IID/OOD를 평가하고 사례별 확률·probe 활성·모든 상태를 저장한다. 평가에서 학습 상태나 RNG를 바꾸지 않는다. 반전 시작점에서는 기준 방향만 큰 수량에서 작은 수량으로 바뀌며 물리적 가중치는 그대로다. OOD는 nuisance 좌표의 변화이며 새 수량·새 규칙 전이가 아니다.

## 주 가설과 반증 기준

전체 10개 시드에서 같은 모델의 짝지은 **반전 최종 IID 기준 선택 확률** 차이를 계산한다.

- **H-I:** 실제 배선의 `full−head_only` 평균이 .05 이상이고 차이가 엄격히 양수인 시드가 8/10 이상인가?
- **H-H:** 실제 배선의 `full−internal_only` 평균이 .05 이상이고 차이가 엄격히 양수인 시드가 8/10 이상인가?

각 가설은 두 기준을 모두 만족할 때만 지지다. 둘은 별도 판정하며 하나의 성공으로 다른 실패를 대체하지 않는다. .05와 8/10은 이 모델의 실용적 진단 기준이며 통계적 유의성·생물학적 임계값이 아니다. 재배선·일반망·OOD가 좋다고 실제 배선의 IID 가설을 성공으로 바꾸지 않는다. **prefix 습득 미달 시드도 모든 주 평균과 분모에 남긴다.** 미달은 삭제하거나 예산을 늘리지 않는다.

H-I는 출력 갱신이 있는 상태에서 내부 갱신 허용의 전체 경로 효과이고 H-H는 내부 갱신이 있는 상태에서 출력 갱신 허용의 전체 경로 효과다. 서로 독립·가산적인 기작 효과라고 부르지 않는다. 선택·보상의 이후 경로 변화도 개입 효과에 포함된다.

## 모든 조건에서 함께 보고할 값

prefix 습득은 IID 최종 기준 선택 확률 ≥.75와 시작 대비 향상 ≥.15를 모두 요구한다. 반전 기준은 최종 ≥.75이며 prefix 습득과 동시에 충족한 `qualified_adaptation`을 별도로 기록한다. 미달 여부와 반전 중 부분적 향상을 구분한다.

모델별·시드별·IID/OOD에서 시작·끝·gain, 다섯 checkpoint 사다리꼴 적분/400인 raw AUC와 시작점 보정 AUC, 최초 관측 threshold checkpoint를 기록한다. 최초 관측 시점은 실제 최초 도달 시행이나 지속 성공이 아니다. 모든 분기의 아래 차이를 endpoint·gain·AUC에서 보고한다.

- 내부 효과: `full−head_only`, `internal_only−frozen`.
- 출력 효과: `full−internal_only`, `head_only−frozen`.
- 상호작용: `full−head_only−internal_only+frozen`.
- 2×2 평균 효과는 위 두 해당 효과의 평균으로 기술한다. 가산적 생물학적 기작을 가정하지 않는다.

평가의 `p_rule`은 현재 기준 수량 선택 확률이다. 기대 보상은 `.2+.6*p_rule`이고 실제 보상률은 별도다. 가중치 변화와 단순 활성 변화, 내부와 출력을 각각 저장한다. 실제·재배선·일반망의 모든 결과와 자원을 보존하며 별도의 배선 우위 가설은 없다.

## 실행 자원·보존·검증

실제 선택·피드백은 prefix `10×4×400=16,000`, 반전 `10×4×4×400=64,000`, 합계 **80,000회**다. 출력 갱신은 prefix 16,000와 반전 32,000으로 **48,000회**, 내부 갱신은 네트워크 prefix 12,000와 반전 24,000으로 **36,000회**, 정답 직접 접근 갱신은 0회다. 한 시행에서 두 종류를 갱신했다고 두 경험으로 세지 않는다. 복제된 누적 counter를 실제 전체 합계로 더하지 않는다. phase-local와 native 누적 counter를 따로 저장한다.

새 결과 폴더는 배타 생성하고 입력·uniform·topology·모든 checkpoint·시행별 CSV·곡선·자원·미달·summary·metadata·artifact hash를 저장한다. 예외가 발생하면 부분 기록과 실패 metadata를 보존한다. 기존 결과·원자료·코드·등록을 수정하지 않는다. 해시 동결 목록은 실제 import 소스·원 graph·출처/라이선스·환경 잠금·새 구현/독립 검산/시험/설정/프로토콜/설계 감사를 포함한다.

개발 시험은 마스크별 1-step, old-head 사용, deepcopy 비공유, prefix 단일 실행, clone 상태, 상한/척도 유지, 선형 두 동치 쌍, 모든 실제 선택·보상, phase-local counter와 누적 counter, 공유 stream, 평가 비변경, 부모 gate/출력 덮어쓰기 거부, H-I/H-H 경계·미달 보존을 포함한다.

독립 검산은 producer 학습자·forward·update·summary를 호출하지 않고 이전 독립 감사의 수학 helper만 재사용하여 모든 입력/초기화/선택/보상/마스크 갱신/checkpoint/확률/곡선/분모/판정을 재계산한다. hash를 고쳐 숨긴 의미 변조도 개발 시험에서 거부해야 한다. 무결성 실패는 과학적 미지지와 다르게 기록하고 넘어가지 않는다.

## 해석 범위

이 개입은 지정된 인공 입력·학습 규칙·예산에서 허용된 계산 갱신의 역할을 검사한다. 학습 가능한 자원 차이와 정책 경로가 효과에 포함된다. 같은 prefix는 이 차이를 없애는 것이 아니라 출발 상태를 맞추는 통제다. 다른 종류의 갱신 규칙에도 내부 또는 출력 학습이 반드시 필요하다는 일반 명제는 검정하지 않는다.

새로운 fresh-low 대조가 없으므로 순수 학습 속도나 과거 기억의 비용 자체를 추정하지 않는다. 실제 시각 입력·LC11/DAN 회로·동물 시냅스 학습을 재현하지 않는다. 계산 시드는 동물·인간 개체가 아니며 Level4 인간 유사성·Level5 공통 기작·수학교육 효과를 주장하지 않는다. 장기 인간 비교를 위해서는 행동 지표를 단순한 습관·표현·과제 차이와 구분하는 이 통제가 먼저 필요하다.

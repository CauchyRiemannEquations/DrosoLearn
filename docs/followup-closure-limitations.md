# 후속 연구 종합의 범위와 해석 한계

2026-10-21, Asia/Seoul. 첫 [Phase 5 보고서](phase5-final-report.md) 뒤의 표현·갱신·번짐 연구를 종합하는 보충 문서다. 원 [LIMITATIONS.md](../LIMITATIONS.md), 개별 연구의 사전 기준과 판정, 기존 사람 비교와 DrosoMem 감사는 그대로 보존한다. 이 문서는 과거 결과의 정정이나 새 효과 검정이 아니다.

## 1. 마감하는 연구 범위

이번 종료 대상은 사용자가 승인한 로컬 계산 연구와 후속 결과의 종합·한계 정리·재현 확인이다. 원래의 다섯 연구 질문에 대한 최종 답은 첫 Phase 5와 후속 증거를 함께 읽어야 한다. 모든 수학 규칙·시각 회로·인간 학습 가설을 해결했다는 의미의 완료가 아니다.

추가 가능한 질문을 남기는 것과 현재 범위를 끝내는 것은 양립한다. 현재 실패를 성공으로 바꿀 때까지 시드·학습 예산·모델 크기를 늘리는 것을 종료 조건으로 삼지 않는다. 새 연구가 필요하다면 별도 질문·자료·자원·사전 기준을 정해야 하며 이번 마감 뒤 자동으로 시작하지 않는다.

## 2. 과제와 입력의 범위

후속 연구의 네 입력은 전체 문자열 `ABAB`, `BABA`, `ABBA`, `BAAB`다. 원 문자열의 인공 표현과 문제별 이름표 표현을 비교했고, 알려진 네 입력 전체를 이용한 방향 분리 계산을 포함한다. 네 입력의 개별 정체성을 기억하는 조회표로 해결할 수 있는 과제이며, 수학적 규칙이나 기호의 의미를 이해해야만 풀리는 과제가 아니다.

고정 특징에서 정답을 나누는 분석용 출력 계수를 찾은 것은 그 표현의 구별 용량 진단이다. 정답을 알고 계산한 계수와 실제 보상으로 학습한 출력은 다르다. 원 네 입력의 정보가 특정 고정 특징에서 유지됐다는 결과를 이전 M11이나 모든 입력 표현에 확대하지 않는다. [표현·갱신 분리](representation-update-findings.md)

초기 연구의 인공 수량 입력은 이미 수량의 순서를 제공했다. 그 조건에서 확인한 제한적 새 수량 적용을 부정하지 않지만, 실제 이미지에서 점의 개수를 추출한 결과로 바꾸지 않는다. 후속 네 문자열의 반복 학습은 새 수량·새 문자열·새 규칙 일반화의 추가 증거가 아니다.

## 3. 무엇이 학습된 상태인가

후속의 실제 학습에서는 출력 계수를 바꿨다. 관측 기반 선택 억제·전환·U/P 방향은 직접 획득한 보상 부호를 별도 네 칸 기록에 저장해 이용한다. 이 기록도 추가 학습 상태지만, 출력 가중치나 내부 KC→MBON 시냅스와 같은 상태는 아니다. NoGo의 0보상은 숨은 정답을 알려주지 않으며, 주 정책은 기억표를 직접 조회해 답하지 않는다.

이 후속들에서 내부 KC→MBON 가중치·인코더·같은 입력의 내부 활성은 고정이었다. 상태가 바뀐 앞선 내부 가소성 연구나 인간 조개 비교의 모델과 혼동하지 않는다. 가중치가 변했다는 사실, 내부 활성이 변했다는 사실, 행동 수행이 충분히 좋아졌다는 사실은 별도 결과다. [기존 내부·출력 갱신 비교](learning-ablation-findings.md), [인간 비교](human-shell-findings.md)

실제 연결 자료에서 유도한 부분 투사망은 전체 초파리 뇌의 생리학적 실행을 재현하지 않는다. 전체 annotation에서 LC11 뉴런을 확인한 사실과 LC11 자극 경로를 구현한 사실은 다르다. 모델의 보상 스칼라나 안전 제약을 실제 DAN 발화·도파민 생화학·구획별 가소성과 동일시하지 않는다. [DrosoMem 재사용 감사](drosomem-audit.md), [문헌의 직접 근거와 모델 가정](literature-review.md)

## 4. 공통 수정 상한과 실제 자원은 다르다

자기 문제의 점수 수정 폭을 맞추는 기준과 출력 가중치의 L2 이동 길이를 맞추는 기준은 다르다. 투영 방식의 충분한 습득에는 더 큰 이동과 추가 고정 계수·행렬 계산이 들어갔다. 반대로 단위 길이로 정규화하면 자기 수정과 남겨 둔 도움의 크기도 줄 수 있다. [수정량 제한](update-budget-findings.md), [정규화 약화](normalization-loss-findings.md)

같은 한 번 수정 상한·시행 수·누적 상한을 적용해도 실제 Go 횟수, 획득 보상, 누적 이동 길이, 제곱 이동량, 최적화·캐시·기억 처리 비용은 같아지지 않는다. 동일한 출력 좌표에서의 L2는 계산상 자원 지표이며 생리학적 에너지나 다른 매개변수화에서도 불변인 비용이 아니다.

같은 제한에서 일부 방법이 개선 기준을 통과하지 못한 것은 그 등록의 입력·규칙·예산에서 얻은 결과다. 모든 비용 제한 학습이나 다른 목적의 불가능성을 증명하지 않는다. 정답표를 제공한 진단, 정적 조회 참고, 분석적 상한의 유리한 값으로 실제 보상만 받은 주 방법의 실패를 대체하지 않는다.

## 5. 한 번의 수정, 실제 경로, 장부 배분을 구분한다

고정 저장 상태에 대안 방향을 한 번 대입한 점수·확률 이득은 그 방향으로 실제 학습한 최종 성적이 아니다. 방향을 바꾸면 뒤의 상태·선택·보상·보상 기록과 실제 수정량도 함께 달라진다. 선형 목적의 전역 최적성 인증은 해당 목적·제약의 증거이며 유한한 확률 변화나 미래 최종 성적의 전역 최적성을 보장하지 않는다. [단일 수정의 목표 정렬](probability-alignment-findings.md), [U/P 실제 학습](objective-learning-findings.md)

저장 경로의 Shapley 분해는 상태·실제 스칼라·방향을 가져오는 순서를 대칭적으로 평균한 정확한 장부다. 혼합 셀에서는 실제 스칼라를 새 상태의 확률로 다시 계산하지 않아 일부 셀이 실제 학습 규칙의 관계를 동시에 만족하지 않을 수 있다. 이후 선택과 보상을 실행한 독립 개입, 유일한 원인 비율, 새 정책의 성적 예측으로 해석하지 않는다.

교차 계산은 양쪽 모두 실제로 Go를 한 적격 시행에 한정하고, 한쪽만 Go인 실제 효과를 별도 보존했다. NoGo의 잠재 방향이나 보상을 새로 생성하지 않았다. 음수 상태 몫은 당시 상태가 더 나빴다는 뜻이 아니며, 같은 수정이 확률로 변환되는 정도의 차이도 포함한다. [최신 경로 분해](objective-pathways-findings.md)

누적 도움·방해 질량, 정답 확률의 마지막 수준, 선택 전 점수(logit), 단위 방향 영향, 실제 이동 길이는 다른 양이다. 확률이 여러 번 오르내린 누계는 100%p를 넘을 수 있다. 양수·음수 질량을 나눈 몫의 부호와 실제 새 피해 시행을 동일시하지 않는다. 시드별 비율의 평균과 전체 질량을 합친 비율도 구분한다.

## 6. 습득·보호·일반화의 판정

작은 양수 성적 차이, 사전 실용 개선 기준 통과, 충분한 습득, 보호 동작은 별개다. 5%p·8/10 같은 문턱은 각 연구에서 미리 정한 실용 기준이며 통계적 유의성이나 생물학적 경계가 아니다. 미지지는 효과가 정확히 0임을 확인한 판정이 아니다. 유리한 보조 표현이나 대조의 결과로 원래 주 조건을 바꾸지 않는다.

여기서 미관측 다른 입력은 **아직 실제 Go 보상 부호를 얻지 못한 다른 연습 입력**이다. 게이트가 닫힌 동안 다른 입력을 움직이지 않고, 완전 관측 뒤에는 미관측 입력이 없으므로 U/P 등에서 보호가 통과하는 것은 설계상 예상된 작동 검사다. 새로운 입력·규칙에도 안전하거나 잘 일반화한다는 증거가 아니다.

첫 Phase 5에서 패턴 주 모델의 습득이 미달한 일반화 판정과, 개별·공동 습득 자격이 미달한 간섭·순서 판정은 그대로 닫혀 있다. 후속 네 문제의 출력 학습이나 보호 통과로 해당 과제의 선행 조건을 자동 통과시키지 않는다. [패턴 연구](pattern-rule-findings.md), [간섭·순서 연구](interference-order-findings.md)

## 7. 비교 단위와 인간 학습

계산 시드는 인간·초파리 개체가 아니다. 같은 참조 경로를 여러 후보나 대조에 재사용한 셀·시행·짝 경로도 새 독립 표본으로 늘려 세지 않는다. 후향 분석은 이미 알려진 부모 결과에서 질문을 정했으며 새 눈가림 확인 실험이 아니다. 서로 다른 등록·시드 집단의 끝점들을 임의로 빼거나 효과 크기로 합치지 않는다. 이번 종합은 새로운 메타분석이나 최신 체계적 문헌 고찰이 아니다.

후속들은 같은 네 문자열과 선행 결과를 바탕으로 순차 개발됐다. 새 시드와 사전 등록을 사용했어도 완전히 새 과제에서의 독립 확인을 뜻하지 않으며, 반복 개발 중 생길 수 있는 암묵적 선택 가능성을 모두 없앴다고 주장하지 않는다. 각 등록의 기준을 보존한 비교와 외부 자료·독립 과제에서의 재확인을 구분한다.

원래 공개 인간 조개 과제에서는 정한 학습 유사성 기준과 종합 예측 가설이 미지지였다. 일부 단순 대조의 평균 근접이나 무작위보다 좋은 조건부 예측으로 자율 학습 유사성을 대신하지 않는다. 원 난수 주소 오류 실행과 별도 수정 실행을 독립적인 두 인간 근거로 합치지 않는다.

이 결과는 인간 전체·초파리 전체의 학습 기작이 다르다는 결론도, 가능한 공통 계산 원리가 없다는 증명도 아니다. 인공 입력·과제·보상·사전 연습·실제 시간·집단 구성이 다르며, 후속 연구는 새 인간 효과를 검정하지 않았다. 행동 유사성만으로 공통 신경 기작을 주장할 수 없고, 이번에는 양성 행동 유사성 자체도 지지되지 않았다. 고등학교 수학 학습의 교육 효과나 수업 지침을 제안하지 않는다.

## 8. 보존과 재현 확인의 의미

원 등록·소스 버전·데이터 출처/라이선스·설정·해시·재현 명령과 독립 검산 영수증을 연구별로 유지한다. DrosoMem의 과거 입력 읽기 근거, 모든 대조보다 실제 배선이 우수하다는 근거 부재, M11 습득·전이 미달과 역사적 내부 학습의 한계를 이번 출력 후속의 성공으로 지우지 않는다.

수치·정보·해시 검사를 통과한 것과 과학 가설이 지지된 것은 다르다. 개발 오류, 등록 거부, 표시·소비자 형식 오류와 수정, 보고서 EOF 빈 줄 한 건의 표시 예외도 해당 원본과 별도 설명을 보존한다. 형식 예외를 과학적 무결성·습득 조건의 예외로 확대하지 않는다.

이번 마감의 재현 확인은 저장된 근거를 다시 확인하는 범위다. 모든 옛 자율 학습이나 방향 최적화를 새로 실행하지 않는다. 원자료·태그·등록·검산의 바이트 검증, 새 종합의 문자 그대로의 관측값 대조, 저장 기록의 읽기 전용 독립 산술을 구분하고 실제 실행 범위를 최종 영수증에 남긴다. 자동검사 수를 연구별로 단순 합산해 중복을 독립 검사로 세지 않는다. 해시 보존 확인을 원자료의 새로운 생물학적 독립 재현으로 부르지 않는다.

현재까지 얻은 계산적 구별과 경험에 따른 변화는 구체적인 모델·과제에 묶어 기술한다. 새 입력 일반화(Level 3), 인간 연구와의 정량 행동 유사성(Level 4), 독립 생물학 근거를 갖춘 관련 기작(Level 5)은 서로 다른 주장이다. 이번 마감 자체는 새 양성 Level 3·4·5를 추가하지 않는다. [쉬운 종료 설명](followup-closure-plain-language.md)

# 순서를 유지하는 입력 간격의 수학적 확인

2026-10-14, Asia/Seoul. 아래는 이번 설계에서 직접 도출한 계산적 사실이며 초파리나 인간의 관찰 결과가 아니다.

## 입력값과 주 비교

수량 n∈{1,…,8}에 대응하는 코드는 `[1,2,3,4,6−α,6,6+α,8]`이고 실제 입력 첫 좌표는 이 값을8로 나눈 것이다. α는 `{0.25,0.5,1,1.5}`로 고정한다. α=1은 기존 n/8 입력과 같다. 모든 코드 배열은 엄격하게 증가하며 범위·끝점·훈련 수량2/4의 값을 보존한다. 따라서 모든 배열에서 코드 크기만 비교하는 분석적 기준 모델은 정답을100% 맞힌다. 이 100%는 생물학적 모델의 결과가 아니다.

주 수량쌍5/7의 입력 중간값은 모든 α에서 `(6−α+6+α)/16=0.75`다. 입력 간격은 `2α/8=α/4`, 즉 `0.0625,0.125,0.25,0.375`이다. 참 수량쌍·비율5/7·수량차2·nuisance 행·후보 위치·모델 파라미터는 같고, 주 비교에서 두 수량을 부호화한 값의 간격만 달라진다. 이 두 수량은 훈련2/4의 입력 범위 밖에 있다. 다른 쌍은 코드 간격과 중간값이 함께 달라질 수 있어 같은 해석을 적용하지 않는다.

## 확률과 선택 방향이 다른 이유

현재 모델의 후보별 출력 점수는 고정 평가 상태에서 `s(q,u)=Σ_k g_k ReLU(e_k q+b_k+v_k·u)`로 쓸 수 있다. 내부 가중치와 마지막 선택 가중치의 곱을 합친 g를 이용한 계산이며, 별도 학습 규칙을 도입한 것이 아니다. 동일 nuisance를 가정한 작은 구간에서는 이 점수가 q에 대해 선형이다. 그 경우 두 후보의 점수 차이는 입력 간격에 비례할 수 있다. 점수 차이를 sigmoid 확률로 바꾸므로 간격이 좁아지면 정답 선택 확률이50%에 가까워져도, 더 큰 점수의 후보를 고르는 방향은 유지될 수 있다.

실제 평가에는 서로 다른 nuisance와 ReLU 경계가 있으므로 완전한 선형·단조 반응이나 모든 greedy 선택의 보존을 가정하지 않는다. 이 식은 가능한 설명이지 결과를 미리 보장하는 정리가 아니다. 주 지표는 **정답 선택 확률에 나타나는 학습 의존적 간격 민감도**이며, 결정적 큰 쪽 선택 비율(greedy)과 구분한다. 학습 전 대비 차이도 함께 계산한다. 사람의 심리적 확신을 직접 측정한 값은 아니다.

같은 참 수량 비율에서 인공 코드 간격을 바꾼 검사는, 모델 반응을 인간의 Weber 법칙이나 자연 수량 지각으로 읽기 전에 입력 표현의 기여를 점검하는 연구 절차다. 물체 그림·LC11·기호 의미·인간의 심리 물리 법칙은 이번 구현 범위에 없다. [사전 프로토콜](spacing-protocol.md)의 통과·실패 기준을 그대로 사용한다.

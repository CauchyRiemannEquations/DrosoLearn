# 인간과 모델의 조개 선택·반전 학습 비교: 실행 전 계획

작성일: 2026-10-19 (Asia/Seoul). 신규 독립 연구다. 이 계획·설정·분할·원자료·실행 소스를 해시로 동결하고 등록을 별도 커밋으로 공개한 뒤 실제 학습과 행동 집계를 시작한다. 비공개 Git의 전향적 동결이며 공인 공개 사전등록은 아니다.

## 쉽게 설명하면

사람이 조개를 줍거나 지나가게 하는 게임의 공개 기록을 이용한다. 어떤 조개는 좋은 것을, 어떤 조개는 나쁜 것을 주다가 도중에 성질이 바뀐다. 모델에도 **같은 조개 순서와 조개 속 내용**을 제공하되, 모델이 줍기로 결정했을 때만 내용을 알려 준다. 사람이 받았던 보상을 모델의 다른 선택에 그대로 주지 않는다.

두 가지 질문을 분리한다. 첫째, 사람의 과거 경험을 본 모델이 그 사람의 다음 선택을 예측하는가? 둘째, 스스로 선택하며 학습한 모델이 사람과 비슷한 속도로 배우고 반전에 적응하는가? 다음 선택 예측이 좋아도 두 번째 질문의 답이 자동으로 긍정이 되지는 않는다.

## 근거와 범위

원자료는 TNU, *Dataset from a probabilistic Go/NoGo reversal-learning task*, 고정 Zenodo 기록 [10066829](https://doi.org/10.5281/zenodo.10066829)의 `readme.pdf`와 `Dataset_TNU.zip`이다. 이 연구는 새로운 인간 실험을 실시하지 않는다. 기존 Marković 자료의 정확한 실행판 미확인 gate를 해제하거나 재해석하지 않는다.

저장소 메타데이터의 CC BY 4.0과 첨부 설명서의 CC BY-NC 4.0 표기가 다르므로 출처 검토에서 두 진술을 함께 보존한다. 원자료를 새로 재배포하지 않고 비상업적 로컬 연구에 사용한다. 코드 라이선스가 원자료 라이선스를 바꾸지 않는다.

약물군 표기와 혈중 농도 사이의 불확실성이 있어 특정 집단을 생물학적 위약군으로 확정하지 않는다. 원자료의 검증 가능한 전체 참가자를 포함하며 약물·진단·연령 효과를 분석하지 않는다. 모델에 약물군·개인 인적 정보를 입력하지 않는다. 결과는 해당 혼합 집단의 기록된 행동에 한정한다. 정상인 전체나 초파리 개체에 일반화하지 않는다.

## 과제와 기록의 의미

각 시행에는 조개 ID 1–6, 숨은 상태 1/2, 잠재 내용 0/1/2가 있다. 내용은 0=빈 조개, 1=진주, 2=흙이다. Go는 수집, NoGo는 수집하지 않음이다. 실제 사람의 Go/NoGo와 반응 시간은 별도 로그에 있으며 trace와 로그의 조개·내용·원 시행 번호 대응을 검증한다. NoGo 때도 원파일에 잠재 내용이 저장되지만 **학습자에게는 공개되지 않는다**.

| 조개 ID | 순서 | 상태 1 | 상태 2 |
|---|---|---|---|
| 1 | RNRN | R | N |
| 2 | NRNR | N | R |
| 3 | RPRP | R | P |
| 4 | PRPR | P | R |
| 5 | PNPN | P | N |
| 6 | NPNP | N | P |

설명서에서 R은 진주 80%·빈 조개 20%, P는 흙 80%·빈 조개 20%, N은 항상 빈 조개다. 상태 변화 시점은 조개별로 따로 기록한다. 관측된 유한 trace의 빈도가 정확히 80%가 될 것을 요구하지 않는다. 문서상 불가능한 상태·내용 조합, 중복 ID, 대응 오류, 비이진 행동이나 불연속 시행 번호는 무결성 실패로 중단한다. 행동 성과를 이유로 사람을 제외하지 않는다.

모델의 Go 보상은 해당 원 시행의 잠재 내용에 따라 +1/0/−1, NoGo 보상은 0이다. 학습자 API에는 선택 조개·선택 행동·실제 획득 보상만 전달한다. 숨은 상태·반전 일정·잠재 내용·향후 기록은 평가와 환경 계층에만 둔다. 이 자율 실행은 기록된 외생 trace를 다시 사용하는 계산 벤치마크다. 새 보상을 뽑는 시뮬레이션이나 사람의 실제 반사실적 행동 재현으로 부르지 않는다.

## 분할과 누출 방지

원본 구조·메타데이터만으로 참가자 전원과 누락 여부를 확정한다. 메타데이터 50명 중 A0016은 구조적으로 잘린 기록이어서 제외하고, 서로 정합한 완전 기록 49명(각 216시행)을 포함한다. 이는 학습 성과에 따른 제외가 아니다. 참가자 ID에 접두사 `drosolearn-shell-v1:`를 붙인 문자열의 SHA-256 오름차순 앞 20명을 calibration, 나머지 29명을 test로 지정한다. ID 목록과 정확한 정렬 문자열을 설정·분할 파일에 고정한다. 사람별 모든 시행은 한 분할에만 속한다. 학습 성과나 약물값을 보고 분할하지 않는다.

calibration은 모형별 사전 후보 중 학습률을 고르는 데만 사용한다. 사람마다 동일한 가중치로 다음 선택 NLL을 평균하고, seed 평균으로 후보를 선택한다. 학습률 후보는 `[.03,.1,.3]`, 내부 학습률은 출력 학습률의 .1배다. Q-learning의 alpha도 같은 세 후보이며 beta는 4로 고정한다. 동점이면 작은 학습률을 고른다. calibration seed는 13001–13003, test seed는 13101–13105다. 가장 잘된 seed를 고르지 않는다. test를 본 뒤 학습률·예산·허용폭·평가 창을 바꾸지 않는다. 이는 계산 예산을 제한한 초기 검증이며 불확실하다고 test seed를 추가하지 않는다.

test 참가자마다 모델은 초기 가중치로 새로 시작한다. calibration 참가자의 학습된 시냅스나 출력 계수를 넘기지 않는다. test에서 하는 온라인 갱신은 해당 참가자의 과거 시행에만 의존한다. 이는 새 참가자에 대한 순차 예측 검증이며, 전체 미래를 한 번에 예측하는 검증이나 새로운 수학 규칙의 일반화가 아니다.

## 표현·모델·자원

입력은 두 행동의 7차원 벡터다. NoGo는 영벡터, Go는 조개 ID에 대응하는 앞 여섯 좌표의 one-hot 벡터이며 마지막 좌표는 0이다. 조개 ID는 인공 기호이며 실제 조개 시각 인식·수량 부호화가 아니다. 초기 feature RMS는 여섯 조개 사전으로 계산해 고정하고 사람의 평가 행동으로 정하지 않는다.

조건은 `fixed`, `plastic`, `rewired_fixed`, `rewired_plastic`, `ann_fixed`, `ann_plastic`, `linear`, `q`, `uniform`, `bias`, `persistence`의 11개다. 실제 KC→MBON 부분 배선의 고정·가소성 조건, 같은 수의 뉴런·연결과 정해진 특성을 보존한 재배선의 고정·가소성 조건, 일반 무작위 희소망의 고정·가소성 조건을 비교한다. 선형 정책, 단순 Q-learning, 무학습 대조도 포함한다. 조건 목록·학습률 후보·초기화·연결 수·갱신 수·계산 seed 수는 설정과 결과에 기록한다. 일반망과 실제 배선의 자원 차이는 숨기지 않는다.

네트워크 출력은 두 행동 점수 차이의 logistic 확률이고 head는 0으로 시작한다. 새 독립 코드에서 선택 행동 a, Go 확률 p, 획득 보상 r의 정책경사 계수 `(a−p)×r`를 사용한다. 내부 가소성은 기존과 같은 마스크·비음수 상하한·갱신 전 head를 사용한 단순화된 규칙으로 제한한다. NoGo와 중립 보상의 계수는 0이다. 처음에는 head가 0이므로 첫 강화 시행의 내부 변화가 0일 수 있다. 갱신 호출 수와 실제 비영 변화 수를 구분한다.

Q-learning은 Q=0으로 시작하고 선택한 행동의 관측 보상만 사용하며 NoGo에서 잠재 Go 내용을 보지 않는다. uniform은 항상 Go 확률 .5, bias는 calibration 전체 Go 횟수에 Laplace 보정을 한 `(Go+1)/(시행수+2)`의 고정 확률이다. persistence는 직전 **같은 조개** 행동을 .9 확률로 반복하며 해당 조개를 아직 보지 않았으면 .5다. 무학습 대조는 보상을 이용해 매개변수를 바꾸지 않는다. 실제 배선에 대한 주장은 일반망·재배선·단순 학습자와의 결과를 함께 보고 판단한다. 이 규칙은 보정된 DAN 모델이나 생물학적 dopamine 가소성의 재현이 아니다.

## 두 실행의 분리

**조건화된 다음 선택 예측:** 시행 t의 Go 확률을 먼저 저장하고 실제 사람 선택에 대한 NLL/Brier를 채점한다. 그 다음에만 그 사람이 선택해 얻은 보상으로 갱신한다. 사람의 NoGo에는 잠재 내용을 공개하지 않는다. 조건·seed별 참가자 평균 점수와 무학습·단순 학습자 대비 차이를 보고한다. 좋은 예측은 독립적인 자율 학습의 성공을 뜻하지 않는다.

**자율 trace 실행:** 모델이 고른 행동을 기록하고 그 행동에 맞는 보상을 환경에서 받는다. 입력 조개·잠재 내용·반전 시점은 같은 참가자 trace에서 공유하지만 행동·획득 보상·이후 가중치는 모델별로 달라질 수 있다. 초기화 seed와 행동 추출 seed를 기록하며 조건 간 공유 난수 의존성도 남긴다. 사람 시행과 모델 시행, 공유 trace와 독립 표본을 혼동하지 않는다.

## 행동 비교와 사전 허용폭

엄격히 유리한 행동이 뒤집히는 조개 3/4의 R↔P 반전만 일차 반전 지표로 사용한다. R에서 Go, P에서 NoGo가 기대 보상상 유리하다. N에서는 두 행동의 기대 보상이 같으므로 N을 무조건 정답/오답으로 채점하지 않는다.

일차 지표는 (1) 조개 3/4 최초 상태의 마지막 3회 최적 행동률 − 첫 3회 최적 행동률, (2) 조개 3/4 각 반전 후 첫 3회 최적 행동률, (3) 같은 반전 상태의 마지막 3회 − 첫 3회 최적 행동률이다. 원자료에서 이 두 조개는 각각 40회이며 네 상태 구간의 길이는 달라질 수 있다. 상태 순서 `[1,2,1,2]`와 구간당 최소 6회 노출을 요구해 첫/마지막 창이 겹치지 않게 한다. 조개별 노출 횟수로 창을 잡고 다른 조개 시행을 섞지 않는다. 조개·반전별 값을 먼저 계산한 후 참가자 안에서 동일 가중치로 평균한다. 계획한 구조가 맞지 않으면 사후 창 변경 대신 무결성 실패로 보존한다. 참여자 전체를 행동 성과로 사후 제외하지 않는다.

사람은 관측 행동으로, 자율 모델은 기록된 확률과 실제 표본 행동을 각각 계산한다. 유사성 일차 판정에는 실제 표본 행동을 쓰고 확률 곡선은 분리된 보조 결과로 둔다. 이번 집계의 중심은 세 행동 지표와 NLL/Brier다. 조개 3/4의 반전 후 첫 7회 노출 곡선은 기술적 보조 그림으로 남기며 참가자 내 여섯 반전을 독립 사람 표본으로 세지 않는다. 여섯 조개의 Go 변화, 보상/흙/빈 조개 뒤 전환과 오류 분포는 보존된 원 시행 배열로 추후 별도 분석할 수 있지만 이번에 그 보조 집계를 모두 실행했다고 표현하지 않는다. 전환을 후속 보고할 때는 원래 시행 순서·같은 조개의 다음 관측·상태 경계와 분모 정의를 명시하고, 결측을 이어 새 관측을 만들지 않는다.

세 일차 지표의 인간·자율 모델 평균 차이에 대해 각각 사전에 ±0.10, 즉 10%포인트의 실용적 동등성 허용폭을 둔다. 이는 인간 집단의 자연적 경계나 생물학적 동등성 정의가 아니다. 사람 ID와 모델 seed를 별도 축으로 2,000회 재표집하고, 같은 trace 및 seed를 공유하는 상관을 보존해 90% 구간을 계산한다. 재표집 seed도 설정에 고정한다.

일차 행동 가설 H_similarity는 `plastic`으로 지정한다. 세 지표 구간이 **모두** 닫힌 허용폭 안에 있을 때만 이 과제·세 지표·허용폭의 제한적 행동 유사성이 지지된다고 부른다. 구간이 허용폭 경계를 걸쳐 넘으면 불확실, 구간 전체가 허용폭 밖이면 그 지표의 실질적 차이로 보고한다. 다른 조건은 같은 계산의 기술적 대조로 보고하며 가장 잘 맞는 조건을 일차 조건으로 바꾸지 않는다. `p>.05`나 비슷한 모양만으로 유사성을 인정하지 않는다. 모든 조건과 실패를 보고한다. 계산 seed는 사람 수를 늘리지 않는다.

별도 일차 예측 가설 H_prediction은 `plastic`의 참가자 평균 NLL 개선량이 uniform, calibration-only bias, persistence 각각에 대해 사람·seed 축을 보존한 paired 90% 구간 하한에서 .01 nats/시행을 초과하는지로 판정한다. 세 대조를 모두 통과해야 한다. Q-learning·선형·다른 배선과의 예측 차이는 함께 기술하되 일차 가설의 대조를 교체하지 않는다. H_prediction과 H_similarity는 독립적으로 보고한다. 인간의 최초 gain이 작아도 사전 연습·기존 경험 때문에 인간이 학습하지 않는다고 결론 내리지 않는다. 경험에 따른 최초 변화까지 동반한 패턴은 사람·plastic의 초기 gain 구간 하한이 각각 .05를 초과하고 H_similarity도 통과할 때만 별도로 지지한다. 무학습 모델도 세 요약값을 맞출 수 있으므로 행동 유사성만으로 경험에 따른 학습이나 공통 기작을 추가 주장하지 않는다.

모델 초기/최종 가중치·활성의 상세 witness는 동결된 test 순서의 첫 사람 A0021 한 명에 대해 모든 조건·시드·두 실행 경로를 보존한다. 이는 저장량을 제한한 진단 기록이며 대표 참가자를 고르거나 전원 상태를 측정했다는 뜻이 아니다. 전원에 대해서는 시행별 변화량과 참가자별 요약을 보존한다. Q의 value table 변화는 신경 출력 가중치 변화와 구분한다.

## 검증·실패·해석

구조 검증, 합성 소규모 자동검사, 원자료/코드/설정 해시 동결, 등록 커밋의 원격 확인 후 본 실행을 한 번 수행한다. 실제 학습·예측·시행 집계 수를 기록한다. 독립 검산은 원 trace·사람 로그에서 보상을 재구성하고, 저장한 시행 확률/행동으로 NLL·Brier·평가 창·세 지표·분모·동등성 판정을 별도로 다시 계산한다. 무학습 내부/출력 불변, 숨은 내용 차단, 이전 시점만 소비, seed/사람 분할, 자원·그림 정합성을 검사한다.

무결성 실패는 그 경로와 오류를 보존하고 과학적 미지지와 구분한다. 같은 등록의 시드 교체나 시행 연장으로 실패를 성공으로 바꾸지 않는다. 후속 수정이 필요하면 원 실패를 남긴 새 등록으로 진행한다.

가능한 결론은 다음 선택 예측과 제한적인 행동 측정의 유사성·차이·불확실성이다. 사람과 모델은 감각·운동·사전 경험·보상 가치가 다르다. 인간의 뇌 내부 변화는 측정하지 않았고 실제 초파리의 해당 과제 행동도 시험하지 않았다. 공통 신경 기작, 교육 효과, 수학 개념 이해나 모든 Phase 3 과제의 완료를 주장하지 않는다. Phase 5 종합은 이 비교의 실제 결과와 실패를 확인한 다음 별도로 진행한다.

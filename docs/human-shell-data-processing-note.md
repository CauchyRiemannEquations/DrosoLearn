# 인간 자료의 파생 시행 기록과 저장 범위

2026-10-19 (Asia/Seoul). 원 문서·등록·산출물을 변경하지 않는 추가 설명이다.

[동결된 출처 검토](human-shell-source-review.md)는 저장소에 “집계 결과만 기록”한다고 적었다. 그러나 [동결된 실험 계획](human-shell-protocol.md)은 시행별 확률·행동·보상과 배열을 보존하도록 명시했고, 실제 구현도 이 계획을 따른다. 따라서 출처 검토의 집계 한정 표현은 구현과 일치하지 않는 불완전한 설명이었다.

원 ZIP·PDF·개별 CSV/TXT는 저장소 밖 캐시에 보존하고 그대로 재포장해 올리지 않았다. 다만 연구 저장소의 파생 `trajectories.npz` conditional 축에는 평가 대상 29명의 실제 선택 6,264개와 해당 선택에서 획득한 보상이 조건·시드 축에 반복 저장된다. 시행별 파생 기록이 있으며, 집계만 저장한 것은 아니다. 같은 선택의 반복 저장을 독립 인간 시행이나 추가 참가자로 세지 않는다. 원자료의 참가자 코드를 사용하며 신원을 새로 연결하지 않는다.

비공개 GitHub도 로컬 캐시와 구분되는 외부 보관이다. 원출처의 CC BY 4.0 메타데이터와 PDF의 CC BY-NC 4.0 진술을 둘 다 유지하며, 더 제한적인 비상업 연구 범위를 함께 따른다. 파생 자료에도 원출처·권한 조건을 적용한다. 프로젝트의 MIT 코드 라이선스가 인간 자료나 커넥톰의 조건을 바꾸지 않는다. 공개 배포·상업 이용으로 범위를 넓히는 근거를 이번 작업에서 마련했다고 주장하지 않는다.

두 실행의 원본 결과와 이 설명을 함께 보존한다. 보정과 조건부 예측을 v2에서 다시 수행하지 않고 원래 배열·선택·요약과 바이트 대응을 검증하는 것도 실제 재사용 범위를 확인하기 위해서다.

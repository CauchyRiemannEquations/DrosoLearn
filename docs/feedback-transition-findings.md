# 실제 기록의 피드백 뒤 선택 유지·전환 집계

작성일: 2026-10-15 (Asia/Seoul). 연구 ID `feedback_transition_v1`.

## 먼저 쉽게 설명하면

카드를 고른 뒤 좋은 결과나 좋지 않은 결과를 받았을 때, 바로 다음에 같은 선택을 했는지 셌다. 사람의 두 카드는 원본 코드가 가리키는 같은 카드끼리, 모델은 화면 좌우를 바로잡은 ‘작은 수량/큰 수량’ 범주끼리 비교했다.

**사람 원본25개와 모델280개 경로 모두 끝까지 처리했고, 별도 프로그램의 재계산도 일치했다.** 이는 실제 선택 기록을 같은 수식으로 측정할 도구가 작동한다는 결과다. 사람과 모델이 같은 방식으로 배우거나 어느 쪽이 더 잘 배웠다는 결과는 아니다.

예를 들어 설명용 가상 기록에서 실제 이득 뒤 계산 가능한 이웃 선택이10쌍이고 그중7쌍이 같은 카드면 유지율은70%다. 실제 결과에는 이 분자·분모와 기록별 비율을 모두 남겼다. 정보 요청이나 빈칸 사이를 건너뛰어 두 선택을 붙이지 않았다. 이 예시 숫자는 실제 자료의 성적이 아니다.

## 실제 처리 범위

아래 표는 자료 처리와 분모 현황이며 학습 성적표가 아니다. 조건부 유지·전환 비율은 [기록별 원 결과](../results/feedback_transition_v1/metrics.json)의 각 `by_feedback`에 있다. 집단·종간 평균이나 차이를 계산하지 않았다.

| 자료 | 기록 경로 | 원 시행 | 원 인접 후보 쌍 | 유효 쌍 | 제외 쌍 |
|---|---:|---:|---:|---:|---:|
| 사람: 원본 검증 Main 전체25행 | 25 | 25,000 | 24,975 | 21,530 | 3,445 |
| 모델: 이전 반전 실험 phase2 전체 | 280 | 112,000 | 111,720 | 111,720 | 0 |

모델은10계산시드×7조건×4이력의400시행씩이다. 사람 기록과 같은 수의 독립 참가자라는 뜻이 아니다. phase1의 공유 선행 학습, 정답을 쓰는 `expected_updates.csv`, 평가 probe와 계수 축소 연구는 넣지 않았다. 원 모델을 새로 훈련하거나 과거 실패를 바꾸지 않았다.

합계137,000시행에서136,695개 원 이웃 쌍을 검사했다. 유효133,250개와 제외3,445개의 합계가 맞는다. 이는 **쌍의 처리 수**이며 독립 표본 수나 학습 성공 횟수가 아니다. 모델 제외0개는 기록 형식상 빠질 쌍이 없었다는 뜻이며 정답률100%가 아니다.

한 쌍에 여러 사유가 겹칠 수 있어 위 건수 합은3,445와 다르다. 예를 들어 정보 요청 시행은 현재 선택과 이진 피드백 조건을 동시에 충족하지 못한다. 상태 경계1,260건은25기록에서 경계를 가로지르는 쌍의 표시이며 서로 다른 독립 반전 환경1,260개가 아니다. 같은 조건의 원 일정은 공유된다.

각 후보의 원 파일 위치·원 시행 위치·채택 여부·겹친 사유·현재 이진 피드백·유지 여부는 [전체 ledger](../results/feedback_transition_v1/ledger.csv)에 있다. 사람은 MAT 원 위치1기반, 모델은 헤더를1행으로 세는 CSV 원행 번호다. 다음 시행의 피드백이 비어 있다는 사실만으로 현재 쌍을 빼지 않는다. 분모0은 `null`이고0%로 채우지 않는다.

## 해석에서 남는 차이

- 사람 과제는 확률적 금전 이득/손실과 세 번째 정보 요청 선택이 있다. 모델은 인공 수량 두 선택과 결정적 정오 보상을 사용한다. 사람의 피드백0은 금전 손실이고 모델의0은 무보상이다.
- 모델 phase2의 보상1은 곧 현재 작은 수량 선택, 보상0은 큰 수량 선택이다. 따라서 조건부 유지율은 보상 효과와 현재 선택 지속성을 분리하지 못한다. 사람은 같은 카드에서도 이득과 손실을 받을 수 있어 조건화 구조가 다르다.
- 사람 카드와 모델 수량 범주는 같은 자극이 아니다. 모델의 수량은 입력에서 직접 제공되며 시각적으로 개수를 알아낸 결과가 아니다.
- 사람은1,000시행과 여러 상태 반전, 모델은선행경험이 서로 다른400시행 구간이다. 인간의 정보 요청/결측을 제외한 쌍은 전체 행동을 대표한다고 보장할 수 없다.
- 일부 비가소성 조건의 fresh/reset phase2는 기존 독립 감사가 정확 중복을 확인했다. 같은 시드의 다른 조건도 입력·행동 난수를 공유한다. 이력을 보존하되 독립 반복으로 합산 추정하지 않는다.
- 공개 과제 코드와 실제2018 원본의 정확한 실행판 연결은 미확인이다. 원 코드와 구조가 함께 지지한 `source-coded card identity`의 제한적 기술 결과다. 미대응49행과 OpenNeuro 코드 의미 미해결 결과도 그대로 남는다.

이 결과는 Level4 또는 Level5의 증거가 아니다. 같은 수식으로 숫자를 얻는 것과 같은 학습 메커니즘을 확인하는 것은 별개다. 사람이나 실제 초파리의 수학 이해, 교육 효과로 확대하지 않는다.

## 재현

[실행 전 프로토콜](feedback-transition-protocol.md)의 명령과 Python3.12 고정 의존성을 사용한다. 최초 결과는 `feedback-transition-v1` 태그의 별도 checkout에서 같은 고정 원본으로 재현한다. 경로는 모두 새 출력으로 바꾼다. 원본 캐시 복구는 [원본 감사](human-osf-origin-protocol.md)의 `register --fetch`를 사용하며 원 MATLAB 코드를 실행하지 않는다. 설정을 바꾼 연구는 새 이름·프로토콜·등록으로 진행한다.

다음 단계는 보상 확률·선택 수·반전 일정·입력과 예산을 통제한 작은 계산 대조 실험에서 이 지표가 무엇에 민감한지 확인하는 것이다. 같은 측정값이 생겨도 단순 선택 편향이나 무학습 정책으로 설명되는지 먼저 검사하고, 그 결과를 보기 전에 비교 가설과 반증 기준을 별도 고정한다.

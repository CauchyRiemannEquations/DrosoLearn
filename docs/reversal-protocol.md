# 보상 반전 비용 진단 — 사전 프로토콜 v1

작성일: 2026-10-14 (Asia/Seoul). 이 문서는 **smoke v1의 반전 실패를 확인한 뒤, 새로운 시드를 실행하기 전에 정한 후속 진단 계획**이다. 탐색에서 나온 가설을 전향적으로 검사하지만, 최초 연구 전체의 외부 확증 사전등록은 아니다. 이 문서와 설정·코드·데이터의 해시를 등록한 뒤 실행한다. 등록 이후 내용을 바꾸면 새 등록과 새 결과 디렉터리를 사용한다.

기존 `smoke_v1`의 코드 기준 버전은 `ef5ffdb70c037e4b9617e7ada8969a6e9a5bfda7`이다. 기존 [실험 프로토콜](experimental-protocol.md), 3시드 결과와 실패 기준을 보존한다. 이번 실험은 기존 실패를 성공으로 바꾸기 위한 학습률 변경이나 시행 연장이 아니다. 기존 확장 설정의 시드 1001–1010도 사용하지 않는다.

## 비전공자를 위한 설명

지금의 모델에는 “2개” 또는 “4개”라는 수량 정보를 직접 넣어 준다. 그림을 보고 물체를 세는 단계는 아직 구현하지 않았다. 따라서 현재 질문은 이미 주어진 수량에 보상을 연결해 선택을 바꿀 수 있는지다.

첫 실험에서 모델은 “2개와 4개 중 4개를 고르면 보상”이라는 규칙을 일부 조건에서 배웠다. 그런데 이후 “이제 2개를 고르면 보상”으로 규칙을 바꾸자, 정한 연습 횟수 안에 새 규칙을 충분히 배우지 못했다.

이번에는 원인을 나눠 본다. **처음부터 2개를 고르도록 배우는 모델**도 실패하는지, 아니면 **4개를 고르던 경험이 있는 모델**이 특히 느린지 비교한다. 계속 같은 규칙을 연습하는 모델도 둔다. 마지막으로 모델의 최종 선택 담당 가중치만 처음 상태로 되돌려, 앞서 바뀐 내부 연결과 최종 선택 담당 부분의 영향을 구분한다. 이 되돌림은 컴퓨터 안에서만 하는 조작이다.

“학습 곡선”은 연습 횟수에 따라 정답을 고를 확률이 어떻게 변했는지를 나타낸다. “반전 비용”은 처음부터 새 규칙을 배우는 모델과 비교했을 때, 이전 규칙을 바꿔 배우는 모델이 얼마나 뒤처졌는지다. 값이 양수면 이전 경험이 새 학습을 늦춘 것이고, 음수면 오히려 도움이 된 것이다. 양수라고 해도 사람이나 살아 있는 초파리의 뇌에서 같은 원인이 작동한다고 결론내릴 수는 없다.

## 질문, 가설과 반증

연구 질문: 같은 인공 입력·학습 규칙·새 규칙 학습 예산에서, 먼저 반대 규칙을 학습한 이력이 새 규칙의 학습 곡선에 비용을 만드는가?

주 가설 H-R: 아래에서 정의한 `fresh_low − high_then_low`의 정규화 IID 학습 곡선 면적 차이가 **각 모델 조건에서 평균 0.10 이상**이고, 그 조건의 **10시드 중 8시드 이상에서 차이가 엄격히 양수**다. 두 조건을 모두 충족해야 해당 모델 조건의 H-R 기준 통과로 기록한다. 0.10은 평균 정답 선택 확률의 10%포인트 차이를 요구하는 계산적 실용 기준이며, 문헌에서 확정된 생물학적 임계값이 아니다. 이를 인간의 의미 있는 학습 비용으로 환산하지 않는다.

모델 조건별로 따로 판정한다. 여섯 조건을 합쳐 하나의 성공으로 만들거나, 성공한 조건만 대표 결과로 보고하지 않는다. 해당 기준 미달·반대 방향·무차이는 모두 가설 미지지로 남긴다. 이 판정은 사전 정의한 계산 지표를 충족했는지를 뜻하며 유의성 검정이나 커넥톰 우위의 증명이 아니다.

새 규칙을 처음 배우는 `fresh_low`가 습득 기준에도 못 미치면, 기존 반전의 절대 성능 미달을 “배운 규칙 때문에 생긴 어려움”만으로 설명할 수 없다. 그래도 전체 시드의 연속형 차이와 H-R 판정은 보고하며, 낮은 규칙 자체의 습득 실패라는 대안을 함께 기록한다. 먼저 높은 규칙을 습득하지 못한 경우에는 “이미 습득한 규칙의 수정”이라는 해석도 제한한다.

보조 질문은 내부 가소성·배선에 따라 비용이 달라지는지, 최종 선택 가중치 초기화 이후에도 학습 이력의 효과가 남는지다. 방향·통계적 우열을 미리 가정하지 않는 진단으로 둔다.

## 모델과 변경하지 않는 사항

기존 `Learner`를 사용한다. 실제 연결은 FlyWire v783에서 확보한 한 단계 KC→MBON 투영의 1,474쌍이며, nominal 512 KC·48 MBON 중 489 KC·29 MBON에 해당 연결이 있다. DAN·APL·재귀 상태·LC11 시각 회로는 계산하지 않는다. 입력은 수량을 직접 제공한 `n/8`과 여섯 인공 nuisance descriptor다. 점 이미지를 보고 수량을 추출하는 실험이 아니다.

출력 학습률 0.1, 내부 학습률 0.01, 무작위 고정 encoder, 초기값 생성 방식, 선택·보상 기반 갱신, 초기 내부 가중치 대비 `[0, 2w_initial]` 제한은 유지한다. 출력층은 48개 가중치, 가소성 조건에는 1,474개 추가 내부 학습 가중치가 있다. 고정과 가소성의 총 학습 자원이 같다는 가정은 하지 않는다.

| 모델 조건 | 배선 | 내부 가중치 학습 | 최종 선택 가중치 학습 |
|---|---|---|---|
| `fixed` | 원래 KC→MBON | 없음 | 있음 |
| `plastic` | 원래 KC→MBON | 있음 | 있음 |
| `rewired_fixed` | 차수 보존 재배선 | 없음 | 있음 |
| `rewired_plastic` | 같은 재배선 | 있음 | 있음 |
| `ann_fixed` | 일반 무작위 희소 신경망 | 없음 | 있음 |
| `ann_plastic` | 같은 일반망 | 있음 | 있음 |

재배선은 KC outdegree·MBON indegree·MBON별 입력 가중치 multiset을 보존한다. ANN은 MBON indegree·입력 가중치 multiset을 보존하지만 KC outdegree는 보존하지 않는다. 모두 같은 뉴런 차원, 입력·학습 시행, 출력 크기를 사용한다. 가소성끼리는 내부 학습 파라미터 수도 맞춘다. 한 원본 부분집합과 시드별 한 대조 배선으로 얻은 차이를 모든 초파리 회로에 일반화하지 않는다.

## 다섯 학습 이력

각 모델 조건에서 다음 다섯 이력을 모두 수행한다. `high`는 4개 선택에 보상, `low`는 2개 선택에 보상한다. 정답을 고르면 보상 1, 다른 선택이면 0이며 습득과 반전의 시행별 입력은 서로 다르다.

| 이력 | 1단계 | 경계에서 하는 조작 | 2단계 | 비교 목적 |
|---|---|---|---|---|
| `high_then_low` | 높은 수량 보상, 400 학습 시행 | 없음 | 낮은 수량 보상, 400 학습 시행 | 기존 규칙과 충돌하는 학습 |
| `low_then_low` | 낮은 수량 보상, 400 학습 시행 | 없음 | 낮은 수량 보상, 400 학습 시행 | 같은 총 학습 횟수의 반복 연습 |
| `high_then_high` | 높은 수량 보상, 400 학습 시행 | 없음 | 높은 수량 보상, 400 학습 시행 | 같은 총 학습 횟수의 무반전 대조 |
| `fresh_low` | 수행하지 않음: 1단계 학습 시행 0 | 초기 상태 그대로 | 낮은 수량 보상, 같은 400 학습 시행 | 이전 학습이 없는 수치적 기준 |
| `reset_head_after_high` | 높은 수량 보상, 400 학습 시행 | 출력 가중치만 같은 시드의 초기 값으로 되돌림 | 낮은 수량 보상, 400 학습 시행 | 내부 변화와 출력 부분의 상호작용 진단 |

`fresh_low`는 총 400 학습 시행, 다른 이력은 800 학습 시행이다. 주 비교에서 맞추는 자원은 **2단계 새 규칙의 학습 예산 400회**다. 이전 학습 유무가 질문의 조작 변수이므로 총 경험까지 같다고 표현하지 않는다. 총 예산 800회의 대조는 `low_then_low`와 `high_then_high`가 담당한다.

`reset_head_after_high`는 내부 가중치·encoder·bias·초기 가중치 제한을 보존하고 출력 가중치만 되돌린다. 경계 직전 1단계 종료 상태와 되돌림 직후 2단계 시작 상태를 별도로 저장한다. 되돌림의 출력 변위와 내부 변위 0을 기록하고, 되돌림을 보상 학습 갱신 횟수에 포함하지 않는다. 이 조작을 실제 생물학적 기억 삭제로 해석하지 않는다.

## 시드, 입력과 대응 비교

새 계산 시드는 **2001, 2002, …, 2010**이며 전부 보고한다. 6모델×5이력×10시드다. 총 학습 시행은 `6×10×(4×800+400)=216,000`이다. 이 수와 평가 행 수는 계산량이며 독립 초파리 개체 수가 아니다. 조기 종료·유리한 시드 추가·실패 시드 교체를 하지 않는다.

시드마다 동일한 원본·재배선·ANN을 모든 이력에 재사용한다. 같은 시드의 encoder·bias·초기 출력 가중치도 조건과 이력에 맞춘다. 입력 stream은 `seed*100+21`(1단계), `+22`(2단계), `+23`(IID 평가), `+24`(OOD 평가) 방식으로 생성한다. IID/OOD 평가 각 128행, 고정 전체 활성 probe 8행을 사용한다. 학습과 평가 사이 실제 입력 fingerprint 중복, nuisance 교차 균형, 수량 oracle=1.0·각 nuisance 단서 oracle=0.5를 검사한다.

1단계 행동(`seed+180000`)과 2단계 행동(`seed+190000`)의 난수 uniform stream을 독립적으로 미리 생성하고, 2단계 stream을 모든 이력에 공통 사용한다. encoder·초기 head는 `seed+70000`, 재배선은 `seed+50000`, ANN은 `seed+60000`을 사용한다. `fresh_low`의 1단계 생략으로 2단계 난수 위치가 달라지면 안 된다. 행동 확률이 다르면 동일 uniform에서도 실제 선택이 달라질 수 있다. 그것은 의도한 정책 비교다. 입력·행동 stream의 정확한 시드와 uniform 배열은 결과 파일에 기록한다.

높은 규칙으로 시작하는 세 이력은 1단계에 정확히 같은 입력·행동 난수·초기값·학습 규칙을 사용해야 한다. 1단계 종료 내부·출력 가중치, 행동과 보상이 동일한지 검증한다. 같은 평가 입력을 반복해서 측정하지만 평가에서는 학습·행동 난수 소비·내부 변경을 하지 않는다.

## 지표와 사전 판정

주 평가값 `p_target`은 평가 행마다 정답 쪽을 고를 **확률의 평균**이다. 평가 중 새 행동을 샘플링한 실측 성공 비율이나 greedy 선택 정확도와 구분한다. `p_larger`, `p_smaller`를 함께 저장하므로 같은 상태를 두 보상 규칙 기준으로 해석할 수 있다.

`high_then_high`의 `p_target`은 높은 수량 기준이다. 나머지 이력의 2단계 `p_target`은 낮은 수량 기준이다. 무반전 대조의 높은 규칙 성능을 낮은 규칙 성공률과 혼동하지 않는다.

2단계 IID probe는 시행 0·100·200·300·400에서 측정한다. 시행 0은 경계 조작이 끝난 후의 상태다. 곡선 면적은 인접 checkpoint 사이를 직선으로 연결한 사다리꼴 적분을 400으로 나눈다.

`AUC = [Σ_j (p(t_j)+p(t_(j+1)))/2 × (t_(j+1)−t_j)] / 400`

따라서 AUC는 `[0,1]` 범위이며, 즉시 나타나는 기존 선호와 이후 회복 모두에 영향을 받는다. 이는 100시행 간격으로 측정한 곡선의 요약이며 매 시행의 정확한 평가 곡선 적분이 아니다. 초기 성능 차이를 통계적으로 없애서 반전의 직접 비용을 제거하지 않는다.

| 지표 | 계산과 판정 | 역할 |
|---|---|---|
| 주 반전 비용 | 시드별 `AUC(fresh_low)−AUC(high_then_low)`; 모델별 평균 ≥0.10 **및** 양수 시드 ≥8/10 | 전체 10시드로 H-R 판정 |
| 끝점 비용 | 400시행 IID `p_target(fresh_low)−p_target(high_then_low)` | 보조: 최종 성능만의 차이 |
| 습득 기준 | 1단계 종료의 해당 규칙 `p_target≥0.75` 그리고 1단계 초기 대비 증가 `≥0.15` | 처음 규칙의 습득 gate |
| 처음부터 낮은 규칙의 습득 | `fresh_low`의 2단계 종료 `p_small≥0.75` 그리고 시작 대비 증가 `≥0.15` | 새 규칙 자체의 학습 가능성 |
| 반전 기준 | `high_then_low`의 1단계 습득 통과 그리고 2단계 종료 IID `p_small≥0.75` | 기존 실패 기준과 같은 의미의 수정 성공 |
| OOD 성능 | IID와 별도로 처음/끝·각 checkpoint의 OOD `p_target` | 이미 제공된 수량의 nuisance shift 견고성 |
| 출력 초기화 비용 | 가소성 조건의 `AUC(fresh_low)−AUC(reset_head_after_high)` | 방향을 정하지 않은 내부 상태 잔여 효과 진단 |
| 최초 기준 도달 | 2단계에서 처음 IID `p_target≥0.75`인 100시행 간격 checkpoint | 보조; 미도달은 null/right-censored |

주 지표는 습득 여부로 시드를 고르지 않고 10개 전체에서 계산한다. 습득 gate를 통과한 시드의 조건부 비교는 **별도 보조 분석**으로 표기하며 해당 시드 수와 실패 시드 원자료를 함께 제공한다. OOD·최초 도달 시점·여섯 모델 차이·출력 초기화 진단을 근거로 주 판정을 사후 변경하지 않는다. 추가 학습률·예산·인코더 탐색은 새 실험에 해당한다.

모델별 시드 결과, 평균·표준편차·양수 개수·gate 통과 개수를 보고한다. 시드 수준의 계산 변이를 평가 사례를 독립 표본처럼 부풀린 신뢰도로 대체하지 않는다. 여섯 모델 간 작은 수치 차이만으로 우월성·동등성을 주장하지 않는다.

## 선택 확신과 알고리즘의 계산적 예측

변경하지 않은 갱신은 `f=(a−p)(r−0.5)`를 사용한다. 여기서 `p=P(right)`, 행동 `a`와 보상 `r`은 0/1이다. 정답 위치를 `y∈{0,1}`라 하면 이 완전한 이진 보상 조건에서 다음이 성립한다.

`E[f] = (2y−1)p(1−p)`

예를 들어 `y=1`이면 행동 1의 보상은 1, 행동 0의 보상은 0이다. 두 경우의 factor는 각각 `0.5(1−p)`, `0.5p`이며, 선택 확률로 평균하면 `p(1−p)`다. `y=0`이면 부호가 반대다. 이는 기존 알고리즘에 대한 대수적 도출이며 인간이나 초파리 문헌에서 관찰한 새 사실이 아니다.

`p`가 0.5일 때 이 평균 factor의 절댓값은 가장 크고, 0 또는 1에 가까우면 작아진다. 그래서 이전 답을 매우 확신하는 정책은 새 보상으로 바뀌었을 때 기대되는 scalar 갱신이 작을 수 있다. probe에서 `mean[p(1−p)]`를 기록해 이 대안을 확인한다. 실제 전체 가중치 갱신 크기는 활성 차이·head·학습률·clipping도 포함하므로 이 factor만으로 전체 원인을 확정하지 않는다.

고정 모델에서 head를 초기 상태로 되돌리면 내부 가중치와 모든 입력 변환도 초기 상태 그대로이므로 `reset_head_after_high`의 2단계는 `fresh_low`와 동일해야 한다. 이는 중요한 구현 무결성 검사이며 별도의 과학적 성공으로 세지 않는다. 가소성 모델에서 두 이력의 차이가 남으면 **바뀐 내부 상태와 초기화된 head가 함께 만든 계산적 효과**다. 내부 저장의 생물학적 기작이나 내부 상태만의 독립적인 원인을 증명하지 않는다. 이전 내부 학습이 새 학습을 돕는 방향도 가능하다.

## 기록과 독립 검증

학습식의 배경은 확률적 선택과 보상을 사용하는 REINFORCE 계열이다. [Williams (1992)의 출판사 서지·초록](https://doi.org/10.1007/BF00992696)을 확인했다. 위 이진 factor 식과 p(1−p)의 도출은 이 구현을 대상으로 한 자체 계산이며, 논문이나 실제 초파리 실험이 이 모델의 세부 규칙·clipping·생물학적 타당성을 입증했다고 인용하지 않는다.

실행 전 소프트웨어 검증의 작은8시행 fixture가 한 차례 계획 시드2001을 사용했다. 고정400시행 연구나 결과 기반 튜닝은 하지 않았고, 이후 fixture는31 등 별도 시드로 분리했다. 기준·학습률·예산은 그 검증 전후에 바꾸지 않았다. 이 진단을 완전히 눈가림된 독립 확증으로 표현하지 않는다.

새 결과 디렉터리를 사용하고 기존 결과 덮어쓰기를 거부한다. 등록 시 프로토콜·설정·새 코드 및 기존 공유 코드·입력 원본의 해시를 동결한다. 실행 환경, 코드 버전·dirty 상태, 모든 시드, 시행 예산·업데이트 횟수, model family·이력 및 난수 stream을 기록한다.

모든 학습 시행의 입력 식별자·uniform·행동·보상·선택 확률·내부와 출력 변화 norm을 보존한다. checkpoint에는 내부/출력 가중치·고정 입력의 KC/MBON 활성·encoder/bias·평가 확률을 저장한다. 경계 초기화는 별도 사건으로 남긴다. 곡선·끝점·gate·AUC·주 반전 비용과 내부/출력 변화 그래프를 자동 생성한다.

독립 검증은 학습 클래스의 update나 실험의 metric 계산을 호출하지 않고, 저장한 입력·초기 상태·선택 난수·행동/보상과 별도의 산술식으로 모든 갱신을 재계산한다. checkpoint와 평가 지표, 해시, 전체 시드/조건/이력/시행 coverage, shared stream, high-prefix 동일성, reset 경계의 허용된 변화, fixed reset=fresh 동일성, 내부 clipping 범위와 학습하지 않는 평가를 검사한다. NaN·해시 불일치·누출·재배선 불변량 위반·허용되지 않은 경계 변화·평가 중 변경은 검증 실패다. 실패 기록을 보존하며 과학적 판정으로 대체하지 않는다.

## 해석과 다음 단계

이번 관찰은 인공 수량 입력에서 학습 이력이 계산 모델의 행동을 바꾸는 Level 2, 적절한 습득 이후 nuisance 일반화의 제한된 Level 3 범위다. 실제 시각 수량 인지·수학 규칙 발견·DAN 구획 작동·인간 자료와의 정량적 유사성·같은 신경 메커니즘을 주장하지 않는다. 생리 시간과 model trial을 대응시키지 않으며, 지속 상태나 시간에 따른 decay가 없는 모델에서 결과를 자연 망각으로 부르지 않는다.

반전 비용이 지지되면 출력 확신·내부 변화·표현 중첩 중 어떤 조작이 비용을 바꾸는지 새 예산과 지표로 독립 등록한다. 지지되지 않거나 낮은 규칙도 습득하지 못하면 그 실패를 먼저 보고하고, 문제 구조·알고리즘 및 표현의 한계를 다음 질문으로 삼는다. 고난도 수열로 넘어가 성공 사례를 찾는 이유로 쓰지 않는다.

장기 인간 비교에서 대응 가능한 후보는 “처음부터 새 규칙을 배운 경우 대비 기존 규칙을 바꿨을 때의 곡선·끝점·추가 시행 비용”이다. 기존 인간 자료의 보상·훈련량·성공 기준을 확인한 뒤 과제 구조를 맞춰야 한다. 이번 모델만으로 인간의 인지적 유연성·수학 성취·교육 효과를 주장하지 않는다. 기존 [인간 학습 비교 체계](human-learning-comparison.md)를 유지한다.

# 인간 기초 학습과의 정량 비교 체계

작성일: 2026-10-14 (Asia/Seoul). 인간 학습과의 연결은 DrosoLearn의 장기 핵심 목표다. 이 문서는 Phase 4의 사전 설계이며, 현재 인간 데이터 재분석이나 종간 유사성 검증이 완료되었다는 결과 보고가 아니다. 초기에는 기존 논문과 공개 자료만 사용한다.

후속 업데이트: Honoré & Noël의 S1/S6 파일을 확보하고 집계·결측·제외 인원을 제한적으로 재계산했다. 인간/모델 유사성 검정이나 논문 전체 분석의 재현은 수행하지 않았다. 아래 최초 자료 목록보다 최신 실제 상태는 [human-data-readiness.md](human-data-readiness.md)에 명시한다.

## 비교할 수준과 대상

동일한 문제나 동일한 신경 구조를 가정하지 않고, 수량 비교·경험에 따른 선택 변화·보상 수정·일반화·간섭이라는 **과제 구조와 행동 지표**를 맞춘다. 인간 고등 수학, 언어적 개념, 의식, 교수법 효과는 초기 비교 대상에서 제외한다.

모델의 독립 시드는 계산 반복이다. 한 개체의 커넥톰에서 여러 번 돌린 결과를 독립적인 초파리 개체 표본으로 취급하지 않는다. 사람 참가자 수준의 변이와 모델 초기화 수준의 변이는 별도 층으로 보고한다. 구조를 섞은 시뮬레이션과 사람 원자료를 합쳐 하나의 유의성 검정을 하지 않는다.

Level 1은 모델의 정보 구별, Level 2는 경험에 따른 모델 변화, Level 3은 미학습 입력 일반화다. 충분히 조정된 기존 행동 자료와 정량적 유사성이 확인되어야 Level 4 후보가 된다. 같은 반응 곡선만으로 동일 신경 메커니즘인 Level 5를 주장하지 않는다. 현재 입력이 인공적으로 부호화되어 있다면 사람과 모델의 지각 단계가 같다는 결론을 허용하지 않는다.

## 공통 지표와 측정의 조건

아래는 DrosoLearn이 제안하는 분석 규약이다. 시행 수, 학습 기준, probe 간격, 비교하는 수량쌍은 각 실험 실행 전에 experimental-protocol과 config에 고정한다.

| 학습 특성 | 모델과 기존 인간 자료의 공통 지표 후보 | 주의점 / 반증 가능성 |
|---|---|---|
| 수량 비율 | r=min(n1,n2)/max(n1,n2), 수량쌍·r별 선택 정확도와 신뢰구간, log 수량비에 대한 선택 회귀 계수 | 차이 Δn와 절대 수량도 기록한다. 같은 r의 다른 수량쌍을 비교해야 비율만의 설명을 시험할 수 있다. 인코더가 비율 효과를 강제했다면 독립 발견이 아니다. |
| 시각 단서 의존 | 수량·크기·총면적·밀도·범위·간격 metadata, 단서 일치/불일치 조건별 정확도 차이, 수량 이외 단서만 쓰는 예측기의 성능 | 단서 간 구조적 종속성을 인정하고 full-rank 설명 변수만 사용한다. 단서 반전에서 실패하면 수량 중심 해석을 낮춘다. |
| 경험에 따른 향상 | 평가 probe 정확도 p(t), baseline 대비 변화 Δp, 학습 곡선 면적, 사전 기준에 도달하는 시행 수 | 학습 중 선택 반응과 학습에 쓰지 않는 probe를 구분한다. 기준 미도달 시 right-censored 결과를 보존한다. 실제 생리 시간과 model timestep을 동일시하지 않는다. |
| 일반화 | 습득 평가 정확도, 미학습 배치/수량/시작값의 정확도, generalization gap=p_new−p_acquired | 습득 성공 여부와 일반화를 별도 판정한다. 성공한 시드만 고르지 않고 전체 시드와 습득 조건부 분석을 함께 보고한다. |
| 보상 규칙 수정 | 반전 직후 오류, 반전 후 새 기준 도달 시행 수, 과거 규칙 선택 비율, 처음부터 새 규칙을 학습한 군 대비 추가 비용 | 이미 배운 규칙의 수정인지 단순히 새 과제를 못 푸는 것인지 분리한다. 통제군은 보상·시행·자원량을 맞춘다. |
| 학습 간섭 | B 학습의 A 사전학습 비용; A의 B 후 유지 성능; A→B, B→A, 단독 학습의 차이 | 전향·역향 간섭을 따로 측정한다. 단순 휴지 지연, 다른 과제 학습, 가중치 감쇠를 구분한다. |
| 망각 / 유지 | 학습 직후 대비 지연 후 정확도 변화, 재학습 비용 또는 절감량 | 모델에서 시간이 지나도 갱신이 없으면 자동 망각은 없다. 명시한 decay/state reset가 만든 결과라고 기록한다. |
| 오류 집중 | 수량비·입력 범위·단서조건·규칙별 혼동행렬, 오답/지속 반응의 비율 | 지표 방향을 맞추고 전체 조건을 보고한다. 사람 오류와 모델 오류의 원인이 같다고 가정하지 않는다. |

균형 이진 과제는 원래 정확도와 함께 chance-adjusted 값 2p−1을 보조로 보고할 수 있다. 이는 단위 변환이며 종간 능력의 동일성을 보장하지 않는다. 무조건 더 큰 수량을 선택하는 선호와 보상 규칙에 따른 ‘정답’은 다르다. 초파리 arena의 체류 선호 지수는 모델 선택 확률과 직접 같은 관측값으로 합치지 않는다. [Bengochea et al., 행동 측정 방법](https://pmc.ncbi.nlm.nih.gov/articles/PMC10442639/)

비율별 정확도와 Weber fraction은 인간 psychophysics에서 사용되었다. [Halberda et al. (2008)](https://pubmed.ncbi.nlm.nih.gov/18776888/) 그러나 Weber 모델은 적절한 수량 범위·단조성·잡음 가정을 확인한 뒤 적합하며, 모델의 임의 출력 slope를 사람 Weber fraction으로 이름만 바꾸지 않는다. 시각 단서를 회귀에 포함하는 접근은 [DeWind et al. (2015)](https://pmc.ncbi.nlm.nih.gov/articles/PMC4831213/)을 따른 후보 방법이다. 작은 수량과 큰 수량의 범위를 사람 연구에서 같은 처리 체계라고 가정하지 않는다.

## 공개 근거를 이용하는 순서

1. **문헌의 측정 정의 추출:** [literature-review.md](literature-review.md)의 각 연구에 대해 모집단·과제·훈련량·보상·수량 범위·종속변수·단서 통제·제외 조건을 표로 고정한다. 초록만 확인한 논문은 그 한계를 유지한다.
2. **자료 가용성 확인:** 공개 파일이 있더라도 시행별 자료인지 참가자별 요약인지 확인한다. 허용되는 granularity에서만 분석하고, 비공개 reaction time이나 session log를 만들어내지 않는다.
3. **기존 결과 재현:** 연구의 원래 포함·제외 기준과 분석을 먼저 재현하고 편차를 기록한다. 논문과 불일치가 해결되기 전에는 DrosoLearn 비교를 확증 분석으로 하지 않는다.
4. **공통 지표 계산:** 새로운 harmonization과 비교 가설을 사전 문서화한다. 방향과 chance baseline만 조정하며 자료가 제공하지 않는 시간·단서조건을 추정해 추가하지 않는다.
5. **정량적 유사성과 차이 보고:** 곡선 형태·차이·불확실성을 보고하고, model family·인코더·가소성·일반 ANN 대조군에 따라 결론이 달라지는지 확인한다. 실패·무차이도 남긴다.

| 우선 자료 / 근거 | 가능한 첫 비교 | 확보·검증 상태와 제한 |
|---|---|---|
| [Honoré & Noël (2016) 수량 비교 S1 Data](https://doi.org/10.1371/journal.pone.0166685.s002) 및 [덧셈 S6 Data](https://doi.org/10.1371/journal.pone.0166685.s007) | 비기호·기호 훈련과 통제의 pre/post 변화, 비율/단서 조건이 자료에 있으면 해당 조건 비교, 훈련 과제 향상과 별도 과제 전이 구분 | 논문 첨부 XLSX 목록 확인. 파일 schema·granularity·결측·라이선스 검증 및 원 분석 재현은 미완료. 논문은 touchscreen 측정 문제로 RT 분석을 제외했으므로 이 자료에서 RT 유사성을 주장하지 않는다. [원 논문](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0166685) |
| [Kattner, Cox & Green (2016) 범주 전이 S1 Data](https://doi.org/10.1371/journal.pone.0165260.s001) | 습득과 전이 단계, 구별/식별 훈련의 과제 구조, 전이 gap | 원 논문이 Rdata+ReadMe 공개를 명시. 원자료 미다운로드. 수량·산술 연구가 아니므로 방법론 비교로 제한. [원 논문](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0165260) |
| [Chen & Li (2014)](https://pubmed.ncbi.nlm.nih.gov/24583622/) 및 [Gilmore et al. (2013)](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0067374) | 수량 수행↔수학 성취 관련성 및 억제 요구라는 대안 설명 검토 | 실제 관련성 증거와 대안 설명을 함께 유지. 원자료가 없는 효과량을 개별 시행처럼 취급하지 않음. 초파리 모델 결과로 사람 성취를 예측하지 않음. |
| 보상 반전·학습 순서·간섭·망각을 모두 포함하는 인간 수량 원자료 | reversal cost, interference cost, retention 비교 | 이번 검토에서 대응 원자료를 확정하지 못했다. Phase 4 추가 탐색 항목이며 현재 결과로 비워 둔다. |

파일을 실제 가져올 때에는 `data/source-manifest`에 DOI·정확한 URL·파일명·원 라이선스·접근일·버전·SHA-256을 남긴다. 기존 참가자 ID는 원자료 규정을 따르며 새로운 개인 정보와 결합하지 않는다. 원 논문의 공개성만으로 모든 재배포 권한이 검증됐다고 간주하지 않는다.

## 검증 가능한 장기 가설

이 표는 **DrosoLearn이 새로 제안하는 가설**이다. 아직 관찰 결과나 인간 교육 권고가 아니다.

| 가설 | 모델에서 할 조작 | 실패 또는 대안 설명 |
|---|---|---|
| 입력 표현의 중첩이 일반화와 간섭 사이의 절충을 만든다. | 입력 sparsity/overlap을 정한 범위로 조작하고 습득 수준·자원을 맞춘 뒤 새 입력과 충돌 규칙을 평가 | 인코더·출력층만으로 현상이 모두 설명되거나 일반 ANN에서도 동등하면 커넥톰 고유 설명이 약해진다. sparse code와 후각 기억 일반화의 생물학적 출발점은 [Hige et al. (2015)](https://pubmed.ncbi.nlm.nih.gov/26637800/)이며 수량/인간에 대한 확장은 새 가설이다. |
| 제한된 내부 학습이 최종 정확도보다 보상 수정 비용이나 유지에 영향을 준다. | 내부 frozen/plastic, 출력 frozen/trainable의 요소별 ablation; 보상 반전과 휴지/간섭 비교 | 자원량을 맞추면 차이가 사라지거나 성능 변화를 출력층 갱신만으로 설명할 수 있다. 인간과 동일한 DAN 작동 원리를 뜻하지 않는다. |
| 비율 의존적 오류 일부는 수량 이외 단서와 입력 잡음의 산물일 수 있다. | 동일 자극의 인코더 변경, 잡음 없음/가산/비례 조건, 단서 일치/반전, 단서 전용 기준 모델 | 비율 곡선이 인코더 가정만으로 결정되면 모델에서 ANS 원리를 새로 발견한 것이 아니다. |
| 습득 성공과 일반화 성공을 분리하면 과제별 학습 방식 차이가 드러난다. | 사전 습득 gate 후 새 시작값/배치/규칙 probe, 모든 시드의 습득 실패도 보고 | 습득 gate 실패 상태에서 전이 실패를 해석하면 가설을 평가하지 못한 것으로 기록한다. |

독립적인 사람 연구의 후속 가설로 나아가려면 실제 인간 공개 자료에서 비슷한 지표가 신뢰성 있게 재현되고, 모델의 단순 인코더·보상·학습률 선택에 의해 결론이 정해지지 않아야 한다. 그 뒤에도 신규 인간 실험 설계는 별도 검토 과제다. 현재 연구에서 고등학교 수학 수업의 효과나 특정 교수법의 타당성을 주장하지 않는다.

# 인간 시행별 공개 자료의 가용성 감사 계획

작성일: 2026-10-15 (Asia/Seoul). 대상은 이미 공개된 자료다. 새 사람 실험, 사람의 학습 성과 분석, 인간과 모델 사이의 유사성 검정은 이번 작업에 포함하지 않는다.

## 먼저 쉽게 설명하면

이전 단계에서 확보한 인간 자료는 연습 전후의 성적표였다. 이번에는 **문제를 한 번 풀 때마다 무엇을 골랐고, 어떤 피드백을 받았으며, 규칙이 언제 바뀌었는지 적힌 기록**을 찾는다. 이 기록이 있어야 나중에 사람과 모델의 학습 과정을 같은 뜻의 지표로 비교할 수 있다.

공개 파일이 있다는 사실만으로 비교가 가능해지는 것은 아니다. 예를 들어 정답을 골라도 가끔 보상을 주지 않는 과제에서는 ‘보상을 받지 못한 선택’이 곧 오답은 아니다. 성적이 좋아지면 규칙을 바꾸는 과제에서는 사람마다 반전 시점도 달라진다. 이번 작업은 이런 차이를 확인하고, 비교할 수 없는 항목을 빈칸으로 남기는 준비 단계다.

## 이번에 답할 질문과 범위

질문은 ‘인간도 DrosoLearn과 닮은 결과를 보이는가’가 아니라 다음과 같다.

1. 원자료에서 참가자별 시행 순서와 선택을 확인할 수 있는가?
2. 선택, 실제 피드백, 보상 확률, 과제에서 정한 유리한 선택을 서로 구분할 수 있는가?
3. 규칙의 반전 위치와 반전 조건을 자료 또는 검증 가능한 과제 코드에서 확인할 수 있는가?
4. 정해진 연습량, 참가자 수행에 따른 종료, 쉬는 시간, 피드백 없는 평가를 구분할 수 있는가?
5. 이후 별도 사전등록을 하면 어떤 공통 지표를 계산할 수 있고, 어떤 지표는 계산할 수 없는가?

이번에 허용하는 계산은 파일 해시, 열 이름과 자료형, 파일·행·참가자·세션 수, 결측과 응답 없음의 개수, 원시 코드의 값 목록, 순서와 식별자 중복, 기록 간 연결 여부, 명시된 반전 위치 및 과제 메타데이터의 정합성 점검이다. 이 수치는 자료의 목록과 구조를 설명한다. 참가자별 성공률·학습 곡선·반전 비용·집단 효과량·회귀·모델 적합·인간/모델 상관은 계산하지 않는다. 과제 정의 확인에 필요한 원 논문의 결과 설명을 읽은 경우에도 이를 새 재분석 결과로 제시하지 않는다.

개발과 자동 테스트에는 인공적으로 만든 작은 자료만 사용한다. 실제 사람 자료의 성과를 보고 파서, 포함 기준 또는 비교 가설을 조정하지 않는다. 실제 파일의 행 구조를 확인하는 감사와 행동 가설을 검정하는 분석을 별도 명령·산출물로 구분한다.

## 자료를 선정하는 순서

우선순위는 수량 과제인지 여부 하나로 정하지 않는다. 시행별 선택과 피드백이 실제로 남아 있는지, 보상 규칙의 변경을 확인할 수 있는지, 출처와 사용 권한이 명확한지를 먼저 본다. 수량·산술 자료에서 적합한 기록을 찾지 못하면 일반적인 인간 보상 학습 또는 반전 학습 자료를 **방법론 비교 후보**로 검토할 수 있다. 그런 자료에서 수학 능력이나 수량 인지를 측정했다고 주장하지 않는다.

후보별로 원 논문, 공식 데이터 저장소, 코드북 또는 과제 코드를 함께 확인한다. 요약 표나 그림만 공개된 자료, 원 시행 순서를 복원할 수 없는 집계, 다운로드가 차단된 자료, 권한이 불명확한 파일은 그 이유와 함께 후보 목록에 남긴다. 적합한 자료가 없으면 ‘현재 비교 준비 미달’이 정당한 결과다. 비슷한 성과가 나올 때까지 자료를 계속 바꾸지 않는다.

선정 기록에는 탐색한 후보, 유지 또는 보류한 이유, 확인한 자료의 정확한 버전과 파일 범위를 남긴다. 구조 감사 대상 파일과 규칙을 설정에 고정하고 그 설정·파서·프로토콜의 해시와 Git 버전을 남긴 뒤 실제 파일 감사를 실행한다. 탐색과 다운로드 자체는 이 고정 이전에 가능하지만, 이번 범위를 벗어나는 성과 분석은 다음 연구의 사전등록 전까지 실행하지 않는다.

이번 자료 선정에서는 일부 원자료 헤더와 예시 행을 먼저 보았다. 따라서 이 고정은 탐색적 가용성 감사의 재현 범위를 정하는 절차이며, 자료를 보지 않은 상태의 확증 가설 사전등록이라고 부르지 않는다.

## 출처와 원자료 보존

각 파일에 다음 정보를 기록한다.

| 항목 | 기록할 내용 |
|---|---|
| 학술 출처 | 저자, 연도, 제목, DOI 또는 영구 링크, 자료가 해당 연구에 속한다는 근거 |
| 저장소 버전 | 저장소 식별자, 릴리스 또는 버전, Git 커밋이 있으면 그 값. 서버의 수정 시각을 실험 날짜로 취급하지 않음 |
| 파일 식별 | 원래 파일명, 정확한 다운로드 URL, 접근 시각, 바이트 수, SHA-256 |
| 권한 | 원자료의 라이선스 원문 링크와 적용 범위, 논문·코드·자료별 권한 차이, 재배포 가능 여부 |
| 해석 근거 | 코드북과 과제 코드의 버전·파일·열 또는 코드 위치, 원 코드와 표준 의미의 대응 |
| 범위 | 포함한 실험·세션·파일, 보류한 파일과 이유, 집계인지 시행별인지 |

원본 파일은 수정하지 않는다. 압축 파일이면 원 압축 파일과 사용한 구성 파일의 해시를 각각 보존한다. 파일의 내장 값과 구조만 읽고 원자료의 매크로·수식·외부 코드를 실행하지 않는다. 공개 파일이라는 이유만으로 재배포 권한을 추정하지 않는다. 허용되지 않거나 확인되지 않은 파일은 원문 바이트를 저장소에 게시하지 않고, 접근 경로·해시·제약과 감사 가능 범위를 남긴다.

공개 참가자 식별자를 이름이나 다른 개인정보에 연결하지 않는다. 원자료에 없는 나이, 진단, 인구통계, 시간 정보 또는 시행을 만들어 넣지 않는다. 서로 다른 파일의 숫자 ID가 같다는 이유만으로 같은 참가자로 연결하지 않는다.

## 시행 기록의 필수 확인 항목

열 이름이 비슷하다는 이유만으로 뜻을 정하지 않는다. 다음 항목마다 `확인`, `없음`, `미확정`, `해당 없음`을 구분하고, 근거를 기록한다.

| 영역 | 반드시 구분할 내용 |
|---|---|
| 관측 단위 | 한 행이 시행인지 사건인지, 참가자·실험·세션·블록·시행 키, 시행 번호의 시작값과 재시작 범위 |
| 선택 | 왼쪽/오른쪽, 자극/행동 식별자, 눌렀던 키의 대응, 선택 전 제시 순서, 참가자의 실제 응답 |
| 결과 | 실제로 제시된 보상 또는 손실, 과제상 유리한 선택, 피드백의 제시 여부, 확률적 보상의 각 선택별 예정 확률 |
| 규칙 | 고정·확률적·가변 보상, 명시적 반전 표시, 자극 교체와 보상 반전의 구분, 원 코드와 반전 위치의 대응 |
| 연습량 | 예정 시행 수, 실제 시행 수, 연습과 본 시행, 습득 기준에 따른 연장·종료, 최대 시행 수 |
| 평가 | 학습용 시행과 피드백 없는 probe, 새로운 자극과 이전 자극, 강제 선택과 자유 선택, 전이와 단순 연습 지속 |
| 시간 | RT의 단위·시작 기준, 타임아웃, 세션 간 간격, 휴식·중단 기록. 시행 번호를 실제 시간으로 대체하지 않음 |
| 결측 | 빈 값, NA 문자열, 특별 코드, 무응답, 기기 오류, 미실시 시행, 탈락 또는 제외 표시 |

선택과 결과의 코드는 원 값 그대로 보존하고 별도 대응표로 설명한다. 보상 확률이 `.8`이라는 사실과 실제 보상 `1`은 서로 다른 필드다. ‘정답’이라는 열의 뜻이 실제 피드백인지 유리한 선택인지 확인되지 않으면 정확도로 이름을 바꾸지 않는다. 보상이 없는 평가 시행을 보상 `0`으로 채우지 않는다. 반응 시간 단위가 확인되지 않으면 밀리초로 추정하지 않는다.

무응답을 오답 또는 특정 행동으로 바꾸지 않는다. 결측·무응답·미실시를 합치지 않고 원 코드별 개수를 남긴다. 일부 원파일이 없거나 시행이 누락되면 예정 시행을 합성해서 채우지 않는다. 감사 단계에서는 수행 성적을 기준으로 참가자를 제외하지 않는다. 원 연구의 제외 표시와 규칙은 기록하되, 후속 분석에서 실제 적용할 포함 기준은 별도 사전등록한다.

## 순서·반전·학습 예산의 검증

원 행 순서, 원 시행 번호, 원 시각 값을 가능한 범위에서 각각 점검한다. 참가자·세션 안에서 키가 중복되거나 번호가 빠진 경우 이를 실패 또는 미확정 항목으로 보존한다. 행을 임의로 정렬해 누락을 숨기지 않는다. 블록마다 번호가 다시 시작하는 구조라면 전체 키에 블록을 포함한다.

반전은 가능하면 명시된 과제 상태 또는 과제 코드가 정하는 변경 규칙으로 확인한다. 우연한 보상 연속이나 참가자 선택이 달라졌다는 사실만으로 반전을 추정하지 않는다. 시행마다 보상 확률이 서서히 달라지는 과제는 고정 지점에서 규칙을 바꾸는 과제와 구분한다. 원자료에서 반전 지점을 결정할 수 없으면 반전 이후 지표는 사용 불가다.

참가자가 일정 성적에 도달하면 반전하는 **적응형 기준**이 있으면 기준 자체를 기록한다. 이 경우 ‘첫 반전까지 시행 수’는 참가자 수행과 과제 설계가 함께 정한 값이다. 고정 400회 뒤 반전하는 DrosoLearn과 그대로 같은 연습 예산이라고 부르지 않는다. 고정 종료·기준 종료·상한 도달·참가자 중단을 구별하며, 이번에는 그 차이를 보정하는 학습 모형을 적합하지 않는다.

쉬는 시간이 기록되지 않았다고 휴식이 없었다고 결론 내리지 않는다. 자료가 제공하는 보상·시행 수·평가 빈도와 제공하지 않는 실제 시간·휴식·피로를 함께 표시한다. 사람과 모델의 같은 시행 수가 같은 시간·노력·정보량을 뜻한다고 가정하지 않는다.

## 후속 비교의 가용성 판정

판정은 자료 전체에 한 번 붙이는 합격증이 아니라 **지표별 판정**이다. 선택 순서는 쓸 수 있어도 반전 비용은 사용할 수 없을 수 있다.

| 후속 지표 후보 | 이번 감사에서 확인해야 할 조건 | 조건이 없을 때 |
|---|---|---|
| 시행에 따른 실제 선택 변화 | 시행별 선택, 참가자·세션 키, 순서, 선택지 의미 | 해당 곡선 계산 불가 또는 의미 미확정 |
| 과제상 유리한 선택의 비율 | 선택별 예정 보상 규칙과 상태 또는 검증 가능한 유리한 선택 코드 | 실제 보상률로 대체하지 않고 정확도 후보 보류 |
| 반전 이후 과거 선택의 유지 | 명확한 반전 경계, 경계 전후 동일 행동의 대응, 새 규칙의 의미 | 반전 비용 계산 불가 |
| 기준 도달까지 시행 수 | 시행 순서, 원 기준, 평가 방식, 상한·종료·결측 정보 | 종료 또는 미도달을 성공으로 바꾸지 않고 보류 |
| 연습에 따른 평가 성능 변화 | 학습 시행과 피드백 없는 평가의 명시적 구분 | 학습 중 응답을 모델의 비학습 probe와 동일시하지 않음 |
| 전이·일반화 | 미학습 자극 또는 조건 표시, 훈련·평가 분할 근거 | 새 시행이라는 이유만으로 일반화로 분류하지 않음 |
| 망각·유지 | 학습 직후와 지연 후 기록, 실제 지연 및 중간 경험 | 시행 간 선택 변화만으로 망각을 추정하지 않음 |
| 수량 비율 또는 수학 학습 | 실제 수량·자극 메타데이터와 과제 목표 | 일반 보상 학습 자료로 수량·산술 결론을 내리지 않음 |

각 판정에는 원 파일·열·코드북 근거와 남은 불확실성을 붙인다. 구조가 준비되어 있어도 곧바로 공통 지표가 타당하다는 뜻은 아니다. 특히 DrosoLearn의 확률 `p`는 모델이 선택할 가능성이고 사람의 한 시행 선택은 실제 관측 행동이다. 사람의 단일 선택을 확률 `0` 또는 `1`의 내적 확신으로 해석하지 않는다. 여러 시행의 관측 비율을 모델 확률과 비교하려면 평가 단위·분모·불확실성·피드백 여부를 다음 프로토콜에서 먼저 정해야 한다.

고정/가소성/재배선/일반 신경망의 결과 중 사람과 닮아 보이는 조건만 고르지 않는다. 어떤 모델 조건과 어떤 인간 자료 범위를 비교할지는 별도 사전등록 사항이다. 이번 감사에서는 어느 조건이 더 닮았는지 계산하지 않는다.

## 산출물과 종료 기준

이번 작업은 다음 자료를 남기고 끝낸다.

1. 검토한 후보와 선정·보류 이유, 직접 확인한 1차 출처 링크.
2. 실제 확보한 파일의 출처·버전·권한·SHA-256을 담은 manifest와 저자 표시.
3. 새 파서와 합성 자료 기반 자동 테스트, 원자료를 바꾸지 않는 재현 명령.
4. 열·코드·행수·키·결측·순서·과제 메타데이터의 기계 판독 감사 결과와 원시 파일 대응.
5. 지표별 `사용 가능 후보 / 없음 / 의미 미확정 / 범위 차이` 표 및 후속 사전등록에서 풀어야 할 문제.

자료 확보 불가, 시행 순서 복원 불가, 코드 의미 미확정, 라이선스 미확인, 반전 구조 부재는 삭제할 실패가 아니라 가용성 감사의 결과다. ‘모델과 인간이 비슷하지 않음’과 ‘자료가 없어 비교할 수 없음’을 구분한다. 이번 단계에서는 유사성에 대한 긍정·부정 판정을 모두 유보한다.

기존 Honoré & Noël 원자료·감사·문서와 모든 계산 실험의 원본·설정·가설·실패·결과는 덮어쓰지 않는다. 새 자료와 감사 결과는 별도 경로로 보존한다. 사람과 모델의 학습 지표 계산은 그 범위와 성공·실패 기준을 새 프로토콜로 고정한 뒤 다음 작업으로 진행한다. 이 준비 작업은 Level 4 또는 Level 5의 증거가 아니다. 인간의 고등 수학 학습이나 교육 방법에 관한 권고도 하지 않는다.

## 이번 감사에서 고정한 자료와 해석

주 자료는 [OpenNeuro ds004295, 버전 1.0.0](https://openneuro.org/datasets/ds004295/versions/1.0.0)이다. 원자료의 고정 Git 커밋은 `c7c5d3a164425af3e65cc908ef0d41f01725984c`다. OpenNeuro 저장소가 명시한 원자료 라이선스는 CC0이며, 확보 파일별 적용 범위와 실제 해시는 새 source manifest에 남긴다. 이 자료는 수학·수량 검사 자료로 취급하지 않는다. 보상 또는 처벌을 경험하며 선택하는 인간 과제의 기록 구조를 확인하는 후보로 사용한다.

보존 대상은 원 `README`, `dataset_description.json`, `task-task_events.json`, `sub-s1`부터 `sub-s26`까지의 EEG 사건 기록 `events.tsv`, 그리고 `code/Data/`의 두 MAT 파일이다. EEG 신호 자체를 분석하거나 새로 확보하는 것은 이번 범위가 아니다. 원자료는 `data/human/stolz_2022_openneuro/` 아래에 파일명을 유지하고 보존한다.

각 `events.tsv`의 네 열은 `onset`, `duration`, `sample`, `value`다. 한 행은 문제 한 번의 답변이 아니라 **하나의 사건**이다. 따라서 파일 행수를 시행 수로 부르지 않는다. 사건 코드를 이어 보아 선택–기대 보고–피드백 후보를 묶되, 이를 원파일에 제공된 완전한 시행 테이블로 소개하지 않는다. 새 묶음 번호는 관측된 선택 사건의 순서이며, 원래 예정 시행 번호가 아니다. 각 묶음에 원 행 번호와 사건 시각을 남긴다.

| 원 사건 코드 | 이번 감사의 해석 | 해석하지 않는 내용 |
|---|---|---|
| `S100`, `S101` | 보상 과제 시작·끝 | 참가자의 습득 또는 실패 |
| `S200`, `S201` | 처벌 과제 시작·끝 | 보상 과제와 같은 결과 척도 |
| `S150`, `S151` | 일시 중단·재개 표시 | 표시 없는 구간에 휴식이 없었다는 주장 |
| `S51`, `S52` | 보상 과제의 두 선택 | 정답/오답 또는 현재 유리한 선택 |
| `S71`, `S72` | 처벌 과제의 두 선택 | 정답/오답 또는 현재 유리한 선택 |
| `S53`–`S56`, `S73`–`S76` | 과제별 네 단계 기대 보고, 순서 코드 `0`–`3` | 객관적 보상 확률, 모델의 sigmoid 선택 확률, 직접 측정한 내부 확신 |
| `S60`, `S61` | 보상 과제의 음성 피드백(0센트)·양성 피드백(10센트) | 과제에서 정한 유리한 선택 여부 |
| `S80`, `S81` | 처벌 과제의 음성 피드백(소음)·양성 피드백(소음 없음) | 과제에서 정한 유리한 선택 여부 |

공백 또는 밑줄이 낀 `S 51`, `S_51`, `S51`은 같은 코드 `S51`로 정규화하며, 원 값도 보존한다. 지정되지 않은 숫자나 비슷한 접두어를 임의로 기존 코드에 넣지 않는다. 미지 코드·짝이 없는 사건·시간 역행은 문제 목록에 남기며, 사건을 재정렬하거나 선택을 만들어 채우지 않는다. 과제 밖 피드백이나 다른 과제의 기대 보고를 인접 선택에 자동 연결하지 않는다. 불완전한 선택 묶음도 삭제하지 않고 `complete`와 문제 항목으로 표시한다.

위 대응의 근거는 고정 버전의 [task-task_events.json](https://raw.githubusercontent.com/OpenNeuroDatasets/ds004295/c7c5d3a164425af3e65cc908ef0d41f01725984c/task-task_events.json)이다. 이 메타데이터에는 `response_time` 등에 관한 일반적인 설명도 있지만, 설명이 있다는 사실만으로 실제 TSV에 해당 열과 값이 있다고 판단하지 않는다.

이 사건 파일에는 잠재적인 유리한 선택, 반전 위치 또는 반응 시간 전용 열이 없다. 선택–피드백 사이의 시간 차이를 반응 시간이라고 이름 붙이지 않는다. `S60`이 관측되었다는 사실은 음성 피드백이지 선택 정확도의 직접 증거가 아니다. 기대 보고의 네 단계를 `.0`, `.33`, `.67`, `1.0` 같은 확률로 바꾸지 않는다. 원 과제 코드의 상태와 직접 대조할 근거가 확보되지 않는 한 이 TSV만으로 정확도·반전 경계·반전 비용을 계산하지 않는다.

연구 전체의 반전 계획이 알려지지 않았다는 뜻은 아니다. 원 논문 Methods 2.5는 과제별 280회, 70/30 대 30/70의 확률 구조, 첫 과제의 82·150·225회 뒤와 둘째 과제의 86·160·223회 뒤 반전, 과제 시작 전 별도 연습 4회를 설명한다. **도형의 좌우 위치는 매번 무작위**이므로 사건의 왼쪽/오른쪽 응답이 고정 도형 ID와 같지 않다. 이 일정과 사건들을 연결하려면 연습·미응답·누락을 포함한 원 시행 번호 및 도형–좌우 대응을 따로 확인해야 한다. 예정 반전 시점을 관측 선택 묶음 번호에 바로 붙이지 않는다. [원 논문 Methods 2.5](https://onlinelibrary.wiley.com/doi/full/10.1111/psyp.14235).

두 MAT 파일은 각각 23개 cell에 280개 항목이 있는 별도 구조다. 조건, 선택, 피드백, 기대 보고, RT, 응답–피드백 간격과 같은 필드의 존재·차원·결측만 확인한다. 23개 cell과 26개 사건 파일을 연결하는 검증된 참가자 ID 대응이 없으므로 파일 순서나 번호만으로 서로 연결하지 않는다. MAT의 RT를 TSV에 덧붙이지 않으며, MAT에서 발견한 시간 정보가 모든 참가자·사건의 시간을 보완한다고 주장하지 않는다.

원 논문은 26명을 모집해 3명을 제외한 23명을 분석했다고 설명한다. MAT의 23개 cell과 인원이 같아도 참가자 대응이 확인된 것은 아니다. 기대 보고를 3으로 나눈 논문의 계산 역시 그 보고를 보정된 선택 확률로 검증했다는 뜻이 아니다. [원 논문 Methods 2.1, 2.5](https://onlinelibrary.wiley.com/doi/full/10.1111/psyp.14235).

새 파서는 `src/drosolearn/human_trial_data.py`, 합성 자료 테스트는 `tests/test_human_trial_data.py`에 둔다. 실제 감사 전 이 문서·설정·파서·테스트·원자료 manifest의 해시와 코드 버전을 고정한다. 원자료에서 만든 결과는 새 출력 경로에 한 번 저장하고 기존 파일 덮어쓰기를 거부한다. 테스트가 보장하는 범위는 사건 해석과 누락 보존이며, 원 연구의 성과 재현 또는 사람/모델 비교의 타당성을 보장하지 않는다.

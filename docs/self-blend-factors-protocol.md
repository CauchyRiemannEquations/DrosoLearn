## 정확한8셀과 대칭 배분

대조를C, 새 혼합을N이라 한다. 같은 source와 고정 특징D에서 각자 실제 출력 수정 전
logit벡터z, 실제 signed scalar g, 방향 영향f=D@w를 읽는다. 평가용 참 부호y는 학습자나
방향 선택기에 새로 주지 않는다. 네 목적지의 정답 선택 확률 증분은 다음 원식이다.

```text
F(state,scalar,direction) = y*(sigmoid(z_state + g_scalar*f_direction)-sigmoid(z_state))
```

bit4는상태, bit2는스칼라, bit1은방향이다.0은C,1은N이며000/111셀은 두 실제 단일
수정과 일치해야 한다. sigmoid는 부모의±40clipping을 그대로 쓰며 미분 근사로 바꾸지 않는다.

g는 학습률0.1 자체나 수정 길이가 아니다. 실제 학습에서는
`g=.1*(action-p)*obtained_reward`이며 확률·행동·보상과 연결된다. 혼합 셀에서는
g를 새 상태의 확률로 다시 계산하지 않고 저장된 값을 그대로 쓴다. 일부 셀은 실제 학습
규칙의 상태·행동·보상 관계를 동시에 만족하지 않을 수 있는 수학적 대입이다. 이후의
선택·보상·기억을 실행한 새 정책이나 실현 가능한 독립 개입이라고 주장하지 않는다.

세 요소의 모든 교체 순서를 대칭적으로 평균하는 Shapley 장부를 쓴다.

```text
phi[r] = sum_T |T|!*(2-|T|)!/3! * (F[T union {r}]-F[T])
sum_r phi[r] = F[111]-F[000]
```

T는r이외 요소 중 이미N으로 바꾼 집합이다. 원소 수0/1/2의 가중치는 각각1/3,1/6,1/3이다.
상태·스칼라·방향 순서의 세 배분을 네 목적지별로 구한 뒤 현재source인자기(own)와
다른세연습입력(other)으로 합친다. 모든 목적지가 빠짐없이 한 번만 배정되어야 한다.

순확률 변화뿐 아니라 각 셀의 양수 부분과 음수 부분 절댓값을 **먼저** 구하고 각각 배분한다.
그 뒤 순배분=양수질량배분−음수질량배분을 검산한다. 양수 질량을 나눈 몫도 음수일 수
있고, 이는 그 요소에 배분된 도움 감소분이다. 음수 질량 배분이 음수면 방해 감소 몫이다.
배분의 부호를 실제 새로운 피해/도움 시행과 동일시하지 않는다.

각 목적지 집합에서 세 요소를 더하면 양쪽Go 실제N−C 차이가 복원되어야 한다.
C만Go는 실제C의 순효과·양수질량·음수질량에 각각−1을 곱하고, N만Go는 실제N의 세
값을 더한다. 둘 다NoGo는0이다. 여섯 성분을 모두 합하면 전체 공통 후반의 자기/다른
기여 차이에 돌아와야 한다. 부모 후반 장부와 전환 전 prefix를 대조해 최종 성적 차이와의
관계를 확인하되 후반 배분을 충분한 습득·전체 원인의 고유한 비율로 바꾸지 않는다.

## 같은 실제 대상의 여덟 진단

양쪽 실제Go인 같은 시행에서 각 경로C/N순서로 다음을 저장한다.

1. 현재source의 정답 정렬 수정 전logit `y[i]*z[i]`.
2. 현재source의 정답 선택 확률.
3. 로지스틱 민감도 참고 값`p*(1-p)`.
4. 실제 스칼라 절댓값`abs(g)`.
5. 실제 출력 계수 이동 길이`abs(g)*||w||`.
6. 단위 방향 자체의 자기 영향`D[i]@w`.
7. 다른세입력의 부호 정렬 방향 영향 평균`mean(y[i]*y[j]*(D[j]@w), j!=i)`.
8. 방향 자체의 길이`||w||`.

순서는`aligned_source_logit_before, correct_source_probability, logistic_sensitivity_value,
abs_update_factor, head_step_l2, own_unit_direction_influence,
other_unit_aligned_influence_mean, direction_l2`다. unit이라는 이름은 방향 상한을 가리키며
임의의 실제 방향 길이가 반드시1이라는 뜻은 아니다. 실제 정답 정렬 점수 변화는 여기에
현재의 부호 있는g가 곱해져야 한다. 실제 확률 변화는 위 비선형 원식으로 계산한다.

민감도 참고 값은clipping밖의 실제 미분이나 변화량 근사로 쓰지 않는다. 이미 더 좋은
출력 상태에서 같은 수정을 더했을 때 개선 여지가 줄어드는 효과도 상태 몫에 들어갈 수
있으므로 음수 상태 몫을 상태가 더 나빠졌다는 뜻으로 읽지 않는다. 평균 민감도·평균
스칼라·평균 방향을 곱해 평균 실제 효과라고 부르지 않는다.

새 실제 학습에서 검산한 자기영향≥0.75I·도움영향≥0.25B는 **같은 정보와 단위 방향의
점수 하한**이었다. 이번의 서로 다른 실제 경로·signed scalar·정답 확률 장부에서
자기 성적75%·도움25% 보존을 가정하거나 그 비율에 맞춰 결과를 분류하지 않는다.

## 원래 균형 방향과 혼합 재료의 수치 관계

주 대조인 기존 gated와 새 혼합이 공통 후반에서 **양쪽 모두 실제Go인 시행**만 골라
새 혼합의 원B재료가 기존 gated의 실제 방향과 같은지 별도로 검산한다. 여섯 배선·표현과
각 시드에서 혼합 전 길이n의 평균, `.25/n`의 평균·최소·최대, `.75/n`의 평균과 대상 수를
남긴다. 대상이 없으면 수치 요약은null, 잔차는0, `has_both_Go_evidence=False`로 구분한다.

같은 대상에서 다른 목적지I영향이0이면 새 혼합의 다른 영향은`(.25/n)*(B의 다른 영향)`이다.
자기 영향은`(.75*I자기영향+.25*B자기영향)/n`이다. B재료일치, 다른영향식, 자기혼합식,
원 혼합길이, 전체 혼합방향식의 다섯 잔차를1e-8안에서 확인한다. 이는 각 시행의
단위방향식이며 평균의 비를 평균배율로
대체하지 않는다. 이 수치 관계를 다른 실제 선택·상태·g를 가진 두 학습 경로의 도움
확률이나 최종 성적의 비율로 바꾸지 않는다. 다른 대조·한쪽만Go·전환 전 방향까지
B가 같다는 주장을 확대하지 않는다.

## 단위·모든 기록·수치 잔차

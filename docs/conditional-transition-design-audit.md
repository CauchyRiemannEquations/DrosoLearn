# 선택·상태 조건부 측정의 설계 감사

작성일: 2026-10-16 (Asia/Seoul). 연구 ID `conditional_transition_v1`. 이 문서는 새 자료 집계 전의 설계·재사용 감사이며 사람 또는 모델의 새 결과가 아니다.

## 쉬운 설명과 연구 범위

‘좋은 결과 뒤에 같은 선택을 더 자주 했다’는 숫자는 원래 어느 쪽을 자주 골랐는지에도 영향을 받는다. 이번에는 같은 선택·같은 과제 상태의 기록끼리 나눠 놓고, 좋은 결과와 좋지 않은 결과가 **둘 다 기록돼 있는지부터** 확인한다. 한쪽 기록이 없으면 차이를 모른다고 남긴다.

이는 Phase 4의 측정 준비를 이어가는 한 작업이다. 사람의 학습 곡선이나 모델과의 유사성을 새로 검정하는 것이 아니다. 같은 종류의 숫자를 만들 수 있는지와 그 분모의 한계를 드러내는 것이 산출물이다. 현재 데이터와 앞 결과를 이미 보았다는 사실도 유지한다.

새 producer는 확률적 로그용 어댑터와 층별 산술만 추가한다. 새 verifier는 주 어댑터·주 층 집계 함수를 호출하지 않고 원 자료에서 독립적으로 복원한다. 기존 소스·실험 기준·결과·실패·DrosoMem은 수정하지 않는다.

## 층과 분모의 감사

사람의 설계층은 단계 2 × 원 상태 2 × 절대 카드 정체성 2 = 8개다. 모델은 한 단계에 하나의 참조 상태만 있으므로 `phase1/larger`와 `phase2/smaller` 각각의 절대 수량 선택 2개, 총 4개다. 모델의 불가능한 단계·상태 조합을 관측 누락처럼 추가하지 않는다. 설계상 존재하는 층의 관측이 0이면 그 층은 반드시 남긴다.

25개 사람 기록 × 8층과 240개 모델 경로 × 4층의 합은 1,160층, 피드백 셀은 2,320개다. 원 인접 후보는 사람 24,975 + 모델 191,760 = 216,735쌍이다. 같은 원자료·규칙의 기존 결과에 따라 유효 213,050쌍과 제외 3,685쌍을 검사한다. 사람의 3,445 제외와 모델의 단계 경계 240쌍을 성공·실패나 독립 반전 수로 읽지 않는다.

층의 피드백별 분모·유지 횟수·전환 횟수는 서로 정수로 맞아야 한다. 모든 층의 횟수를 원 경로 안에서 더하면 기존 전체 지표와 같아야 한다. 이 등식은 처리 무결성 검사이며 층별 비율을 평균하는 새로운 효과 추정이 아니다.

`common_support`는 두 피드백의 유효 분모가 모두 양수라는 제한된 표시다. 큰 표본, 충분한 정밀성, 무작위 배정, 보상의 인과 효과, 종간 과제 정합을 보증하지 않는다. 한쪽 분모가 0이면 차이는 `null`이며 0%포인트가 아니다. 결정적 모델에서 현재 선택·단계가 정해지면 피드백도 정해지는 구조를 이 구분이 드러내야 한다.

## 사전에 막아야 할 구현·해석 오류

1. **현재 정오와 절대 선택의 혼동:** 사람의 source-coded 카드 0/1과 모델의 작은/큰 수량 0/1을 각각 유지한다. 현재 유리한 선택 여부를 절대 선택 코드로 대체하면 분석 질문이 달라진다.
2. **다음 시행 또는 경계 위치의 착오:** 피드백은 현재 `t`, 유지 여부는 `t`와 원래의 `t+1`이다. 층도 현재 `t`의 단계·상태·선택이다. 현재와 다음의 로컬 시행·원 위치를 모두 남긴다.
3. **확률적 결과를 정오로 강제:** 정보 있는 확률적 환경에서 유리한 수량을 골라도 보상 0이 가능하다. 무정보 환경의 참조 방향을 보상 우세 선택이라고 부르지 않는다.
4. **정보 요청·결측의 조용한 삭제:** 기존의 다음 정보 요청·무응답 제외가 선택적일 수 있음을 명시하고 모든 원 후보와 겹친 사유를 보존한다. 별도 다음 행동률이나 새 분모를 이번에 추가하지 않는다.
5. **관측 가능성을 성과로 오독:** 공통 지원이 있는 층이 많거나 차이가 크다고 더 잘 배운 것으로 쓰지 않는다. 결정적·확률적 환경의 지원 차이는 우선 과제 구조와 유한 표본의 차이다.
6. **기록과 반복 단위의 혼동:** 모델 경로는 같은 시드의 입력·난수·조건 공유를 포함한다. 사람 기록 25개와 계산 경로 240개를 합쳐 모집단 추정이나 유의성 검정을 하지 않는다.
7. **사후 선택:** 조건·단계·시드·원본·분모가 유리한 층을 보고 범위를 줄이지 않는다. 불가능한 설계층과 설계층 안의 관측 0을 구별하며 후자는 전부 보고한다.
8. **완료 기록의 바이트 연결 누락:** 부모 검산·등록·실제 원파일·새 소스·산출물의 SHA를 결합해야 한다. 이름이 같은 새 바이트에 과거 통과 판정을 재사용하지 않는다.

## 실패와 반증을 보존하는 방법

행 중복·순서 역전·불허 코드·비유한 값·원본 및 부모 해시 불일치·전체/층 횟수 불일치·독립 복원 불일치는 무결성 실패로 남긴다. 원자료를 고치거나 잘못된 행을 조용히 빼지 않는다.

설계층 안에서 어느 피드백의 분모가 없는 결과, 정의된 차이가 0이거나 부호가 서로 다른 결과는 정상적인 기술 결과다. 지원 없는 층을 삭제하거나 보간해 비교가 가능한 것처럼 만들지 않는다. 정의된 차이가 있어도 고정 선택 편향 이외의 시간·경험·숨은 상태·자극·정보 요청 제외를 통제했다고 주장하지 않는다. 이번 작업에는 행동 유사성의 성공 기준이나 가설 검정이 없다.

## 사람 학습과 연결할 수 있는 범위

사람 자료는 금전 카드·정보 요청·여러 반전·1,000시행이고 모델은 인공 수량 두 선택·한 번의 반전·800시행이다. 손실과 무보상, 카드와 수량, 실제 시각 정보와 입력에 이미 주어진 수량 순서를 같은 뜻으로 합치지 않는다. 공개 과제 코드와 실제 과거 실행판의 연결 미확인, 원본 미대응 49행과 OpenNeuro 코드 의미 미해결도 남는다.

정해진 수식과 분모로 공통 지표를 계산하는 것은 향후 인간 학습 가설의 준비다. 이번 결과만으로 Level 4의 정량적 유사성·Level 5의 동일 신경 기작·수량 이해·수학교육 효과를 판정하지 않는다. 과제 구조가 다른 자료에서 같은 수치가 나와도 원인이 같다고 할 수 없다.

## 그림·동결·종료 확인

그림은 독립 검산을 통과한 정확한 결과 바이트와 사전 고정된 plot 소스만 사용한다. 사람의 8층과 환경별 모델의 4층은 네 별도 영역에 전체 기록 순서로 표시하며 색은 두 분모의 존재 분류만 뜻한다. 사람은 원본 행 순서, 모델은 조건 순서 안의 시드 순서다. 층 평균·집단 차이·종간 효과량·유사성 검정은 추가하지 않는다. 새 sibling 출력 폴더의 metadata에 원 입력 결과·스크립트·PNG SHA를 남긴다.

사전 동결 대상에는 이 문서, 별도 프로토콜, 설정, 새 producer·CLI·독립 verifier·plot·시험, 실제 import한 기존 해시·변환·환경 코드, 부모 검산과 출처 근거를 포함한다. 정확한 파일 목록은 root가 새 설정과 등록에 고정한다. 모든 실제 집계는 동결·원격 동일 바이트 확인 후에 한 번 진행하고 독립 검산을 별도로 수행한다.

추가 학습 갱신·학습자 구성·데이터 생성·난수 추출은 0회다. 이 한 작업을 완료한 뒤 자동 이어가기는 PAUSED를 유지하고 다음 연구에 착수하지 않는다.

# 따로 보관된 인간 기록을 연결해 본 결과

작성일: 2026-10-15 (Asia/Seoul). 완료 보존 태그: `human-trial-linkage-v1`.

## 먼저 쉽게 설명하면

**23쌍의 기록에서 두 과제의 피드백 전체 순서가 유일하게 일치했다.** 이름표가 있는 사건 기록과 이름표 없이 묶인 행동 기록 사이에 연결 근거가 생겼다. 파일 순서나 참가자 번호를 추측해 붙인 결과는 아니다.

하지만 모든 열을 바로 합칠 수 있는 것은 아니었다. 같은 피드백 순서를 가진 기록에서도 선택·기대 보고의 숫자 코드는 일괄 변환으로 전부 맞지 않았다. 예를 들어 두 일지에 같은 순서로 결과가 적혀 있어도, 한쪽의 ‘왼쪽’이 다른 쪽의 ‘도형 1’이라는 뜻은 아니다. 이번 작업은 **기록 연결과 코드 의미 확인이 서로 다른 문제**임을 실제 자료에서 확인했다.

## 무엇을 어떻게 연결했는가

대상은 이전에 고정한 [OpenNeuro ds004295 v1.0.0](https://openneuro.org/datasets/ds004295/versions/1.0.0/download)의 26개 사건 TSV와 행동 MAT의 23개 cell이다. 같은 MAT cell의 REW/PUN 두 피드백 배열을 한 묶음으로 사용했다. 새로 보존한 저자 MATLAB 코드 5개는 해석 근거로만 읽었고 실행하지 않았다.

사전에 고정한 [연결 계획](human-trial-linkage-protocol.md)에 따라 26×23 = **598개 조합**을 모두 검사했다. 두 과제의 전체 피드백이 길이·값·순서 모두 같고, 양쪽에서 후보가 각각 하나일 때만 연결 후보로 남겼다. 부분 일치, 원소 삭제, 누락 채우기, 순열 변경 또는 비슷한 기록 선택은 하지 않았다.

| 항목 | 결과 |
|---|---:|
| 양방향 유일 완전 일치 후보 | 23쌍 |
| 후보가 없는 사건 파일 | `sub-s5`, `sub-s7`, `sub-s9` |
| 후보가 없는 MAT cell | 0개 |
| 후보가 여럿인 사건 파일 / MAT cell | 각각 0개 |
| 후보 23쌍의 조건별 피드백 길이 | 모두 REW 280개 + PUN 280개 |

명시된 저자 ID 대응표를 발견한 것은 아니다. 공개된 익명 기록 사이에서 두 결과열이 일치한다는 근거다. 이 일치를 실제 개인의 신원 확인이나 확률적으로 독립된 560비트의 검정으로 해석하지 않는다. 후보가 없는 파일을 참가자의 학습 실패나 새로운 제외 기준으로 읽지 않는다. 전체 대응은 [record-links.csv](../results/human_trial_linkage_v1/record-links.csv), 모든 조합은 [alignment-matrix.csv](../results/human_trial_linkage_v1/alignment-matrix.csv)에 있다.

## 같은 피드백이라도 다른 코드는 모두 맞지 않았다

각 피드백 바로 앞의 사건 구간에서 같은 과제의 선택·기대 보고가 각각 하나이고, 순서·과제 상태·중단·시간 조건이 맞는 경우만 수치 코드를 대조했다. 구간은 원 시행으로 확정한 단위가 아니라 **직전 피드백부터 현재 피드백까지의 관측 기록**이다.

| 후보 23쌍의 피드백 구간 | 개수 |
|---|---:|
| 전체 위치 대조 기록 | 12,880 |
| 고정한 엄격 비교 조건 통과 | 12,334 |
| 엄격 비교 불가, 원값과 위치는 보존 | 546 |
| 선택: `왼쪽→1 / 오른쪽→2` 수치 일치 | 6,220 |
| 같은 선택 수치 대응 불일치 | 6,114 |
| 기대: `사건 평정 0–3 + 3 → MAT 3–6` 일치 | 8,199 |
| 같은 기대 수치 대응 불일치 | 4,135 |

선택 일치 6,220 + 불일치 6,114 = 12,334이며, 기대도 8,199 + 4,135 = 12,334다. **이 숫자는 정답률이나 학습 능력이 아니다.** 고정한 코드 대응이 같은 관측 위치에서 성립하는지의 진단이다. 불일치를 사람의 오답이나 원자료 오류라고 이름 붙이지 않는다. 숫자를 뒤집거나 다른 offset을 찾아 이번 결과에 채택하지 않았다.

선택의 경우 원 코드북은 화면 좌우를 설명하고, 논문은 도형별 선택의 모형을 설명한다. 원 저자 코드만으로 MAT 숫자→구체 도형→매 시행 화면 위치를 복원하는 변환을 확인하지 못했다. 기대 보고 역시 단순 `+3` 대응이 전 항목에서 성립하지 않았다. 따라서 피드백 일치만을 근거로 기대 값·도형 선택·반응 시간을 TSV에 붙여 사용하지 않는다. 어느 단계에서 값이 달라지는지는 후속 검증 대상이다. [저자 코드 검토](human-trial-linkage-source-review.md), [원 코드북](https://raw.githubusercontent.com/OpenNeuroDatasets/ds004295/c7c5d3a164425af3e65cc908ef0d41f01725984c/task-task_events.json), [원 논문 Methods 2.5–2.6](https://onlinelibrary.wiley.com/doi/full/10.1111/psyp.14235).

## 원 사건은 빠짐없이 남겼다

26개 파일의 사건 **44,262행**을 관측 피드백 구간 14,552개와 마지막 피드백 뒤 꼬리 26행으로 나누어 원행 위치를 남겼다. 후보가 없는 세 파일도 이 기록에서 삭제하지 않았다. 구간별 선택·기대가 없거나 여러 개인 경우, 활성 과제 밖인 경우도 문제 표시와 함께 보존했다.

| 전체 파일에서의 구간 문제 표시 | 건수 |
|---|---:|
| 선택 사건이 정확히 하나가 아님 | 44 |
| 기대 사건이 정확히 하나가 아님 | 301 |
| 일치하는 활성 과제 밖의 선택 | 343 |
| 일치하는 활성 과제 밖의 피드백 | 353 |

여러 표시가 같은 구간에 겹칠 수 있다. 이전 감사의 13,954개 연결 후보·614개 불완전 선택·1,720개 표시는 그대로 보존했다. 그때는 선택 사건 중심이고 이번에는 피드백 구간 중심이므로 서로를 고친 값으로 제시하지 않는다. 특히 이번 546개는 연결 후보 23쌍에서 엄격 코드 비교가 안 된 구간 수이며 이전 614개와 분모·기준이 다르다.

## 자료 사용 조건도 한 걸음 확인했다

이전 조사에서 timeout이 났던 OSF가 이번 정상 공개 API 요청에는 응답했다. Marković 프로젝트 `h526v`와 하위 실제 데이터 component `75jrf`, Cheng 프로젝트 `x2rau`는 공개 상태와 CC BY 4.0 관계를 직접 명시했다. 공식 JSON 메타데이터 14개를 보존하고 해시·관계·목록을 다시 검사했다. [새 권한 확인 기록](human-trial-permissions-followup.md), [공식 OSF 라이선스](https://api.osf.io/v2/licenses/563c1cf88c5e4a3877f9e96a/).

이는 현재 공식 표시를 확인한 결과다. 과거 timeout 기록을 지우지 않았고 참가자 응답·자극 이미지의 본문도 새로 받지 않았다. OSF 원본과 GitHub pybefit 가공 CSV의 동일성·변환 관계는 아직 확인하지 않았다. 따라서 가공 CSV에 이 권한을 자동으로 옮기거나 원자료 내부의 모든 예외를 검토했다고 주장하지 않는다.

## 무엇이 준비됐고 무엇이 남았는가

| 항목 | 현재 상태 |
|---|---|
| 익명 사건 파일과 MAT 기록의 대응 | 두 과제의 전체 피드백에 근거한 유일 후보 23쌍 확보 |
| 그 대응이 다른 열의 의미까지 보증하는가 | 아니오. 고정 코드 대응의 불일치도 실제로 보존 |
| 원 예정 시행 번호와 반전 경계 | 복원하지 않음. 관측 피드백 순번을 원 시행 번호로 바꾸지 않음 |
| 도형–좌우 변환, 기대 코드 변환 | 근거와 불일치 원인 추가 검증 필요 |
| 인간 학습 곡선·정답률·반전 비용 | 계산하지 않음 |
| 인간과 모델의 행동·신경 기작 유사성 | 시험하지 않음. Level 4·5 근거 아님 |

다음 단계는 **기대 코드 불일치의 변환 근거와 도형 코드의 정의를 확인하고, 공식 OSF 원본과 가공 자료의 대응을 검증하는 것**이다. 이번 연결 기준을 사후에 완화하지 않는다. 필요한 원 로그·과제 코드가 공개되지 않았다면 해당 지표를 보류하고, 확인할 수 있는 다른 자료 범위를 별도 계획으로 검토한다. 공통 학습 지표는 그 이후에 사전 정의한다.

## 재현과 검증

관련 합성 테스트 **184개가 41.00초에 통과**했다. 새 도구 126개와 재사용하는 입력 처리의 기존 테스트 58개다. 모든 과거 모델 실험 테스트를 다시 실행한 결과는 아니다. 개발 중 합성 fixture의 기대 개수를 바로잡은 기록도 [테스트 검증 기록](../results/test-validation-human-trial-linkage.json)에 남겼다. 실제 사람 자료를 보고 테스트나 파서를 고치지 않았다.

주 파서를 가져오지 않는 독립 검증기가 36개 원본, 동결 파일 49개, 주 산출물 7개의 해시, 전체 598조합, 사건 44,262행의 분할과 12,880개 코드 대조 기록을 다시 계산해 통과했다.

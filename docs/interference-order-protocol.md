# 맥락이 있는 두 규칙의 학습 순서·간섭·즉시 유지: 실행 전 계획

2026-10-19 (Asia/Seoul). 연구 ID `interference_order_v1`. 선행 연구의 완료·독립 검산 뒤 별도
설정·소스·입력 파일·원 그래프·부모 결과 해시를 동결하고 비공개 원격 등록을 확인한 다음
고정 예산의 실제 학습을 한 번 수행한다. 기존 실험·실패·등록은 수정하지 않는다.

## 쉽게 설명하면

같은 여섯 이름표를 보고 행동하되, A 상황과 B 상황에서 일부 이름표의 좋은/나쁜 결과가 달라진다.
A를 배운 뒤 B를 배우면 A를 얼마나 유지하는지, 순서를 바꾸면 무엇이 달라지는지 확인한다.
계속 A만 연습했을 때의 이득과 B를 배운 뒤의 손실을 구분한다. 업데이트를 멈춘 상태의 동일성도
확인하지만 실제 시간이 흘러 생기는 망각을 시험하는 것은 아니다.

이 연구는 패턴 습득 실패를 성공으로 바꾸는 재시도가 아니다. 인공 ID와 명시적 상황 신호를
쓰는 독립 과제로 자체 습득·공동학습 조건을 적용한다. 앞선 패턴 연구가 실패해도 그 결과와
닫힌 패턴 일반화 gate는 그대로 남긴다. 새 과제의 긍정적 결과로 구제하지 않는다.

## 입력과 두 규칙의 공동 해결 가능성

입력은 ID 1..6의 one-hot 여섯 좌표와 상황 A=-1/B=+1의 한 좌표, 총 7차원이다.
NoGo 입력은 영벡터, Go 입력은 위 벡터다. 다음 표의 종류 1은 Go이면 +1, 종류 0은 Go이면 -1이다.
NoGo는 항상 보상 0이며 그때 잠재 Go 결과·종류를 학습자에게 알려 주지 않는다.

| ID | A의 종류 | B의 종류 | 고정 분석 그룹 |
|---|---:|---:|---|
| 1 | 1 | 0 | 충돌 |
| 2 | 0 | 1 | 충돌 |
| 3 | 1 | 1 | 일관 |
| 4 | 0 | 0 | 일관 |
| 5 | 1 | 1 | 일관 |
| 6 | 0 | 0 | 일관 |

각 task는 종류 1/0을 세 개씩 가진다. 상황 신호가 있으므로 12개 입력이 모두 다르고,
분석적 `(상황, ID)` oracle은 두 규칙을 동시에 풀 수 있다. 상황을 없앤 같은 입력에 두 정답을
강요하지 않는다. 이름표와 상황은 인공 표현이며 인간의 상황 전환 회로나 실제 감각 인식은 구현하지 않는다.

실제 유한 입력은 `data/synthetic/interference_order_v1/input_catalog.json`에 12입력·종류·
원 ID·충돌 그룹으로 보존한다. byte hash를 등록하고 producer가 직접 읽어 전체 key·shape·dtype 종류·
값을 사전 명세와 대조한다. 없거나 다르면 자동 생성/수정하지 않는다. 입력 준비는 학습자·행동 RNG를 쓰지 않는다.

## 모델·동결된 계산 규칙·자원

9조건은 fixed, plastic, rewired_fixed, rewired_plastic, ann_fixed, ann_plastic, linear,
uniform, context_q이다. 일차 조건은 plastic이며 결과를 보고 교체하지 않는다.
앞서 동결한 `pattern_rule`의 범용 7차원 VectorActor/VectorSimple와 그래프 초기화 함수를 재사용한다.
이전 파일은 수정하지 않고 본 연구 소스 목록에 정확한 버전을 포함한다.

head는 0에서 시작한다. 출력 학습률 .1, 내부 학습률 .01, `(a-p)*reward`, 갱신 전 head 기반
eligibility·정해진 마스크/비음수 상하한을 유지한다. encoder 초기화 seed는 model_seed+100000이다.
특징 차이 RMS는 12개 ID×상황 사전의 초기 상태에서 정하며 라벨이나 성과로 정규화하지 않는다.
공통 입력 사전은 알려 주지만 보상 종류를 actor의 입력으로 주지 않는다.

linear는 같은 12 raw 벡터의 RMS와 head 7개를 사용한다. uniform은 항상 pGo=.5이며
학습 계수·내부·value table이 비어 있다. context_q는 명시적 12입력×2행동 table을 0에서 시작하고
alpha=.1, beta=4로 자기 선택의 보상만 학습한다. 새로운 입력을 평가한다고 table 행을 만들지 않는다.
table 변화는 신경 출력/내부 가중치와 구분한다. 모델별 head/내부/value/fixed encoder 자원과
업데이트 호출·실제 비영 변화 수를 각각 보고하며 전체 자원이 같다고 주장하지 않는다.

context_q의 상황별 table 행은 서로 독립이다. 같은 task별 순서/uniform을 공유하므로
AB·BA·joint의 최종 table 일치는 이 대조의 구조적 항등성이다. 그 대조에서 손실과 순서 차이가
0인 것을 새로운 기억 기작 발견으로 세지 않는다. 해당 예산의 실제 습득 여부는 별도로 측정한다.

## 다섯 이력과 공유 prefix

model seed는 15201..15210의 10개로 고정한다. task stage 하나는 360시행이며,
여섯 ID를 한 번씩 섞은 60 block이다. 각 task·stage에서 각 ID는 60회 나타난다.

- AB: A 360 뒤 B 360.
- BA: B 360 뒤 A 360.
- AA / BB: 한 task를 720회 반복하는 같은 총 예산의 연습 대조.
- joint: A/B를 한 번씩 번갈아 720회 학습하며 task마다 360시행.

joint는 A,B,A,B의 결정적 교대이며, task 내부의 ID 순서와 행동 uniform은 순차 이력에서 쓴
A0/B0와 같다. 공동 해결 가능성을 실제 학습자가 이 예산에서 달성하는지 확인하는 대조이며
새로운 최적 상황 전환 정책을 찾는 실험은 아니다.

같은 초기 모델의 복사본에서 A360/B360 두 prefix를 한 번씩 실행한다. A prefix를 그대로 복사해
B/A suffix를, B prefix를 복사해 A/B suffix를 실행한다. joint는 같은 초기 상태에서 따로 시작한다.
prefix를 다시 학습하지 않는다. 실제 피드백은 모델·seed당 prefix 720+active suffix 1,440+
joint 720=2,880회, 전체 9×10×2,880=259,200회다. 다섯 논리 이력을 각각 전부 더하면
324,000시행이지만 공유 prefix 64,800회가 중복되므로 실제 실행 수와 구분한다.

각 prefix의 idle 상태는 배열을 그대로 복사해 보존한다. 추가 학습·시간 시뮬레이션·확률 평가를
하지 않는다. 동일 상태·동일 반응은 구현 항등성이며 생물학적 망각이 없다는 발견이 아니다.
idle은 업데이트 수가 같은 대조라고 하지 않는다. 자연 시간의 망각은 본 연구에서 미검정이다.

## 난수와 상태 기록

task별 입력 순서 주소는 `SeedSequence([202610192,seed,task,repetition,0])`, 행동 uniform
주소는 마지막 값 1이다. task는 A=0/B=1, repetition은 첫 노출 0/AA·BB의 두 번째 노출 1이다.
AB의 첫 A와 BA의 두 번째 A는 A0를 공유하고 B0도 동일하게 공유한다. 모든 모델 조건도 같은
cell의 순서/uniform을 공유한다. 합으로 주소를 합치거나 공유된 난수를 독립 표본으로 세지 않는다.

7개 실제 stream은 prefix_A, prefix_B, AB suffix, AA suffix, BA suffix, BB suffix, joint다.
앞 여섯은 360시행, joint는 720시행이다. 저장 배열의 720칸 padding은 valid mask로 구분하며
행동 -1·보상/변경 0·확률 .5의 무관측 칸을 실제 시행으로 세지 않는다. CSV에는 실제 시행만 남긴다.
행위자 누적 호출 수와 이번 시행의 실제 호출 증가분을 모두 기록해 공유 prefix를 이중 계산하지 않는다.

prefix/suffix는 60회마다, joint는 120회마다 두 task의 고정 12입력을 정적으로 평가한다.
초기 1+두 prefix×6+네 suffix×6+joint×6=43 checkpoint이며 총 43×12×9×10=46,440사례다.
greedy를 기술할 경우 pGo=.5 동률은 Go다. 일차 지표는 기대 최적 행동률이다.

모든 조건·seed·checkpoint에서 head·내부 가중치·초기/상한·encoder·입력 catalog·value table 및
12 probe의 KC/MBON/결정 특징·raw 점수 차이·pGo를 보존한다. 실제 선택·보상·new-minus-old
head/내부/value 변화량과 호출/비영 여부도 전 시행 기록한다. probe 활성은 지속 기억 상태가 아니다.

## 습득·공동학습 자격과 동결 전 구조 보완

각 task의 첫 prefix는 평균 기대 최적 행동률≥.80, 초기 대비 gain≥.25,
양/음 종류 각각≥.70, **충돌 ID1/2 평균≥.75**를 모두 요구한다.
joint 마지막에는 A/B 각각 평균≥.80, 종류별≥.70, 충돌 ID 평균≥.75를 요구한다.
plastic의 10seed 중 8개 이상이 두 prefix와 두 joint 조건을 함께 통과해야 간섭/순서 가설의
연구 단위 해석 자격을 얻는다. 다른 모델도 같은 자격 상태를 기술한다. 모든 seed는 효과 집계에 남긴다.

충돌 ID 조건은 실제 O 입력 생성·학습 전에 발견한 설계상 빈틈을 막는 보완이다.
일관된 네 ID를 모두 맞추고 충돌 두 ID에서는 p=.5로 상황을 무시해도 전체와 종류별 성적은
각각 5/6=.8333으로 원래 .80/.70 조건을 통과한다. 그러한 기계를 두 충돌 규칙을 공동 학습한
것으로 해석하지 않기 위해 .75 조건을 추가했다. 기존 모델·시드·예산·다른 기준은 바꾸지 않는다.
이 보완은 앞선 패턴 결과를 구제하지 않으며, 이미 등록된 이전 연구에는 소급 적용하지 않는다.

## 고정 지표와 판정

`S_X(state)`는 task X의 여섯 ID에 대한 평균 기대 최적 행동률이다.

- 역행 손실 A = `S_A(after A)−S_A(after AB)`; B = `S_B(after B)−S_B(after BA)`.
- 계속 연습 이득 A = `S_A(after AA)−S_A(after A)`; B도 같은 방식이다.
- 같은 총 예산 terminal cost A = `S_A(after AA)−S_A(after AB)`; B도 동일하다.
- `terminal cost = 역행 손실 + 계속 연습 이득`을 1e-12 이내로 검산한다.
  계속 A를 연습해 생긴 이득을 모두 B가 파괴한 효과로 해석하지 않는다.
- 순서 차이 = `mean(S_A,S_B after AB)−mean(S_A,S_B after BA)`.
  두 순서는 총 시행 수와 task별 노출 수가 같다.

충돌 두 ID/일관 네 ID의 손실을 정해진 그룹대로 보고한다. suffix의 새 task 학습 곡선과
0..360 checkpoint trapezoid AUC, 같은 task를 처음부터 배운 prefix와의 차이도 기술한다.
이 보조 지표로 일차 판정을 바꾸지 않는다. task·ID·시행·여러 branch를 독립 개체로 세지 않는다.

H_interference는 plastic의 seed별 A/B 평균 역행 손실이 10seed 평균≥.10이고 paired 90%
bootstrap 구간 하한>0일 때 지지한다. H_order는 평균 순서 차이의 절댓값≥.05이고 paired 90%
구간이 0을 포함하지 않을 때 지지한다. 순서 차이의 부호는 그대로 보고하며 유리한 순서를 미리 가정하지 않는다.
두 가설은 위 습득/공동학습 자격이 있어야 판정한다. 미달이면 `not_assessable`이며 수치는 보존한다.

bootstrap은 2,000회이며 `SeedSequence([202610192,15301,2])`로 고정한다. 10계산 seed를
paired로 재표집하고 같은 인덱스를 모든 모델·이력·지표에 공유한다. 분위수는 .05/.95, linear 방식이다.
자격 미달 seed도 수치 추정에서 제외하지 않는다. 이 구간은 계산 반복의 변이이며 생물학적 집단 효과가 아니다.

## 실행 전후 검증과 해석

개발은 별도 synthetic seed 91001..91100·stage 6/12만 허용하는 integration_test scope로 한다.
공통 등록기는 이 scope를 실제 과학 실행으로 허용하지 않는다. 본 실행 전에 전향적 원격 등록을 확인한다.
독립 검산은 producer/actor/지표 함수를 호출하지 않고 원 입력·그래프·난수·분기 초기 상태·갱신·
전체 checkpoint·padding mask·실제 호출 수·idle 원문 상태·모든 gate/가설을 재구성한다.

무결성 오류와 과학적 미지지/자격 미충족을 구분한다. 같은 등록의 seed·횟수·허용폭을 바꾸지 않는다.
모든 실패와 두 규칙의 차이도 결과로 보존하고 그 다음 Phase 5에서 종합한다.

공동학습 gate가 미달인 네트워크의 순차 손실은 표현 용량·학습 충분성과 간섭을 구분할 근거가
부족하다고 보고한다. 맥락을 공급한 계산 모델의 행동·상태 차이가 인간/초파리의 공통 신경 기작,
수학 기호 이해·교육 효과·자연적 망각을 입증하지 않는다.

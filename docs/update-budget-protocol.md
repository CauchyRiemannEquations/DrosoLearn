## 과제·입력·보상

부모의 유한 인공 문자열 네 개와 두 표현을 원문 그대로 사용한다.

| 문제 | 문자열 | 목표 행동 | 실제 Go를 선택했을 때의 보상 |
|---|---|---|---:|
| 0 | ABAB | Go | +1 |
| 1 | BABA | Go | +1 |
| 2 | ABBA | NoGo | -1 |
| 3 | BAAB | NoGo | -1 |

NoGo의 획득 보상은 모두 0이다. NoGo에서 숨겨진 Go 보상이나 정답 라벨을 학습자에게 주지 않는다.
학습자는 현재 문제·자기 행동·획득 보상만 받는다. 목표 라벨은 환경과 평가에서만 사용한다.

`raw`는 A=0, B=1인 `[s0/3,s1/3,s2/3,s3/3,0,0,2/3]`이다.

마지막 길이 좌표에 `2/3`을 주는 7차원 표현이다. 원 문제 순서의 이름표 번호는 `[0,3,1,2]`다.
두 표현의 각 입력 L2 길이는 `sqrt(2/3)`으로 같다. 이름표는 정답을 사용하지 않으며,
알려진 네 문제에 대한 암기 대조용이다.

입력 파일은 완료한 `data/synthetic/representation_update_v1/input_catalog.json`과
원 출처인 `data/synthetic/pattern_rule_v1/input_catalog.json`을 그대로 해시 동결한다.
새 입력 파일을 만들거나 부모 파일의 미학습 문제를 추가 평가하지 않는다.
전체 문자열을 인공적으로 주므로 실제 시각 인식·수량 회로나 생물학적 순차 기억을 재현하지 않는다.

## 조건: 배선 3 × 표현 2 × 갱신 3

배선은 `real`, `rewired`, `ann`이다. 실제 배선은 부모와 같은 FlyWire v783 왼쪽 MB 부분
투영의 512 KC·48 MBON·1,474 연결이다. 고정된 `build_graphs`가 차수 통제 재배선과 일반
희소 무작위 대조를 생성한다. 모든 해부학적 특성이 같거나 실제 배선이 우수하다고 가정하지 않는다.

표현은 `raw`, `identity`, 갱신은 `shared`, `projected_own`, `projected_l2`다. 총 18조건이다.
일차 비교는 **real/raw의 projected_l2−shared**다. 자기 점수 폭을 맞춘 `projected_own`은
부모 방식을 새 시드에서 함께 측정하는 기준 조건이다. 다른 배선·표현·기준 조건은 기술적으로 보고하며
일차 비교가 실패했을 때 그 조건들로 성공 가설을 바꾸지 않는다.

encoder·bias·KC→MBON 배선과 내부 가중치는 고정된다. 출력 계수 h는 48개이며 모두 0에서 시작한다.
동일 seed에서 표현과 갱신은 동일 encoder를 쓰고, encoder seed+100000,
재배선 seed+110000, ANN seed+120000의 동결된 생성 규칙을 사용한다.
내부 시냅스 가소성·가치표 학습·시간에 따른 자연 망각은 없다.

## 세 출력 갱신과 서로 다른 자원 기준

각 고정 신경망에 NoGo 영벡터와 Go 입력을 주고 MBON 활성의 차이를 구한다.
네 문제 각각의 차이를 자신의 L2 길이로 나눈 단위 행벡터를 d_i, 이를 쌓은 행렬을 D라 한다.
정규화와 방향 계산에는 정답 라벨이나 학습 성적을 사용하지 않는다.

Go 확률은 `p=logistic(clip(d_i·h,−40,40))`다.
학습률 eta=.1, 실제 선택 a∈{0,1}, 획득 보상 r∈{−1,0,1}에서
공통 스칼라는 `g=eta×(a−p)×r`다. 선택한 방향 w_i로 `h_new=h_old+g×w_i`를 수행한다.

| 갱신 | 방향 w_i | 방향 L2 | 같은 g에서 자기 문제 점수 변화 |
|---|---|---|---|
| shared | d_i | 1 | g |
| projected_own | u_i | ||u_i|| | g |
| projected_l2 | u_i/||u_i|| | 1 | g/||u_i|| |

`projected_own`은 부모와 같은 고정된 SVD 규칙이다.

`C=pinv(D,rcond=1e−12), P=D C, u_i=C[:,i]/P[i,i]`

최대 특이값의 `1e−12`배보다 엄격하게 큰 방향만 유지한다. 이는 성적을 보고 바꾸는 대체법이 아니다.
이 유지 반응 부분공간 안에서 u_i는 자기 점수 영향을 1로 맞추면서 다른 입력으로 번지는 제곱 영향을
최소화한다. 아주 작은 제외 방향까지 포함한 전체 공간의 최소성은 주장하지 않는다.

`projected_l2`는 이 방향을 자신의 길이로 한 번 더 나눌 뿐이다.
단위 길이 조건 자체에서 다른 입력의 영향을 새로 최적화했다고 주장하지 않는다.
정확한 분리가 가능한 경우 0이던 다른 문제의 영향은 0으로 유지되지만 자기 문제의 수정 폭도 작아진다.

자기 점수 폭과 전체 L2를 일반적으로 동시에 맞출 수 없는 이유는 Cauchy–Schwarz 부등식이다.
`||d_i||=1`이며 `d_i·u_i=1`이면 `||u_i||≥1`이다. 길이도 정확히 1이어야 한다면 등호 조건에 의해
u_i=d_i여야 한다. d_i가 다른 문제도 움직이는 상황에서는 그 영향까지 없애는 동일 방향을 선택할 수 없다.
따라서 이번 계획은 두 자원 기준을 별도 조건으로 보존한다.

정적 영향 행렬은 **행=고친 문제, 열=검사한 문제**이며 각 방향 행렬 W에 대해 `W Dᵀ`다.
실제 점수 변화에는 g를 곱한다. 방향 길이·자기 영향·비대각 제곱 영향·단위 이동당 자기 영향을 기록한다.
처음 p=.5인 Go 선택에서 ±1 보상의 정적 변화는 ±.05×방향이다.

## 시행당 상한과 실제 총 이동량

|a−p|≤1, |r|≤1이므로 shared와 projected_l2의 이론적 시행당 이동은 `||delta_h||≤eta=.1`이다.
400회에서 경로의 누적 길이 `sum_t ||delta_h_t||≤400×.1=40`이다.
제곱 이동량 합의 이론적 상한도 `400×.1²=4`다.
출력 계수의 끝점 길이는 삼각부등식에 의해 누적 길이 이하이다.

이는 두 방식이 **같은 상한**을 가진다는 뜻이며 실제 누적 길이 40을 모두 쓰거나 같은 길이를 쓴다는 뜻은
아니다. 확률·행동·보상은 자율 경로에서 달라질 수 있다. 다른 조건의 행동·보상을 강제로 복사하거나,
보상 뒤 실제 변화량을 소급 조정하지 않는다. 별도 강제 피드백 학습이나 추가 갱신도 수행하지 않는다.

매 시행의 실제 변화 `h_new−h_old`로 L2·제곱 L2·자기 점수 변화·다른 세 점수 변화 L2·비영 여부를
기록한다. 호출 수와 실제 비영 변화 수, 누적 L2·누적 제곱 L2·최종 head L2를 구분한다.
두 단위 방향 조건의 최대 시행당 실제 변화 ≤.1+1e−8, 누적 길이 ≤40+1e−8을 확인한다.
이 한도를 넘으면 해당 자원 통제 가설은 지지하지 않으며 오류·위반 증거를 보존한다.
자기 점수 폭을 맞춘 projected_own에는 단위 방향 상한을 강요하지 않고 실제 비용을 보고한다.

## 실행 전에 정한 보수적인 점수 상한

각 문제는 100번 제시되고 모든 갱신 스칼라의 절댓값은 eta 이하이다.
초기 출력 계수가 0이므로 갱신 u의 영향 행렬 M에서 검사 문제 j의 마지막 점수 절댓값은
`100×eta×sum_i |M[u,i,j]|` 이하이다. 이 식은 다른 입력에서 번지는 작은 영향까지 포함하며,
정답 라벨이나 실제 행동을 사용하지 않는다. 그 값에 logistic을 적용한 값은 어느 종류의 정답에도
적용할 수 있는 보수적인 선택 확률 상한이다. 고정 400회 예산의 수치 진단이며 형식 검증 증명은 아니다.

이 상한과 실제 마지막 선택 확률의 관계를 허용 오차 1e−8로 독립 확인한다.
상한이 낮다고 과학 시행을 생략하거나 예산을 늘리지 않는다. 별도 성공 가설도 추가하지 않는다.
정확한 분리나 full rank가 아니어도 절대 영향의 합을 사용하므로 같은 식을 계산한다.

## 행동 시작 전 필수 수치 조건

모든 seed·배선·표현에서 원 특징 길이·P 대각선·u_i의 길이는 유한한 양수여야 한다.
공유와 projected_own의 자기 점수 차이, shared/projected_l2의 단위 길이 잔차와 조건부 L2 차이,
정규화 재구성 잔차, `own(projected_l2)×||u_i||−own(projected_own)` 잔차는 각각 ≤1e−8을 요구한다.
`||u_i||≥1`와 projected_l2의 자기 영향 ≤shared의 자기 영향도 같은 허용 오차로 확인한다.
실패하면 과학 행동 추출을 시작하지 않고 수치/무결성 실패를 보존한다.

유지 rank=4, D 전체 행 조건수 ≤1e6, 자기 영향 잔차와 비대각 최대 잔차 ≤1e−8일 때만
“정확한 분리”라는 강한 해석을 허용한다. 이 자격이 닫혀도 필수 수치 조건을 통과한 사전 지정 경로는
실행하고 남은 간섭을 보고한다. 자격이 닫힌 seed를 교체하거나 cutoff·정칙화·예산을 바꾸지 않는다.

엄격 부동소수점 rank와 등록 cutoff의 유지 rank, 특이값·조건수·원 특징 길이·방향·영향·P를 기록한다.
rank만으로 라벨별 분류 가능성을 단정하지 않는다. 새 시드에서는 부모의 15개 라벨 활성 집합 분석을
반복하지 않는다. 분석용 정답으로 학습자에게 방향이나 출력 계수를 주지 않는다.

## 고정 시행 수·난수·평가

새 계산 seed는 **17201..17210**의 10개다. seed마다 네 문제를 한 번씩 섞은 100 block으로
**400회 실제 선택·피드백**을 제공한다. RNG 주소는 `SeedSequence([202610194,seed,0])`가 순서,
`[202610194,seed,1]`가 행동 uniform이다. seed를 더해 주소를 만들지 않는다.
동일 seed의 18조건은 문제 순서와 uniform을 공유하지만, 실제 선택·획득 보상은 달라질 수 있다.

checkpoint는 **0,50,100,200,400**이며 네 연습문제를 추가 행동 추출·보상·학습 없이 정적으로 평가한다.
예산은 **18×10×400=72,000회 선택·피드백**, 정적 평가는 **18×10×5×4=3,600개**다.
계산 seed는 동물 개체나 사람 참가자의 수가 아니다. 시드·시행 수를 늘려 실패를 성공으로 바꾸지 않는다.

학습자 내부 가중치와 특징이 고정됐음을 초기/최종 증거로 확인하고, 출력 계수 변화와 입력에 따른
활성 반응을 구분한다. 모든 시행의 확률·행동·획득 보상·갱신 비용과 모든 checkpoint의 출력 계수·
점수·확률을 보존한다. NoGo의 0 변화와 갱신 호출 자체는 별개다.

18조건 모두 출력 계수 48개를 학습한다. 투영 방향은 배선·표현마다 추가 고정 계수 4×48개와 SVD 계산을
사용하며, 단위 L2로 나눠도 이 추가 계산 자원은 남는다. 한 배선·표현·seed마다 방향용 SVD 1회와
원/정규화 기하 진단 SVD 2회, 총 **60×3=180회 producer SVD**를 사용한다.
모든 자원이 같거나 해당 계산이 생물학적으로 구현됐다고 주장하지 않는다.

## 사전 가설과 판정

일차 지표는 네 연습문제의 **정답 행동을 선택할 기대 확률 평균**이다.
실제 추출 행동의 정답률·획득 보상·비용은 별도 기록한다. seed별 습득은 마지막 평균 ≥.80,
처음 대비 증가 ≥.25, 두 정답 종류 각각 평균 ≥.70을 모두 요구한다. 조건 단위 지지는 8/10 이상이다.

일차 **H_budget**은 real/raw에서 projected_l2−shared에 대해 다음을 모두 요구한다.

1. 10seed의 최종 평균 차이 ≥.10.
2. 양의 차이가 8/10seed 이상.
3. projected_l2의 습득 통과가 8/10seed 이상.
4. 모든 조건의 필수 수치 자격 통과.
5. shared와 projected_l2 모든 실행에서 최대 실제 시행당 L2 ≤.1+1e−8, 누적 L2 ≤40+1e−8.

실제 변화량과 스칼라×방향 길이의 일치, 실제 확률과 위 보수적 상한의 관계도 전체 수치 자격에 포함한다.

이 실용 문턱은 통계적 유의성이나 생물학적 학습 경계가 아니다. 결과를 본 뒤 조건·문턱·예산을 바꾸지 않는다.
차이가 양수여도 문턱에 못 미치면 H_budget은 미지지이며 효과 0이라고 단정하지 않는다.

projected_own과 projected_l2의 성적·습득 차이와 비용 변화, 다른 표현·배선·상호작용은 기술적으로 보고한다.
일차 가설이 미지지일 때 비용이 큰 기준 조건의 성공으로 이를 대신하지 않는다.
H_budget이 지지돼도 실제 총 비용이 같거나 가장 효율적인 방법을 찾았다고 주장하지 않는다.
미지지면 이 제한된 예산·방향에서 사전 목표를 달성하지 못한 것이며 모든 저비용 학습의 불가능 증명이 아니다.

## 실행 전 동결·실제 실행·독립 검산

새 envelope와 CLI는 완료한 기존 소스·등록을 수정하지 않는 별도 구현이다.
설정의 정확한 소스 24개·부모 증거 6개·그래프 4개·입력 2개 목록을 SHA-256과 Git commit으로 동결한다.
부모 결과의 검산·완료 상태와 기준선 원문을 확인한다. 개발 검사는 만든 작은 행렬·가짜 저장소만 사용하고
실제 그래프와 연구 seed의 결과를 등록 전에 확인하지 않는다.

```text
python scripts/run_update_budget.py register --config configs/update_budget_v1.json --out results/registration_update_budget_v1.json
```

등록을 commit·push한 뒤 원격의 같은 등록 bytes를 확인하고 source commit·published commit·등록 hash·
확인 UTC를 `results/update_budget_publication_proof.json`에 보존한다. 실제 계산 시작보다 앞서야 한다.

```text
python scripts/run_update_budget.py run --config configs/update_budget_v1.json --registration results/registration_update_budget_v1.json --publication-proof results/update_budget_publication_proof.json --out results/update_budget_v1
```

기존 결과 경로를 덮어쓰지 않는다. 실행 실패 시에도 metadata와 만들어진 파일의 hash를 보존한다.
독립 검산은 새 producer와 새 기하 helper를 import하지 않고, 원 그래프·encoder·입력·정규화·SVD·
세 방향·고정 스칼라 영향·RNG 주소·모든 행동과 보상·실제 비용·checkpoint·습득·가설을 다시 구성한다.
등록/원격 확인/계산 시작/완료의 시간 순서와 모든 고정 상태·파일 hash도 확인한다.
요약 숫자만 옮겨 적은 검사는 독립 검산으로 세지 않는다.

## 해석의 범위

이번 최대 범위는 네 인공 연습문제의 **출력 학습(Level 2)**과 계산상 비용·간섭의 관계다.
내부 시냅스 학습·새 문자열 일반화(Level 3)·인간 행동 유사성(Level 4)·공통 신경 기작(Level 5)을
검사하지 않는다. 수학 규칙 이해나 실제 초파리의 문자·수량 인지, 교육 효과도 주장하지 않는다.
새 인간 자료나 신규 인간 실험은 없다. 기존 인간 비교의 미지지와 맥락별 공동 습득·간섭·순서의
닫힌 판정 조건은 그대로 보존한다. 후속 연구는 이 결과와 별도 게이트에 근거해 새로 등록해야 한다.

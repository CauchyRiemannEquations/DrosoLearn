# 두 과제의 간섭·학습 순서: 조건 미충족 결과

2026-10-19. 네 번째 추가 연구 `interference_order_v1`의 실제 259,200회 선택·피드백과 정적 평가 46,440사례를 끝내고, 모든 분기·가중치·활성·판정을 독립 검산했다.

쉽게 말하면, 먼저 A를 배우고 B를 배우면 A를 잊는지 보려 했다. 그런데 **주 커넥톰 모델은 A와 B를 각각 충분히 배우는 첫 기준부터 통과하지 못했다.** 두 과제를 함께 해결하는 대조에서도 기준 미달이었다. 따라서 간섭이 있다/없다, 어떤 순서가 좋다는 결론은 이번 설정에서 내리지 않는다.

| 조건 | 처음 A/B를 각각 배운 성적 평균 | 번갈아 학습한 뒤 A/B 평균 | 두 개별 습득+공동학습 자격 |
|---|---:|---:|---:|
| 실제 부분 배선·출력만 | 52.64% | 52.63% | 0/10 |
| 실제 부분 배선·내부와 출력(일차) | 55.10% | 58.28% | 0/10 |
| 재배선·출력만 | 53.75% | 53.73% | 0/10 |
| 재배선·내부와 출력 | 56.85% | 60.12% | 0/10 |
| 일반망·출력만 | 53.78% | 54.55% | 0/10 |
| 일반망·내부와 출력 | 56.92% | 61.06% | 0/10 |
| 선형 | 67.13% | 69.03% | 0/10 |
| 무학습 균등 | 50.00% | 50.00% | 0/10 |
| 맥락별 Q | 95.34% | 95.34% | 10/10 |

확률은 두 과제·모든 10계산 시드의 기대 최적 행동률 평균이다. 단순 평균이 높아도 종류별·충돌 입력별 조건과 향상 기준까지 통과해야 자격이 생긴다. 모든 신경망·선형 조건에서 두 개별 prefix와 두 joint 기준은 각각 0/10이었다. 일차 간섭·순서는 모두 `not_assessable`이다.

주 모델이 다른 과제를 배운 뒤 원 과제를 수행한 성적은 평균 57.02%, 같은 과제를 계속 반복한 뒤는 66.57%였다. 두 성적의 차이 9.54%포인트를 전부 ‘다른 과제가 기억을 파괴했다’고 해석하면 안 된다. 원 prefix 55.10%에서 다른 과제 뒤에는 오히려 1.92%포인트 높았고, 계속 연습하면 11.46%포인트 높았다. 정의한 유지 손실 −1.92%포인트와 계속 연습 이득 +11.46%포인트를 더해야 끝점 비용 +9.54%포인트가 된다. 이 항등식은 전 시드에서 1e-12 이내로 맞았다. 습득 자격이 없으므로 향상 역시 확증된 전이 효과로 부르지 않는다.

주 모델의 A→B/B→A 평균 순서 차이는 −0.032%포인트, 계산 시드의 paired 90% 구간은 [−0.655,+0.593]%포인트였다. 수치를 보존하되 자격 미달 상태를 ‘순서 효과가 없음’이라는 확증으로 바꾸지 않는다.

맥락별 Q는 각 상황·ID의 값을 별도 칸에 보관하며 습득·공동학습 자격 10/10을 통과했다. 유지 손실과 순서 차이는 정확히 0이다. 같은 과제 순서·난수를 공유하고 다른 칸은 갱신하지 않는 구조이므로 이 0은 사전 예측된 항등성이다. 새로운 기억 기작 발견이나 인간의 인지적 유연성을 재현한 결과가 아니다. 이 대조는 유한 과제의 해결 가능성을 보여 주지만 다른 모델에 같은 예산이 충분하다는 증명은 아니다.

갱신하지 않은 idle은 원 prefix 상태의 그대로인 복사본이다. 새 학습·시간·확률 평가가 없으며 자연 시간 망각은 미검증이다. 서로 다른 문맥은 인공 입력으로 제공했다. 같은 입력에 모순된 답을 요구하지 않았고, 네 일관 문제만 맞혀 평균 83.33%가 되는 지름길도 충돌 문제별 기준으로 차단했다.

출력/내부/Q 값 갱신 호출은 201,600/86,400/28,800회이고 실제 비영 변화는 104,653/44,971/15,485회다. 공유 prefix를 한 번씩만 실행했으므로 논리 이력 합 324,000회와 실제 259,200회를 구분한다. 계산 시드·분기·시행을 사람이나 초파리 개체 수로 해석하지 않는다.

합성 자동검사 93개(공통 12·생산자 31·독립 검산 50)가 통과했다. 검산기 방어 검사 추가 편집이 소스 동결과 겹친 개발 경합은 실제 실행 전에 원 Git 바이트로 복구하고 [별도 기록](../results/interference_order_prefreeze_engineering_evidence.json)에 남겼다. 등록·기준·과학 실행은 바꾸지 않았다. 원 결과 파일의 크기와 바이트 보존 포장은 [저장 설명](result-storage.md)에 구분한다.

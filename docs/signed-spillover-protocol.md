## 쉽게 설명하면

한 문제의 답을 고칠 때 다른 문제의 답도 함께 움직인다. 지금까지는 얼마나 크게 움직였는지를
주로 보았다. 하지만 그 움직임이 다른 문제의 정답 쪽이라면 도움이고, 오답 쪽이라면 방해다.
이번에는 **같이 움직인 크기를 좋은 방향과 나쁜 방향으로 나누어 장부를 맞춘다.**

예를 들어 둘 다 Go가 정답인 두 문제라도, 한 문제의 수정이 다른 문제의 Go 점수를 떨어뜨리면
방해다. 정답 행동이 다른 두 문제라도 한쪽이 오를 때 다른 쪽이 내려간다면 도움이 될 수 있다.
따라서 같은 정답끼리인지 다른 정답끼리인지만 보고 도움·방해를 붙이지 않는다.

새로 훈련하지 않는다. 이미 저장한 12만 회의 선택과 출력 변화만 읽는다.
이는 학습 방법을 바꿔 다시 실행했을 때의 성적을 예측하거나, 인간·초파리에서 같은 원리가
작동한다고 증명하는 실험이 아니다.

내부 시냅스 갱신, 가치표 갱신의 수는 모두 0이다. 부모 계산 시드는 동물 개체나 인간 참가자가 아니다.

## 정적 번짐의 부호

부모가 저장한 단위 입력 특징 행렬을 D, 해당 alpha의 출력 갱신 방향 행렬을 W라 한다.
둘의 행은 입력, 열은 출력 좌표다. 저장된 영향 행렬은 다음과 같다.

```text
M = W D^T
M[i,j]: source i를 고칠 때 destination j의 raw Go 점수가 움직이는 양
B[i,j] = y[i] * y[j] * M[i,j]
```

B는 source를 자기 정답 방향으로 단위 스칼라만큼 고쳤다고 놓았을 때 destination의 정답 쪽
점수 변화다. `B>0`은 도움, `B<0`은 방해다. 실제 시행의 보상 스칼라를 아직 곱하지 않은 기하학적
수치이므로 학습 성적이나 확률 변화로 부르지 않는다.

행=source, 열=destination을 고정한다. 전치 행렬을 잘못 읽는 오류를 별도 검사한다.
다섯 범주를 사용한다.

| 범주 | 포함하는 항 |
|---|---|
| `self` | i=j |
| `cross_same` | i≠j이고 y_i=y_j |
| `cross_opposite` | y_i≠y_j |
| `cross_all` | i≠j; 위 두 cross 범주의 합 |
| `all` | 모든 항; self와 cross_all의 합 |

처음 세 범주는 겹치지 않는다. 뒤 두 범주는 합계용이므로 다섯 범주 전체를 다시 더하지 않는다.
입력별로 정적 항은 self 1개, 같은 정답의 다른 문제 1개, 반대 정답 문제 2개다.

## 실제 저장 경로의 점수 변화

시행 t의 source `i_t`, 저장된 Go 확률 p, 실제 행동 a, 실제 획득 보상 r에서 다음을 다시 확인한다.

```text
g_t = eta * (a_t-p_t) * r_t              eta=.1
delta_z[t,j] = g_t * M[i_t,j]
C[t,j] = y[j] * delta_z[t,j]
```

저장된 초기 raw Go 점수 `z_0`부터 `delta_z`를 순서대로 더하여 각 시행 직전 점수를 재구성한다.
이는 이미 일어난 변화의 선형 회계이며 학습자를 다시 호출하거나 행동을 다시 추출하지 않는다.
출력 가중치도 저장된 방향과 스칼라의 합으로 점검 시점에 재구성해 부모 자료와 대조한다.

각 실제 항 C에 대해 `max(C,0)`을 도움, `max(-C,0)`을 방해, C를 순효과로 저장한다.
도움 합−방해 합=순효과이며, 각 destination에서 모든 시행의 C 합은 마지막 정답 쪽 raw 점수−
처음 정답 쪽 raw 점수와 일치해야 한다. 범주별 항의 합도 전체 항의 합과 맞아야 한다.

## 같은 경로의 정답 확률 변화

확률은 raw 점수와 다르다. 부모와 동일한 clipping 범위로 정답 행동 확률을 정의한다.

```text
q(z_j,y_j) = sigmoid(clip(y_j*z_j,-40,40))
delta_q[t,j] = q(z_pre[t,j]+delta_z[t,j],y_j) - q(z_pre[t,j],y_j)
```

부모가 사용한 `y=+1이면 p_go, y=-1이면 1-p_go` 표현과의 부동소수점 차이는 `1e-8` 이하여야 한다.
같은 점수 변화도 이미 확신이 높은 곳과 반반인 곳에서 확률에 미치는 영향이 다르므로 C와
delta_q의 도움·방해·순효과를 별도 표로 저장한다. 평균 점수 변화를 sigmoid에 넣어 평균 확률
변화라고 부르지 않는다.

실제 저장 순서에 따른 delta_q도 전부 더하면 마지막 정답 확률−처음 정답 확률로 망원합이 된다.
이 합을 source 종류로 나누어 “그 경로에서 어느 수정 사건에 얼마를 기록했는가”를 설명한다.
한 범주의 갱신을 제거한 별도 경로의 성적이나, 순서와 무관한 독립 인과효과를 계산한 것은 아니다.
앞선 갱신을 제거하면 뒤의 확률·행동·보상이 달라질 수 있다.

범주별 점수·확률 총합을 **항상 destination 4개로 나눈 값**이 네 문제 평균 변화에 대한 해당 범주의
기여다. 같은 정답 범주와 반대 정답 범주의 항 개수 차이를 감춰 분모를 바꾸지 않는다.
도움 합과 방해 합은 경로의 오르내림을 모두 센 값이므로, 확률 단위여도 각각 1을 넘을 수 있다.
순확률 변화만 시작과 끝의 차이다. 정적 항별 평균을 보조 표기할 때에는 정적 항 개수를 명시한다.

## 고정 점검 시점의 다음 한 번 기대 변화

각 저장 점검 시점의 점수를 z, source i의 Go 확률을 `p_i=sigmoid(clip(z_i,-40,40))`라 한다.
**source 네 개를 1/4씩 섞고**, `a~Bernoulli(p_i)`, Go 보상 y_i, NoGo 보상 0이라는 부모 규칙에서
두 행동의 가능성을 산술적으로 합한다. 새 행동·난수는 추출하지 않는다.

```text
E[g | source i] = eta*p_i*(1-p_i)*y_i
E[delta_margin_j; source i] = eta/4*p_i*(1-p_i)*y_i*y_j*M[i,j]

go_delta_z[i,j] = eta*(1-p_i)*y_i*M[i,j]
E[delta_q_j; source i] = p_i/4 * (q(z_j+go_delta_z[i,j],y_j)-q(z_j,y_j))
```

source별 기여 행렬에는 이미 `1/4`가 곱해져 있다. 행을 더하면 destination별 한 번 기대 변화다.
이를 같은 범주 마스크로 합한 뒤 destination 4개로 나누면 네 문제 평균의 기대 변화가 된다.
NoGo는 갱신이 0이라 그 확률 기여도 0이다. 기대 확률 변화는 가능한 Go/NoGo 결과의 확률 가중
평균이며, 기대 점수 변화를 sigmoid에 넣은 값으로 대체하지 않는다.

부모 일정은 네 문제를 묶음마다 섞었으므로 실제 바로 다음 source가 항상 균등하다는 주장은 하지
않는다. 이 분석은 균등 source라는 고정 비교 조건에서의 **다음 한 번** 기대 변화다. 400회 이후의
학습 궤적이나 새 조건의 성적을 예측하지 않는다.

## 수치 중립과 항등식

분류의 수치 중립은 `abs(value)<=1e-8`로 고정한다. 그보다 큰 양수·음수·중립의 개수를 각각 센다.
하지만 아주 작은 항도 도움·방해·순효과의 정확한 질량에는 그대로 넣는다. 중립이라고 0으로
바꾸지 않는다. helper에서 exact 양수·음수·0의 개수와 중립 항의 signed/absolute mass를
보조 계산한다. 이 보조 항목이 모두 CSV 열에 저장되는 것은 아니며, 원시 signed 배열로 다시 계산할 수 있다.

필수 재구성 잔차 11개는 다음 순서로 저장하며 모두 유한하고 최대 절대 오차 `1e-8` 이하여야 한다.

1. 정적 M과 저장된 W D^T의 일치.
2. 실제 g와 저장된 행동·확률·획득 보상 계산의 일치.
3. source의 재구성된 시행 직전 p와 저장 p의 일치.
4. 자기 점수 변화와 부모 시행 기록의 일치.
5. 다른 세 입력 점수 변화 L2와 부모 기록의 일치.
6. 출력 L2 변화와 부모 기록의 일치.
7. 점검 시점 출력 가중치 재구성.
8. 점검 시점 raw 점수 재구성.
9. 점검 시점 Go 선택 확률 및 그에 대응하는 정답 확률 재구성.
10. 실제 margin 변화의 망원합.
11. 실제 정답 확률 변화의 망원합.

질량 항등식, 처음 세 범주의 분할, 도움·방해·중립 개수의 완전성도 확인한다. 실패하면 결과를
보존하고 해석을 멈춘다. tolerance·입력·시드·방향·예산을 바꾸어 통과시키지 않는다.

## 산출물과 검증

새 경로 `results/signed_spillover_v1`에 메타데이터, 아래 8종 배열, 1,500개 조건·시드·범주별
measurement 행, 요약, 아티팩트 해시, 독립 검산을 남긴다.

- 정적 target-aligned 행렬: `(3,2,5,10,4,4)`.
- 시행 margin delta, probability delta, pre logits: 각각 `(3,2,5,10,400,4)`.
- checkpoint expected margin/probability by source: 각각 `(3,2,5,10,5,4,4)`.
- 위 재구성 잔차: `(3,2,5,10,11)`.
- 마지막 정답 확률: `(3,2,5,10,4)`.

부모 120,000시행 × 4 destination = 480,000개 실제 효과, 그중 360,000개 cross 효과를 분석한다.
정적 ordered pair는 4,800개, 점검 시점 destination은 6,000개, source×destination 기대 기여는
24,000개다. 분석 그룹은 300개이며 과학적 반복 횟수가 새로 늘어난 것은 아니다.
조건별 평균·표준편차는 기존 10계산 시드에 걸쳐 기술적으로 보고한다. 표준편차는 사람·동물
개체의 불확실성, 신뢰구간 또는 생물학적 표본 수가 아니다.

source/config/protocol 및 정확한 파일 집합은 새 등록으로 SHA-256과 Git commit에 고정한다.
원격 등록 bytes가 같고 실제 분석 시작 전 확인되었음을 새 publication proof에 남긴다.
출력 경로는 새로 배타적으로 만든다. 독립 검산은 새 producer나 새 signed helper를 import하지 않고
부모의 고정 배열·CSV로 부호·두 종류 효과·점검 시점 기대값·집계·항등식을 각각 다시 계산한다.
만든 작은 행렬의 자동검사로 잘못된 부호, 음의 cross 영향, 축 전치, 중립 질량 삭제,
확률 비선형성, 실제 경로 망원합, 균등 source의 행동 열거 기대값 오류를 확인한 뒤 등록한다.

## 해석과 다음 작업의 경계

이번 결과는 완료한 네 인공 문제 출력 학습(Level 2)에서 **이미 저장된 경로의 변화 회계**다.
부모의 고정 내부 시냅스와 입력 활성, 학습된 출력 가중치를 구분한다. 내부 가소성 증거를
추가하지 않으며 실제 시각 수량 회로, 새 문자열 일반화(Level 3), 인간 행동 유사성(Level 4),
공통 신경 기작(Level 5), 교육 효과를 주장하지 않는다. 새 인간 자료·실험은 없다.

도움·방해 집계는 어느 배선이 우수하다는 전제가 아니며 실제 배선과 대조 배선의 전체 결과를
보존한다. 단순한 방향별 합이 학습 실패의 유일한 원인이라는 인과 결론을 내리지 않는다.
이번에는 최소 출력 비용 계산, 최적 출력 계수 탐색, 새 alpha·시드·예산 탐색·훈련을 하지 않는다.
그런 후속 질문은 이번 분석과 분리해 새로 계획한다. 기존 인간 비교의 미지지, 습득·일반화·
간섭·순서의 닫힌 선행 게이트도 이번 기술적 집계로 열지 않는다.

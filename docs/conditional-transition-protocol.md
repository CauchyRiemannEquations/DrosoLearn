# 같은 선택·상태에서 피드백 뒤 행동을 측정하는 계획

작성일: 2026-10-16 (Asia/Seoul). 연구 ID `conditional_transition_v1`.

## 먼저 쉽게 설명하면

앞 점검에서는 학습하지 않고 한쪽 선택만 자주 하는 규칙도 ‘좋은 결과 뒤 유지율’과 ‘좋지 않은 결과 뒤 유지율’의 차이를 만들었다. 그래서 이번에는 **어느 선택을 했는지와 과제 상태까지 같은 기록 안에서 두 피드백을 모두 관측할 수 있는지** 확인한다. 예를 들어 같은 카드를 골랐을 때 이득 뒤 기록과 손실 뒤 기록이 모두 있어야 두 유지율의 차이를 계산할 수 있다.

두 종류의 기록이 있다는 사실은 비교가 정확하거나 보상의 인과 효과를 알아냈다는 뜻이 아니다. 한쪽 분모가 없으면 비교 불가로 남긴다. 사람과 모델이 닮았는지, 어느 쪽이 더 잘 배웠는지는 이번에 판정하지 않는다. 새 모델 학습도 하지 않는다.

## 연구 위치와 사전 고정

이번 작업은 Phase 4의 **공통 지표 측정 준비에 속하는 탐색적 기술 분석**이다. 기존 인간 원자료와 모델 결과, 선택 유지율 측정 및 무학습 반례를 이미 본 뒤 설계했다. 눈가림 확증 연구나 새로운 인간 행동 가설의 검정으로 부르지 않는다.

기존 `feedback_transition_v1`은 원 인접 쌍의 유지·전환을 실제 피드백별로 셌다. `metric_calibration_v1`에서는 선택 혼합만으로 피드백별 유지율 차이가 생기고, 구간을 합치면 차이가 상쇄될 수 있음을 확인했다. 이번에는 기존 전체 지표를 보존하면서 **단계 × 원 상태 × 현재의 절대 선택지 정체성**으로 나눈 분자·분모와 층 안의 차이를 추가한다. 층은 같은 조건으로 묶은 기록 집합을 뜻한다.

실제 집계 전에 새 코드·독립 검산·시험·두 문서·설정·부모 근거·원 입력 목록을 해시로 고정하고 private Git 원격의 동일 바이트를 확인한다. 이전 계획·실패·결과·코드·원자료는 수정하지 않는다. 보존 기준은 완료 태그 `state-decomposition-v1`, 커밋 `addf9dca471bcb97dfc686e0f77a713a195e59e6`이다.

## 초기 원 구조·의미 게이트

사람 원본을 읽을 때 이전 구조 감사가 확인한 `A`, `R`, `S`, `C`의 모양·허용 코드·원 시행 순서·결측 위치와 카드 선택에서의 `C == (A == S)` 관계를 다시 검사한다. `A=1/2`는 source-coded 카드 0/1, `A=3`은 정보 요청, 선택한 카드 열의 `R=-1/+1`은 실제 금전 손실/이득으로 옮긴다. 정보 결과와 결측을 이진 보상이나 오답으로 채우지 않는다.

모델은 원 `action`과 좌우 수량을 함께 읽어 작은 수량 선택 0·큰 수량 선택 1로 옮긴다. 화면 쪽의 반복을 수량 정체성의 반복으로 세지 않는다. 실제 `reward`와 환경·단계·선택에 따른 `q_reward`를 검사하되, 확률적 보상을 결정적 정답과 같다고 강제하지 않는다. 확률·기대 갱신·평가 probe를 실제 행동으로 바꾸지 않는다.

공개 사람 과제 코드와 2018년 원 기록의 **정확한 역사적 실행판 연결은 미확인**이다. 기존 구조·공식 formatter·과제 근거가 함께 지지하는 source-coded 카드 정체성의 기술 범위에 한정한다. 사람 피드백 0은 금전 손실이며 모델 피드백 0은 무보상이다. 같은 숫자 코드가 같은 경험을 뜻하지 않는다. 원 근거와 권한·라이선스·접근 기록도 부모 자료와 함께 고정한다.

## 원 인접성과 제외 규칙

한 경로의 바로 이웃한 원 시행 `t, t+1`만 후보로 삼는다. 정보 요청·결측을 삭제한 뒤 그 전후 선택을 이어 붙이지 않는다. 다음 조건은 기존 `feedback_transition`의 원 인접성·제외 규칙을 그대로 따른다.

- 두 시행 모두 실제 학습 기록의 유효한 카드 또는 수량 선택이어야 한다.
- 현재 `t`의 실제 이진 피드백이 있어야 한다. 다음 피드백 결측만으로 현재 쌍을 제외하지 않는다.
- 원 시행이 연속하고 같은 과제·단계·상태에 있어야 한다.
- 사람의 800→801 구획 경계와 원 `S` 반전, 모델의 phase1→phase2 경계를 넘지 않는다.
- 정보 요청·현재/다음 선택 결측·현재 피드백 결측 또는 비이진·경계 등 겹친 제외 사유를 모두 기록하되 총 제외에서는 한 쌍으로 센다.

정보 요청을 포함하는 새 반응률이나 별도 분모는 이번에 추가하지 않는다. 따라서 이 지표는 다음 시행에 정보 요청·무응답을 한 사례를 제외한 조건부 기술값이며 전체 행동을 대표한다고 가정하지 않는다.

| 자료 | 원 인접 후보 | 유효 쌍 | 제외 쌍 |
|---|---:|---:|---:|
| 사람 | `25 × 999 = 24,975` | 21,530 | 3,445 |
| 모델 | `240 × 799 = 191,760` | `240 × 798 = 191,520` | 240 |
| 합계 | **216,735** | **213,050** | **3,685** |

위 값은 같은 고정 입력과 규칙을 적용할 때의 무결성 검산값이다. 사람 기존 유효 분모가 달라지거나 모델에서 추가 제외가 생기면 이유를 조사하고 실패를 남긴다. 결과를 맞추려고 원자료나 제외 기준을 바꾸지 않는다. 사유별 건수의 합은 중복 사유 때문에 총 제외보다 클 수 있다.

## 전체 지표와 설계층

먼저 경로별 기존 전체 `by_feedback` 지표를 같은 정의로 계산한다. 이어 각 유효 쌍을 **현재 시행**의 단계·상태·절대 선택지 정체성으로 하나의 층에만 넣는다. 정오·유리한 카드 여부로 현재 선택을 재부호화하지 않는다.

| 자료 | 경로마다 고정할 설계층 | 전체 층 수 |
|---|---|---:|
| 사람 | `initial/transfer × 원 S의 1/2 × 현재 카드 0/1` = 8개 | 200 |
| 모델 | `phase1/larger × 현재 수량 0/1`, `phase2/smaller × 현재 수량 0/1` = 4개 | 960 |
| 합계 | 설계상 가능한 층만 보고 | **1,160** |

모델의 `phase1/smaller`, `phase2/larger`는 관측이 빠진 조합이 아니라 이 설계에서 불가능한 조합이므로 가짜 층을 만들지 않는다. 반면 위 설계층 안에서 실제 관측이 없는 층은 삭제하지 않고 횟수 0과 비율 `null`로 남긴다. 피드백 셀은 층마다 2개, 총 **2,320개**다.

각 층 `z`와 현재 피드백 `f=0,1`에서 다음을 보존한다.

| 항목 | 정의 |
|---|---|
| `D[z,f]` | 해당 층·피드백의 유효 원 인접 쌍 수 |
| `S[z,f]` | 그중 같은 절대 선택지를 유지한 쌍 수 |
| `X[z,f]` | 그중 다른 절대 선택지로 바꾼 쌍 수 |
| 유지율 | `S[z,f] / D[z,f]`, 분모 0이면 `null` |
| 전환율 | `X[z,f] / D[z,f]`, 분모 0이면 `null` |
| 층 안의 차이 | `유지율[z,1] − 유지율[z,0]`, 두 분모가 모두 양수일 때만 정의 |

`S+X=D`와 피드백별 모든 층의 횟수 합이 해당 경로의 전체 횟수와 일치해야 한다. 층별 비율의 평균이나 평균 차이는 계산하지 않는다. 전체 유지율은 그 피드백이 관측된 층의 분모에 따른 혼합이므로, 층별 비율과 분모를 함께 읽는다.

## 공통 관측 가능성의 고정 정의

`common_support`는 **그 설계층에서 유효한 피드백 0·1 분모가 모두 양수인지**만 나타내는 불리언이다. 다음 네 가지를 함께 기록한다.

| 분류 | 조건 |
|---|---|
| `both_feedback` | `D0>0`이고 `D1>0` |
| `feedback_0_only` | `D0>0`이고 `D1=0` |
| `feedback_1_only` | `D0=0`이고 `D1>0` |
| `neither` | `D0=D1=0` |

한쪽이 0인 층의 차이를 0으로 넣거나 이웃 층·다른 참가자·다른 시드에서 빌려 채우지 않는다. 둘 다 양수여도 아주 작은 분모일 수 있으므로 추정의 정밀성·무편향·인과 식별·학습 성공을 뜻하지 않는다. 성공 기준을 사람과 모델의 값이 비슷한지에 두지 않는다.

## 대조·반증과 해석 경계

결정적 모델에서는 한 단계·현재 수량이 주어지면 보상이 결정되므로 피드백 양쪽이 동시에 관측될 수 없다. 이 경우 층 안의 차이는 계산 불가여야 하며 0 차이로 보고해서는 안 된다. 확률적·무정보 환경에서도 유한 기록에서는 어느 셀이 0일 수 있으므로 두 피드백이 반드시 관측된다고 강제하지 않는다.

원 인접 순서·좌우 보정·경계·관측 0·현재 피드백 조건·현재 절대 선택 층이 잘못 처리되면 무결성 실패다. 같은 분자·분모를 독립적으로 복원하지 못해도 실패를 보존한다. 반면 공통 관측이 없거나 차이가 작고 부호가 섞이는 결과는 수정할 오류가 아니라 그대로 남길 기술 결과다.

현재 선택과 상태를 나눠도 과거 경험·시간·숨은 정책 상태·입력 특징·정보 요청 제외의 영향을 모두 제거하지 못한다. 이 차이를 ‘보상 반응의 순수 효과’나 ‘선택 편향을 완전히 제거한 학습 지수’라고 부르지 않는다. 기존 무학습 반례를 새 인간 학습 검정으로 재포장하지 않는다.

## 출력·검증·재현

새 결과 경로에는 실행 metadata, 등록 사본, 경로별 전체 지표, 모든 설계층 지표, 모든 원 인접 후보의 ledger, 산출물 SHA-256 목록, 별도 독립 검산을 보존한다. ledger는 원 위치와 원 구획·상태·현재/다음 선택을 함께 보존해 층과 원 기록의 대응을 확인할 수 있게 한다. 등록·원격 확인·실제 집계·독립 검산의 UTC 순서를 기록한다. 결과 경로와 그림 경로는 배타 생성하며 기존 파일을 덮어쓰지 않는다.

독립 검산은 주 변환·층 집계 함수를 호출하지 않고 원 MAT와 원 CSV에서 선택·실제 피드백·구획·상태·인접성·전체 및 층 분자·분모·비율·지원 분류를 따로 복원한다. 원 입력·부모 검산·소스·설정·등록·산출물의 정확한 해시 연결과 전체 범위를 확인한다. 자동 시험은 수작업 합성 기록만 사용하고 과학 자료를 사전 성과 조정에 쓰지 않는다.

그림을 생성한다면 독립 검산이 통과한 결과만 읽어 사람 25경로의 8층과 모델의 환경별 80경로·4층에 대한 네 관측 분류를 한 그림의 네 별도 영역으로 표시한다. 사람은 원본 행 순서, 모델은 조건 순서 안의 시드 순서로 모든 기록을 표시한다. 비율 평균·효과량·오차막대·집단 또는 종간 비교 검정은 만들지 않는다. 그림은 새 sibling 폴더에 PNG와 입력·스크립트·그림 해시 metadata를 따로 남긴다. 그림의 색은 성과나 학습 성공이 아니라 **분모의 존재 여부**다.

## 주장 수준과 이번 작업의 종료

현재 모델의 수량 순서는 인공 입력으로 이미 주어진다. 사람은 확률적 금전 카드 과제와 정보 요청 선택을 수행했고 모델은 인공 수량의 두 선택을 수행했다. 사람의 여러 반전·800/200 구획과 모델의 한 번의 400/400 반전을 같은 학습 경험으로 간주하지 않는다. 데이터의 구조·분자·분모를 맞춘 결과만으로 Level 4 유사성이나 Level 5 공통 신경 기작, 수학 이해 또는 교육 효과를 주장하지 않는다.

이 단일 작업은 실제 공통 지표의 관측 가능성을 명확히 하는 데서 끝낸다. 추가 학습·학습자 구성·데이터 생성·난수 추출·새 행동 가설 검정은 모두 0이다. 자동 이어가기는 PAUSED를 유지하며 다음 연구를 자동으로 시작하지 않는다.

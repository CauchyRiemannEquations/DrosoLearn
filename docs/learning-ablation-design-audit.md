# 같은 학습 상태에서 출력·내부 갱신을 나누어 보는 설계 감사

작성일: 2026-10-16 (Asia/Seoul). 새 학습 성분 개입 연구의 실행 전 코드·설계 검토다. 기존 확률 보상 연구의 설정·실패·결과·코드는 수정하지 않는다. 실제 가설·예산·시드·반증 기준의 최종 정의는 [프로토콜](learning-ablation-protocol.md)과 [설정](../configs/learning_ablation_v1.json) 및 새 등록에 고정한다.

## 쉽게 설명하면

같은 모델을 먼저 똑같이 가르친 뒤 그 상태를 네 벌 복사한다. 다음 규칙을 배울 때 한 벌은 모두 배우게 하고, 한 벌은 출력 부분만, 다른 한 벌은 내부 연결만 바꾸게 하며, 마지막 한 벌은 학습을 멈춘다. 네 벌의 출발 상태가 같으므로, 처음에 우연히 잘 배운 모델과 못 배운 모델을 비교하는 문제를 줄일 수 있다.

여기서 ‘출력’은 활성된 정보를 최종 선택으로 바꾸는 계수이고, ‘내부’는 KC→MBON 연결의 계산 가중치다. 둘 다 생물학을 단순화한 소프트웨어 변수다. 어느 부분을 바꾸게 했을 때 행동이 달라지는지 살피는 것으로, 인간과 초파리의 학습 기작이 같다고 검증하는 실험은 아니다.

## 이전 연구에서 남은 질문

앞선 확률 보상 연구에서는 출력만 학습하는 모델과 출력·내부 연결을 함께 학습하는 모델의 전체 경로가 달랐다. 처음부터 서로 다른 경험과 가중치를 쌓았기 때문에 최종 차이를 반전 시점의 내부 학습 역할만으로 설명할 수 없었다.

이번에는 모델 종류마다 큰 수량을 고르는 공통 학습 400회를 한 번 실행한다. 그 뒤 얻은 **동일한 물리적 상태**를 복제하고, 작은 수량을 고르는 규칙에서 출력 갱신과 내부 갱신을 각각 켜거나 끈다. 앞부분을 네 번의 독립 학습으로 세지 않는다. 첫 규칙 습득 미달 시드도 보존하며 주 효과 계산에서 제외하지 않는다.

| 분기 | 출력 갱신 | 내부 갱신 |
|---|---|---|
| `full` | 허용 | 허용 |
| `head_only` | 허용 | 중지 |
| `internal_only` | 중지 | 허용 |
| `frozen` | 중지 | 중지 |

모델은 `linear`, `real`, `rewired`, `ann` 네 종류다. 선형 모델에는 내부 연결이 없으므로 내부 갱신 허용이 실제 갱신이나 추가 계수를 만들지 않는다. 선형 `internal_only`와 `frozen`, 선형 `full`과 `head_only`가 각각 같은 경로를 보여야 하는 것은 유용한 구현 대조다.

## 재사용할 코드와 그대로 사용할 수 없는 부분

| 기존 구성요소 | 새 연구에서의 재사용 범위 | 필요한 확인 |
|---|---|---|
| `data.make_dataset`·`assert_disjoint` | 인공 수량·교차 nuisance 입력, TRAIN/IID/OOD 분리 | 새 시드·split별 fingerprint 교집합 0, nuisance-only .5 |
| `graph.load_projection`·`rewire`·`random_ann` | 고정 KC→MBON 부분집합과 대조 구조 | 원 graph 해시, 보존·비보존 불변량, 모델별 자원 기록 |
| `reward_linear.LinearLearner` | 선형 특징·초기 척도·확률·snapshot | 내부 계수 없음, 출력0 초기화, TRAIN-only RMS 고정 |
| `reward_linear.NormalizedLearner` | 내부 특징·초기화·확률·snapshot | 기존 update를 분기 제어용으로 직접 호출하지 않음 |
| `stochastic_feedback`의 평가 구조 | 실제 선택 뒤 보상, 고정 checkpoint, 비학습 평가의 의미 | 새 등록·독립 검산, 공통 prefix 한 번만 계수 |

기존 `NormalizedLearner.update`는 `learning`·`head_learning` 속성만 바꾸어도 출력 갱신을 멈추지 않는다. 따라서 새 파일에 명시적으로 두 성분을 제어하는 갱신을 구현해야 한다. 기존 소스의 함수를 고쳐 과거 결과의 의미를 바꾸지 않는다. 새 `full` 갱신이 기존 갱신과 같은 식을 구현하는지 작은 개발 fixture에서 별도로 확인한다.

학습 함수의 인자는 계속 `inputs, action, actual_reward`로 제한한다. 환경이 선택 우세 방향과 보상 확률을 계산하더라도 학습 함수에 정답·다른 선택의 잠재 보상·q·평가 점수를 주지 않는다. .8/.2의 실제 이진 보상을 사용하며 정답 접근 기대 갱신은 없다.

## 갱신 순서와 숨은 상태

한 시행의 갱신 전 확률을 p, 실제 선택을 a, 실제 보상을 r이라 하면 고정 보상 중심화 계수는 `f=(a-p)*(r-.5)`다. 출력 갱신은 기존과 같이 `head += head_lr*f*(phi_right-phi_left)`이고, 내부 갱신의 eligibility는 반드시 **그 시행의 출력 갱신 전 `old_head`**로 계산한다. `full`에서 새 head를 사용하면 두 성분을 동시에 갱신하던 기존 수식과 달라진다.

`internal_only`는 공통 앞부분에서 학습한 출력 계수를 그대로 보존한다. 출력을 0으로 다시 만들면 이 규칙의 내부 eligibility까지 0이 되어 내부 학습을 인위적으로 꺼 버린다. `frozen`도 학습된 상태를 보존한다. ‘학습 중지’와 ‘미학습 초기 모델’은 서로 다른 대조다.

복제 대상은 현재 내부·출력 가중치만이 아니다. encoder·bias·원래 `initial_weights`·clipping 상한 `upper`·incoming normalizer·고정 feature scale·pre/post index·graph 구조 및 누적 갱신 counter도 포함한다. 원 모델에 없는 새로운 hidden state나 동적 정규화가 생기지 않는지 확인한다. mutable 배열을 분기끼리 공유하지 않으며 한 분기를 갱신한 뒤 다른 분기의 상태가 변하지 않아야 한다.

특히 공통 학습 종료 가중치로 clipping 상한을 다시 만들거나 phase2 입력으로 척도를 재계산하면 내부 학습 자원과 입력 척도가 함께 바뀐다. 상한과 척도는 공통 앞부분보다 이전에 정한 값을 계속 사용한다. 구조·encoder·bias는 모든 후속 분기에서 고정한다.

누적 counter는 prefix의 값을 상속하고, 분기 안에서 추가된 갱신 횟수는 별도 기록한다. 내부 첫 step의 실제 변위가 0이어도 호출 counter는 증가할 수 있다. 출력 갱신·내부 갱신·입력에 따른 활성 변화·실제 가중치 변위는 다른 항목이다. 동일한 고정 probe에서 KC 활성은 encoder/bias가 고정되어 변하지 않아야 하고, 내부 연결이 고정된 분기의 MBON·정규화 특징도 같은 probe에서 변하지 않아야 한다.

## 동일 난수의 뜻과 시행 예산

한 시드의 입력·행동 uniform·보상 uniform 배열을 모델·분기 사이에 고정된 위치대로 공유한다. phase1은 새 데이터 offset61, phase2는64, IID62, OOD63이며 데이터 seed는 `seed*100+offset`이다. 행동 offset은610000/620000, 보상은630000/640000, 재배선650000, ANN660000, encoder670000이다. 새 과학 시드12001–12010은 소스·등록 동결 전 개발 시험에 사용하지 않는다.

같은 난수를 써도 정책이 달라지면 실제 선택이 달라질 수 있고, 선택이 달라지면 같은 보상 uniform에서도 실제 보상이 달라질 수 있다. 선택·보상을 모든 분기에 강제로 같게 맞추지 않는다. 이 실험은 **갱신 성분을 바꾼 뒤 그에 따라 생기는 정책과 경험의 전체 경로**에 대한 개입이다. 같은 행동 경험에 대한 직접적인 한 성분의 효과만 분리한 실험은 아니다.

전체 실제 선택·보상 표시는 prefix `10×4×400=16,000`, 분기 `10×4×4×400=64,000`, 합계80,000회다. head 갱신은 prefix16,000회와 두 head-on 분기32,000회로48,000회다. 내부 갱신은 내부 연결이 있는 세 모델에서 prefix12,000회와 두 internal-on 분기24,000회로36,000회다. head와 내부를 모두 바꾼 한 시행을 별개의 두 선택 경험으로 세지 않는다. 분기 시작 snapshot을 남기는 것도 새 경험이나 새 학습이 아니다.

## 어떤 효과를 묻고 무엇을 반증하는가

`real`의 최종 IID 작은 수량 선택 확률에서 `full−head_only`를 H-I로, `full−internal_only`를 H-H로 따로 평가한다. 각각 전체10시드 평균 차이가 .05, 즉 **5%포인트 이상**이고, 엄격하게 양수인 시드가8개 이상이어야 등록한 지지를 얻는다. 주 가설은 전체 시드를 사용하며 첫 규칙 습득 성공 시드만 골라 적용하지 않는다. 시드별 결과·반전 시작점·gain·AUC·미달·qualified adaptation을 함께 남긴다.

H-I는 head가 갱신되는 상황에서 내부 갱신을 추가로 허용한 효과이고, H-H는 내부 갱신이 허용된 상황에서 head 갱신을 추가로 허용한 효과다. 이는 서로 독립적인 기작의 기여도 분해가 아니다. 각 모델의 `full−head_only−internal_only+frozen` 상호작용은 미리 정한 기술값으로 보고한다. 여러 분기의 입력이 고정되어도 실제 행동·보상 이력은 정책에 따라 달라진다.

기준 미달이면 해당 성분이 이 조건·예산·갱신식에서 사전 수준의 차이를 만들었다는 가설을 지지하지 않는다. ‘내부 학습이 원래 불가능하다’거나 ‘모든 조건에서 그 성분이 필요 없다’고 결론 내리지 않는다. 고정 head의 방향, 비음수 내부 가중치와 원래 상한, feature 기하 및 포화가 가능한 제약이다. 반전 성공을 미리 가정하거나 미달 시드를 교체하지 않는다.

선형·재배선·일반망도 같은 범위에서 모두 보고한다. 모델 사이에는 특징 방향·활성 구조·가중치 수·추가 갱신 자원이 다르므로 계산 예산이나 초기 RMS를 맞췄다는 이유만으로 동일 자원 비교가 되지 않는다. 실제 배선의 우수성을 판정하는 새 주 가설을 끼워 넣지 않는다.

## 평가·그림·독립 검산

학습용 수량쌍은 계속2대4이며 `n/8`과 여섯 인공 nuisance 좌표를 입력으로 받는다. IID/OOD는 같은 수량쌍에서 nuisance 범위를 달리하는 평가다. 새 수량에 대한 일반화, 점 그림에서 수를 알아내는 시각적 수량 인지, 수학 기호·수열 규칙 전이는 검사하지 않는다.

평가가 가중치·counter·척도·encoder·bias·RNG를 바꾸지 않아야 한다. 분기 phase2 trial0의 물리적 상태는 공통 prefix 마지막 상태와 같아야 하며, 그때 기준 방향이 큰 수량에서 작은 수량으로 바뀌는 것은 즉각적인 망각이나 가중치 변화가 아니다.

새 정적 그림은 독립 검산 `passed`와 입력 해시를 확인한 결과에서만 생성한다. 하나는 모델별2×2 최종 선택 확률에 모든 시드의 짝지은 값을 표시하고, 다른 하나는 공통 앞부분과 네 분기의 고정 checkpoint 평균·표준편차를 표시한다. 표준편차는 신뢰구간이 아니고, 새 통계 검정이나 유리한 시드 선택을 추가하지 않는다. 별도 sibling 폴더에 배타 저장하며 입력·검산·스크립트·PNG의 SHA-256을 기록한다.

완료된 실행의 같은 source checkout에서 다음과 같이 그림만 재현한다. 출력 폴더는 아직 존재하지 않아야 하며 원 결과 폴더와 같은 부모 아래에 둔다. 그림 코드는 학습자를 import하거나 추가 학습을 실행하지 않는다.

```powershell
python scripts/plot_learning_ablation.py --result-dir results/learning_ablation_v1 --out results/learning_ablation_figures_v1
```

입력은 `metadata/registration/summary/verification/artifact_hashes` JSON과 `learning_curves.csv`다. 검산 보고서가 summary뿐 아니라 곡선·artifact inventory의 정확 SHA-256을 가리키는지 확인한다. `paired_endpoints.png`, `learning_curves.png`, 별도 `metadata.json`을 새 폴더에 저장하고, 그 사이 입력이 바뀌어도 실패로 남긴다. 한글 글꼴이 없는 환경에서는 같은 값의 영어 표기를 사용하며 그림 언어를 metadata에 기록한다.

독립 검산은 producer의 선택적 갱신·요약 함수를 불러 답을 재사용하지 않는다. 고정 입력·난수·구조·초기화에서 prefix와 각 분기의 모든 선택·보상·갱신·snapshot·평가·판정을 다시 계산하고, 모든 clone의 시작 상태·분기 분리·상한·척도·누적/분기 counter 및80,000회의 물리적 경험 예산을 확인한다. 과학적 기준 미달과 무결성 실패를 구분한다.

## 해석의 한계와 인간 학습이라는 장기 목표

확인 가능한 것은 이 계산 모델 안에서 특정 갱신 성분을 허용하거나 중지했을 때 나타나는 선택 변화다. 이중 개입은 실제 초파리의 KC→MBON·DAN 조절을 생리학적으로 재현하지 않는다. LC11·실제 시각 입력 경로·재귀 회로·APL·생리학적 시간도 구현하지 않는다. 계산 시드는 독립된 초파리 개체나 인간 참가자가 아니다.

장기적으로는 같은 학습 이력 뒤 새 규칙을 배우는 방식, 두 성분의 상호작용, 보상 잡음과 학습 수정의 관계에서 검증 가능한 인간 학습 가설을 만들 수 있다. 그러나 이 실험의 인공 수량·두 선택·.8/.2·한 번의 반전과 인간의 카드·금전·정보 요청·학습 과제는 다르다. 이번 결과만으로 Level4의 사람과 정량적 유사성, Level5의 공통 신경 기작, 인간 수학교육 효과를 주장하지 않는다. 이전 DrosoMem·DrosoLearn의 실패와 해석 한계는 그대로 보존한다.

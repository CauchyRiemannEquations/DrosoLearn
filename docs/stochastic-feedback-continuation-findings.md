# 이어서 진행한 세 단계의 쉬운 결과

작성일: 2026-10-16 (Asia/Seoul).

**세 단계 모두 실제 실행과 독립 검산을 마쳤다.** 학습하지 않는 대조로 측정법을 점검한 뒤, 실제 학습을 단순 모델에서 확인하고 새 시드의 배선 비교까지 이어갔다. 성공과 실패를 함께 보존했다.

## 1. 습관만으로도 학습처럼 보이는 수치가 나올까?

그럴 수 있었다. 보상을 무시하고 B를 80% 확률로 고르는 고정 규칙만으로도, 보상 뒤 유지율의 기대 기준 50%와 무보상 뒤 76.47%가 나온다. 직전 선택을 90% 반복하는 규칙은 학습 갱신 0 회로 높은 유지율을 만든다. 두 시기를 합치면 각 시기의 차이가 가려질 수도 있었다.

이것은 ‘지표가 높다→잘 배웠다’는 단순 해석을 막는 대조다. 이 지표와 가중치·성능 변화, 정보를 주지 않는 무작위 보상 대조를 함께 봐야 한다. [그림과 전체 설명](metric-calibration-findings.md).

## 2. 보상이 불확실해도 단순 모델은 배울까?

첫 규칙은 배웠다. 유리한 선택에 80%, 다른 선택에 20% 보상을 주었을 때 10 개 계산 실행 모두 미리 정한 습득 기준을 통과했다. 첫 단계 끝에서 유리한 수량 선택 확률은 평균 94.93%, 선택과 상관없이 보상을 준 대조는 비교용 기준 선택 확률 46.53%였다. 이 차이는 48.40%포인트로 사전 기준을 통과했다.

하지만 규칙을 뒤집은 뒤 적응 기준을 통과한 실행은 0/10이었다. 첫 습득과 반전 후 적응은 다른 결과다. 미달을 지우거나 연습 횟수를 늘리지 않았다. [단순 모델의 결과](stochastic-feedback-linear-findings.md).

## 3. 배선·내부 학습이 다른 모델에서는?

앞 단계의 습득과 검산이 통과한 뒤 새 시드 11001–11010 으로 실행했다. 학습 모델 7 조건은 확률적 보상의 첫 규칙을 모두 10/10 실행에서 습득했다. 반전 후 적응은 조건별 2–7/10 이었다. 실제 배선의 내부 가소성 조건은 7/10, 재배선 가소성은 6/10, 일반망 가소성은 6/10 이었다.

**이 숫자 차이만으로 실제 초파리 배선의 우수성을 입증한 것은 아니다.** 가소성 조건은 학습 가능한 내부 연결이 추가되고, 출력 계수 수도 단순 모델과 다르다. 처음 규칙을 얼마나 강하게 배웠는지도 반전 출발점에 영향을 준다. 모든 모델·개별 시드·실패와 자원을 함께 남겼다. [배선 비교의 전체 표와 그림](stochastic-feedback-network-findings.md).

## 지금 알게 된 것과 남은 것

현재 확인한 것은 **입력에 이미 주어진 수량 순서를 보상에 연결하는 계산 학습**이다. 실제 점 그림에서 개수를 알아내거나 수학 원리를 발견한 결과가 아니다. 사람이 같은 방식으로 배운다는 주장도 아직 할 수 없다.

학습 없이도 행동 지표가 만들어질 수 있다는 반례와, 실제 보상 경험·가중치 변화로 첫 규칙을 습득할 수 있다는 결과를 구분했다. 내부 가소성이 반전에 어떤 역할을 했는지는 같은 과거 학습 상태에서 내부 학습·출력 학습을 선택적으로 끄는 대조가 더 필요하다. 다음 연구는 그 대조를 별도 등록해 진행한다. 성공할 것을 전제하지 않는다.

이번 새 자동검사는 124+202=**326 개 통과**했다. 학습 없는 대조 192,000 회와 두 실제 학습 연구의 선택·피드백 48,000/192,000 회를 모두 처리·독립 검산했다. 모두 가중치 갱신 횟수나 독립 동물 개체 수와 다르다. [보존·동결·산술 검증 기록](../results/stochastic_feedback_continuation_archive_validation.json)에 기존 파일 보호와 세 단계의 근거를 모았다.

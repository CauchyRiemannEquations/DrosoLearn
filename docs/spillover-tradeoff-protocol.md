## 라벨을 사용하지 않는 방향 계산

각 고정 신경망에 NoGo 영벡터와 Go 입력을 주어 MBON 활성 차이를 구한다.
각 문제의 차이를 자신의 L2 길이로 나눈 단위 행벡터를 d_i, 네 행을 모은 행렬을 D라 한다.
정규화·SVD·혼합 방향 계산은 정답 라벨이나 성적을 사용하지 않는다.

공유 방향은 d_i다. 부모와 같은 고정 SVD 규칙으로 다음을 구한다.

```text
C = pinv(D, rcond=1e-12)
P = D C
u_i = C[:,i] / P[i,i]
v_i = u_i / ||u_i||
```

최대 특이값의 `1e-12`배보다 엄격히 큰 특이 방향만 유지한다. 성적에 따라 cutoff나 대체법을
선택하지 않는다. u_i는 유지 반응 부분공간에서 자기 점수 영향을 1로 하면서 다른 입력으로 번지는
제곱 영향을 최소화하는 부모의 방향이다. v_i는 그 길이를 1로 줄인 끝 방향이다.

새 방향 가족은 다음과 같다.

```text
m_i(alpha) = (1-alpha) d_i + alpha v_i
w_i(alpha) = m_i(alpha) / ||m_i(alpha)||
alpha ∈ {0, .25, .5, .75, 1}
```

두 끝점은 동결된 d_i와 v_i를 그대로 사용한다. alpha=.5는 두 **단위 방향**의 가운데 방향이다.
길이가 큰 u_i를 직접 섞지 않는다. alpha는 방향을 섞는 계수이며 “번짐의 몇 퍼센트를 없앴다”는
뜻이 아니다. 이 유한 가족이 모든 단위 방향 중 최적이거나 생물학적으로 구현됐다고 주장하지 않는다.

`c_i=d_i·v_i=1/||u_i||>0`이면 혼합 길이는 다음과 같다.

```text
q_i(alpha)^2 = (1-alpha)^2 + alpha^2 + 2 alpha (1-alpha) c_i >= 1/2
own_i(alpha) = ((1-alpha) + alpha c_i) / q_i(alpha)
```

따라서 서로 반대인 방향의 상쇄로 분모가 0이 되는 문제는 없다. alpha가 커지면 자기 입력에 대한
점수 수정 효율이 낮아진다. 정확한 다른 입력 분리가 자격을 갖춘 경우 번짐도 줄어든다.
rank가 부족해 투영 끝점에도 번짐이 남는 경우에는 번짐의 단조 감소를 일반적으로 보장하지 않는다.
모든 경우 실제 정적 영향 행렬을 보고한다.

방향 W의 정적 영향은 `W Dᵀ`이며 **행=고친 문제, 열=검사한 문제**다.
자기 영향·다른 세 입력 영향의 제곱합·방향 길이·혼합 길이·분석식·특이값·rank·조건수·P를 저장한다.
rank만으로 라벨별 분류 가능성을 단정하거나 새 정답 기반 최적 출력 계수를 학습자에게 주지 않는다.

## 실제 보상 학습과 자원 기준

현재 입력 i에서 `p=logistic(clip(d_i·h,−40,40))`이며 공통 uniform으로 Go 행동 a를 추출한다.
학습률 eta=.1, 획득 보상 r에서 다음 한 번의 출력 갱신만 한다.

```text
g = eta × (a−p) × r
h_new = h_old + g × w_i(alpha)
```

다섯 방향은 모두 단위 L2이므로 **같은 g에서** 출력 이동 길이는 같다. 그러나 자율 학습이 시작되면
p·행동·획득 보상이 달라진다. 실제 총 이동량까지 같다는 주장은 하지 않는다.
다른 조건의 행동이나 보상을 강제로 복사하거나 성적을 본 뒤 학습률·갱신 횟수를 조절하지 않는다.

`|a−p|≤1`, `|r|≤1`에서 시행당 L2 상한은 eta=.1이다. 400회 누적 경로 길이 상한은 40,
제곱 이동량 합 상한은 4이며, 최종 출력 계수 길이는 누적 경로 길이 이하이다.
이는 실제 비용이 상한에 도달하거나 조건 간 총 비용이 같다는 뜻이 아니다.

매 시행의 실제 변화 `h_new−h_old`로 L2·제곱 L2·자기 점수 변화·다른 입력 점수 변화 L2·
비영 여부를 기록한다. 갱신 호출 수와 실제 비영 변화 수·누적 길이·최종 출력 길이를 구분한다.
내부 가중치와 고정 특징의 초기/최종 증거를 확인하며 출력 변화와 단순 입력 활성 반응을 구분한다.

모든 조건은 학습 출력 계수 48개를 쓴다. 투영·혼합에는 추가 고정 계수와 계산이 필요하다.
원/단위 특징 기하 진단과 방향 계산으로 배선·표현·seed당 producer SVD 3회, 총 180회를 쓴다.
SVD를 방향별·시행별 반복하지 않는다. 고정된 다섯 방향 계수는 그룹당 5×4×48개이며,
공유 방향을 따로 쓰는 실제 구현보다 추가 계산·저장 자원이 남는다. 모든 자원을 동일하게
맞췄거나 L2가 생물학적 비용을 나타낸다고 주장하지 않는다.

## 행동 전에 요구하는 수치 자격

모든 특징 길이·P 대각선·u_i 길이·혼합 길이는 유한한 양수여야 한다.
부모의 수치 자격 외에 다음 잔차가 각각 1e-8 이하여야 한다.

- 다섯 방향의 단위 길이와 같은 스칼라 아래 조건 간 L2 차이.
- 혼합의 정규화 재구성, 혼합 길이 분석식, 자기 영향 분석식의 차이.
- `d_i·v_i=1/||u_i||`의 차이, 혼합 길이 제곱의 .5 하한 위반.
- 자기 영향의 증가 위반과 끝 방향 cos의 1 상한 위반.

끝 방향 cos는 양수여야 한다. 필수 자격이 실패하면 과학 행동 추출 전에 멈추고 실패를 보존한다.
정확한 투영 분리의 강한 해석은 부모와 같이 유지 rank=4, D 전체 행 조건수 ≤1e6,
자기 영향/비대각 잔차 ≤1e-8일 때만 허용한다. 이 강한 자격이 닫혀도 필수 수치 자격을 통과하면
등록된 방향을 그대로 실행하고 남은 번짐을 보고한다. seed·cutoff·방향·예산을 바꾸지 않는다.

각 문제는 100번 제시되므로, 영향 행렬 M에서 마지막 검사 입력 j의 절대 점수에 대한 보수적 상한은
`100×eta×sum_i |M[alpha,i,j]|`다. 라벨이나 실제 행동을 사용하지 않는 수치 진단이며 형식 검증
증명은 아니다. logistic을 적용한 값은 각 정답 행동 확률의 보수적 상한이다.
다섯 alpha 모두 상한과 실제 최종 확률의 관계를 1e-8 허용 오차로 확인한다.
상한이 낮아도 과학 시행을 생략하거나 예산을 늘리지 않는다.

## 고정 예산·난수·평가

새 계산 seed는 **17301..17310**의 10개다. 네 문제를 한 번씩 섞은 100 block으로 seed마다
**400회 선택·획득 피드백**을 준다. 순서는 `SeedSequence([202610195,seed,0])`, 행동 uniform은
`SeedSequence([202610195,seed,1])`을 사용한다. seed를 더해 난수 주소를 만들지 않는다.
같은 seed의 30조건은 순서와 uniform을 공유하지만 실제 행동·보상은 달라질 수 있다.

checkpoint는 **0,50,100,200,400**이다. 네 연습 입력을 추가 행동 추출·보상·학습 없이 정적으로
평가한다. 총 예산은 **30×10×400=120,000회 선택·피드백**, 정적 평가
**30×10×5×4=6,000개**다. 계산 seed는 동물 개체나 사람 참가자의 수가 아니다.
seed 교체·추가·예산 연장·성과 기반 중간 중단은 하지 않는다.

일차 점수는 네 연습문제에서 **정답 행동을 선택할 기대 확률의 평균**이다.
실제 추출 행동의 정답률·획득 보상·실제 비용은 따로 보고한다.

## 미리 정한 두 가설

**H_tradeoff**는 real/raw의 **alpha=.5**에 대해 다음을 모두 요구한다.

1. alpha=0보다 최종 기대 정답 확률 평균이 10seed 평균에서 .05 이상 높다.
2. alpha=1보다 같은 평균 차이가 .05 이상 높다.
3. 각 끝 방향과의 차이가 양수인 seed가 각각 8/10 이상이다.
4. 모든 조건의 필수 정적 수치 자격이 통과한다.
5. 모든 실행에서 실제 시행당 L2 ≤.1+1e-8, 누적 L2 ≤40+1e-8, 제곱 이동량 합 ≤4+1e-8이며,
   실제 변화와 스칼라×방향 계산, 최종 출력 길이와 경로 길이, 보수적 확률 상한이 일치한다.

이 가설은 **같은 조건부 이동 길이와 공통 상한에서 가운데 방향의 실용적 개선**을 묻는다.
완전 습득을 가설 지지의 필수 조건으로 섞지 않는다. 조금 좋아진 것과 충분히 배운 것은 별개다.

**H_acquisition**은 real/raw의 **alpha=.5**에서 seed별로 마지막 기대 정답 확률 평균 ≥.80,
처음 대비 증가 ≥.25, 두 정답 종류 각각 평균 ≥.70을 모두 만족하는 seed가 8/10 이상이며,
위 모든 수치·실제 비용 검사를 통과해야 한다.
H_acquisition은 H_tradeoff의 지지를 요구하지 않는다. 두 가설은 따로 판정·보고한다.

.05·8/10·습득 문턱은 실용적 사전 기준이며 통계적 유의성이나 생물학적 학습 경계가 아니다.
결과를 본 뒤 임계값·주 alpha·seed·예산을 바꾸지 않는다. 일부 평균이 좋아져도 문턱을 못 넘으면
해당 가설은 미지지이고 효과가 정확히 0이라고 단정하지 않는다.

다른 alpha·표현·배선의 모든 seed 성적·습득·비용·정적 영향은 기술적으로 공개한다.
가장 좋은 관측 alpha는 이 등록에서 확인적 최적값으로 선택하지 않는다.
일차 미지지를 다른 조건으로 대신하거나 모든 절충 방식의 불가능으로 확대하지 않는다.

## 등록·실행·독립 검산

설정의 정확한 소스 28개·부모 증거 6개·그래프 4개·입력 2개를 SHA-256과 Git commit으로
동결한다. 완료 기준선의 literal bytes와 부모 결과의 완료·검산 상태를 확인한다.
개발 검사는 만든 작은 행렬과 가짜 저장소만 사용하며, 등록 전에 실제 그래프·연구 seed의 결과를
살펴보지 않는다. 기존 envelope나 완료 소스를 새 실험에 맞춰 수정하지 않는다.

```text
python scripts/run_spillover_tradeoff.py register --config configs/spillover_tradeoff_v1.json --out results/registration_spillover_tradeoff_v1.json
```

등록을 commit·push하고 비공개 원격의 같은 등록 bytes를 확인한다. source commit·published
commit·등록 SHA·확인 UTC를 `results/spillover_tradeoff_publication_proof.json`에 남긴다.
확인 시점은 실제 과학 계산 시작보다 앞서야 한다.

```text
python scripts/run_spillover_tradeoff.py run --config configs/spillover_tradeoff_v1.json --registration results/registration_spillover_tradeoff_v1.json --publication-proof results/spillover_tradeoff_publication_proof.json --out results/spillover_tradeoff_v1
```

결과 경로는 배타적으로 새로 만들며 실패해도 metadata와 만들어진 파일의 해시를 보존한다.
독립 검산은 새 producer·새 기하 helper를 import하지 않고 그래프·encoder·입력·정규화·SVD·
두 끝 방향·다섯 혼합 방향·정적 영향·난수 주소·모든 실제 행동/보상/비용·checkpoint·습득·
두 가설을 다시 구성한다. 등록·원격 확인·계산 시작·완료의 시간 순서와 고정 상태·파일 해시도
확인한다. producer 요약을 옮겨 적은 검사는 독립 산술 검산으로 세지 않는다.

## 해석의 한계

최대 범위는 알려진 네 인공 연습문제의 **출력 학습(Level 2)**과 계산상 이동 비용·점수 번짐의 관계다.
내부 시냅스 학습·새 문자열 일반화(Level 3)·인간 행동 유사성(Level 4)·공통 신경 기작(Level 5)을
검사하지 않는다. 수학 규칙 이해, 실제 초파리의 문자·수량 인지, 교육 효과도 주장하지 않는다.
새 인간 자료나 신규 인간 실험은 없다. 기존 인간 비교의 미지지와 맥락별 공동 습득·간섭·순서
연구의 닫힌 판정 조건을 그대로 보존한다. 후속 연구는 이번 결과와 별도 게이트에 따라 새로 등록한다.

# 순서를 유지한 입력 간격 진단 — 사전 프로토콜 v1

작성일: 2026-10-14 (Asia/Seoul). 앞선 [입력 표현 진단 결과](encoding-findings.md)를 본 뒤, **새 시드 4001–4010의 연구 실행 전에 정한 후속 계획**이다. 기존 smoke·보상 반전·입력 표현 실험의 프로토콜, 설정, 코드, 실패 및 결과를 보존한다. 새 문서·설정·코드·공유 코드·원자료의 해시를 별도 등록으로 동결하고, 새 결과 경로를 사용한다. 실행 전 비공개 Git 기록으로 동결을 확인하며 이를 외부 공인 사전등록이나 완전한 눈가림 확증이라고 표현하지 않는다.

## 비전공자를 위한 설명

모델에는 그림 대신 이미 계산된 수량을 숫자로 알려 주었다. 예를 들어 2개는 2/8, 4개는 4/8이다. 지난 실험에서는 처음 보는 개수에 붙인 숫자표의 순서를 섞었다. 그때는 숫자표의 순서와 값 사이의 간격이 함께 바뀌었다.

이번에는 **많은 개수에 더 큰 입력값을 준다는 순서는 유지하고, 입력값 사이의 간격만 좁히거나 넓힌다.** 연습한 2개와 4개의 입력값은 고정한다. 특히 새 문제인 5개와 7개를 검사할 때는 두 값의 가운데 위치도 그대로 둔다. 같은 연습을 마친 모델에 가까운 두 입력과 멀리 떨어진 두 입력을 보여 주는 비교다. 시험 중에는 추가 보상이나 학습을 하지 않는다.

정답을 고를 확률과 실제로 어느 쪽을 고르는지는 다를 수 있다. 예를 들어 정답 확률 60%와 90% 모두 확률이 큰 쪽만 고르면 같은 정답을 낸다. 따라서 간격을 줄였을 때 확률만 낮아지는지, 선택 자체도 틀리는지를 따로 기록한다. 이 실험은 수량의 의미를 발견했는지보다 **학습한 선택 함수가 입력의 숫자 간격에 얼마나 민감한지**를 묻는다.

## 연구 질문과 사전 판정

연구 질문: 수량의 순서, 훈련 입력, 보상 경험을 동일하게 유지하면서 완전 미학습 수량쌍 5 대 7의 입력 간격만 바꾸면, 정답 선택 확률과 greedy 선택이 얼마나 달라지는가? greedy는 확률이 더 큰 선택지를 고르는 평가이며, 확률의 확신 정도와 구별한다.

주 가설 H-S는 **학습으로 증가한 입력 간격 민감도**다. 각 시드·모델 조건에서 주 쌍 5 대 7의 평가 평균을 사용해 다음을 계산한다.

`D_before = p_correct(alpha=1, 학습 전) − p_correct(alpha=0.25, 학습 전)`

`D_after = p_correct(alpha=1, 학습 후) − p_correct(alpha=0.25, 학습 후)`

`H-S 지표 = D_after − D_before`

여섯 모델 조건마다 **전체 10시드 평균 H-S 지표 ≥0.10 및 엄격히 양수인 시드 ≥8/10**을 모두 만족하면 해당 조건의 계산 기준 통과로 기록한다. 0.10은 선택 확률의 10%포인트 차이를 요구하는 연구용 실용 기준이며, 생물학적 임계값이나 통계적 유의성 기준이 아니다. `D_before`, `D_after`, 차이의 차이와 각 코드의 학습 전후 값을 모두 보존한다. 상대 대비가 통과해도 절대 정답 확률이나 선택의 견고함이 높은지는 별도 판정한다.

**습득 gate**는 훈련 수량쌍 2 대 4의 최종 IID `p_correct≥0.75` 및 학습 전 대비 향상 `≥0.15`를 모두 만족하는 것이다. H-S의 주 결과는 습득 실패 시드도 포함한 전체 10시드에서 계산한다. 습득 gate 조건부 요약을 추가할 때는 포함한 시드 수와 해당 결과를 밝히며, 전체 결과를 대체하지 않는다. 실패한 시드 삭제, 시드 교체, 추가 시행, 학습률 탐색 및 기준 변경을 금지한다.

보조 H-R은 **간격 변화에도 선택이 유지되는가**다. 각 시드에서 습득 gate를 통과하고, 주 쌍 5 대 7의 최종 greedy 정확도가 사전 지정한 네 코드 모두에서 `≥0.90`이면 견고한 선택 기준 통과로 기록한다. 조건별 통과 수를 보고하되 그 개수에 사후 가족 성공 임계값을 붙이지 않는다. `p_correct`가 줄어도 greedy 기준은 통과할 수 있고, 확률 차이가 작아도 greedy 기준은 실패할 수 있다.

각 코드에서 주 쌍의 최종 `p_correct≥0.75`와 습득 gate를 모두 충족한 시드 수를 절대 미학습 수행으로 별도 보고한다. 완전 미학습 15쌍 macro 평균의 같은 절대 기준 통과 수는 보조 지표로 구분한다. 주 쌍 수행과 15쌍 평균을 서로 대체하거나 합쳐서 하나의 전이 성공으로 만들지 않는다. 여섯 조건을 합쳐 가장 유리한 성공만 보고하지 않는다.

## 입력 코드와 분리 가능한 조작

실제 수량 `n∈{1,…,8}`에 대해 다음 코드 벡터를 사용한다. 첫 입력 좌표는 `code_alpha(n)/8`이다. 나머지 여섯 인공 nuisance 좌표는 기존과 같은 `0.1×(u−0.5)`다. 이는 실제 물체 그림의 크기·면적·밀도·간격·배치·범위를 동시에 독립적으로 조절한 시각 자극이 아니다.

`code_alpha = [1, 2, 3, 4, 6−alpha, 6, 6+alpha, 8]`

| alpha | 역할 | 5의 코드 | 7의 코드 | 5 대 7의 실제 입력 간격 | 실제 입력 중간값 |
|---|---|---:|---:|---:|---:|
| 0.25 | 주 압축 | 5.75 | 6.25 | 0.0625 | 0.75 |
| 0.5 | 보조 압축 | 5.5 | 6.5 | 0.125 | 0.75 |
| 1 | 원래 수량 코드 | 5 | 7 | 0.25 | 0.75 |
| 1.5 | 보조 확장 | 4.5 | 7.5 | 0.375 | 0.75 |

네 코드 모두 엄격한 수량 순서를 유지한다. 훈련 anchor 2와 4, 양 끝 1과 8, 수량 3과 6의 코드는 고정한다. 전체 입력 범위 `[1/8,1]`도 같다. 주 쌍 5 대 7에서는 실제 수량의 차이 2, 작은 수량/큰 수량 비율 5/7, 정답, nuisance 행, 코드 중간값 6/8을 고정하고, 코드 간격 `2×alpha/8`만 조작한다. 5와 7은 훈련 수량도 아니며 네 코드에서 모두 훈련 입력 구간 `[2/8,4/8]` 밖이다. 따라서 이 주 쌍은 미학습 입력에 대한 외삽 반응을 검사한다.

나머지 수량쌍에는 5 또는 7의 이동으로 간격과 중간값이 함께 변할 수 있고, 일부 쌍은 입력이 전혀 변하지 않는다. 각 쌍의 실제 수량 비율·차이와 코드 간격·중간값을 저장한다. **주 쌍 외의 평가에서 입력 간격 하나만의 기여라고 주장하지 않는다.** 같은 실제 수량쌍의 코딩만 바꾸는 주 비교에서는 수량 비율을 변화시키지 않았으므로, 인간의 수량 비율 효과나 Weber 법칙을 검증했다고 해석하지 않는다.

학습은 2 대 4의 원래 입력을 사용하며 큰 수량을 선택하면 보상 1, 다른 선택이면 보상 0을 준다. 알고리즘에는 선택 행동과 scalar 보상만 전달한다. 미학습 수량의 정답이나 평가 결과를 갱신·설정 선택에 쓰지 않는다. 모든 코드에서 훈련 입력 및 2 대 4 IID/OOD 평가 입력이 byte 수준에서 동일해야 한다. 같은 초기 상태·행동 난수·보상·갱신 규칙이면 학습 궤적도 같으므로, **시드·모델 조건당 학습은 한 번만 수행**하고 그 상태를 네 코드의 frozen 평가에 공통 사용한다.

총 실제 학습량은 `10시드×6조건×400시행=24,000`이다. 네 코드는 네 번의 독립 학습이나 초파리 개체가 아니다. 이번에는 수량 제거 입력을 별도로 학습하지 않는다. nuisance-only 기준은 자료 구조와 분석적 계산으로 확인한다. 네 코드의 신경망 결과를 50%나 특정 방향으로 강제하지 않는다.

## 모델, 자원과 생물학적 구현 범위

기존 `Learner`의 encoder, 활성 함수, 선택 확률, 갱신식 및 clipping을 변경하지 않는다. 원래 배선은 FlyWire v783에서 확보한 KC→MBON 1,474개 연결이며 nominal 512 KC·48 MBON 중 489 KC·29 MBON에 이 부분집합의 연결이 있다. LC11·DAN·APL·재귀 상태·시각 입력에서의 수량 추출은 구현하지 않는다. [기술 설계](technical-design.md), [자료 감사](drosomem-audit.md), [해석 한계](../LIMITATIONS.md)를 보존한다.

| 조건 | 배선 | 내부 가중치 학습 | 출력 가중치 학습 |
|---|---|---|---|
| `fixed` | 실제 부분집합 | 없음 | 있음 |
| `plastic` | 실제 부분집합 | 있음 | 있음 |
| `rewired_fixed` | 차수 보존 재배선 | 없음 | 있음 |
| `rewired_plastic` | 동일 재배선 | 있음 | 있음 |
| `ann_fixed` | 무작위 희소 일반망 | 없음 | 있음 |
| `ann_plastic` | 동일 일반망 | 있음 | 있음 |

모든 조건에서 같은 7차원 입력, 뉴런 차원, 출력 크기 및 400 학습 시행을 사용한다. 출력 학습률은 0.1, 내부 학습률은 0.01이다. 가소성은 확보한 KC→MBON mask 안에서만 허용하며 내부 가중치를 초기값 대비 `[0,2w_initial]`로 제한한다. 고정 조건은 출력 가중치 48개를 학습하고, 가소성 조건은 내부 가중치 1,474개를 추가로 학습한다. 따라서 두 방식의 총 학습 자원이 같다고 표현하지 않는다.

재배선은 KC outdegree·MBON indegree·MBON별 incoming weight multiset을 보존한다. ANN은 MBON indegree와 incoming weight multiset을 보존하며 KC outdegree까지 같다고 가정하지 않는다. 같은 시드의 여섯 조건은 encoder·초기 head·자료 및 행동 uniform stream을 공유한다. 확률이 달라 같은 uniform에서 행동이 달라지는 것은 허용된 정책 차이다. 원래 배선이 대조보다 우월해야 한다는 성공 목표를 세우지 않는다.

## 새 시드, 자료 분할과 checkpoint

연구 시드는 **4001–4010**이다. 자료 난수는 `seed*100+31`(train), `+32`(IID), `+33`(nuisance OOD), `+40+i`(사전식 27쌍의 index i=0,…,26)를 사용한다. 행동 uniform은 `seed+280000`, encoder·초기 head는 `seed+70000`, 재배선은 `seed+50000`, ANN은 `seed+60000`이다. 작은 구현 검증 fixture는 61/62 등 별도 시드·8시행을 사용한다. 계획된 4001–4010의 결과로 코드·기준·학습 예산을 튜닝하지 않는다.

학습 자료는 2 대 4의 400행이다. 학습과 분리한 2 대 4 IID와 nuisance OOD는 각각 128행이며, 훈련하지 않은 27수량쌍의 IID 평가는 쌍마다 128행이다. 모든 코드와 모델 조건에서 같은 원래 평가 행을 사용한다. nuisance OOD는 비수량 좌표의 분포 변화이며, 실제 시각 자극에서의 일반화가 아니다.

각 nuisance family는 네 행 교차 설계를 사용해 양 후보의 위치와 nuisance 벡터가 정답 수량에 균형 있게 대응하게 한다. orientation에 독립적인 자극 fingerprint로 모든 분할 간 중복이 없는지 확인한다. family ID·counts·nuisance·행동 uniform 및 코드 벡터를 원자료로 보존한다. 훈련 시드는 정답이나 코드의 조건별 유불리에 따라 고르지 않는다.

checkpoint는 시행 `0·100·200·300·400`이다. 각 checkpoint에서 2 대 4 IID/OOD 지표를 네 코드로 평가해 입력과 출력이 byte 수준에서 동일한지 확인한다. 고정 probe는 IID의 사전 지정 첫 8행이며 KC·MBON 활성, 내부·출력 가중치 및 선택 확률을 남긴다. 미학습 27쌍의 네 코드 평가는 학습 전과 400시행 후에 수행한다. 평가 중 가중치 갱신, 행동 난수 소비 또는 추가 보상을 금지한다.

| 평가 범위 | 쌍 수 | 역할 |
|---|---:|---|
| 5 대 7 | 1 | 주 H-S 및 보조 H-R, 주 쌍 절대 수행 |
| `{1,3,5,6,7,8}`의 모든 조합 | 15 | 완전 미학습 macro 보조 요약; 5 대 7 포함 |
| 2 또는 4와 위 여섯 수량의 조합 | 12 | 학습 anchor 포함 보조 요약 |
| 위 두 범위를 합한 미학습 쌍 | 27 | 전체 보조 요약; 훈련 2 대 4 제외 |

27쌍은 1–8의 서로 다른 두 수량의 사전식 조합에서 2 대 4만 제외한다. 15쌍·12쌍·27쌍의 macro 평균은 쌍에 같은 가중치를 준다. 이 세 요약을 별도 주 가설로 추가하지 않는다.

## 분석적 대조와 해석의 한계

모든 코드가 실제 수량의 순서를 보존하므로 큰 입력값을 고르는 **code-ranking oracle**은 모든 평가 쌍에서 1.0이다. 실제 수량을 아는 oracle도 1.0이다. 이는 구조적으로 정답을 낼 정보가 유지됐다는 확인이며, 같은 보상 경험으로 학습한 대조 모델의 성과로 표현하지 않는다.

수량 입력을 보지 않고 nuisance만 사용하는 고정된 정책은 네 행 교차 자료에서 같은 입력에 반대 정답이 균형 있게 대응하므로 평균 `p_correct=0.5`다. 이 값은 구현 점검용 설계 성질이다. 반면 네 수량 코드의 전체 평가에는 앞선 720순열의 교환 대칭이 없으므로 **신경망 성능이 0.5이거나 H-S가 양수여야 한다는 항등식은 없다.** 비단조 점수 함수, 활성 구간 변화 및 포화 때문에 간격을 넓혀도 확률이 반드시 개선된다고 가정하지 않는다.

주 `p_correct`는 평가에서 선택을 새로 샘플링한 정답률이 아니라 정답을 고를 확률의 평균이다. greedy 정확도는 `p_right>0.5`일 때 오른쪽, 작을 때 왼쪽을 선택한 정답률이며, `|p_right−0.5|<1e−12`인 계산상 동률은 0.5점으로 센다. 주 비교는 확률 차이이므로 greedy가 네 코드에서 모두 같아도 H-S가 통과할 수 있다. 서로 다른 정답 선택 확률은 선택 함수의 확신 정도 차이이며, 새 지능 수준이나 생물학적 주관적 확신을 직접 측정한 것이 아니다.

시드별·조건별 전체 값, 평균, 계산 시드의 표본 표준편차, 엄격히 양수인 시드 수, 습득 gate 수 및 gate 조건부 요약을 남긴다. 10시드는 계산적 반복이며 독립 초파리나 인간 개체가 아니다. 평가 행·수량쌍·코드·checkpoint를 표본 수로 부풀리거나 조건 중 가장 좋은 결과만 발표하지 않는다. 이번 실용 기준을 p값이나 다중 비교를 통과한 통계 검정으로 표현하지 않으며, 생물학적 결론 또는 인간 학습의 인과 기작을 주장하지 않는다.

학습 전후 차이를 빼는 것은 초기 정책에 있던 코드 간격 반응을 구분하기 위한 것이다. H-S가 통과하면 **기존의 순서 제공 scalar 표현에서 보상 학습 후 간격 민감도가 증가했다**고 표현한다. 학습된 단일 함수의 입력 반응을 검사한 결과이며, 코드별 모델이 서로 다른 학습 원리를 얻은 것이 아니다. 실패·반대 방향·greedy 불안정도 같은 연구 결과로 보존한다.

## 기록, 독립 검산과 중단 규칙

학습 시행마다 입력 식별자, 좌우 수량, action, reward, p_right, 갱신 계수 및 내부·출력 가중치 변화 norm을 저장한다. 행동 uniform 원자료도 보존한다. checkpoint에 내부·출력 가중치, encoder/bias, 연결 인덱스, 고정 probe 활성·선택 확률을 저장한다. 학습 전후의 모든 평가 확률은 코드·수량쌍·seed·condition과 연결해 별도 산술로 재계산 가능해야 한다. 입력 코드의 차이와 활성 상태 차이를 내부 시냅스 학습 변화와 혼동하지 않는다. encoder와 KC 활성 함수는 학습하지 않는다.

계산 효율을 위해 같은 모델에서 가능한 코드값별 후보 점수를 미리 계산할 수 있다. 저장한 cache는 직접 순전파와 일치해야 하며, 여러 코드 평가를 독립 학습으로 세지 않는다. 신경망의 두 후보 점수 차이에 같은 clipped logistic 선택 함수를 사용한다. 코드값이 소수인 이번 설계에서 이전 정수 순열 cache의 인덱스 가정을 그대로 적용하지 않는다.

독립 auditor는 학습 클래스의 update·실험 입력 변환·지표 요약 함수를 호출하지 않고 저장한 원자료와 초기 상태를 별도 산술로 replay한다. 전체 24,000갱신, reward/action/uniform 대응, 가소성 mask와 clipping, 고정 조건의 내부 불변성, 모든 시드·조건·시행 coverage, 학습 및 2 대 4 평가의 네 코드 동등성, 엄격한 코드 순서·고정 anchor·범위·주 쌍 중간값, nuisance 교차와 자료 누출, checkpoint, 모든 평가 확률, 요약·gate·해시를 확인한다. fixed probe의 KC 변화는 0이어야 하고 MBON·head 변화는 조건의 허용된 갱신과 구별해 재계산한다.

등록 뒤 source/config/protocol drift, NaN, 누락·중복, 허용되지 않은 내부 변화, 자료 교차 위반 또는 독립 산술 불일치는 검증 실패다. 실패한 실행과 부분 결과를 보존하고 과학적 결과를 승인하지 않는다. 같은 경로를 덮어쓰거나 기준을 바꿔 재실행하지 않는다. 구현 수정이 필요하면 이유와 변경을 기록하고 새 전향적 동결·새 결과 경로를 사용한다. 예산은 사전 400시행에서 끝내며 결과가 좋지 않아도 연장하지 않는다.

## 연구 수준과 인간 학습 비교의 다음 질문

이번 연구는 경험 의존적 모델 변화(Level 2)와, 습득 확인 이후 인공 표현에서 미학습 입력에 반응하는 제한된 Level 3 진단이다. 실제 시각 수량 인지·LC11 기능·수학 기호 의미 이해·일반 수학 규칙 발견·인간과의 정량적 행동 유사성(Level 4)·공통 신경 기작(Level 5)을 검증하지 않는다. 기존 M11의 규칙 습득·일반화 실패와 보상 반전의 실패를 보존한다.

인간 학습과의 연결은 장기 핵심 목표로 유지한다. [기존 비교 체계](human-learning-comparison.md)를 따라, 인간 공개자료에서도 실제 수량 비율, 비수량 단서, 입력 표현의 간격, 습득 전후 변화 및 선택 지표를 구분해 비교할 수 있는가라는 검증 가능한 질문을 남긴다. 이미 확보한 [인간 자료](human-data-readiness.md)에 이번 코드 조작이나 시행별 반응이 있다고 가정하지 않는다. 현재 scalar 코드 효과를 실제 점 배열의 수량 감각이나 학교 수학교육의 효과와 직접 연결하지 않는다. 순서를 유지한 코드 간격 효과를 먼저 측정하는 이유는 이후 인간 비교에서 어떤 정보가 이미 입력에 제공됐는지 구분하기 위해서다.

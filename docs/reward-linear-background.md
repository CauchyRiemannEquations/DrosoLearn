# 독립 보상 선형 학습자의 계산적 배경

2026-10-14, Asia/Seoul. 이 문서는 이전 실험 결과, 직접 확인한 문헌과 이번 설계의 수학적 성질을 구분한다. 새 결과를 미리 가정하지 않는다.

## 설명식에서 독립 학습자로

앞선 [선형 참조 진단](linearity-findings.md)은 복잡한 모델이 낸 점수를 받아 간단한 식을 만들었다. 새 입력에서 원래 반응을 잘 따라갔지만, 같은 보상 경험으로 식 자체가 학습할 수 있는지는 확인하지 않았다. 이번에는 계수를 모두 0에서 시작하고 선택과 보상으로만 갱신하는 독립 선형 정책을 둔다. 훈련한 모델의 점수·가중치·참조 계수·평가 정답을 제공하지 않는다.

각 후보는 7차원 입력 `x=(수량코드/8, nuisance1,…,nuisance6)`다. 선형 모델은 `s(x)=w·x`, 두 후보의 차이 `d=w·(x_right−x_left)`에서 오른쪽 선택 확률을 만든다. 공통 상수항은 차이에서 사라지므로 별도 bias를 두지 않는다. 수량 좌표만 미리 골라 쓰지 않고 일곱 좌표 모두 학습한다. 다만 숫자의 순서는 이미 입력이 제공한다. 물체 그림에서 수량을 추출하거나 수량의 의미를 발견하는 실험은 아니다.

## 보상 갱신식과 정보량

확률 정책의 보상에 따른 가중치 조정이라는 계산 계열은 Williams (1992), *Simple statistical gradient-following algorithms for connectionist reinforcement learning*, Machine Learning 8, 229–256, [DOI 10.1007/BF00992696](https://link.springer.com/article/10.1007/BF00992696)의 REINFORCE 연구에 근거한다. 공식 출판 페이지에서 서지·초록을 확인했으며 유료 본문 전체를 새로 확인하지 않았다. 논문은 확률적 연결망에서 기대 보상 기울기를 따르는 알고리즘을 제시한다. 아래 식과 특정 척도 통제는 DrosoLearn의 설계·미분이며 논문이 초파리 수량 학습을 입증했다는 뜻은 아니다.

정규화된 특징을 `φ(x)`라 할 때 `Δφ=φ_right−φ_left`, `p=sigmoid(clip(w·Δφ,−40,40))`, 선택 `a∈{0,1}`, 받은 보상 `r∈{0,1}`이다. 선택은 미리 저장한 uniform `u`에 대해 `a=1[u<p]`다. 갱신 계수는 `f=(a−p)(r−0.5)`이며 `w←w+0.1 f Δφ`다. 0.5는 고정 보상 baseline이며 기대 보상을 학습하는 별도 모델이 아니다. clipping이 실제로 작동하는 구간에서도 이 갱신식을 그대로 쓰는 구현이므로 모든 상태에서 clipped 정책의 정확한 수학적 기울기라고 주장하지 않는다.

보상은 관측한 선택이 큰 수량이면 1, 아니면 0이다. **두 선택에서 결정적인 0/1 보상을 받으면 선택과 보상만으로 정답을 완전히 복원할 수 있다.** 정답쪽은 `r=1`이면 선택한 쪽, `r=0`이면 반대쪽이다. 학습 함수에 정답 라벨을 직접 전달하지 않지만 보상 정보량은 라벨과 동등하다. 지연되거나 드문 보상에서 스스로 수량 개념을 발견하는 어려운 탐색으로 해석하지 않는다.

실제로 정답이 오른쪽일 때 `f`는 오른쪽 선택에서 `0.5(1−p)`, 왼쪽 선택에서 `0.5p`로 항상 양수다. 정답이 왼쪽이면 두 경우 모두 음수다. 따라서 현재 규칙은 매 시행 정답 방향으로 특징 차이를 더한다. 행동 평균에서 정답이 오른쪽이면 `E[f]=p(1−p)`다. 이는 이번 이진·결정적 보상 구조에서 도출한 성질이며 DAN 신경 신호의 측정 결과가 아니다.

`linear_random_reward`는 선택과 무관한 독립 fair-coin 보상을 받는다. 같은 학습 입력·초기 계수·정규화·행동 uniform을 사용하지만 선택 확률이 달라지면 실제 선택도 달라질 수 있다. 무작위 보상은 각 시드의 유한 표본에서 우연한 편향을 만들 수 있다. 따라서 결과를 자동으로 정확히 50%라고 만들거나 실패한 난수를 교체하지 않는다. 기대 갱신이 0인 대조와 실제 유한 경로를 구분한다.

## 특징 척도가 학습에 주는 영향

같은 학습률 숫자를 써도 입력 특징 차이가 크면 한 번의 계수 갱신과 이후 점수 변화도 크다. 원시 선형 모델의 수량 차이는 2대4에서 0.25인 반면 48개 MBON 특징의 전체 차이는 다른 크기를 가질 수 있다. 척도 차이로 400시행의 성능이 달라지는 것을 커넥톰의 계산 원리 차이라고 읽지 않도록 초기 특징 차이의 전체 크기를 맞춘 조건을 둔다.

모든 400개 훈련 입력을 보상·선택 이전에 제시해 초기 후보 특징 차이 `Δz_i=z_i,right−z_i,left`를 계산한다. `g=sqrt(mean_i Σ_j Δz_ij²)`를 고정한다. `linear_raw`만 `φ=x`이며, 다른 선형 조건은 `φ=x/g`, 여섯 네트워크는 `φ=MBON/g`다. `g`는 정답 라벨, 보상, 모델 점수, 평가 자료에서 추정하지 않는다. 선형 계수는 0이고 초기 네트워크 head도 0이라 이 전처리에서 학습된 출력 정보가 생기지 않는다.

이 방법은 모든 normalized 조건에서 훈련 특징 차이의 평균 제곱 길이를 처음에 1로 맞춘다. 원시 선형 모델은 동일 입력에 대한 척도 진단이다. 정규화 자체는 학습률을 다르게 적용하는 효과를 가진다. 사후 유리한 성능을 보고 나눈 값이 아니라 입력과 초기 특징만으로 정한 규칙이다.

한 개의 전체 크기를 맞춰도 특징 간 상관, 각 방향의 크기, 파라미터 수, 가중치 제약과 내부 가소성 자원은 같아지지 않는다. 특히 내부 가소성 후 MBON 특징이 변해도 `g`는 재추정하지 않는다. 이는 매번 바뀌는 활성의 척도를 계속 같게 유지한 비교가 아니다. 전체 훈련 입력의 사전 관찰을 허용하는 무보상 batch 전처리이므로 미래 입력을 전혀 보지 못하는 순수 online 설정으로도 부르지 않는다.

## 내부 학습의 계산 범위

네트워크는 기존 KC ReLU encoder와 KC→MBON mask를 유지하며 이번 새 wrapper 안에서 head 초기값과 고정 `g`를 바꾼다. head 갱신은 정규화된 MBON 특징 차이이고, 내부 가중치 갱신은 `0.01 f old_head[post] (KC_right−KC_left)/g`다. head 변경 전 값으로 내부 eligibility를 계산하고 초기 내부 가중치의 `[0,2배]`에 제한한다. 모두 0인 초기 head 때문에 첫 시행 내부 갱신량은 0이다. 내부 가중치·출력 계수·일시적 활성 변화는 별도 기록한다.

이 갱신은 단순화한 계산 규칙이다. 실제 KC→MBON 가소성이 시간 순서와 구획에 의존하고 DAN·MBON 상호작용을 가진다는 [Huang et al. (2024)](https://www.nature.com/articles/s41586-024-07819-w)의 기존 문헌 검토와 구분한다. 이번 모델은 LC11 입력 경로와 실제 DAN·APL·재귀 회로를 구현하지 않는다. 행위가 보상에 따라 바뀌는 것이 같아도 생물학적 기작이 같다는 결론은 나오지 않는다.

## 인간 비교에 남기는 질문

조건에 따라 같은 순서 입력·연습 횟수에서도 학습 곡선이 달라진다면 그 차이가 입력 척도, 학습 가능한 자원 또는 피드백 구조에서 생겼는지 후속 가설로 분리할 수 있다. 사람의 정답 선택률, 시행별 향상, 새로운 사례 반응을 비교할 장기 목표는 유지한다. 현재 공개 인간 자료에는 이번과 동일한 입력 코드·보상 시행 기록이 없으므로 새로운 인간 비교 결과를 만들지 않는다. 성공·실패 어느 쪽도 인간의 수학 학습 능력이나 교육 효과, 공통 신경 메커니즘의 증거로 확대하지 않는다.

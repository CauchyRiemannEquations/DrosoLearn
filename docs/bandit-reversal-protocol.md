# 독립 보상 학습자의 보상 반전 — 사전 프로토콜 v1

작성일: 2026-10-14 (Asia/Seoul). [독립 보상 선형 학습 결과](reward-linear-findings.md)를 확인한 뒤, 새 연구 시드 7001–7010을 실행하기 전에 정한 후속 계획이다. 기존 연구의 소스·자료·설정·등록·결과와 실패를 변경하지 않는다. 이번 연구는 새 코드·문서·설정·해시 등록·결과 경로를 사용한다. 실행 전 비공개 Git 원격에 보존하되 외부 공인 공개 사전등록이나 완전히 눈가림한 확증 연구로 표현하지 않는다.

## 비전공자를 위한 설명

지난 실험에서는 복잡한 모델의 점수를 주지 않아도, 간단한 모델이 ‘2개와 4개 중 큰 쪽을 고르면 보상’이라는 규칙을 배웠다. 이번에는 **‘이제 작은 쪽을 고르면 보상’으로 규칙을 바꾸었을 때도 선택을 고칠 수 있는지** 확인한다. 처음부터 작은 쪽을 배우는 모델과 비교하고, 계속 작은 쪽을 연습하는 모델도 둔다.

모델이 옛 답을 아주 높은 확률로 선택한다면 반전 직후 새 규칙 성적은 낮아질 수밖에 없다. 그래서 곡선의 전체 높이만 보고 ‘학습 능력 자체가 느려졌다’고 말하지 않는다. **새 규칙을 같은 400번 연습한 뒤 얼마나 뒤처지는지**, 어디서 출발했는지, 그동안 얼마나 회복했는지를 따로 기록한다.

또한 선택 담당 계수만 0으로 되돌리는 컴퓨터 조작을 둔다. 단순 선형 모델과 내부 연결이 고정된 모델은 이 조작 뒤 처음부터 배우는 경우와 같아야 한다. 내부 연결도 바뀐 모델에서는 차이가 남을 수 있다. 이 되돌림을 실제 뇌의 기억 삭제라고 부르지 않는다.

수량은 그림 대신 순서를 이미 나타내는 숫자로 입력한다. 실제 물체를 세는 시각 능력이나 인간 수학 이해를 시험하는 실험이 아니다.

## 주 질문과 기준

주 질문 **H-B**: `linear_normalized`에서도 이미 높은 수량을 선택하도록 습득한 이력이, 처음부터 낮은 수량을 배우는 경우보다 **고정된 새 규칙 연습 예산 뒤의 성적 차이**를 만드는가?

각 시드에서 2단계 IID 400시행 종료의 낮은 수량 정답 선택 확률을 사용한다.

`endpoint_cost = p_small(fresh_low, phase2 trial400) − p_small(high_to_low, phase2 trial400)`

다음 네 조건을 모두 만족해야 주 H-B 기준 통과다.

1. `linear_normalized`의 `fresh_low`가 최종 IID 확률 `≥0.75` 및 2단계 시작 대비 증가 `≥0.15`를 함께 충족한 시드가 8/10 이상이다.
2. 같은 모델의 `high_to_low` 1단계가 높은 수량 기준 IID 확률 `≥0.75` 및 1단계 시작 대비 증가 `≥0.15`를 함께 충족한 시드가 8/10 이상이다.
3. `endpoint_cost`의 **전체 10시드 평균이 ≥0.10**이다.
4. `endpoint_cost`가 엄격히 `>0`인 시드가 8/10 이상이다. 정확히 0은 양수로 세지 않는다.

조건 3·4의 평균과 개수에서 습득 미달 시드를 제외하지 않는다. 0.10은 10%포인트 차이이며 75%, 15%포인트, 8/10과 함께 실행 전 정한 연구용 실용 기준이다. 유의성 검정이나 생물학적 임계값은 아니다. 주 기준의 하나라도 미달하면 해당 H-B는 미지지로 남긴다. 높은 규칙 또는 처음부터 낮은 규칙을 충분히 습득하지 못했다면 ‘배운 규칙의 수정’이라는 해석도 제한한다.

같은 기준을 여섯 네트워크에도 별도 보조 판정으로 적용한다. 유리한 네트워크의 성공으로 주 선형 모델의 실패를 대체하지 않는다. 모델별 원값·개별 판정·전체 시드 평균·표본 표준편차와 실패를 모두 보존한다. 실제 커넥톰의 우수성을 성공 목표로 정하지 않는다.

## 모델 조건과 자원

| 조건 | 특징과 연결 | 학습 가능한 부분 |
|---|---|---|
| `linear_normalized` | 원래 7차원 인공 입력 | 7개 선택 계수 |
| `fixed` / `plastic` | 실제 KC→MBON 부분집합, 48차원 MBON 슬롯 | 48개 출력 / 출력과 1,474개 내부 가중치 |
| `rewired_fixed` / `rewired_plastic` | 차수 보존 재배선의 같은 크기 | 같은 출력 / 출력과 내부 가중치 |
| `ann_fixed` / `ann_plastic` | 무작위 희소 일반망의 같은 크기 | 같은 출력 / 출력과 내부 가중치 |

출력 초기값은 모두 정확히 0이다. 출력 학습률 0.1, 내부 학습률 0.01과 이전 독립 보상 학습자의 갱신식을 유지한다. 초기 특징 척도는 아래의 1단계 훈련 입력만으로 계산하여 고정한다. 원시 척도 선형·무작위 보상 조건은 이번 학습 이력 질문의 조건에 포함하지 않는다. 지난 두 대조의 실패 기록은 그대로 남긴다.

실제 연결은 FlyWire v783에서 보존한 nominal 512 KC·48 MBON 부분집합의 1,474쌍이다. 그 연결에 참여하는 뉴런은 489 KC·29 MBON이며 19 MBON 슬롯에는 연결이 없다. 재배선은 KC outdegree·MBON indegree·MBON별 incoming weight multiset을 보존하고 ANN은 뒤 두 특성을 보존한다. encoder와 KC ReLU는 고정이다. LC11·DAN·APL·재귀 회로와 생리학적 시간을 구현하지 않는다.

같은 시행 수·출력 초기값·초기 특징 차이의 전체 크기를 맞춰도 계수 수, 특징 방향·상관, 내부 추가 자원과 제한은 같지 않다. 가소성 조건의 1,474개 추가 가중치를 포함한 전체 자원이 동등한 우열 실험으로 표현하지 않는다. 이전 초기 head·척도가 달랐던 연구의 성적 개선 실험으로도 부르지 않는다.

## 네 학습 이력

`high`는 4개 선택, `low`는 2개 선택에 보상 1을 주는 규칙이다. 다른 선택에는 보상 0을 준다.

| 이력 | 1단계 | 경계 조작 | 2단계 | 실제 보상 갱신 수 |
|---|---|---|---|---:|
| `fresh_low` | 보상 학습 생략 | 초기 head와 내부 연결 그대로 | low 400시행 | 400 |
| `high_to_low` | high 400시행 | 없음 | low 400시행 | 800 |
| `high_to_low_reset_head` | high 400시행 | head만 정확히 0으로 되돌림 | low 400시행 | 800 |
| `low_to_low` | low 400시행 | 없음 | low 400시행 | 800 |

모든 이력에서 2단계 입력과 행동 uniform stream이 같다. 높은 규칙으로 시작하는 두 이력은 1단계 입력·초기 상태·행동·보상·종료 상태가 정확히 같아야 한다. `fresh_low`에서 1단계 reward update는 0이다. 다만 척도 계산을 위한 동일한 1단계 입력 400개의 무보상 관찰은 허용한다.

주 비교가 맞추는 것은 **새 규칙에 대한 2단계 연습 400회**다. `fresh_low`와 다른 이력의 총 보상 경험까지 같다고 말하지 않는다. `low_to_low`는 총 800회인 같은 규칙 반복 대조다. 이번에는 27쌍 새 수량 전이와 네 간격 코드 평가를 추가하지 않는다. 학습 이력·반전과 기대 갱신의 설명에 초점을 맞춘다.

head reset은 선택 담당 계수만 바꾼다. 내부 가중치·encoder·bias·초기 내부 upper bound·특징 척도·난수 stream은 보존한다. 경계 직전과 직후 상태 및 변위, head reset 사건을 별도로 남긴다. 이 사건을 보상 학습 갱신으로 세지 않는다. 갱신 counter는 실제 실행한 학습 시행을 보존한다.

선형 모델에는 학습 가능한 내부 상태가 없다. 같은 척도와 2단계 입력·uniform을 쓰므로 `high_to_low_reset_head`의 2단계 head·행동·보상·확률은 `fresh_low`와 같아야 한다. 내부가 고정인 네트워크에서도 같은 관계가 성립한다. 누적 갱신 counter는 이전 400회 때문에 다를 수 있으며 상태 동일성 검사에서 구분한다. 이 일치는 과학적 성공이 아니라 구현 무결성 검사다. 가소성 모델의 차이는 바뀐 내부 상태와 0 head가 함께 만든 계산 효과이며 생물학적 기억 기작을 입증하지 않는다.

실제 보상 갱신 호출 수는 `10시드×7조건×(400+800+800+800)=196,000`이다. head reset, 무보상 척도 전처리, 평가와 아래 기술 참조 계산은 이 수에 더하지 않는다. 조기 종료·시드 교체·사후 예산 연장·학습률 조정은 하지 않는다.

## 초기 척도와 갱신식

각 조건의 초기 raw 특징 `z`에 대해 **1단계 훈련 입력**의 후보 차이를 계산한다.

`g = sqrt(mean_i sum_j (z_i,right,j − z_i,left,j)^2)`

`g`는 양의 유한값이어야 하며 아니면 구현·검증 실패로 중단한다. 선형 조건은 `z=x`, 네트워크는 초기 raw MBON이다. 같은 시드의 모든 이력에 같은 `g`를 쓰며 고정/가소성 초기 배선 쌍도 같은 `g`를 가져야 한다. `φ=z/g`를 고정 규칙으로 사용한다. 2단계 입력·평가 입력·정답·보상·teacher 점수나 이전 학습 가중치를 사용해 `g`를 추정하지 않는다. 반전·head reset·내부 변화 이후에도 재계산하지 않는다.

전체 1단계 입력의 무보상 관찰을 허용한 batch 전처리다. `fresh_low`도 같은 전처리 입력을 관찰한다. 미래 연습 입력을 전혀 보지 못하는 순수 온라인 설정이라고 말하지 않는다. 정규화는 초기 평균 제곱 특징 차이 길이를 1로 맞추지만 모든 방향과 내부 변화 후 척도까지 맞추지는 않는다.

후보 점수 차이 `d=(φ_right−φ_left)·head`, 오른쪽 선택 확률 `p=sigmoid(clip(d,−40,40))`, 행동 `a=1[u<p]`, 보상 `r∈{0,1}`다. 학습 함수는 선택과 scalar 보상만 받아 `f=(a−p)(r−0.5)` 및 `head←head+0.1 f (φ_right−φ_left)`를 사용한다. 결정적 두 선택 보상에는 정답쪽을 복원할 수 있는 정보가 들어 있으므로 어려운 무라벨 개념 발견이라고 표현하지 않는다.

가소성 연결은 갱신 전 `old_head`를 사용해 `eligibility=old_head[post]*(KC_right−KC_left)[pre]/g`, `weights←clip(weights+0.01 f eligibility,0,2*initial_weights)`다. head·내부 변화와 KC·raw MBON·정규화 특징 활성 변화를 각각 보존한다. 활성의 변화만으로 내부 학습을 주장하지 않는다. clipping 구간에서도 이 갱신을 그대로 쓰는 구현이므로 모든 상태에서 clipped 확률의 정확한 기울기라고 주장하지 않는다. 실제 DAN 신호나 생물학적 시간 순서 가소성 규칙과 구분한다.

## 시드·자료와 누출 검사

새 과학 실행 시드는 **7001–7010**이다. 작은 구현 fixture는 91/92 등 다른 시드·예산을 사용한다. 새 계획 시드로 척도·예산·기준을 튜닝하지 않는다.

| stream | 난수 시드 | 행 수 |
|---|---|---:|
| 1단계 2대4 train | `seed*100+31` | 400 |
| 2단계 2대4 train | `seed*100+34` | 400 |
| 2대4 IID 평가 | `seed*100+32` | 128 |
| 2대4 nuisance OOD 평가 | `seed*100+33` | 128 |
| 1단계 행동 uniform | `seed+280000` | 400 |
| 2단계 행동 uniform | `seed+300000` | 400 |
| encoder 초기화 | `seed+70000` | — |
| 재배선 / ANN | `seed+50000` / `seed+60000` | — |

모든 후보 입력은 `x=(n/8,여섯 인공 nuisance 좌표)`다. 후보 위치·수량과 nuisance를 기존 네 행 교차 설계로 균형화한다. 네 데이터 split의 방향 독립 자극 fingerprint를 실제로 비교해 중복을 검사한다. 수량 oracle은 높은 또는 낮은 수량 규칙을 구조적으로 해결할 수 있어야 하며 nuisance-only 기준은 교차 자료에서 0.5다. 독립 난수 시드만으로 누출이 없다고 가정하지 않는다.

행동 uniform을 조건·이력 사이에 맞춰도 정책 확률이 다르면 선택과 보상은 달라질 수 있다. 실제 선택·받은 보상·갱신 전 확률·입력과 stream 정보를 모두 남긴다. fresh의 1단계 생략이나 head reset이 2단계 RNG 위치를 바꾸면 안 된다. 평가 중 상태·난수 위치·특징 척도·갱신 counter를 바꾸지 않는다.

## 평가와 보조 지표

각 실행 단계의 시행 0·100·200·300·400에서 IID/OOD를 평가한다. 2단계 시행 0은 경계 조작 뒤의 상태이며 1단계 종료와 따로 저장한다. fresh에는 1단계 학습 궤적이 없다. 평가의 `p_target`은 해당 규칙의 정답쪽을 고를 **확률을 사례별 평균한 값**이다. 평가 행동을 새로 뽑은 실측 정답률이나 더 큰 확률만 고르는 greedy 정확도와 구분한다. `p_larger`, `p_smaller`, `p_right`도 보존한다.

greedy 점수는 `|p_right−0.5|<1e−12`면 0.5, 그 밖에는 더 높은 확률의 선택이 정답인지 0/1이다. 초기 head가 0이므로 처음에는 정확히 동률이다.

| 지표 | 계산과 해석 |
|---|---|
| 주 끝점 비용 | H-B의 전체 시드 `fresh_low−high_to_low` phase2 최종 IID 확률 |
| 1단계 습득 | 현재 1단계 규칙 최종 IID `≥.75`와 단계 시작 대비 gain `≥.15` |
| fresh low 습득 | phase2 최종 IID `≥.75`와 시작 대비 gain `≥.15` |
| 2단계 목표 기준 | 각 이력 phase2 최종 IID 낮은 수량 확률 `≥.75` |
| 습득을 확인한 수정·유지 | 사전 학습 이력에는 1단계 습득과 2단계 목표 기준을 모두 요구; fresh에는 fresh low 습득 요구 |
| 회복량 | phase2 최종 `p_small−phase2 trial0 p_small` |
| AUC | 다섯 phase2 checkpoint를 사다리꼴 적분하고 400으로 나눈 값 |
| 최초 관측 목표 도달 | phase2에서 처음 IID 낮은 수량 확률 `≥.75`인 저장 checkpoint; 미도달은 null |
| reset 잔여 효과 | `high_to_low_reset_head−fresh_low` 끝점(양수면 reset 이후 더 높은 확률), AUC·단계 시작 성적과 내부/출력 변화 |
| 같은 규칙 반복 | `low_to_low`의 phase1/phase2 성적과 총 예산800에서의 유지·변화 |
| OOD | 인공 nuisance 분포 이동 성적; IID와 별도 보고 |

사전 학습 이력의 2단계에는 추가 15%포인트 gain을 성공 조건으로 요구하지 않는다. 특히 `low_to_low`는 이미 높은 출발점으로 gain이 작을 수 있다. phase1 습득을 확인한 뒤 목표 확률 .75를 유지하는지 본다. 높은 규칙을 충분히 습득하지 못한 채 낮은 규칙 끝점만 좋은 경우를 ‘습득한 규칙의 수정’으로 세지 않는다.

AUC와 최초 관측 도달은 보조다. AUC는 출발 성적 차이를 포함하며 곡선의 절대 높이 요약이다. 반전 뒤 gain이 더 커도 더 낮은 출발점을 회복하는 것일 수 있다. 어떤 지표 하나만으로 학습 능력 자체가 느려졌거나 내부 학습 간섭이 독립적으로 발견됐다고 결론내리지 않는다. 100시행 간격 최초 관측값으로 1–99시행의 실제 최초 도달 또는 지속 성공을 추정하지 않는다. 반복·reset·OOD·모델 간 차이를 주 기준의 대체로 쓰지 않는다.

## 행동 평균 갱신 참조: 별도 기술 계산

선형 모델에만 **현재 상태에서 행동 선택을 평균낸 갱신식**을 반복하는 참조를 별도로 계산한다. 정답이 오른쪽이면 `y=1`, 왼쪽이면 `y=0`에서 이 결정적 보상 구조는 다음 자체 대수식이 성립한다.

`E_action[(a−p)(r−.5) | current_head,input,y] = (2y−1)p(1−p)`

참조는 같은 7차원 특징·고정 `g`·초기 0 head·학습률·train stream·네 이력을 사용하고 매 시행 `head←head+.1(2y−1)p(1−p)Δφ`를 반복한다. 같은 경계 head reset을 적용한다. 라벨에 해당하는 현재 정답쪽 `y`를 참조 계산이 직접 받으므로 **보상 학습자와 같은 정보·자원의 독립 대조 모델이 아니다.** 별도 학습 성공 조건을 두지 않는다. 실제 stochastic 보상 궤적이나 teacher 점수에 적합하지 않는다.

이 반복식은 그 시점의 **참조 자신의 상태**에서 조건부 행동 기대갱신을 적용한다. 비선형 확률 때문에 `E[update(random_head)]`와 `update(E[random_head])`는 일반적으로 같지 않다. 따라서 참조 head·확률 곡선을 모든 확률적 학습 실행의 정확한 기대값, 동일한 seed ensemble 평균 또는 닫힌 형태 해라고 부르지 않는다. 10개 시드의 입력·척도도 다르므로 그 평균 역시 동일 입력에서 행동만 반복한 ensemble가 아니다.

각 시드·이력에서 phase2 다섯 checkpoint의 실제 선형 IID/OOD 확률과 참조값 및 차이·절대오차를 남긴다. primary summary의 `reference_comparisons`는 IID 확률과 부호 있는 차이를 기록한다. OOD·절대오차·개별경로 평균절대오차는 전체 checkpoint·curve 원자료에서 계산하여 파생 `reference_comparison.csv`와 `analysis_summary.json`에 보존한다. 전체 시드 평균 곡선의 차이도 별도 기술 보고하고 개별 경로 절대오차와 혼동하지 않는다. 성공 임계값·새 주 가설·참조 성능에 따른 예산 변경은 없다. 참조는 `10×(400+800+800+800)=28,000`번의 결정적 기술 갱신이며 **196,000 실제 선택·보상 갱신과 별도 집계**한다.

`p(1−p)`가 0.5 부근에서 크고 확신한 정책에서 작다는 수학적 성질은 계산적 대안 설명이다. raw margin, phase2 시작 성적, `p(1−p)`, 실제 갱신 크기와 참조 곡선을 함께 보여 준다. raw margin은 별도 primary field가 아니라 저장한 전체 입력·encoder·연결·내부/출력 가중치·고정 척도에서 학습 없이 복원하는 파생값이며 primary 사례 확률과의 일치를 검사한다. 참조와 실제 곡선이 비슷해도 원인을 완전히 입증하거나 인간·초파리 신경 기작을 확인한 것은 아니다. 차이가 크면 유한 행동 경로·nuisance·비선형 상태와 근사 한계를 기록한다.

## 실행 전 동결과 독립 검산

이번 설정·프로토콜·배경, 전체 Python 소스, 원자료 projection·manifest·license와 환경 잠금 파일을 새 등록의 해시로 동결한다. source commit과 등록 commit을 비공개 원격에 먼저 보존하고 원격 byte 해시·UTC 시간을 확인한 뒤 주요 실행을 시작한다. 새 결과 경로를 배타 생성하며 이전 결과를 덮어쓰지 않는다. 해시·환경·실행 시작/종료 시간·dirty 상태·전 시드와 이력·counter·모델 자원을 남긴다.

자동 테스트는 제로 head·1단계 TRAIN-only 고정 척도·단계별 자료/행동 난수·4이력 예산·high-prefix 동일성·reset 허용 상태·선형/고정 reset=fresh·평가 상태 비변경·누출·H-B 경계·실패 보존·기술 기대참조의 식과 집계를 검사한다.

독립 검산은 producer 학습 클래스·정규화·요약·기대참조 함수를 호출하지 않고 별도 산술로 모든 초기 특징 척도, 실제 선택·보상·head/내부 갱신, checkpoint 활성·확률·raw margin, 기술 참조 경로, 주/보조 판정을 재구성한다. 원자료 해시, 분할 fingerprints, family와 history coverage·counter·공통 stream, prefix 동일성, reset 전후 허용된 변화와 고정 reset=fresh를 검증한다. NaN·누출·해시 불일치·재배선 불변량 위반·허용하지 않은 상태변화는 무결성 실패다. 과학적 성공 기준과 구분하여 원기록을 보존한다.

별도 `study-bandit-reversal-v1` 태그 checkout에서 README의 잠금 환경을 설치하고 존재하지 않는 새 결과 경로로 재현한다.

## 반증·해석 수준과 인간 비교

H-B 미지지면 이 입력·척도·400시행에서 주 끝점 비용 기준을 충족하지 못한 결과다. 반전이 언제나 쉽다거나 모든 간섭이 없다는 결론은 아니다. 지지되면 이전 반대 선택 경험 이후 고정 예산의 낮은 규칙 끝점 비용이 단순 정책에서도 나타날 수 있다는 결과다. 단순 모델에는 학습 가능한 내부 시냅스가 없으므로 그 결과를 복잡한 뇌 회로의 내부 간섭 증거로 확대하지 않는다. head reset 또는 기술 참조의 설명 범위를 함께 보고 차이와 실패도 보존한다.

인공 입력에서 경험에 따른 head·내부·출력 변화는 Level 2다. 이번 새 수량 일반화는 실행하지 않으므로 새 수량의 Level 3 결과를 만들지 않는다. 습득 뒤 nuisance OOD 반응은 제한된 인공 분포 이동 진단이다. 실제 초파리·인간 자료의 정량 비교 Level 4와 관련 신경 기작 Level 5를 주장하지 않는다. 계산 시드는 생물학적 개체나 인간 참가자가 아니다. decay·생리 시간이 없는 이 모델에서 학습 이력 효과를 자연 망각으로 부르지 않는다.

인간 기초 학습과 수학 학습에 연결할 장기 목표는 유지한다. 비교 후보는 새 규칙을 처음 배우는 경우 대비 반대 규칙 경험 후의 **출발 선택 편향·고정 예산 끝점 차이·회복량·기준 도달·오류 방향**이다. 인간 자료에서도 피드백·훈련량·출발 수행과 확률/실측 선택 지표를 확인해야 한다. 현재 확보한 인간 공개 자료는 전후 요약이며 이번 시행별 반전 stream에 대응하지 않는다. 새 인간 실험·수학 교육 효과·같은 신경 기작에 관한 주장을 하지 않는다. [인간 학습 비교 체계](human-learning-comparison.md)에 따라 대응 가능한 기존 원자료가 확보되면 별도 가설과 지표로 등록한다.

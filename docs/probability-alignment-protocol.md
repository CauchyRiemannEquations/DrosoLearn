## 공통 안전 영역과 다섯 후보

각 후보 방향 w의 영역은 다음으로 동일하다.

```text
||w||_2 <= 1
(k[i]*k[j]*D[j]) @ w >= 0       j=0,1,2,3
```

관측 부호가 네 칸 모두 있어 자기와 다른 세 목적지를 모두 안전 조건에 넣는다. 안전 범위를
넓히거나 정답을 더 제공해 특정 후보를 유리하게 만들지 않는다. 같은 단위 상한은 같은
실제 처리 비용이나 새로운 학습 궤적의 누적 비용을 뜻하지 않는다.

1. **B:** 부모가 이 시행에 실제 사용한 기존 균형 방향. 저장된 방향과 최적성 증거를 사용한다.
2. **I:** 부모 고정 특징의 isolated 방향. 다른 입력을0으로 억제하는 참고이며, 모든 안전
   방향 중 자기 점수가 가장 큰 방향이라고 일반화하지 않는다.
3. **W:** 고정 `normalize(.75*I+.25*B)` 방향. 비율 탐색이나 새 혼합 학습은 하지 않는다.
4. **U:** 네 입력의 정답 정렬 점수 평균을 균등하게 최대화하는 새 방향.
5. **P:** 현재 네 입력의 정답 확률의 일차 변화가 가장 커지는 새 방향.

부모 B의 도움 집합은 `H={j!=i: k[i]*k[j]*(D[i]@D[j])>1e-8}`이다. H가 있으면
`c_B=.5*D[i]+.5*mean(k[i]*k[j]*D[j],j in H)`, 비면 `c_B=D[i]`다.
이 선택된 도움 평균과 보고서의 다른 세 입력 전체의 확률 기여를 동일 지표로 취급하지 않는다.
H와 그 크기·목적 벡터를 기록해 지표 차이를 확인한다.

U와 P는 같은 안전 영역에서 다음의 선형 목적을 각각 최대화한다.

```text
c_U = k[i]/4 * sum_j k[j]*D[j]
c_P = k[i]/4 * sum_j k[j]*p[j]*(1-p[j])*D[j]
```

P에는 현재 source만 아니라 네 입력의 **수정 전** 확률을 사용한다. U는 전체 네 입력을
균등하게 보는 목적 대조이며, P−U가 현재 확률 민감도를 반영한 차이를 보여준다.
B−U 비교는 원래 선택된 도움 목적과 전체 평가 목적의 차이를 살피는 보완 비교다.
W와 I는 이번 고정 상태에서의 참고이며 원래 다른 정책이 실제 학습한 성적이 아니다.

## 선형 최적성, 실제 확률 변화, clipping

정확한 네 입력 평균 정답 확률 증분은 다음 원식으로 평가한다.

```text
F(w) = mean_j y[j]*(sigmoid(z[j]+g*(D[j]@w))-sigmoid(z[j]))
```

sigmoid는 부모의±40clipping을 유지한다. 평가용 y는 실제 획득 부호와 대조하지만 새 목적
선택기의 숨은 정답으로 사용하지 않는다. 현재 실제 Go의 g 부호는 k[i]와 같으므로
`|g|*c_P@w`는 수정 전의 전체 정답 확률 일차 증분이다.

이 미분 해석을 위해 모든 대상의 네 수정 전 logit에 **|z[j]|<40**을 요구한다.
한 대상이라도 벗어나면 실패를 기록하고 해석을 중단한다. 대상을 사후 삭제하거나
미분식을 바꾸는 fallback을 쓰지 않는다. 현재점의 내부 조건과 후보 수정 후 실제 clipping
계산을 구분하며, 실제 F는 언제나 원 비선형 식으로 구한다.

U/P에는 비음수 쌍대 승수·안전 제약·단위 길이·달성 목적과 상한의 일치를 검산하는
선형 전역 최적성 증거를 남긴다. 따라서 P의 일차 목적이 다른 가능한 방향보다 작지
않은 것은 **예상되는 무결성 항목**이다. 이를 새 행동 발견이나 실제 F의 전역 최적성으로
부르지 않는다. 유한한 한 번의 수정에서의 F(P)−F(B), F(P)−F(U)는 별도로 측정한다.
선형 예측과 실제 변화의 차이·부호 반전을 숨기지 않는다.

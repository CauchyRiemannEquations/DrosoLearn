# 후속 연구 종합·한계·재현 확인과 범위 종료 계획

연구 ID는 `followup_closure_v1`이다. 2026-10-21 사용자의 후속 종합·한계 정리·재현 확인·프로젝트 마무리 요청에 따른다. 기준선은 `objective-pathways-v1`, commit `beec7eb421b4574231f74ea0b2ede4dbc99e1ecc`다.

## 쉽게 설명하면

지금까지의 후속 작업은 “한 문제를 고치면 다른 문제에 어떤 영향이 번지는가”, “그 번짐을 막는 데 어떤 계산과 수정량이 드는가”를 좁혀 온 과정이다. 이번에는 새 성적을 만들지 않고, 그 과정에서 확인한 것과 실패한 가설을 한 권의 끝맺음 보고서로 묶는다.

종료는 수학 학습 성공을 선언하는 것이 아니다. 현재 승인된 계산 연구의 결과·한계·실행 증거가 완결됐다는 뜻이다. 충분한 습득·새 문제 일반화·인간 유사성·생물학적 기작에 대해 남은 질문은 미해결인 그대로 보존한다. 좋은 성적이 나올 때까지 시드·예산·방법을 자동으로 늘리지 않는다.

## 기존 자료를 안 시점과 연구 범위

원 Phase 5의 첫 종합은 2026-10-19에 완료됐다. 그 보고서는 28개 이전 연구·25개 주장·60개 원 관측의 연결을 보존했다. 이번에는 그 파일을 수정하지 않고, **그 뒤의 17개 별도 후속 등록**을 추가 종합한다.

17개에는 새 실제 학습 등록 8개와 이미 저장된 경로를 분석한 등록 9개가 있다. 후자는 일부가 같은 원 경로를 여러 번 분석한 것이므로 독립적인 학습 실험 17회로 읽지 않는다. 당시 방향 최적화를 수행한 저장 분석과 당시 새 실제 학습을 구분하며, 이번 종합에서는 양쪽 모두 다시 수행하지 않는다. `17101..17110`부터 `17801..17810`까지 여덟 코호트의 시드는 계산 초기값이며 인간이나 동물 개체가 아니다.

다음 순서를 고정한다.

1. 표현·갱신 영향 분리 `representation_update_v1`.
2. 같은 이동량 상한 `update_budget_v1`.
3. 부분 번짐 절충 `spillover_tradeoff_v1`.
4. 도움·방해 부호 장부 `signed_spillover_v1`.
5. 획득 보상에 따른 선택 억제 `selective_spillover_v1`.
6. 정규화 약화 `normalization_loss_v1`.
7. 안전 방향 기하 `cone_frontier_v1`.
8. 균형 방향의 실제 학습 `balanced_learning_v1`.
9. 균형 실제 경로 `balanced_pathways_v1`.
10. 초반 보호 뒤 전환 실제 학습 `gated_learning_v1`.
11. 전환 전후 경로 `gated_pathways_v1`.
12. 전환 상태·크기·방향 배분 `gated_factors_v1`.
13. 자기 우선 혼합 실제 학습 `self_blend_learning_v1`.
14. 혼합의 자기 회복·도움 손실 배분 `self_blend_factors_v1`.
15. 같은 저장 상태의 전체 목표·현재 확률 정렬 `probability_alignment_v1`.
16. U/P의 실제 학습 `objective_learning_v1`.
17. U/P 실제 경로의 상태·크기·방향·선택/보상 장부 `objective_pathways_v1`.

이 연구들의 결과와 실패를 이미 알고 이번 종합을 설계했다. 새로운 눈가림 가설 검정·효과 검정·메타분석이라고 부르지 않는다. 각 코호트가 다르므로 서로 다른 등록의 최종 평균을 하나의 공정한 성능 순위로 나열하지 않는다. 공유한 시험을 연구별로 합쳐 전체 고유 시험 수로 주장하지 않는다.

## 고정 증거 장부

설정은 `configs/followup_closure_v1.json`, 알려진 원 관측의 선택 목록은 `configs/followup_closure_evidence_v1.json`이다. 증거 목록은 17개 연구의 ID·완료 태그/커밋·최초 소스 커밋·등록·원 산출물·독립 검산·보존 감사·프로토콜·읽기용 결과·재현 문서와 코호트를 직접 가리킨다.

장부에는 24개 범위가 제한된 주장과 그 근거인 원 JSON 참조 80개를 고정한다. 같은 파일/필드를 다른 주장에서 다시 쓸 수 있으므로 이를 80개 독립 증거라고 부르지 않는다. 연구별 가설/산술 판정 관측 66개도 별도 원문 객체나 원문 boolean으로 보존한다. 산술 검사 통과와 과학 가설 지지는 다른 칸이다.

참조는 RFC 6901 JSON Pointer다. `file`은 저장소 기준 고정 상대 경로, `pointer`는 원 JSON 값의 위치, `expected`는 이미 게시된 값의 원 타입을 유지한 리터럴이다. 문자열의 `~`/`/`는 각각 `~0`/`~1`로 해석한다. 존재하지 않는 필드·잘못된 리스트 주소·임의 타입 변환을 거부한다. `true`를 숫자 1로 바꾸거나 `null`을 0으로 채우지 않는다.

주장 상태는 `supported`, `not_supported`, `not_assessable`, `descriptive`, `untested`로 구분한다. Level 1–5는 원 요청에서 정한 주장의 해석 수준이다. 음성 Level 3/4/5 칸은 그 수준의 양성 성과를 달성했다는 뜻이 아니다. Level 0은 출처·산술 장부처럼 그 양성 인지 주장을 하지 않는 보조 표기다.

각 주장은 원 다섯 질문 중 하나에 연결한다. 후속 연구가 주로 출력 갱신과 학습 과정에 관한 것이라는 이유로 인간 비교와 일반화의 미해결 칸을 종합에서 없애지 않는다.

## 기존 첫 종합과 닫힌 조건 보존

보존 앵커는 여섯 묶음이다. 원 Phase 5의 요약·검산·보고서, DrosoMem 원 저장소 감사와 그래프 출처, 수정된 인간 조개 비교의 요약·검산·오류 이력, 원 패턴 과제의 습득 후 일반화 조건, 원 간섭·순서 과제의 개별/공동 습득 조건, 문헌·인간 비교 체계·원 한계 문서다.

다음 판정을 바꾸지 않는다.

- 원 패턴 주 모델의 습득 미달과 일반화 `not_assessable_without_acquisition`.
- 원 간섭·순서 과제의 자격 미달과 확증 판정 `not_assessable`.
- 공개 인간 조개 비교의 주 행동 유사성·종합 예측 미지지, 원 난수 주소 오류와 별도 수정의 구분.
- DrosoMem M11의 습득·전이 기준 미달과 원 저장소 불변.
- 생물학적 시각 수량/LC11 입력·DAN 동역학·공통 신경 기작·교육 효과의 미검증.

획득 보상 부호 기억·출력 계수·내부 시냅스·같은 입력의 활성 상태를 구별한다. 후속의 출력 계수 학습을 초파리 내부 시냅스 가소성으로 바꾸지 않는다. 일부 과거 내부 갱신 실험의 결과도 이번 후속이 새로 반복한 것처럼 쓰지 않는다.

## 동결과 실행 순서

새 소스·설정·이 프로토콜·증거 목록·실제 소비하는 원 자료/검산/보존 문서의 SHA-256을 고정한다. 새 종합 자체의 검사에는 원 과학 데이터를 새로 생성하지 않는 작은 허구 JSON·태그·파일 예제만 쓴다. 새 집계 전에 기준선의 기존 Git blob 원 바이트 보존을 확인한다. 원 학습·실패·등록·원 결과의 내용은 바꾸지 않는다. `README.md`, `docs/research-roadmap.md`, `docs/repository-status.json` 세 상태 인덱스만 새 완료 문서를 안내할 수 있다.

소스 커밋과 등록 `results/registration_followup_closure_v1.json`을 먼저 저장한다. 비공개 원격의 같은 등록 bytes를 확인한 증거 `results/followup_closure_publication_proof.json`의 시각이 첫 새 종합 및 아래 재검산보다 앞서야 한다. 실행 전 가설을 새로 세우거나 성공 문턱·시드를 바꾸는 연구가 아니며, 알려진 증거 연결의 규칙을 먼저 고정하는 과정이다.

산출물은 별도 `results/followup_closure_v1`과 새 문서 경로를 쓴다. 기존 완료 폴더를 덮어쓰지 않는다. 새 소스·원 입력·설정의 불변, 정확한 리터럴·분모·판정, 태그와 원 자료/검산의 연결, 모든 고정 연구/주장/앵커의 빠짐없는 포함이 이번 종합의 통과 기준이다. 과학 가설이 지지돼야 통과하는 기준이 아니다. 오류가 생기면 원 진단을 보존하고 과학 기준 미달과 무결성 실패를 나누어 해결한다.

## 재현 확인의 실제 범위

모든 17개 후속의 원 설정·코드·태그·입력/산출물 해시·게시 증거·독립 검산·보존 감사와 이전 실패 원문을 연결해 확인한다. 같은 환경에서 17개 학습을 전부 다시 실행했다는 주장은 하지 않는다. 완료 원 결과의 전체 산술 검산 통과 증거는 해시 고정한 원 영수증으로 재사용한다.

별도로 최신 `objective_pathways_v1`의 **저장 자료만 읽는 독립 검산**을 한 번 실행한다. `scripts/verify_objective_pathways.py`의 원 버전과 다음 원 설정/입력을 고정한다. 출력은 기존 영수증을 덮어쓰지 않는 `results/followup_closure_reproduction_v1/objective_pathways_reverification.json`이다.

```powershell
python scripts/verify_objective_pathways.py --config configs/objective_pathways_v1.json --registration results/registration_objective_pathways_v1.json --result-dir results/objective_pathways_v1 --publication-proof results/objective_pathways_publication_proof.json --out results/followup_closure_reproduction_v1/objective_pathways_reverification.json
```

이 재검산은 새 학습·선택 생성·그래프/특징 구성·난수·방향 최적화가 0회인 저장 산술이다. 원 192,000시행의 선택·보상·기억·출력 prefix·16개 저장 배열·2,160행·기존 경로와 요약의 항등식을 별도 코드로 다시 대조하는 것이다. 기존 실제 학습의 그래프/코호트 생성과 방향 최적화를 다시 수행한 것으로 표현하지 않는다. 재검산의 새 실행 시각과 원 해시, 실제 확인한 수를 기록한다.

원 실행의 종합/독립 검사와 별도로 이번 종합 생산 코드를 import하지 않는 독립 검산자가 17개 고정 레코드와 24개 주장, 원 JSON 참조 80개, 연구별 원 판정·태그·환경·무결성 연결을 다시 확인한다. 새 종합의 고유 시험 수만 별도로 보고하고 원 연구의 시험 수를 중복 합산하지 않는다.

## 종료 보고서의 내용과 완료 조건

읽기용 최종 보고서, 주장/원값 부록, 별도 한계 정리, 재현 안내와 종료 상태를 새 경로에 남긴다. 문헌의 실제 관찰과 모델 가정을 구분하며 기존 문헌 검토의 접근 범위도 보존한다. 이번 작업은 새로운 체계적 최신 문헌 고찰이 아니다.

종합의 핵심은 다음을 함께 남기는 것이다. 더 큰 이동·계산을 허용한 출력 분리는 연습 습득을 개선했으나 같은 이동 상한의 주 조건은 충분한 습득에 이르지 못했다. 도움과 방해를 따로 관찰할 수 있었고 보호는 구현할 수 있었지만 보호가 충분한 학습이나 새 문제 일반화와 같지는 않았다. 정적 방향의 작은 이득이 실제 선택·보상 경로의 최종 성적 개선으로 그대로 이어지지 않았다. 이 과정에서 얻은 계산 모델의 제약을 인간이나 초파리의 학습 불가능성으로 바꾸지 않는다.

완료는 새 종합·한계·재현 확인·독립 검산·보존 감사·비공개 저장소의 완료 커밋/태그가 서로 연결되고 기존 완료 바이트가 보존된 때다. 현재 승인 범위를 완료로 표시하되 장기 질문은 별도로 남긴다. 자동 반복은 꺼진 상태/PAUSED로 유지하고, 새로운 일반화·간섭·시각 회로·인간 연구를 시작하지 않는다.

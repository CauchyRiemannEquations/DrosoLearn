# 전체 평가 목적과 상태 가중 목적을 실제 학습에 적용하는 실험

작성일: 2026-10-21 (Asia/Seoul). 연구 ID는 `objective_learning_v1`이다.
완료 기준선은 `probability-alignment-v1`, commit
`9159aa764d44183c21468974ba3b0f208d676731`이다. 기존 소스·원자료·설정·실패를
보존하고 새 프로토콜·설정·소스·입력·검사를 해시 동결한다. 비공개 원격의 동일 bytes를
확인한 뒤 새 시드의 첫 그래프/특징 구성과 실제 학습을 시작한다.

## 쉽게 설명하면

앞선 분석에서는 과거의 같은 순간에서 수정 방향만 바꿔 계산했다. 네 연습 문제 전체를
목표로 삼은U와 현재 정답 확률이 잘 변하는 문제를 더 고려한P가 단일 수정의 평균을
조금 높였다. 그러나 그 값을 더한다고 새로운 학습의 최종 성적이 되는 것은 아니었다.

이번에는 두 규칙을 실제 학습에 넣는다. 모델이 직접 선택하고 보상을 얻으며 자신의 답을
고친다. U는 네 문제를 고르게 고려하고, P는 **그때그때 자신의 현재 상태**를 함께 본다.
이후의 상태와 선택도 달라지므로 실제 기록 전체를 새로 비교한다.

초반에는 다른 문제로 번짐을 막고, 네 문제의 보상 부호를 모두 직접 얻은 다음 시행부터
U 또는 P로 전환한다. 수정량 상한은 모든 대조와 같게 두고, 아직 보상을 모르는 다른
입력에 준 방해도 함께 센다. 더 좋은 성적이나 충분한 습득이 나올 것으로 미리 가정하지 않는다.

## 선행 근거와 별도 새 집단

부모 저장 분석의 real/raw에서 U−B의 평균 단일 수정 전체 증분은 약+0.00120739%p,
P−U는 약+0.0000389332%p였다. 자기 수정과 도움의 절충은 남아 있었다. P의 선형
최적성은 이미 수학적으로 예상되는 검사였고, 실제 유한 증분이 언제나 더 크지도 않았다.
이 결과를 새로운 학습 효과나 일반화의 증거로 바꾸지 않는다.

부모의 충분한 습득·실용 개선 미지지, 주 조건 습득0/10과 설계상 미관측 보호 통과를

사용한다. 이전 시드를 교체하거나 같은 실패의 예산을 연장하는 실험이 아니다.

세 배선 `real, rewired, ann`, 두 표현 `raw, identity`, 여덟 방법과10계산 시드에서

계산 시드는 초파리 또는 인간의 개체가 아니다.

## 입력과 여덟 방법

입력은 인공 전체 문자열 `ABAB, BABA, ABBA, BAAB`, 실제 Go 보상 부호는
`+1,+1,−1,−1`이다. NoGo 획득 보상은0이며 숨은 Go 부호를 알려주지 않는다.
모든 입력을 연습한다. 아직 보상 부호를 얻지 못한 연습 입력을 미관측이라고 부르며,
새로운 입력·규칙으로의 일반화와 구별한다.

방법 순서는 다음으로 고정한다.

1. `shared`: 기존 공유 방향.
2. `isolated`: 다른 입력 영향을 억제하는 분리 방향I.
3. `feedback_selective`: 실제 관측 부호에 따라 방해를 막는 기존 방식.
4. `balanced`: 처음부터 기존 균형 목적B를 사용하는 방식.
5. `gated_balanced`: 초반I, 모두 관측한 뒤 기존B.
6. `gated_self_blend`: 초반I, 모두 관측한 뒤 고정3:1혼합.
7. `gated_uniform`: 초반I, 모두 관측한 뒤 전체 균등 목적U.
8. `gated_probability`: 초반I, 모두 관측한 뒤 현재 상태 가중 목적P.

기존 여섯 대조도 이번 새 시드에서 실행한다. 이전 완료 결과를 새 대조로 가져오지 않는다.
같은 시드의 모든 방법이 네 입력 순열로 된 입력 순서와 공통 균등 난수를 공유한다.
각 방법 자신의 Go 확률이 다르면 같은 난수에서도 선택은 달라질 수 있다.

모델의 고정 내부 가중치·인코더·같은 입력의 활성과 학습되는 출력 계수, 별도 획득 보상
기억을 구분해 기록한다. 출력 정책이 보상 기억 표를 직접 정답으로 조회하는 지름길은
허용하지 않는다. 실제 생물학적 내부 시냅스 가소성이나 LC11/DAN 경로를 추가한 실험이 아니다.

## 피드백 전 기억으로 정하는 전환

새 두 방법의 전환 판단은 현재 피드백 전 `known_before` 네 칸이 모두 채워졌는지다.
마지막 부호를 처음 얻은 시행 역시I를 사용한다. 다음 시행부터U/P모드를 기록하며,
최초 전환 시행이NoGo이면 전환 사건만 한 번 기록하고 출력 수정·새 최적화는0회다.

전환 전에는 I·기존gated·3:1혼합·U·P의 다섯 경로가 같은 입력·난수·확률에서 시작한다.
네 번째 발견 시행까지 행동·기억·출력 계수와 관련 기록의 bytes가 같은지 확인한다.
전환 후에는 각자 자신의 상태에서 실제 선택을 이어가며 같다고 가정하지 않는다.

이전에 관측한 입력의 새 실제Go 보상은 같은 부호여야 한다. NoGo로는 기억을 쓰지 않고
관측하지 않은 부호를 추론하지 않는다. P는 full상태NoGo에서도 목적/solver를 계산하지 않는다.
반복 보상만으로 미관측 칸을 채우거나 전환을 앞당길 수 없다. 모순 보상과 잘못된
행동/보상 조합은 상태를 바꾸기 전에 거절한다.

## 자신의 상태에서 구하는 정확한U/P

D는 처음 고정한 네 입력의 단위 특징 행렬, k는 실제 획득 부호, i는 현재source다.
새 방향을 구하는 실제Go에서는 네 부호가 모두 알려져 있다. 공통 안전 영역은 다음이다.

```text
||w||_2 <= 1
(k[i]*k[j]*D[j]) @ w >= 0       j=0,1,2,3
```

U는 `c_U@w`, P는 `c_P@w`를 이 영역에서 최대화한다.

```text
z = D @ 자신의 실제 현재 출력 계수
p[j] = sigmoid(z[j])
c_U = k[i]/4 * sum_j k[j]*D[j]
c_P = k[i]/4 * sum_j k[j]*p[j]*(1-p[j])*D[j]
g = .1*(실제 행동 - 자신의 현재 p[i])*획득 보상
새 출력 계수 = 이전 출력 계수 + g*w
```

P는 이전 B저장 경로나 다른 방법의z·g를 재사용하지 않는다. 현재 네 출력 확률과
직접 관측한 네 부호만 사용한다. 평가용 참 부호는 방향 선택기나 학습자에 전달하지 않는다.
Go 확률과 정답 확률의 민감도는 p(1−p)로 같지만, 실제 수정의 부호는 k[i]와g로
정확히 반영해야 한다. 1/4정규화를 고정한다.

U의 고정 특징·source·관측 부호 문제는 같은 경로 안에서 캐시한다. P는 매 full실제Go의
수정 전 상태에서 새 목적과 증거를 남기며 이전 상태의 방향을 고정 캐시하지 않는다.
비율·학습률·목적 종류를 탐색하지 않는다. 기존 여섯 방법의 동작은 그대로 재사용한다.

P의 미분 해석을 위해 매 적용 대상의 네 수정 전 logit 모두에 `|z[j]|<40`을 요구한다.
위반하면 실패를 기록하고 실행/해석을 중단한다. 해당 시행을 삭제하거나 다른 방향으로
대체하지 않는다. 실제 선택 확률과 유한 수정 변화는 기존±40clipping sigmoid로 계산한다.

U/P의 각 새 방향에 안전성·단위 길이·비음수 승수·쌍대 상한·달성 목적과 상한 일치의
전역 선형 인증을 남긴다. P의 자기 현재점 일차 최적성은 무결성 항목이며, 미래 성적·
유한 확률 증분의 전역 최적성·다른 경로보다 매번 높은 성적을 보장하지 않는다.

## 같은 수정량 상한과 실제 비용

모든 방법의 학습률은0.1, 한 번 출력 계수 수정 길이는0.1 이하, 400시행 누적 길이는40
이하, 길이 제곱합은4 이하로 고정한다. 최종 출력 계수 길이는 누적 경로를 넘을 수 없다.
실제 수정 길이는 `abs(g)*||w||`이며 단위 방향과g를 구분한다.

같은 상한은 실제Go횟수·누적 길이·최적화/기억 처리 비용을 같게 맞췄다는 뜻이 아니다.
매 시행의 실제 길이·제곱합·누적 경로, 방향 요청·유일 최적화 문제·메모리 관측·전환 시점을
남긴다. U캐시 재사용과 P매시행 새 최적화의 비용 차이도 공개한다. 계산 비용 우월성을
학습 성적 우월성으로 대체하지 않는다.

방향 mode0..3은 기존 공유·분리·선택·균형, mode4는 기존 혼합, mode5/6은새U/P다.
새 두 방법은1에서 각각5/6으로만 전환한다. `first_uniform_mode_trials`와
`first_probability_mode_trials`는 해당 방법의 최초 완전 관측 모드 시행을 기록하며
다른 방법과 미전환 경로의 sentinel은401이다. 최초 모드가NoGo인 경우도 전환 시행은
기록하되 실제Go 적용 횟수와 구별한다.

## 주 조건과 독립된 사전 가설

주 조건은 real/raw의 U와P 두 새 방법이다. 아래 가설은 각 방법별로 독립 판정한다.
다른 다섯 배선·표현은 사전에 정한 대조/기술 결과이며 유리한 조건으로 주 판정을 바꾸지 않는다.
시드 평균은 같은 시드의 짝 차이를 구한 뒤10시드를 같은 비중으로 평균한다.

**H_gain(U), H_gain(P): 실용 개선.** 새 방법의 최종 네 연습 입력 평균 정답 선택
확률이 `gated_balanced, isolated, gated_self_blend` 각각보다 평균5%p 이상 높고,
각 비교에서10시드 중 적어도8개의 차이가 양수여야 한다. 세 비교 모두 통과해야 그
방법의 가설을 지지한다. 일부 대조만 이기거나 작은 평균 차이만으로 대신하지 않는다.

**H_acquisition(U), H_acquisition(P): 충분한 습득.** 한 시드에서 최종 평균0.80 이상,
초기 대비0.25 이상 향상, 양성·음성 두 클래스 각각0.70 이상을 모두 만족해야 한다.
10시드 중 적어도8개가 통과해야 지지다. H_gain과 독립이며, 미지지 때 새 입력 일반화가
성립한 것으로 넘어가지 않는다. 같은 네 입력의 반복 연습 평가는 일반화 검사가 아니다.

**H_protection(U), H_protection(P): 미관측 다른 연습 입력의 운영상 보호.**
매 시행의 피드백 전 아직 보상 부호가 없는 다른 목적지에서 정답 선택 확률의 음수 변화
절댓값을400시행 전체에서 합한다. 각 방법의 주 조건10시드 최대 총합이1e-8 이하여야
하며, `gated_balanced` 및 `isolated`와의 방해 총합 차이가 각각 모든10시드에서1e-8
이하여야 한다. 노출당 평균·logit방해·최종 성적%p로 주 지표를 바꾸지 않는다.

source는 현재 시행의 다른 목적지 집합에서 제외하므로 현재 보상으로source를 발견해도
그 시행의 미관측 다른 목적지mask는 바뀌지 않는다. 평가용 참 부호는 방해 계산에만 쓴다.
노출 수·양수 도움·점수 방해도 함께 보존한다. 초반I·완전 관측 뒤 미관측 목적지 없음의
설계상 기대이므로 통과해도 새로운 보호 기작·학습 우수성·집단 동등성의 발견이라고 부르지 않는다.

## 관측 경계와 정확한 혼합 규칙

전환 판단은 **현재 시행의 피드백을 받기 전**의 획득 부호 기억 `known_before`로 한다.
네 칸이 모두 채워지기 전에는 새 방법도 isolated 방향을 쓴다. 네 번째 부호를 처음
얻은 시행 역시 isolated다. 그 다음 시행부터 혼합 모드를 기록하며 최초 시행이 NoGo여도
전환 사건을 한 번 기록한다. NoGo로는 미관측 부호를 얻거나 균형 방향을 계산하지 않는다.

완전 관측 뒤 실제 Go인 시행에서 현재 source i에 대해 다음을 구한다.

```text
I = 기존 isolated 단위 방향
B = 획득 부호만 사용한 기존 balanced 단위 방향
m = 0.75*I + 0.25*B
w = m / ||m||
g = 0.1*(실제 행동 - 현재 Go 확률)*획득 보상
새 출력 계수 = 이전 출력 계수 + g*w
```

B의 목적 함수는 기존의 자기0.5·선택된 도움 평균0.5다. 이번의 0.75/0.25는 이미
계산된 **방향의 혼합 계수**이며 B의 목적 함수 비율을 바꾸는 값이 아니다. 새로운
최적화 목적·비율 탐색·보상 예측기·정답 표 조회·기억 지름길을 추가하지 않는다.

관측 부호로 안전 조건을 만든 기존 B의 각 실제 Go 상태별 인증을 확인하고 캐시한다.
혼합은 B가 이미 있는 그 시행에서만 수행한다. I와 B가 유효한 단위 방향이면
삼각부등식상 `0.5 <= ||m|| <= 1`이라 0으로 나누는 경우가 없다. 실제 수치가 이 범위·
방향 상한·관측 안전 잔차 문턱에 실패하면 실행/해석을 중단한다. 성공하도록 계수를
바꾸거나 실패 방향을 임의 대체하지 않는다.

I가 다른 입력에 주는 영향은 수치 허용 오차 안에서 0이고, B의 관측 목적지 영향은
획득 부호에 정렬했을 때 비음수다. 따라서 정규화된 혼합의 다른 목적지 정렬 점수 영향은
같은 저장 B 방향 영향의 0.25배 이상으로 남는지 검산할 수 있다. 유한 정밀도 잔차를
그대로 기록한다. 이 성질은 **같은 source·같은 정보의 단위 방향 점수**에 대한 것이다.

현재 자기 입력의 영향도 B·I·혼합을 따로 기록한다. 어떤 특징 기하에서도 B보다 자기
영향이 반드시 커진다는 보편적 약속은 하지 않는다. 유효한 안전 B와 같은 단위 방향에서
자기 점수 영향이 I의0.75배 이상이라는 하한도 별도로 검산한다. 이 역시 방향 점수의
하한이며 실제 성적의 하한이 아니다. 특히 새 경로의 g, 확률의 비선형
변환, 실제 선택과 관측 시점이 바뀔 수 있어 ‘자기 성적75% 보존’·‘도움25% 보존’·
‘최종 정확도 개선’을 수학적으로 보장하지 않는다. 실제 수치와 행동 결과로 평가한다.

## 사전 가설과 별도 판정

주 조건은 `real/raw/gated_self_blend`다. 다른 다섯 배선·표현은 사전에 정한
대조/기술 결과이며 유리한 조건으로 주 판정을 바꾸지 않는다.

**H_gain — 실용적인 최종 성적 개선.** 최종 네 연습 입력 평균 정답 선택 확률에서
새 방법이 `gated_balanced, balanced, isolated` 각각보다 평균 **5%p 이상** 높고,
각 비교의 10시드 중 적어도8개에서 차이가 양수여야 한다. 세 비교를 모두 통과해야
지지다. 단지 한 대조보다 약간 높거나 방향 지표가 좋아진 결과로 대체하지 않는다.

**H_acquisition — 충분한 규칙 습득.** 한 시드에서 최종 평균0.80 이상, 초기 대비
0.25 이상 향상, 양성/음성 두 클래스 각각0.70 이상을 모두 만족해야 한다.
10시드 중 적어도8개가 통과해야 지지다. H_gain과 독립 판정하며 미지지 시 새 입력
일반화가 성립했다고 넘어가지 않는다. 모든 입력이 연습 대상인 현재 평가는 일반화가 아니다.

**H_protection — 미관측 다른 입력의 운영상 보호.** 보상 피드백 전 아직 부호를 얻지
못한 다른 연습 입력을 mask로 삼아, 실제 수정 전후 정답 선택 확률의 음수 변화 절댓값을
400시행 전체에서 더한다. 각 시드의 이 총합 최대값이 `1e-8` 이하여야 하며,
새 방법−`gated_balanced`와 새 방법−`isolated`의 방해 총합 차이가 각각 모든10시드에서
`1e-8` 이하여야 한다. 시행별 노출 수로 나눈 평균이나 logit 방해로 주 지표를 바꾸지 않는다.

보호는 초반 isolated·완전 관측 후 미관측 목적지 없음이라는 설계상 기대다. 통과해도
성적 우수성·집단 동등성·더 나은 학습이나 생물학적 기작의 증거로 해석하지 않는다.
평가자의 참 부호는 방해 계산에만 사용하고 방향 선택기에 주지 않는다. source는 그
시행의 다른 목적지 집합에서 제외하므로 현재 피드백 전후의 source 발견이 mask를
그 시행 안에서 뒤바꾸지 않는다. 전체 미관측 노출·양수 도움·점수 방해도 별도로 보존한다.

세 가설은 무결성·정보·안전·비용 문턱과 분리한다. 수치/무결성 실패는 과학적 미지지와
다르게 기록하고 중단한다. 세 가설은 서로 독립이며 성공·실패 모두 보고한다.

## 해석과 후속 경계

이 실험의 단위 방향 도움 하한은 최종 성적의 Pareto 우월성 증명이 아니다. 고정된
한 혼합이 최선의 비율인지도 묻지 않는다. 성공한 시드만 남기거나 실패 뒤 예산을
늘리지 않는다. 개선·충분한 습득·보호를 각각 정해 둔 기준으로 판단한다.

가능한 긍정 결과도 인공 연습 입력을 경험하며 출력 계수가 바뀐 계산적 결과다.
새 생물학적 내부 시냅스 학습·새 입력/규칙 일반화(Level3)·인간 학습의 정량 유사성(Level4)·
동일 신경 기작(Level5)·교육 효과를 새로 주장하지 않는다. 기존 인간 비교 음성 결과·
닫힌 일반화/간섭/순서 조건·Phase5와 모든 완료 원자료·실패를 보존한다. 이 요청의
고정 실험을 마친 뒤 자동 반복을 재개하지 않는다.

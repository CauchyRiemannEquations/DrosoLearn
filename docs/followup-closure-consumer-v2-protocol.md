# 원 인간 요약 형식에 대한 독립 소비자 검사 v2

## 발견과 보존

이번 종합의 첫 독립 검산은 `Original anchor evidence identities`에서 실패했다. 원 `human_shell_rng_v2/summary.json`에는 최상위 `study_id`가 없으며, 원 독립 검산 영수증에는 있다. 원 인간 분석의 생산·검산 코드는 처음부터 이 요약 구조를 사용했다. 새 검사기가 모든 앵커의 요약에 동일 필드가 있다고 가정한 것이 오류다.

실패 출력과 당시 동결 소스·등록·원 산출물은 `results/followup_closure_verification_attempt01.json` 및 대응 ZIP에 보존한다. 실패를 통과로 바꾸어 덮어쓰거나 원 요약에 ID를 새로 넣지 않는다. 원 35소스·253입력·종합 생산 결과·저장 재검산은 그대로 둔다. 기존 267개 자동검사는 통과했지만 이 실제 자료 형식 문제를 놓쳤다는 한계도 남긴다.

## 제한된 수정과 실행 전 동결

새 `followup_closure_consumer_v2`는 추가 독립 검산 소비자이며 새로운 과학 실험이 아니다. 설정·이 계획·추가 검사기·추가 자동검사 네 소스를 별도로 해시 고정·커밋하고 등록을 비공개 원격에 게시한 다음 실행한다. 등록에는 원 소스·기존 결과·실패 원본·인간 앵커의 원 식별 자료 해시를 포함한다. 새 계산 결과를 보기 전에 검사 규칙을 고정하되, 알려진 형식 오류를 수리하는 사후 작업임을 명시한다.

기존 독립 검산기를 해시 확인하여 사용하고 `check_anchors`의 문서 식별 검증만 제한적으로 대체한다. 다른 앵커는 기존의 같은 ID·원 SHA 검사를 그대로 적용한다. 인간 앵커만 정확한 원 경로/스키마와 `study_id`의 부재를 요구한 뒤 다음 연결을 모두 확인한다.

- 원 요약이 완료 상태이며 원 검산 영수증과 산출물 장부의 요약 SHA-256이 현재 바이트와 일치한다.
- 원 등록·메타데이터·검산 영수증의 연구 ID가 `human_shell_rng_v2`이며 등록 SHA와 소스/설정 해시가 일치한다.
- 원 완료 태그 `human-shell-comparison-v2`의 요약·검산·등록·메타데이터·산출물 장부 바이트가 현재와 일치한다.
- 원 인간 생산/검산 코드도 해시 결합하여 원 형식의 근거를 보존한다. 새로운 숫자나 필드를 원 요약에 보충하지 않는다.

이어 원 독립 검사 전체의 17연구·24주장·80원 JSON 참조·2배열·24행10열·전체 요약·개별 태그와 원 판정·등록 및 게시 시각·새 저장 재검산 영수증 비교를 수행한다. ID 확인을 완화하거나 누락한 값에 기본값을 채우는 일반 예외를 허용하지 않는다. 부정확한 경로·SHA·ID·등록·상태·형식이면 실패한다. 인공 자료 자동검사로 이러한 거부 조건과 비인간 앵커의 기존 검사를 확인한 뒤 소스를 고정한다.

## 출력과 실패 기준

첫 결과는 별도 `results/followup_closure_consumer_v2/verification.json`에 독점 생성한다. 원 실패 위치 `results/followup_closure_v1/verification.json`에는 통과 파일을 소급 작성하지 않는다. 완료 후 읽기 전용 재검산은 원본을 바꾸지 않는 저장소 안의 안전한 새 영수증 경로를 `--out`으로 지정할 수 있으며, 기존 파일의 덮어쓰기는 항상 거부한다. 새 영수증은 원 종합 연구 ID를 유지하되 별도 소비자 등록·게시·실패 해시와 수정 범위를 함께 명시한다. 하나라도 불일치하면 최종 종합 완료를 선언하지 않는다.

기존 생산·저장 재검산·학습·난수·그래프·방향 최적화·효과 검정·인간 실험을 다시 실행하지 않는다. 새 검사에서 과학적 성공 기준이나 원 미지지 판정을 바꾸지 않는다. 최초 267시험과 이번 추가 소비자 시험은 구분하여 기록한다. 이 조치는 원 결과의 과학적 우위를 더하는 작업이 아니다.

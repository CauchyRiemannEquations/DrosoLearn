# 보상 관측이 끝날 때까지 번짐을 억제하는 실제 학습

작성일: 2026-10-20 (Asia/Seoul). 연구 ID는 `gated_learning_v1`이다.
완료 기준선은 `balanced-pathways-v1`, commit
`f291f1f22e7ce83a0c836924530ca93e9bc12d33`다. 새 계획·설정·소스·입력 해시를 동결하고
비공개 원격의 게시 원문 bytes를 확인한 뒤 새 계산 시드에서 정해진 한 번의 실험을 실행한다.

## 쉽게 설명하면

앞선 균형 방식은 이미 확인한 문제를 보호하면서 도움을 늘렸지만, 아직 답을 모르는 다른
문제를 초반에 더 방해했다. 이번에는 **처음에는 자기 문제만 고치고, 네 문제의 보상 부호를
모두 실제로 얻은 다음부터 다른 문제에 도움을 주는 균형 방향을 허용한다.**

전환은 모델 자신의 실제 경험 기록으로만 정한다. 평가자가 아는 정답표나 유리한 학습
시점을 미리 알려주지 않는다. 이렇게 하면 모르는 문제의 방해를 막는 동작이 구현되는지,
그 보호가 마지막 성적과 충분한 습득에도 도움이 되는지를 각각 확인할 수 있다.

## 근거·기존 미지지·새 질문

부모 실제 학습의 real/raw 균형 방식은 같은 코호트 선택 억제보다 +0.187%p 높았지만
사전 실용 개선 기준에 미달했고, 충분한 습득도 0/10이었다. 미관측 다른 문제의 누적 확률
방해는 27.91% 늘었다. 후향 장부에서는 초반 기여 −0.119%p, 완전 관측 뒤 +0.306%p가
합쳐져 작은 마지막 차이가 되었다. 주 조건의 발견 시점·미관측 집합은 같았다. 이 근거를
알고 새 전환 규칙을 정했다. 과거 결과를 모르는 독립 발견이라고 주장하지 않는다.

장부는 새로운 학습 개입의 성공을 보장하지 않는다. 새 코호트의 집계는 동결 뒤 처음
수행한다. 이전 실패의 시드·예산·기준·결과는 유지한다. 새 등록에서 실패해도 시드를
바꾸거나 400시행을 연장하거나 전환 문턱을 낮추어 성공으로 만들지 않는다.

## 과제·표현·배선·예산

기존 네 인공 전체 문자열 `ABAB, BABA, ABBA, BAAB`를 모두 연습한다. 앞 두 입력은
Go 선택 시 +1, 뒤 두 입력은 Go 선택 시 −1이다. NoGo 보상은 항상 0이며 숨은 Go 보상
부호나 정답 여부를 알려주지 않는다. 미관측은 이 네 연습 입력 중 보상 부호가 아직 없는
경우이며 새 문자열·새 규칙 일반화가 아니다. 시각 물체의 수량·LC11 회로를 재현한 과제도 아니다.

배선 `real, rewired, ann` × 표현 `raw, identity`의 6조합을 유지한다. 원 catalog와
FlyWire v783 왼쪽 MB 부분 투사·전처리·출처 bytes, 고정 인코더와 모델 생성 규칙은 보존한다.
인공 이름표 표현은 사전 사전(dictionary) 입력이며 정답으로 만들지 않는다. 재배선과 ANN은
실제 초파리의 동일한 생물학적 개체나 모든 특성을 통제한 생물학적 대조가 아니다.

새 계산 시드 **17601..17610**, 조건·시드당 **400시행**, 체크포인트
**0, 50, 100, 200, 400**, 학습률 **0.1**을 고정한다. namespace는 `202610202`다.
입력 순서와 행동 균등 난수는 각각 `SeedSequence([namespace,seed,0])`,
`SeedSequence([namespace,seed,1])`을 쓴다. 입력은 4개를 각 4시행 블록 안에서 한 번씩
섞는다. 동일 시드의 모든 방법·배선·표현에 같은 입력 순서와 균등 난수를 공유하지만 실제
확률·선택·보상·기억·누적 이동량은 달라질 수 있다.

encoder `seed+100000`, 재배선 `seed+110000`, ANN `seed+120000`의 기존 생성 규칙을
유지한다. 이전 코호트 17501..17510의 성적을 새 시드의 짝 대조로 사용하지 않는다.
5방법×6조합×10시드×400시행 = **120,000회 실제 선택·피드백**, 학습자 **300개**,
고정 특징 구성 **60개**, 체크포인트 정적 입력 평가 **6,000개**다.

## 다섯 방법과 실제 보상 기억

방법 순서는 `shared, isolated, feedback_selective, balanced, gated_balanced`다.

1. `shared`: 현재 단위 입력 특징으로 출력 계수를 수정하며 다른 입력으로 번짐을 허용한다.
2. `isolated`: 다른 세 입력의 점수 영향을 억제하는 기존 단위 방향을 사용한다.
3. `feedback_selective`: 실제 관측으로 확인한 방해만 0으로 만들고 나머지 raw 영향의
   비율을 유지한 뒤 단위 길이로 줄인다.
4. `balanced`: 실제 관측된 문제의 안전 조건 안에서 자기 수정과 알려진 기존 도움 평균을
   같은 비중으로 고려하는 동결된 균형 방향이다.
5. `gated_balanced`: 현재 피드백 **직전**의 자기 보상 기록이 네 칸 미만이면 isolated,
   네 칸이면 balanced를 사용한다. 마지막 새 부호를 얻은 시행도 isolated다.

모든 학습자는 4칸 획득 보상 부호 기록을 0으로 시작한다. 실제 Go의 ±1만 현재 source
칸에 기록하고 NoGo 0은 미관측 칸을 채우지 않는다. 같은 부호의 반복 획득은 새 발견이
아니다. 상충하는 관측은 무결성 실패다. 이 별도 기억은 내부 KC→MBON 시냅스가 아니다.

게이트는 **known_before**의 비영 칸 개수를 읽어 먼저 닫힘/열림을 결정한다. 그 뒤 현재
실제 보상을 기록한다. 열린 Go 균형 방향은 자기 실제 known_after만 사용한다. 평가용
정답표는 생성자·전환 판정·방향 선택기에 전달하지 않는다. 선택은 출력 계수로 계산한
sigmoid 확률만 따르며 4칸 기억을 직접 조회해 답을 선택하지 않는다.

전환 뒤 NoGo는 gate가 열려 있어도 g=0·균형 방향 0·solver 생략으로 기록한다. 열린 상태,
실제 비영 출력 갱신, 실제 균형 solver 요청을 같은 횟수로 세지 않는다. 실제 네 칸을 끝까지
얻지 못하면 닫힘을 유지하며 관측을 강제로 채우지 않는다. 최초 완전 관측 시행과 최초
열린 시행을 구분한다. 마지막 시행에 네 칸이 채워지면 첫 열린 시행은 401 sentinel이다.

같은 난수 스트림 아래에서 gated와 isolated는 마지막 새 부호 발견 시행까지 같은 확률·
행동·보상·관측 기억·출력 계수 경로를 가져야 한다. 따라서 최초 완전 관측 시행도 같아야
한다. 이 동일성은 게이트 구현의 무결성 검사이며 나중의 성적 동일성을 요구하지 않는다.

## 균형 목적과 수치 규칙

기존 `balanced`의 관측 기반 원뿔 방향을 변경 없이 재사용한다. 단위 특징 D, source i,
실제 관측 부호 k에 대해 `||w||<=1`이며 모든 관측 목적지 j에서
`k[i]*k[j]*(D[j]@w)>=0`을 요구한다. 같은 공유 영향에서 알려진 도움이 되는 다른
목적지 집합 H를 `k[i]*k[j]*(D[i]@D[j])>1e-8`로 정한다.

H가 있으면 목적은 `.5*D[i]+.5*mean(k[i]*k[j]*D[j], j in H)`이며 없으면 `D[i]`다.
새 가중치나 시점별 목적을 탐색하지 않는다. 실제 Go에서만 계산하고 같은 실제 관측 상태의
방향·쌍대 상한 증거를 캐시로 재사용한다. 과거 평가 정답으로 만든 캐시를 주지 않는다.

행동 난수 전에 고정 특징의 full row rank 4·condition 1e6 이하와 기존 선택 억제의
81부호 상태×4source = 조합당 324방향을 확인한다. 균형 solver는 실제 만난 Go 상태에만
호출한다. SVD 상대 cutoff `1e-12`, 수치 허용 오차 `1e-8`을 고정한다. 단위 길이·관측
안전·비음수 승수·정류·상보성·쌍대 상한 증거 실패는 보존하고 실행을 중단한다.

출력 갱신은 모든 방법에서 `g=.1*(actual_action-p)*obtained_reward`, `head+=g*w`다.
내부 투사 가중치·인코더·bias·같은 입력의 내부 활성 반응은 고정이다. 실제 학습 상태는
출력 계수와 별도 보상 기록이다. 내부 시냅스 및 가치 계수 갱신은 0회다.

## 같은 수정량 상한과 다른 실제 비용

한 시행 출력 계수 이동은 **0.1 이하**, 전체 경로 길이는 **40 이하**, 이동 제곱합은
**4 이하**다. 실제 각 이동·누적 경로·제곱합·최종 계수 길이를 모든 방법·시드에 남긴다.
최종 길이는 실제 경로 길이 이하여야 한다. 실제 선택이 달라 g와 누적 비용도 달라지므로
같은 상한 아래의 비교이지 총 이동량을 완전히 맞춘 인과 분리가 아니다.

모든 방법이 같은 4칸 기억을 기록하지만 사용한 정보 처리·최적화·캐시·게이트 검사 비용을
같게 맞췄다고 주장하지 않는다. 실제 solver 요청·유일 case·NoGo 생략·닫힌/열린 시행과
관측 횟수·새 발견을 구분해 보고한다. 계산 시드 10개는 동물이나 사람 10명이 아니다.

## 미관측 방해의 측정

수정 직전·직후 같은 출력 상태에서 목적지 j의 정답 선택 확률과 정답 정렬 logit 변화를
구한다. 현재 source를 제외하고 `known_before[j]==0`인 목적지를 미관측 다른 문제로
정한다. 현재 source만 관측을 바꿀 수 있어 다른 문제의 미관측 mask는 전후 같아야 한다.
source까지 포함한 미관측 개수의 감소는 실제 새 발견 수와 같아야 한다.

주 방해 지표 U는 한 학습자의 **400시행 전체 미관측 다른 문제에서 발생한 정답 선택
확률 감소 절댓값의 합**이다. 양수 도움으로 상쇄하지 않는다. 정답 정렬 logit 방해,
양수 확률 도움, 노출 수·발견 시점을 별도 기록한다. 노출 수는 학습자마다 달라 주 지표를
그 수로 나누지 않는다. 기술적 노출당 비율의 분모가 0이면 null이다.

평가자는 정답 부호를 쓰지만 그 정보는 학습자·전환·방향에 전달하지 않는다. 아주 작은
부동소수점 음수도 원자료에는 남긴다. tiny 부호 개수를 생물학적 피해로 해석하지 않는다.
누적 방해 질량은 최종 네 입력 평균 정답률 감소와 다른 단위다.

닫힌 구간에서는 isolated가 다른 문제를 움직이지 않도록 만들고 열린 뒤에는 미관측
목적지가 없으므로, gated의 U≈0은 **설계가 의도한 작동 결과**이기도 하다. 이 사실을
새롭고 독립적인 학습 원리 발견으로 포장하지 않는다. 방해를 막았다는 결과만으로 성적
개선·충분한 습득이 성립하지 않으며 세 판정을 별도로 보고한다.

## 사전 판정

주 조건은 **real/raw/gated_balanced**다. 다른 배선·표현의 유리한 결과로 주 조건을
대체하지 않는다. 전체 시드·모든 방법·구간을 보고한다. 다음 세 판정은 서로 독립이다.

**H_gain — 마지막 성적의 실용적 개선.** 네 연습 입력의 마지막 기대 정답 선택 확률을
사용한다. 같은 새 시드의 balanced, feedback_selective, isolated 각각에 대한 gated 차이가
평균 **0.05 이상**, 양수 차이인 시드 **각각 8/10 이상**이어야 한다. 세 비교와 모든
무결성·수치·정보·상한 게이트를 통과해야 지지한다. 공유 대조와의 차이만으로 대신하지 않는다.

**H_acquisition — 충분한 습득.** 각 시드의 마지막 평균 **0.8 이상**, 초기 대비 향상
**0.25 이상**, Go 정답 두 입력과 NoGo 정답 두 입력의 클래스별 평균이 **각각 0.7 이상**을
모두 만족해야 한다. 적격 시드가 **8/10 이상**이고 모든 게이트가 통과해야 지지한다.

**H_protection — 관측된 주 조건의 작동상 보호.** 각 시드의 gated U가 **모두 1e-8 이하**,
동일 시드의 gated−balanced 및 gated−feedback_selective U 차이가 **각각 모든 10시드에서
1e-8 이하**이고 모든 게이트가 통과해야 지지한다. 이는 이 관측 표본의 보호 결과이며
모집단 비열등성 검정·정확한 수학적 0·새 학습 기작 증거가 아니다. 평균만 낮아 일부 시드의
방해를 감추는 판정은 허용하지 않는다.

획득 정보·전환·내부 불변·상한·방향 증거의 무결성 판정과 H_protection의 누적 결과 판정은
구별한다. 낮은 방해만으로 잘못된 정보 사용이나 전환을 통과시키지 않는다. 과학적 미지지,
수치/무결성 실패, 설계대로의 보호 동작을 각각 보존한다. 사후 문턱 변경·유리한 시드 선택·
예산 연장·다른 표현으로 주 결과 대체를 하지 않는다.

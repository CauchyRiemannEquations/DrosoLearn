# 인간 공개 기록의 대응 후보를 찾는 감사 계획

작성일: 2026-10-15 (Asia/Seoul). 이전 가용성 감사와 원자료를 그대로 보존하는 후속 작업이다. 실제 사람 자료의 연결 결과를 계산하기 전에 처리 규칙과 테스트를 고정한다. 이미 자료 구조를 살펴본 탐색적 감사이며, 눈가림 확증 사전등록이 아니다.

## 먼저 쉽게 설명하면

공개 자료에는 26개 이름표를 가진 사건 기록과, 이름표 없이 23줄로 묶인 행동 기록이 따로 있다. 같은 사람의 기록인지 확인하지 않고 두 파일을 붙이면 다른 사람의 기록이 섞일 수 있다.

이번에는 각 기록에 남은 **피드백의 전체 순서가 보상 과제와 처벌 과제 모두에서 완전히 같은 경우**만 대응 후보로 남긴다. 한쪽에 비슷한 기록이 여러 개 있으면 고르지 않는다. 중간 값을 지우거나 채워서 맞추지도 않는다. 순서가 같더라도 실제 신원을 증명했다고 부르지 않으며, 어떤 도형을 골랐는지나 원래 시행 번호까지 자동으로 알아낸 것으로 취급하지 않는다.

## 목적과 이번에 하지 않는 계산

확인할 대상은 파일 사이의 연결 근거다. 인간의 정확도, 보상률, 학습 곡선, 반전 비용, 반응 시간의 집단 요약, 효과량, 학습 모형 적합, 사람과 DrosoLearn의 유사성을 계산하지 않는다. 피드백 일치율을 참가자 성적이나 모델 성능으로 부르지 않는다.

이번에 허용하는 결과는 원자료 무결성, 조건별 피드백 기록 수, 완전 일치 관계, 후보의 중복·모호성·부재, 관측 피드백 구간의 사건 개수·순서·경계, 사전에 정한 수치 코드 대응의 일치·불일치 개수다. 코드 대응 불일치가 사람의 오답 또는 원자료 오류라는 결론은 허용하지 않는다.

개발·자동 테스트에는 합성 자료만 사용한다. 실제 연결을 실행하기 전에 이 문서, 새 코드·설정·테스트 및 재사용 원자료의 해시와 Git 버전을 동결한다. 실제 결과를 본 뒤 일치 규칙을 느슨하게 하거나 코드를 뒤집지 않는다. 다른 규칙을 검토하려면 이유를 남기고 별도 버전으로 진행한다.

## 재사용 자료와 불변 조건

대상은 [OpenNeuro ds004295 v1.0.0](https://openneuro.org/datasets/ds004295/versions/1.0.0)의 기존 보존 부분집합이다. 원 커밋은 `c7c5d3a164425af3e65cc908ef0d41f01725984c`이며 원자료 라이선스는 CC0다. 26개 사건 TSV와 행동 MAT 두 파일의 원바이트, 저자 표시, source manifest와 이전 감사·결과를 수정하지 않는다. 원파일의 SHA-256과 크기를 다시 확인하고 새 산출물은 별도 경로에 저장한다. 기존 경로 덮어쓰기를 거부한다.

각 TSV 행은 시행이 아니라 사건이다. MAT의 두 조건을 묶는 단위는 같은 파일 안의 cell 인덱스이며, 이를 검증된 참가자 신원으로 부르지 않는다. 두 MAT의 공통 변수는 이전 감사에서 동일함을 확인했으므로 독립 자료로 두 번 더하지 않는다. 새 작업에서 사용할 MAT 파일과 필드는 설정에 하나의 기준으로 고정한다. 모든 TSV 이름표와 MAT cell을 후보 목록에 남기며, 연결이 쉬운 자료만 선택하지 않는다.

기준 MAT는 `code/Data/RevEx1_behavioralData.mat`의 두 조건별 `feedback`, `action`, `expect`다. 코드 의미를 확인할 추가 저자 코드가 있으면 별도 출처 manifest에 파일·버전·해시·권한과 확인 범위를 남기고 함께 동결한다. 원자료의 CC0 선언을 다른 저장소 코드의 권한으로 자동 확장하지 않는다. 추가 근거를 읽었다는 사실과 실제 사람 기록의 대응 결과를 계산했다는 사실을 구분한다.

## 1단계: 피드백 순서를 바꾸지 않고 추출

[고정 코드북](https://raw.githubusercontent.com/OpenNeuroDatasets/ds004295/c7c5d3a164425af3e65cc908ef0d41f01725984c/task-task_events.json)에 따라 `S60/S61`을 보상 조건의 `0/1`, `S80/S81`을 처벌 조건의 `0/1`로 변환한다. `1`은 해당 조건의 양성 피드백이라는 뜻이며 정답 코드가 아니다. `S 60`, `S_60`, `S60` 같은 명시된 표기는 같은 코드로 정규화하되 원값과 원행을 남긴다.

추출은 조건별 피드백 코드가 **원 파일에 등장한 순서 그대로** 수행한다. 활성 과제·중단 상태를 근거로 피드백을 빼거나 이전 파서의 불완전 묶음을 고치지 않는다. 과제 밖 피드백, 중단 경계, 미지 사건, 시간 역행 등은 별도 진단으로 보존한다. 전체 피드백 순서의 일치 여부와 각 사건 구간이 깨끗한지는 다른 판정이다.

MAT에서는 조건별 feedback cell의 원 배열 순서를 사용한다. 값은 유한한 이진 코드인지 확인하며 결측·비이진 값·길이 차이를 조용히 변환하지 않는다. 각 조건의 원 길이를 기록한다. 차이가 나면 추가 연습, 누락 또는 시간 차이를 추정해 보정하지 않는다.

## 2단계: 전체 후보 관계를 만든 뒤 양쪽 유일성 확인

모든 TSV 이름표와 모든 MAT cell 사이에 다음 관계를 계산한다.

`후보(i, j) = REW 전체 순서가 길이와 값 모두 동일 ∧ PUN 전체 순서가 길이와 값 모두 동일`

한 조건만 맞는 경우는 대응 후보가 아니다. 부분 문자열, 편집 거리, 근사 일치, 연속 구간 선택, 순서 재정렬, 원소 삭제·추가, 결측 채우기를 허용하지 않는다. 조건을 뒤집거나 양성·음성 코드를 반전해 맞추지 않는다.

한 TSV와 한 MAT cell이 후보 관계를 가지며 **각각의 전체 후보 수가 모두 1일 때만** ‘양방향 유일 완전 일치 후보’로 표시한다. 전체 후보 관계를 먼저 만든다. 파일 순서, 행 번호, 나이 같은 외부 속성, 임의 동점 처리 또는 후보를 순차 삭제하는 방법으로 모호성을 해소하지 않는다. TSV 쪽 중복과 MAT 쪽 중복을 모두 보존한다.

후보가 없는 경우와 후보가 여럿인 경우를 구분한다. 후보 개수와 상대 파일·cell 인덱스를 양쪽 모두에 기록한다. 결과가 23쌍에 미치지 못해도 일치 기준을 바꾸지 않는다. 26개 이름표가 모두 포함되어야 한다거나 제외된 3개 이름표를 반드시 찾을 수 있다고 가정하지 않는다.

완전 일치는 **관측된 결과열의 일치 근거**다. 같은 사람이라는 독립적인 신원 확인, 올바른 시행 정렬, 과제 코드의 의미 일치, 도형 ID 확인을 각각 대신하지 않는다. 이름표가 없는 MAT 기록에 새 개인정보를 연결하지 않는다.

## 3단계: 관측 피드백 사이의 사건 구간 점검

양방향 유일 후보가 있더라도 우선 비교하는 것은 원 시행이 아니라 **관측 피드백 구간**이다. 조건과 관계없이 바로 직전 피드백 다음부터 현재 피드백 직전까지를 한 구간으로 삼는다. 첫 피드백 앞부분은 원 파일 시작부터 조사한다. 각 원 사건은 하나의 구간 또는 마지막 피드백 뒤의 꼬리 부분에 속하며, 꼬리 사건도 남긴다. 과제별 관측 피드백 순번과 구간에 속한 원행을 함께 기록한다.

사건 개수는 생략하지 않는다. 같은 조건의 선택과 기대 보고가 각각 하나인지, `선택 → 기대 보고 → 현재 피드백` 순서인지 확인한다. 선택·기대가 없거나 여럿이면 특정 사건을 골라 대표값으로 삼지 않는다. 다른 조건의 사건, 과제 시작·끝, 중단·재개, 미지 코드, 시간 역행이 구간에 있는지 표시한다. 경계 첫 구간의 상태도 이후 구간과 구분한다.

‘깨끗한 구간’ 기준에는 단일 선택·단일 기대·올바른 순서·같은 활성 조건·중단 상태 아님·선택 이후 피드백까지 해석되지 않은 사건이나 경계 횡단 없음·해당 구간의 시간 역행 없음이 모두 필요하다. 같은 과제의 시작 표시가 선택보다 앞에 있는 것은 허용한다. 반대 과제의 사건이나 과제·중단 경계가 선택 뒤에 나타나면 불허한다. 여러 문제가 한 구간에 겹칠 수 있으므로 문제 표시 수를 독립 시행 수로 세지 않는다.

관측 피드백 순번이 MAT 원소 번호와 대응한다는 해석은 ‘두 전체 피드백열이 동일하다’는 조건부 진단이다. 원래 예정 시행 번호·누락된 시행 수·연습 구간·원 논문의 예정 반전 위치가 검증되었다는 뜻은 아니다. 그 순번에 반전 표지를 자동으로 붙이지 않는다.

## 4단계: 선택·기대 코드의 조건부 정합성

사전에 정한 깨끗한 구간에서만 MAT의 같은 위치 action·expect와 수치 대응을 검사한다. 원 사건 행과 MAT cell·원소 위치를 함께 남긴다. 다른 결과가 나오면 값을 바꾸지 않고 불일치 항목으로 보존한다.

TSV의 선택은 코드북에 왼쪽·오른쪽으로 정의되어 있다. MAT의 action `1/2`가 같은 좌우 코드인지, 도형 ID인지 별도 원 코드 근거가 없으면 이를 이미 확인된 의미로 가정하지 않는다. `왼쪽 → 1`, `오른쪽 → 2`를 설정에 고정해 점검하더라도 결과 이름은 **가정한 수치 대응의 정합성**이어야 한다. 반대로 뒤집으면 더 잘 맞는지 탐색해 채택하지 않는다.

기대 보고는 TSV의 `0–3`과 MAT의 `3–6`이라는 원 코드를 보존한다. `MAT = TSV + 3`이라는 대응을 사전에 고정한 진단으로 검사할 수 있지만, 결과를 보고 다른 offset이나 순열을 고르지 않는다. 기대 보고를 선택 확률로 바꾸지 않는다. [원 논문 Methods](https://onlinelibrary.wiley.com/doi/full/10.1111/psyp.14235)에 도형의 좌우가 매 시행 바뀐다는 점도 계속 유지한다.

피드백 완전 일치, 선택 코드 정합성, 기대 코드 정합성은 별도 결과로 보고한다. 하나의 성공이 나머지를 자동 통과시키지 않는다. 조건부 검사에 사용할 수 없는 구간은 실패 성적이나 제외된 참가자로 부르지 않고 이유와 함께 보존한다. 이 단계에서 RT를 붙이거나 RT 통계를 계산하지 않는다.

## 자동 검증과 종료 기준

합성 자료 테스트는 다음 상황을 포함한다.

- REW·PUN이 모두 일치하는 경우, 한 조건만 다른 경우, 길이 차이와 한 비트 차이.
- 동일한 MAT cell 두 개, 동일한 TSV 두 개, 양쪽 중복, 후보 부재, 입력 나열 순서 변경.
- 이진 코드의 결측·비이진·유한성 오류와 원자료 해시 변경.
- 단일 선택·기대·피드백의 정상 순서와 각각의 누락·복수·역순.
- 다른 과제의 사건, 과제·중단 경계, 미지 코드, 시간 역행, 첫 피드백 구간.
- 사전 고정한 action·expect 대응의 일치와 불일치 보존.
- 원행과 MAT 위치 추적, 원본 및 입력 객체 불변, 기존 출력 덮어쓰기 거부.

독립 검산은 주 연결 함수를 호출하지 않고 원파일의 해시, 전체 후보 관계, 양방향 유일성, 구간 분류와 코드 정합성 수를 다시 확인한다. 검산의 통과는 기록 처리의 재현성을 뜻하며 사람의 학습 가설이 검증되었다는 뜻이 아니다.

산출물은 원자료·설정·코드 버전, 모든 이름표와 MAT cell의 후보 목록, 모호성·부재 목록, 구간별 원행 대응과 문제 표시, 조건부 코드 검사, 독립 검산, 쉬운 해설이다. 새 결과를 기존 가용성 감사의 13,954개 연결 후보를 수정한 값처럼 제시하지 않는다. 이전 파서·614개 불완전 묶음·1,720개 표시와 원 결과를 보존한다.

구현 경로는 새 `src/drosolearn/human_trial_linkage.py`, 합성 핵심 테스트는 `tests/test_human_trial_linkage.py`다. 실행·동결과 독립 검증 테스트도 새 파일로 분리한다. 이 문서와 모든 새 실행 코드·테스트의 최종 바이트를 실제 감사 전에 고정한다.

관측 기록의 대응을 확정할 수 없거나 코드 뜻이 불분명한 경우에도 그 결과를 남기고 종료한다. 인간과 모델의 공통 학습 지표 계산은 별도 후속 프로토콜에서 정의한다. 이번 감사로 Level 4·Level 5, 인간 수학 학습이나 교육 효과를 주장하지 않는다.

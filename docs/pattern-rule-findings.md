# 패턴 습득과 새 사례 적용을 나눈 결과

2026-10-19. 세 번째 추가 연구 `pattern_rule_v1`의 고정 예산 36,000회 학습·9,000개 정적 평가와 모든 상태의 독립 재계산을 완료했다.

신경망·선형·균등 조건의 세 미학습 set 판정은 모두 `not_assessable_without_acquisition`이다. Q 대조는 습득했지만 새 기호·새 기호와 배치·새 길이의 기대 정답률은 각각 정확히 50%로 제한적 전이 기준을 통과하지 못했다. Q는 처음 본 입력에 확률 .5를 반환하도록 설계됐으므로 이 수치는 예상된 암기 대조의 성질이다. Q로 풀 수 있다는 사실은 유한 과제가 해결 가능함을 보여 주며, 다른 신경망 구조나 같은 예산이 반드시 충분하다는 증명은 아니다.

익숙한 두 문자열과 새 종류 0 문자열 두 개를 섞은 배치 진단에서는 Q가 74.10%였다. 그중 새 두 문자열은 한 종류뿐이다. 항상 NoGo를 택해도 둘을 맞추므로 이 결과를 균형 잡힌 일반화 성공으로 읽지 않는다. 전체 평가 20슬롯은 고유 문자열 16개이며 중복을 독립 사례로 늘리지 않는다.

정답을 아는 인접 교대 oracle은 이 유한 집합을 모두 구별했다. 첫/마지막/기호 빈도만으로는 균형 집합의 종류를 가를 수 없지만, 첫 기호와 끝 기호가 다른지 보는 지름길은 연습과 새 기호 set을 풀었다. 배치·길이를 함께 검사해야 하는 이유다. 이 분석 대조는 보상으로 학습한 모델이 아니다.

문자열 전체를 7차원 인공 이력 버퍼로 제공했다. 초파리의 문자 인식, 내부 순차 기억, 다음 항 예측, 새로운 수학 규칙 계열 이해를 시험한 것이 아니다. 입력의 기호 간 수치 간격도 사람이 제공했다. 이 표현·규칙·예산의 미지지는 다른 모델의 불가능성이나 초파리의 학습 한계를 뜻하지 않는다.

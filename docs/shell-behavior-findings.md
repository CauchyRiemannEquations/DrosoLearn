# 보상 뒤의 반응과 점수가 알려 주는 범위

2026-10-19. 두 번째 추가 연구 `shell_behavior_v1`을 완료하고 독립 계산으로 모든 배열·11,912개 기록·요약을 확인했다.

쉽게 말하면, 시험 점수가 같다는 사실만으로 공부 방법까지 같다고 알 수는 없다. 이를 확인하려고 보상을 보고 값을 고치는 계산 모델과, 그 모델이 만든 답안만 저장했다가 재생하는 장치를 구별했다.

합성 Q 학습기는 연습 전후 향상 +18.61%포인트, 반전 직후 유리한 선택 34.89%, 반전 뒤 회복 +23.11%포인트를 보였다. 무학습 균등 선택의 해당 값은 −1.08%포인트·50.22%·−1.39%포인트, 직전 선택을 반복하는 정책은 −2.51%포인트·50.36%·+0.72%포인트였다. 새 합성 시드 8개와 기존 29명 각각의 입력 흐름에서 계산한 세 지표의 기술적 평균이며, 새로운 인간 집단과의 동등성 검정이 아니다.

Q의 답안을 그대로 재생하면 이 세 점수가 정확히 같았다. 재생 장치는 실행 중 학습 갱신을 한 번도 하지 않는다. 이 일치는 사전에 구성한 반례이므로 새로운 발견처럼 유의성을 계산하지 않는다. 또한 미래 답안에 접근하므로 공정한 학습 경쟁 모델로 인정하지 않는다. 세 지표만으로 학습 기작을 유일하게 식별할 수 없다는 한계를 확인하는 용도다.

새 합성 개입에서 보상의 부호를 뒤집자 Q는 50,112개 선택 중 18,201개(36.32%)를 바꿨다. 저장 답안 재생은 바뀌지 않았다. 행동 점수뿐 아니라 보상이 달라졌을 때 무엇을 수정하는지 따로 살펴야 한다는 계산적 예다. 실제 인간에게 이 개입을 시행하거나 인간이 답안을 재생한다는 가설을 검정한 것은 아니다.

기존 인간 29명과 모델 1,595개 기록 흐름도 다시 집계했다. 같은 조개가 다음에 나왔을 때의 반응을 보되 보상 규칙이 바뀌는 경계 29,232쌍을 제외하고 311,808쌍을 보존했다. 선택하지 않아 내용이 숨겨진 경우, 선택했지만 빈 경우, 이득, 손실을 구분하고 조개·단계별 빈 분모도 삭제하지 않았다. 전체 5,376개 층의 수치가 CSV에 있다. 이 조건부 비율에는 선택 편향과 공유 입력 흐름이 있으므로 보상의 인과 효과나 독립된 사람 수로 해석하지 않는다.

새 합성 선택은 200,448회, 값 갱신 호출은 100,224회(실제 0이 아닌 변화 46,693회)다. 신경망 내부·출력 가중치의 새 갱신과 새 인간 실험은 0회다. 기존 인간 비교의 유사성 미지지는 변경하지 않는다. 인간과 모델이 같은 방식으로 배운다는 증거를 추가한 연구가 아니다.

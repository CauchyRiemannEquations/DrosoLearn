# 입력에 이미 들어 있는 순서의 영향 — 사전 프로토콜 v1

작성일: 2026-10-14 (Asia/Seoul). 이 문서는 기존 smoke 및 보상 반전 결과를 본 뒤, **새 시드 3001–3010의 연구 실행 전에 정한 후속 진단 계획**이다. 기존 프로토콜·코드·설정·결과·태그를 보존하고 별도 등록과 결과 디렉터리를 사용한다. 실행 전 이 문서·설정·새 코드·공유 코드·원본 데이터의 해시를 동결한다. 이는 로컬/Git 기반의 전향적 동결이며 외부 공인 사전등록이나 완전한 눈가림 확증으로 표현하지 않는다.

## 비전공자를 위한 설명

지금까지 모델에는 그림 대신 수량을 직접 알려 주었다. 예를 들어 2개는 `0.25`, 4개는 `0.50`이라는 값을 받는다. 이 방식에는 이미 **개수가 많을수록 입력값도 커진다**는 정보가 들어 있다. 모델이 처음 보는 개수에도 맞게 답했다면, 복잡한 수학 규칙을 발견했기 때문인지 이 미리 제공된 순서를 활용했기 때문인지 구분해야 한다.

이번에는 같은 연습을 마친 모델에 두 종류의 시험지를 준다. 하나는 앞처럼 개수 순서를 알려 준다. 다른 하나는 처음 보는 개수에 **임의의 이름표**를 붙인다. 가령 3개에 큰 값을, 8개에 작은 값을 붙일 수 있다. 이름표가 각 개수를 구별하기는 하지만 실제 개수의 크기 순서를 알려 주지는 않는다. 연습에 쓰는 2개와 4개의 이름표는 바꾸지 않으므로 연습 내용·보상·학습 결과는 정확히 같다. 처음 보는 입력을 표현하는 방법만 달라진다.

가능한 이름표 배치 720개를 모두 시험한다. 좋은 배치만 골라 보고하지 않는다. 개수 정보 자체를 뺀 시험도 한다. 이때 나머지 단서로 정답을 알 수 없도록 만든 균형 자료에서는 정답 선택 확률이 정확히 50%여야 한다.

이 연구가 알려 줄 것은 **새 사례에서의 좋은 성적이 입력에 미리 들어 있는 순서에 얼마나 의존하는지**다. 임의의 이름표만 받은 모델의 실패를 수학 학습 일반의 불가능성으로 해석하지 않는다. 보지 못한 이름표의 뜻을 알려 주지 않은 상황이므로, 무엇을 배울 기회가 있었는지도 함께 따져야 한다.

## 질문, 가설과 반증 조건

연구 질문: 2 대 4 보상 학습을 정확히 동일하게 유지한 채 미학습 수량의 입력 순서를 바꾸면, 동일한 정책의 미학습 수량쌍 선택 성능이 얼마나 달라지는가?

주 가설 H-E의 지표는 각 시드에서 계산한 `순서 제공 입력의 15쌍 macro p_correct − 720개 이름표 입력의 15쌍 macro p_correct`다. 여섯 모델 조건마다 **전체 10시드 평균 차이 ≥0.10 및 엄격히 양수인 시드 ≥8/10**을 모두 만족하면 그 조건의 H-E 계산 기준 통과로 기록한다. 0.10은 선택 확률의 10%포인트 차이를 요구하는 연구용 실용 기준이다. 생물학적 임계값이나 통계적 유의성 기준으로 부르지 않는다.

습득 실패 시드를 버리지 않고 전체 10시드에서 주 차이를 계산한다. 기준 미달·무차이·반대 방향도 결과로 보존한다. 여섯 조건을 합쳐 하나의 성공으로 만들거나 가장 좋은 조건만 보고하지 않는다. 이 지표는 입력 순서의 영향을 검사하며, 수학 규칙을 독립적으로 발견했는지 판정하는 지표가 아니다.

**절대 수행과 습득은 별도로 판정한다.** 2 대 4의 최종 IID `p_correct≥0.75` 및 초기 대비 향상 `≥0.15`를 모두 만족해야 습득 gate를 통과한다. 해당 시드의 순서 제공 입력에서 15개 완전 미학습 쌍 평균 `p_correct≥0.75`까지 충족하면 제한된 습득 후 미학습 입력 수행 기준을 통과한다. 상대 차이 H-E가 통과해도 이 절대 수행 기준은 실패할 수 있다. gate 조건부 요약에는 해당 시드 수를 밝히고 전체 시드 결과를 함께 제공한다.

## 보존하는 모델과 학습 조건

기존 `Learner`의 encoder·활성 함수·선택 확률·보상 기반 갱신식·clipping을 그대로 사용한다. 원래 배선은 FlyWire v783에서 확보한 KC→MBON 1,474개 연결이며 nominal 512 KC·48 MBON 중 489 KC·29 MBON에 해당 연결이 있다. LC11·DAN·APL·재귀 상태·점 이미지로부터의 수량 추출은 구현하지 않는다. 기존 [기술 설계](technical-design.md), [자료 감사](drosomem-audit.md), [해석 한계](../LIMITATIONS.md)를 유지한다.

| 조건 | 배선 | 내부 가중치 학습 | 출력 가중치 학습 |
|---|---|---|---|
| `fixed` | 실제 부분집합 | 없음 | 있음 |
| `plastic` | 실제 부분집합 | 있음 | 있음 |
| `rewired_fixed` | 차수 보존 재배선 | 없음 | 있음 |
| `rewired_plastic` | 동일 재배선 | 있음 | 있음 |
| `ann_fixed` | 무작위 희소 일반망 | 없음 | 있음 |
| `ann_plastic` | 동일 일반망 | 있음 | 있음 |

모든 조건에서 같은 입력 7차원·뉴런 차원·출력 크기·400 학습 시행을 사용한다. 출력 학습률은 0.1, 내부 학습률은 0.01이며 내부 가중치를 초기값 대비 `[0, 2w_initial]`로 제한한다. 기존과 같이 재배선은 KC outdegree·MBON indegree·MBON별 incoming weight multiset을 보존하고, ANN은 MBON indegree·incoming weight multiset을 보존한다. ANN에서 KC outdegree까지 같다고 가정하지 않는다. 고정 조건의 출력 학습 가중치는 48개, 가소성 조건에는 1,474개 내부 학습 가중치가 추가된다. 따라서 고정/가소성의 총 학습 자원이 같다고 표현하지 않는다.

## 세 입력 표현과 정확히 같은 연습

각 후보 입력의 첫 성분만 아래처럼 정한다. 나머지 여섯 인공 nuisance descriptor 및 스케일은 기존 방식과 같다. 물체 크기·총면적·밀도·간격·배치·범위를 실제 이미지로 구현한 것이 아니라 독립적으로 만든 인공 수치 descriptor다.

| 표현 | 첫 입력 성분 | 학습/평가의 의미 |
|---|---|---|
| `ordered` | 실제 수량 `n/8` | 수량의 순서를 입력으로 제공 |
| `permuted` | 수량마다 고유한 `code(n)/8` | 미학습 수량의 이름표 순서를 변경 |
| `quantity_removed` | 항상 0 | 수량을 구별할 정보 자체를 제거 |

`permuted`에서는 `code(2)=2`, `code(4)=4`를 고정한다. 나머지 실제 수량 `[1,3,5,6,7,8]`에 같은 값 집합 `[1,3,5,6,7,8]`을 배정하는 **6!=720개 순열을 사전 정의한 사전식 순서로 전수 사용**한다. 원래 순서를 보존하는 배치도 포함해 하나도 삭제하지 않는다. 이 표현도 고유한 1차원 수치와 인공 거리 구조를 가진다. 순수한 one-hot 표현이나 생물학적 시각 표현이라고 부르지 않는다.

학습은 **2 대 4에서 큰 수량 선택에 보상**하는 400시행뿐이다. 올바른 선택에 보상 1, 다른 선택에 0을 준다. 학습 알고리즘에는 선택 행동과 scalar 보상만 전달하며 정답 수량·평가 정답·이름표 역변환 표를 전달하지 않는다. 보상 반전·추가 시행·학습률 탐색을 수행하지 않는다.

훈련 수량의 이름표를 고정했기 때문에 `ordered`와 모든 `permuted` 표현의 훈련 입력은 byte 수준에서 동일하다. 같은 초기 상태·입력·행동 난수·보상·갱신 규칙이면 학습 궤적도 같다. 따라서 시드·모델 조건당 **수량 정보가 있는 학습 한 번**을 수행하고, 그 상태를 순서 제공 평가와 720개 이름표 평가에 공통 사용한다. `quantity_removed`는 별도 학습한다.

실제 학습량은 `10시드×6조건×2학습 궤적×400시행=48,000`이다. 각 이름표 평가에 대응하는 가상 훈련 이력도 400시행이지만 같은 이력을 재사용한 것이므로 720개의 독립 학습 실험으로 세지 않는다. 이름표 평가는 새로운 보상을 제공하거나 모델을 다시 학습하지 않는다.

## 시드, 자료 분할과 평가 범위

새 계산 시드는 **3001–3010**이다. 이전 smoke 시드·미실행 확장 시드·보상 반전 시드를 사용하지 않는다. encoder·초기 head·대조 배선·시행별 선택 uniform stream·자료 생성 seed의 정확한 값은 설정과 결과 메타데이터에 기록한다. 같은 시드의 모델 비교에는 공통 encoder·초기 head와 입력·행동 uniform stream을 사용한다. 확률이 달라 같은 uniform에서 행동이 달라지는 것은 허용된 정책 차이다.

자료 stream은 `seed*100+31`(train), `+32`(IID), `+33`(OOD), `+40+i`(사전식27쌍의 index i)다. 행동 uniform은 `seed+280000`, encoder·초기 head는 `seed+70000`, 재배선은 `seed+50000`, ANN은 `seed+60000`이다. 작은 소프트웨어 fixture는41/42 등 별도 시드와8시행을 사용하며 계획된3001–3010의400시행 결과로 설계나 기준을 튜닝하지 않는다.

자료는 훈련 2 대 4의 400행, 별도의 2 대 4 IID 128행, nuisance OOD 128행, 그리고 아래 27개 미학습 수량쌍의 IID 평가 각 128행이다. 같은 평가 행을 모든 표현·조건에서 사용한다. `ordered`와 `permuted`의 2 대 4 IID/OOD 평가 입력도 정확히 같아야 한다. 학습 checkpoint는 시행 0·100·200·300·400이며 해당 2 대 4의 IID/OOD 곡선을 기록한다. 미학습 수량쌍은 학습 전과 400시행 후에 평가한다.

각 nuisance family의 네 행 교차 설계에서 후보 위치와 nuisance 벡터가 정답 수량에 균형 있게 대응하도록 한다. 훈련과 모든 평가 사이 orientation에 독립적인 자극 fingerprint 중복이 없어야 한다. nuisance-only 단서 기준 모델은 각각 0.5, 실제 수량 oracle은 1.0이어야 한다. 전체 fingerprint·family ID·nuisance·counts·code mapping과 stream을 보존한다.

| 평가 집합 | 수량쌍 정의 | 역할 |
|---|---|---|
| 완전 미학습 15쌍 | `{1,3,5,6,7,8}`에서 서로 다른 두 수량의 모든 조합 | 주 H-E 및 절대 미학습 수행 |
| 학습 수량 포함 12쌍 | 2 또는 4와 위 여섯 수량의 조합 | 보조: 고정 이름표의 부분적 순서 영향 |
| 전체 미학습 27쌍 | 위 15+12쌍, 훈련 쌍 2 대 4 제외 | 보조: 전체 범위 보고 |

기존 probe의 1 대 3은 주 집합, 3 대 4와 4 대 8은 보조 집합에 들어간다. macro 평균은 각 쌍의 선택 확률 평균에 같은 가중치를 주며, 일부 유리한 쌍만 선택하지 않는다. 수량 차이·비율·절대 수량·입력 코드 차이를 함께 남긴다. 순서 제공 입력에서 비율이나 차이와 성능이 관련되어도 입력의 기하 구조를 분리하기 전에는 인간의 근사 수량 감각이나 Weber 법칙을 발견했다고 해석하지 않는다.

## 실행 전에 알 수 있는 대칭성과 기준 모델

720개 배치를 모두 평균하면, 완전 미학습 두 수량의 코드 배정을 서로 바꾼 짝이 반드시 존재한다. 교차된 nuisance 행도 함께 평균하므로 **어떤 고정된 후보별 점수 함수와 확률적 이진 선택 정책에서도 15쌍의 이름표 평가 평균 `p_correct=0.5`**다. 이는 학습 전·후 모두 성립하는 설계의 수학적 성질이다. 연구 실행에서 이를 새롭게 발견한 학습 실패로 보고하지 않으며, 구현 검증에 사용한다. 개별 배치·개별 쌍의 성능은 달라도 전수 평균은 같다.

훈련 수량의 고정 코드가 들어 있는 12쌍에는 이 전체 대칭이 성립하지 않는다. **그 집합이나 전체 27쌍의 모델 성능이 반드시 0.5라고 주장하지 않는다.** 단순히 큰 코드 쪽을 선택하는 분석적 기준 모델의 전수 평균은 완전 미학습 15쌍에서 0.5, 학습 수량 포함 12쌍에서 `23/36≈0.638889`, 전체 27쌍에서 `91/162≈0.561728`이다. 이 사전 계산도 실행 전에 검증한다.

실제 수량을 직접 비교하는 oracle은 1.0이다. 코드→실제 수량 역변환 표를 제공받은 oracle 역시 1.0이며, 이름표가 수량 식별 정보를 완전히 삭제한 것은 아님을 확인한다. 그러나 학습 모델은 그 표나 미학습 코드의 의미를 받지 않았으므로 역변환 oracle을 같은 학습 자원의 대조로 표현하지 않는다.

수량 제거 자료에서도 동일 nuisance 입력에 반대 정답이 균형 있게 존재하므로 임의의 후보별 점수 함수의 평균 `p_correct`는 0.5다. 학습 중 행동·보상·개별 가중치는 변할 수 있지만 이 평가 평균은 바뀌지 않아야 한다. 0.5에서 벗어나면 과학적 성과가 아니라 자료·평가 구현의 오류를 먼저 조사한다.

따라서 주 대비는 대칭상 0.5인 이름표 기준과 순서 제공 입력의 차이에 해당한다. **입력 순서의 도움을 정량화하는 진단**이며, 같은 훈련을 받은 두 모델이 서로 다른 학습 원리를 습득했다는 증거로 쓰지 않는다.

## 지표, 기록과 독립 검증

주 `p_correct`는 평가 중 행동을 새로 샘플링한 성공 비율이 아니라 **정답 선택 확률의 평균**이다. greedy 정확도·개별 코드 oracle·초기 대비 향상·습득 통과 수·절대 미학습 수행 통과 수는 별도로 보고한다. 조건별 전체 시드 평균·표준편차·양수 시드 수·gate 조건부 시드 수를 남긴다. 720개 배치는 유한한 표현 공간의 전수 평가이며 독립 시드나 초파리 개체 표본이 아니다. nuisance 행·수량쌍·checkpoint도 독립 개체 수로 부풀리지 않는다.

미학습 수량에 대한 정답/보상으로 파라미터·설정·코드 배치를 선택하지 않는다. 평가 중에는 학습·행동 난수 소비·파라미터 변경을 금지한다. 기존 결과를 덮어쓰지 않고 등록 이후 source/config/protocol 해시 변경을 거부한다. 새 기준이나 입력 표현을 검토하려면 새 실험으로 문서화한다.

모든 학습 시행의 입력 식별자·선택 uniform·행동·보상·선택 확률·내부/출력 변화 norm을 저장한다. checkpoint는 내부/출력 가중치·encoder/bias·고정 probe의 KC/MBON 활성과 선택 확률을 보존한다. 새 표현·배치·자료별 선택 확률은 입력 코드·수량·쌍·seed·condition·학습 전/후 상태와 함께 재계산 가능해야 한다.

720번의 불필요한 모델 재훈련이나 동일 후보 활성 계산을 피하기 위해, 같은 후보의 nuisance 입력에 가능한 코드 8개를 각각 넣은 **후보별 점수 cache**를 만들고 코드 배정에 맞는 두 점수로 logits를 구성할 수 있다. cache는 학습 결과 자체와 구분해 저장하고, 직접 모델 순전파와의 일치 및 독립 산술 재계산을 검사한다. cache를 근거 없이 정답 확률로 바꾸거나, 순열별 계산 생략을 독립 시행 증가로 보고하지 않는다.

독립 auditor는 학습 클래스의 update·입력 변환·실험 지표 함수를 호출하지 않고 저장한 원자료·초기 상태·난수·행동·보상을 별도의 산술로 replay한다. 전체 48,000 갱신, 가소성 mask와 clipping, 고정 조건 불변성, 모든 조건/시드/시행 coverage, 평가 중 불변성, 입력 누출·nuisance 교차, 720개 순열의 완전성과 학습 anchor, cache와 평가 지표·요약, 자원 계산 및 파일 해시를 검사한다. NaN·누락·중복·등록 drift·허용되지 않은 내부 변화·대칭 위반은 검증 실패로 남긴다.

## 허용되는 해석과 인간 비교로 이어지는 질문

현재 실험은 인공 입력에서의 경험 의존적 변화(Level 2)와, 습득 gate 이후 미학습 입력 반응의 제한된 Level 3 진단이다. 입력이 순서를 미리 알려 준 사실은 모든 결과에 명시한다. 실제 초파리의 시각 수량 인지·수학 기호 이해·일반 규칙 발견·인간과의 정량적 유사성(Level 4)·같은 신경 기작(Level 5)을 주장하지 않는다. 원래 배선이 다른 배선보다 우월해야 한다는 가설도 세우지 않는다.

장기 인간 비교에서는 [기존 비교 체계](human-learning-comparison.md)의 **표현이 제공하는 정보와 학습 경험의 기여를 분리해야 한다**는 질문을 구체화한다. 숫자·점 배열·낯선 기호가 어떤 정보를 제공하는지 확인한 기존 공개자료에서 습득과 미학습 사례 수행을 따로 비교할 수 있는지를 검토한다. 이번의 임의 scalar 이름표를 인간의 실제 점 배열 지각과 같은 과제로 취급하지 않는다. 확보한 인간 S1/S6 요약 자료에서 없는 시행별 곡선이나 새 표현 조건을 만들어 내지 않는다.

H-E가 지지되더라도 다음 가설은 단순 입력 순서·잡음·표현 중첩을 더 잘 통제했을 때 어떤 효과가 남는지다. 지지되지 않거나 절대 미학습 수행이 실패하면 해당 실패를 먼저 보존한다. 고난도 수열에서 성공 사례를 찾아 이 결과를 대체하지 않는다. 기존 M11의 규칙 습득 및 일반화 실패, 기존 [보상 반전 결과](reversal-findings.md)를 그대로 유지한다.

# 같은 선택 안에서도 시간 혼합이 피드백 차이를 만들 수 있는가?

작성일: 2026-10-19 (Asia/Seoul). 연구 ID `time_mixture_v1`.

## 쉽게 설명하면

같은 선택과 같은 과제 상태의 기록끼리 나눠도, 초반과 후반에 선택 습관과 보상 확률이 함께 달라지면 두 피드백 뒤의 유지율이 다르게 보일 수 있다. 이번에는 **보상 결과를 전혀 읽지 않는 선택 기계**의 가능한 기록을 정확한 분수로 계산한다. 학습이나 실제 사람의 반응을 새로 측정하지 않는다.

앞선 `metric_calibration_v1`은 서로 다른 현재 선택을 합치는 문제를 확인했다. `conditional_transition_v1`은 현재 선택·상태·단계별 분모를 보존했다. 이번 후속은 그 조건화가 시간의 영향을 자동으로 없애지는 않는다는 별도의 계산 반례다. 기존 두 연구의 계획과 결과를 바꾸지 않는다.

## 사전 범위와 해석

기존 측정과 사람·모델 결과를 이미 본 뒤 제안하는 **등록된 합성 산술 진단**이다. 눈가림 인간 학습 검정이 아니다. 새 소스·독립 검산·시험·설정·본 계획·독립 감사와 부모 근거를 SHA-256으로 동결하고, private Git 원격의 같은 등록 바이트를 확인한 뒤 계산한다. 부모 공개 기준 커밋은 `70100478abd7ba86335ae6b277992f40f19b5b9b`이다.

원 사람 MAT, 실제 모델 시행, 신경 가중치를 새로 읽거나 변형하지 않는다. 학습 갱신·학습자 구성·표본 시행 생성·난수 추출은 모두 0이다. 완전 열거의 가능한 경로를 실제 관측 표본이나 새로운 동물로 세지 않는다. 그림은 필요하지 않다.

## 고정된 선택 기계와 네 조건

모든 조건은 원 시행 9개, 원 인접 쌍 8개다. 단계·과제·유리한 선택 정체성은 전체에서 같다. 초반/후반은 외부 시계 구간이며 원 단계 또는 상태 경계가 아니다. 따라서 **4→5 쌍도 제외하지 않는다.**

각 시행의 선택은 다른 시행과 독립이며 선택 0 확률을 `p0(t)`라 한다. 실제 이진 피드백 1 확률은 선택별 `q_a(t)`다. 피드백 난수나 결과는 선택 정책의 입력이 아니며 갱신할 파라미터도 없다. 조건마다 설정의 9개 원 확률 벡터를 정확한 기약분수 문자열로 보존한다. 마지막 시행 피드백은 어느 인접 쌍의 현재 피드백도 아니므로 실제 계산에 쓰지 않는다.

| 조건 | 선택 0 확률 | 피드백 1 확률 `(q0,q1)` |
|---|---|---|
| `joint_drift` | 1–4: 4/5, 5–9: 1/5 | 1–4: (9/10,2/5), 5–9: (3/5,1/10) |
| `p_constant` | 전체 4/5 | 위와 같이 변화 |
| `q_constant` | 위와 같이 변화 | 전체 (9/10,2/5) |
| `joint_constant` | 전체 4/5 | 전체 (9/10,2/5) |

모든 시행에서 `q0>q1`이므로 유리한 선택은 0으로 같다. 보상 확률의 크기가 바뀌는 합성 환경이며 기존 고정 확률 모델과 같은 환경이 아니다. 이 반례가 기존 사람이나 모델의 실제 지표를 설명했다고 주장하지 않는다.

## 정확한 기대 횟수와 원 인접성

각 원 인접 쌍 `t,t+1`에서 현재 선택 a·다음 선택 b·현재 피드백 f의 8가지 경우를 모두 계산한다.

```text
w(t,a,b,f) = P(A_t=a) * P(A_(t+1)=b) * P(F_t=f | A_t=a,t)
D[a,f] = sum_(t,b) w(t,a,b,f)
S[a,f] = sum_t w(t,a,a,f)
X[a,f] = D[a,f] - S[a,f]
ratio[a,f] = S[a,f] / D[a,f], D=0이면 null
difference[a] = ratio[a,1] - ratio[a,0], 둘 다 정의될 때만 계산
```

전체 사례마다 두 선택별·두 피드백별 기대 횟수·기대 횟수의 비율·차이를 보존한다. 같은 계산을 원 `t`마다 따로 남긴다. 확률은 이진 부동소수점으로 근사하지 않고 `fractions.Fraction`으로 합산하며 출력도 기약분수의 정수 분자·양의 분모다. 각 쌍의 8확률 합은 1, 전체 기대 분모 합은 8, 모든 `S+X=D`가 정확히 성립해야 한다.

**`E[S]/E[D]`는 유한 표본에서 계산한 비율의 평균 `E[S/D]`가 아니다.** 이번에는 후자를 계산하거나 근사하지 않는다. 인접한 두 쌍이 한 선택을 공유한다는 사실도 독립 경로 검산에서 보존한다. 주 local-event 계산이 서로의 인접 쌍을 독립적인 시행으로 샘플링한 것은 아니다.

## 사전 예측과 실패 기준

`joint_drift`에서 현재 선택 0의 피드백 1 뒤 기대 횟수 비율은 `41/70`, 피드백 0 뒤는 `17/40`이므로 차이는 **`9/56`**이다. 현재 선택 1에서는 `23/40`과 `103/140`, 차이는 **`−9/56`**이다. 이는 실제 실행값이 아니라 위 가정에서 사전에 도출한 산술 예측이다.

다음 다섯 항목을 실행 결과의 불리언으로 남긴다.

- `time_mixture_counterexample`: 두 현재 선택의 차이가 각각 `9/56`, `−9/56`과 정확히 같다.
- `constant_p_control_zero`: 선택 확률 고정 대조의 두 현재 선택별 차이가 0이다.
- `constant_q_control_zero`: 보상 확률 고정 대조의 차이가 0이다.
- `joint_constant_control_zero`: 두 확률 모두 고정한 대조의 차이가 0이다.
- `exact_time_conditional_zero`: 네 조건 모두 정확한 현재 시간까지 나누면 정의된 차이가 0이다.

실제 결과가 예측과 다르면 해당 false·수치·실패를 보존한다. 확률 벡터·허용 기준·조건·시행 수를 바꿔 같은 등록의 실패를 성공으로 만들지 않는다. 입력 또는 소스 변조, 부모 검산 실패, 원 인접 누락, 독립 산술 불일치는 무결성 실패로 구분한다.

## 독립 검산과 보존

독립 코드는 주 코드·열거·집계 함수를 부르지 않는다. 9개의 선택 비트와 8개의 피드백 비트를 갖는 `2^17=131,072`개 가능한 **전체 경로**를 각 조건에서 열거하고, 정수 가중으로 원 인접쌍별 사건과 기대 횟수를 다시 더한다. 선택과 피드백을 생성하는 실제 난수는 없다. 주 8사건 합산과 독립 전체 경로 합산의 모든 정수·분수를 정확히 대조한다. 소스·부모·설정·등록·산출물 해시와 등록→실행→검산 UTC 순서도 확인한다.

설정은 새 소스 12개와 부모 17개를 명시한다. 부모 `metric_calibration_v1`과 `conditional_transition_v1`의 설정·등록·완료 metadata·지표·독립 검산·전체 산출물 목록을 결합한다. 사람 과제의 등록·구조 감사·독립 검산 및 기존 두 계획을 별도로 고정한다. 부모 산출물 목록이 가리키는 실제 바이트도 다시 확인한다. 기존 인간 게이트의 `direct_human_model_similarity_allowed=false`는 그대로 유지한다. 사람 자료와 모델 결과를 새로 비교하지 않는다.

자동 시험에는 수작업 작은 확률 벡터만 쓴다. 실제 9시행 설정은 구조 검증만 하고, 주 과학 수치는 원격 동결 후에 처음 계산한다. 모든 출력은 배타 생성하며 기존 결과 파일이나 완료한 연구를 덮어쓰지 않는다. 실패 발생 시 새 결과 폴더에 실패 metadata·가능한 산출물·해시를 남긴다.

```powershell

python scripts/run_time_mixture.py --registration results/registration_TIME_NEW.json --config configs/time_mixture_v1.json --out results/TIME_NEW
```

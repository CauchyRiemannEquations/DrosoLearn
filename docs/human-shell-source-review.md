# 인간 조개 과제 원자료의 의미와 사용 범위

작성일: 2026-10-19 (Asia/Seoul). 새 인간-모델 비교의 등록 전 자료 검토이다.
이 문서는 원자료 구조만 확인하며, 인간의 학습 성과나 모델의 적합도를 계산한 결과가 아니다.
기존 Marković 자료의 닫힌 비교 조건은 그대로 유지한다. 아래 조건은 별도의 TNU 자료에만 적용된다.

쉽게 말하면, 사람이 경험한 것과 같은 순서의 조개를 모델에게 보여 줄 수 있는지 확인했다.
사람이 줍지 않은 조개 속 내용도 원자료에 남아 있어, 모델이 사람과 다른 선택을 해도
그때 받을 결과를 원자료에서 정할 수 있다. 단, 선택 전에 그 내용을 모델에게 알려 주면 안 된다.

- 자료: [Dataset from a probabilistic Go/NoGo reversal-learning task](https://zenodo.org/records/10066829).
- 버전 DOI: [10.5281/zenodo.10066829](https://doi.org/10.5281/zenodo.10066829).

## 설명서로 확인한 과제 의미

매 시행에는 여섯 조개 중 하나가 제시된다. 사람은 조개를 줍는 Go 또는 지나가게 하는 NoGo를 선택했다.
Go는 화면의 바구니 방향에 맞는 버튼을 누르는 동작이고, NoGo는 응답을 하지 않는 동작이다.
따라서 두 행동이 대칭적인 두 카드 선택과 같다고 해석하지 않는다.

Go일 때만 조개 내용이 사람에게 보이며 점수가 주어진다. 내용 1은 진주(+1), 2는 흙(-1),
0은 빈 조개(0)이다. NoGo이면 내용을 보여 주지 않고 그 내용의 점수도 주지 않는다.

| 숨은 계절 | Go일 때 내용 분포 | NoGo 점수 | 점수만 고려할 때 행동 |
|---|---|---:|---|
| R | 진주 80%, 빈 조개 20% | 0 | Go의 기대점수가 더 큼 |
| P | 흙 80%, 빈 조개 20% | 0 | NoGo의 기대점수가 더 큼 |
| N | 빈 조개 100% | 0 | Go와 NoGo의 점수가 같음 |

N에서 Go를 오답 또는 정답으로 강제하지 않는다. 반응 비용이나 탐색 가치를 임의로 추가하면
원래의 점수 규칙과 달라진다. N에서의 Go 비율은 행동 기술 지표로 남길 수 있지만,
점수 최적 선택률의 R/P 분모에 넣지 않는다.

조개 번호 1~6은 각각 RNRN, NRNR, RPRP, PRPR, PNPN, NPNP 순서이다.
trace의 상태 코드 1은 해당 조개의 첫 계절, 2는 다른 계절이다. 상태 1을 모든 조개에서 R이라고
해석하면 안 된다. 예를 들어 조개 3의 상태 1은 R, 조개 4의 상태 1은 P이다.
각 조개의 반전 시점은 다른 조개와 독립적으로 정해지므로, 전체 시행 번호 하나를 모든 조개의
공통 반전 경계로 사용하지 않는다.

사람은 변하는 계절의 가능성을 안내받았지만 정확한 확률과 계절 순서는 안내받지 않았다.
본 과제 전 다른 조개를 사용한 짧은 훈련이 있었다. cache에는 이 훈련의 세부 기록이나
시각 자극, 화면의 실행 코드가 없다. 모델의 시각 인식이나 인간의 사전 훈련까지 재현했다고 주장하지 않는다.

## 파일 대응과 parser가 지켜야 할 기준

최상위 zip에는 `A_Data.csv`, `A_OCIR.csv`, `A_Behav.zip`이 있다.
일반 자료의 50개 ID와 nested archive의 50개 ID가 일치하며, 각 ID에는 아래 표준 파일 쌍이 있다.

| 표준 파일 | 구분자/구조 | 각 열의 의미 |
|---|---|---|
| `behavior/AXXXX/GONOGO_trace_AXXXX.csv` | 쉼표 또는 공백으로 나뉜 정수 3열, 빈 줄은 자료 행이 아님 | 조개 번호, 숨은 상태 1/2, 잠재 내용 0/1/2 |
| `behavior/AXXXX/GONOGO_shortlog_AXXXX.txt` | `1:`과 같은 원 시행 번호 뒤 공백 정수, 총 5열 | 원 시행 번호, 조개 번호, 잠재 내용, Go=1/NoGo=0, 반응시간 ms |

표준 parser는 ID가 유일한지, 표준 파일 쌍이 모두 존재하는지, trace와 shortlog의 행 수가 같은지,
열 수가 정확한지, 원 시행 번호가 1부터 연속인지, 조개/내용이 행별로 같은지,
입력 및 행동 코드 범위가 유효한지 검사해야 한다. NoGo 반응시간은 0,
Go 반응시간은 양수라는 설명서 조건도 구조 검사에 포함한다.
구조를 복구하기 위해 행을 건너뛰거나 잘린 prefix만 채택하지 않는다.

trace에는 인간의 NoGo에서도 잠재 내용이 기록되어 있다. shortlog의 내용 열도 trace의 내용과
같지만, 이것은 NoGo 때 사람이 그 내용을 보았다는 뜻이 아니다. 학습 입력을 만들 때
NoGo의 내용은 관찰 불가로 차단해야 한다. 분석자는 숨은 상태를 평가용으로 사용하되,
모델의 시행 전 입력에는 조개 정체성만 제공해야 한다.

## 구조 검토 결과와 등록 전 대상 선정

- 일반 자료는 50명이다. 모든 trace는 216시행으로 합계 10,800 입력 시행이다.
- 49명은 표준 trace/shortlog가 216행씩 완전하고, 원 시행 번호와 조개/내용이 모두 일치한다.
- A0016은 trace 216행에 비해 shortlog가 120행이다. 마지막 shortlog 행은 3열뿐이다.
  이는 학습 실패가 아니라 원기록의 구조 불완전이다. 원파일을 그대로 보존하고 전체 참가자를 구조 사유로 제외한다.
- 등록 전 선정 기준은 약물 코드나 학습 성공 여부가 아니라 **정합한 완전 기록 전원**이다.
  이 기준의 후보는 49명, 10,584시행이다. 성과를 확인한 뒤 참가자나 시행을 추가 제외하지 않는다.
- metadata ID 누락은 없다. 입력 코드 범위는 조개 1~6, 상태 1/2, 내용 0/1/2이며,
  실제 조개별 상태-내용 조합도 설명서의 R/P/N 매핑과 모순되지 않는다.
- nested archive의 비디렉터리 파일은 102개다. 표준 100개 외 A0048 폴더의
  `A0048_2_new.txt`와 `._0009_2_new.txt` 두 파일이 있다. 이 추가 파일의 용도/우선순위는
  설명서로 확인되지 않았다. 보존하되 표준 파일의 대체본으로 임의 채택하지 않는다.
- `A_OCIR.csv` 및 약물·혈중농도·인구학적 자료는 본 비교의 성과 예측이나 하위집단 분석에 사용하지 않는다.

49명 각각에 대해 조개 1/2/5/6은 34회, 조개 3/4는 40회 제시되었다.
모든 조개의 상태 압축 순서는 1,2,1,2로 초기 계절과 세 번의 반전이 있다.

| 조개 | 초기 계절 길이 범위 | 첫 반전 뒤 | 두 번째 반전 뒤 | 세 번째 반전 뒤 |
|---|---:|---:|---:|---:|
| 1 / 5 | 7~13 | 5~9 | 7~13 | 5~9 |
| 2 / 6 | 5~9 | 7~13 | 5~9 | 7~13 |
| 3 / 4 | 7~13 | 7~13 | 7~13 | 7~13 |

길이는 전체 시행 시간이 아니라 해당 조개의 제시 횟수다. 주 비교를 R과 P가 직접 교대하는
조개 3/4로 정하면, 각 계절의 처음 3회와 마지막 3회가 겹치지 않는다.
이것은 원 입력 구조로 확인한 측정 가능성이다. 이 문서는 아직 유사성 허용 오차나
통계적 성공 기준을 정하지 않으며, 그것들은 별도 프로토콜과 설정에서 결과 계산 전에 등록해야 한다.

## 약물 코드 해석의 불확실성

설명서는 `VerumPlacebo` 1을 escitalopram, 0을 placebo라고 기술한다. 실제 metadata에는
0과 1이 각각 25명이다. 그러나 코드 0의 A0005에는 T1=32.3845271,
T2=45.42698777 nmol/l이 기록되어 있고 코드 1의 A0034는 두 값 모두 `<5.0`이다.
이 조합은 코드와 농도 해석을 재확인해야 할 이유이며, 역코딩이나 약물 투여 오류를 증명하지 않는다.

따라서 코드 0만 골라 생물학적으로 확인된 위약군 또는 정상 학습 표본이라고 부르지 않는다.
구조적으로 완전한 양쪽 코드의 기록 전원을 섞인 cohort로 기술하며, 약물 효과나 집단 간 차이는
검정하지 않는다. 인간 전체에 대한 대표성이나 약물과 무관한 신경 기작도 추론하지 않는다.

## 라이선스 불일치와 작업 범위

Zenodo API의 license는 `cc-by-4.0`이다. 반면 제공기관 PDF의 License 절은
[CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/)을 명시한다.
둘 중 하나를 삭제하거나 동일한 조건이라고 정리하지 않는다.

현재 사용 범위는 더 제한적인 비상업 연구 조건을 함께 만족시키는 로컬 연구로 제한한다.
원자료/PDF/archive는 저장소 밖 cache에 두고 외부로 재배포하지 않는다. 저장소에는 원출처,
식별자, byte hash, 구조 검토, 자체 작성 코드·프로토콜·집계 결과만 기록한다.
상업 사용이나 원자료 재배포로 범위를 넓히려면 별도 권한 근거가 필요하다.

## 새 비교에서 열리는 조건과 계속 닫힌 조건

완전한 표준 49쌍의 기록된 조개 정체성·숨은 상태·잠재 내용·선택의 의미를 대응시키는
**TNU trace 재생 기반 행동 비교 준비 조건**은 충족한다. 새로운 학습 실행은 아직 하지 않았다.
각 모델은 동일한 외생 trace를 보고 자기 선택의 결과만 관찰하며 사람의 선택을 정답으로 학습하지 않는다.
선택하지 않은 내용, 숨은 상태, 미래 조개와 미래 반전은 모델 학습에 노출하지 않는다.

이 조건은 완전한 시각·동작 과제 재현이나 실행 당시 코드 버전 확인을 의미하지 않는다.
실제 과제의 코드/visual/runtime 복원, 동일한 인간 사전 훈련, 약물 이력 확인,
신경 메커니즘 비교 조건은 충족하지 않았다. 사람의 간격/버튼 동작과 모델의 시행 수가 같지 않으므로
반응시간이나 실제 시간 단위의 학습 속도를 직접 비교하지 않는다.

허용되는 후속 질문은 '기록된 동일 과제 trace에서 Go/NoGo 조정 곡선과 R/P 반전 후 변화가
사전 정의한 범위에서 비슷한가 또는 다른가'이다. 결과가 비슷해도 수량 인지·수학 이해·교육 효과나
공통 신경 메커니즘의 증거로 확대하지 않는다. 실패와 허용 범위 밖의 차이도 그대로 보고해야 한다.

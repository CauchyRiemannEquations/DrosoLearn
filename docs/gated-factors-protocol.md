## 쉽게 설명하면

앞선 장부에서 보호 뒤 균형 방식은 ‘계속 분리’한 방식보다 다른 문제를 더 도왔지만,
현재 자기 문제를 고친 기여는 작았다. 이번에는 **수정 직전 상태, 실제 수정 스칼라,
움직일 방향**을 저장된 두 경로에서 하나씩 가져와 한 번의 수정 계산만 비교한다.

- 상태는 같은 수정이 시작되는 당시의 점수와 정답 확률이다.
- 스칼라는 그 시행에서 실제 방향에 곱한 수다. 이미 확률·행동·획득 보상에 영향을 받는다.
- 방향은 제한된 한 번의 움직임을 어떤 입력에 배분할지 정한다.

세 요소가 함께 바뀌므로 어느 한 요소만 먼저 바꾸는 계산 대신 가능한 순서를 대칭적으로
평균한 장부를 쓴다. 이 배분이 원인의 유일한 비율은 아니며, 다른 규칙으로 다시 학습한
성적도 아니다. 이후의 선택·보상·기억을 새로 발생시키지 않는다.

## 공통 후반과 실제 행동의 경우

각 배선·표현·시드에서 gated 자신의 `known_before` 네 칸이 모두 비영인 시행을 공통
후반(post)으로 정한다. 네 번째 보상 부호를 처음 얻은 시행은 제외되고 다음 시행부터
포함한다. 같은 후반 시간 mask를 네 대조에도 적용하지만 대조의 보상 지식·출력 상태가
같다고 가정하지 않는다. 현재 source와 입력 순서는 같은 시드에서 두 경로가 공유한다.

주 설명은 **real/raw의 gated−isolated**, 보완 비교는 gated−balanced다. 모든 여섯
배선·표현과 네 대조 `isolated, balanced, feedback_selective, shared`의 기록을 보존한다.
유리한 표현·방법·시드로 주 비교를 바꾸지 않는다.

교차 계산은 공통 후반에서 **두 방법 모두 실제 Go를 선택한 시행만** 수행한다. 한쪽만
Go·둘 다 NoGo인 후반 시행도 실제 기여를 삭제하지 않고 별도 나머지로 남긴다. 전환 전
시행은 이번 요인 배분의 대상이 아니며 그 실제 후반과 섞지 않는다. 비대상 0패딩을 실제
계산된 효과로 세지 않는다.

NoGo의 숨은 Go 보상을 새로 추론하거나 미관측 보상으로 방향을 다시 구하지 않는다.
특히 균형 NoGo의 저장 방향 0과 다른 방법의 비영 스칼라를 교차해 ‘방향 효과’로 세는
가용성 혼동을 피한다. 교차 방향이 원래 자신의 관측 이력에서 안전했다는 사실이 상대
학습자의 관측 집합에서도 안전함을 보장하지는 않는다.

## 8개 단일 수정 셀과 대칭 배분

대조를 C, gated를 G라 한다. 고정 단위 특징 행렬 D에서 실제 수정 전 logit 벡터 z,
실제 스칼라 g, 방향의 목적지별 영향 `f=D@w`를 읽는다. 평가용 정답 부호 y를 사용해
각 셀의 네 목적지 확률 변화를 다음 원식으로 구한다.

```text
F(state,scalar,direction) = y*(sigmoid(z_state + g_scalar*f_direction)-sigmoid(z_state))
```

각 인자는 C 또는 G이므로 2×2×2=8셀이다. bit4는 상태, bit2는 스칼라, bit1은 방향이며
0은 C, 1은 G다. 000과 111은 두 경로의 각자 실제 단일 수정 변화와 일치해야 한다.
sigmoid는 부모의 고정 ±40 clipping을 쓰며 국소 미분으로 확률 변화를 근사하지 않는다.
혼합 셀에서는 g를 바꿔 넣은 상태의 확률로 다시 계산하지 않고, 선택한 경로의 저장 값을
그대로 쓴다. 따라서 일부 혼합은 실제 학습 규칙의 상태·행동·보상 관계를 함께 만족하는
갱신이 아닐 수 있다. 이 대입은 정해진 수학적 배분이며 실현 가능한 새 학습 개입이 아니다.

요소 집합 K={state,scalar,direction}에서 요소 r을 G로 바꿀 때 이미 G로 바꾼 다른 요소
부분집합 T에 대해 다음 Shapley 장부 배분을 계산한다.

```text
phi[r] = sum_T |T|!*(2-|T|)!/3! * (F[T union {r}]-F[T])
sum_r phi[r] = F[111]-F[000]
```

T가 빈 집합·원소 1개·원소 2개일 때 가중치는 각각 1/3·1/6·1/3이다. 네 목적지별
배분을 현재 source(own)와 다른 세 입력(other)으로 따로 합친다. 다른 입력의 효과를
훈련하지 않은 사례로의 일반화라고 부르지 않는다.

각 셀의 부호 있는 확률 변화뿐 아니라 양수 부분과 음수 부분 절댓값을 각각 나눈다.
양수·음수 부분은 셀에 먼저 적용한 뒤 Shapley를 계산하며, 이미 배분한 부호 있는 값에
나중에 max를 씌워 대신하지 않는다. **양수 질량을 나눈 몫도 음수일 수 있다.** 이는 그
요소 교체가 양수 질량을 줄인 장부 몫이지 실제 음수 도움 자체가 아니다. 방해 배분이 음수면 해당 요소를 바꾸자 방해가
줄어드는 장부 몫이며, 물리적으로 음의 피해를 새로 만들었다는 뜻은 아니다.

현재 source/다른 입력 각각에서 세 요소 배분을 더하면 실제 양쪽 Go의 G−C 순효과가
복원되어야 한다. 여기에 한쪽만 Go인 시행의 실제 기여를 합하면 전체 공통 후반의 자기·
다른 문제 기여 차이에 돌아와야 한다. 마지막 전체 성적과의 관계는 이전 전후 장부를
보존해 구별한다. 이번 후반만의 배분을 전체 학습 성공으로 바꾸지 않는다.

## 상태·스칼라·방향을 읽는 별도 실제 지표

양쪽 실제 Go인 같은 대상 시행에서 각 경로의 실제 다음 값을 함께 기록한다.

- 현재 source의 정답 정렬 수정 전 logit `y[i]*z[i]`와 정답 선택 확률.
- 로지스틱 민감도 값 `q*(1-q)`. 상태별 같은 logit 이동의 확률 변환이 다를 수 있음을
  읽는 참고 값이며 실제 확률 차이는 항상 위 비선형 원식으로 계산한다. clipping 범위
  밖의 실제 모델 미분이나 새로운 학습 규칙의 효과로 해석하지 않는다.
- 실제 스칼라 절댓값 `abs(g)`. `g=.1*(action-p)*obtained_reward`이므로 학습률 자체와
  같지 않으며 상태·실제 행동·보상에도 영향을 받는다.
- 실제 출력 계수 이동 길이 `abs(g)*||w||`. 단위 방향 상한과 실제 수정 길이를 구별한다.
- 방향 자체의 source 영향 `D[i]@w`. 실제 자기 정답 정렬 변화는 별도 저장한
  `y[i]*g*(D[i]@w)`와 대조한다. 방향 영향이 커졌다는 말과 실제 수정 이득이 커졌다는 말은 다르다.
- 다른 세 입력의 정답 정렬 방향 영향 평균 `mean(y[i]*y[j]*(D[j]@w), j!=i)`.
  현재 source의 보상 부호로 정렬한 방향끼리 비교하는 값이다. 실제 확률 도움과 다르며
  실제 효과에는 현재의 부호 있는 g가 곱해진다. 평가자의 y를 새 학습자·방향 선택기에
  전달하지 않는다. 합·평균과 양수 도움·음수 방해를 구별한다.
- 방향 자체의 길이 `||w||`. 방향 길이, source 영향, 실제 수정 길이의 차이를 보존한다.

위의 logit·확률을 별개로 세어 총 여덟 실제 진단을 C, G 순서로 저장한다. 이름과 순서는
`aligned_source_logit_before, correct_source_probability, logistic_sensitivity_value,
abs_update_factor, head_step_l2, own_unit_direction_influence,
other_unit_aligned_influence_mean, direction_l2`다. 이름의 unit은 방향 상한을 가리키며
실제 저장 방향의 길이가 반드시 1이라는 뜻은 아니다.

이 지표들은 같은 저장 대상에서 나란히 비교하는 설명 자료다. 평균 민감도·평균 수정량·
평균 방향의 곱이 평균 실제 효과와 같다고 가정하지 않는다. 상태 배분이 음수라고 gated의
상태 자체가 더 나쁘다고 단정하지 않는다. 이미 좋은 확률에서 개선 여지가 줄어드는 효과도
그 몫에 포함될 수 있다. 수정 스칼라와 방향 배분 역시 독립된 무작위 개입의 효과가 아니다.

## 단위·평균·잔차

네 입력 평균 성적 단위에 맞출 때 목적지 확률 합계를 4로 나누고 %p 표시 때 100을
곱한다. 양수 도움과 음수 방해 원래 질량, 부호 있는 순기여, 방향 자체의 점수 영향,
실제 수정 길이의 단위를 구별한다. 누적 양수·음수 질량이 각각 100%p를 넘어도 최종
정답률이 100%를 넘었다는 뜻은 아니다.

각 시드의 대상 수·배분·실제 지표를 모두 남긴다. 공통 후반이나 양쪽 Go 대상이 없으면
그 경로를 삭제하지 않고 0합계·대상 수 0·정의되지 않은 평균/비율 null을 보존한다.
시드 평균은 정의된 시드별 평균을 같은 비중으로 평균한 값이며, 모든 대상 시행을 합친
pooled 평균과 구별한다. 현재의 실제 누적 수정량·출력 상태·관측 정보·계산 비용을
동일하게 맞춘 인과 실험이라고 부르지 않는다.

부호 분류는 `>0,<0,==0`으로 고정하고 tiny 부호를 임의 epsilon으로 지우지 않는다.
canonical 증분 계산과 부모의 계수를 더한 뒤 내적하는 연산 순서에는 부동소수점 잔차가
있을 수 있다. 실제 저장 변화·prefix·체크포인트와 `1e-8` 허용 오차 안에서 대조한다.
무오차 실수 연산·bytes 동일성·원인 배분의 유일성을 주장하지 않는다.

## 동결·검증·산출물

설정 `configs/gated_factors_v1.json`, 계획(이 문서), 소스·검사·부모 증거를 별도 등록에
SHA-256으로 고정한다. 등록 `results/registration_gated_factors_v1.json`, 게시 증거
`results/gated_factors_publication_proof.json`, 결과 `results/gated_factors_v1`과 검산
`results/gated_factors_v1/verification.json`을 새 경로로 배타 생성한다. 비공개 원격에
게시한 같은 원문 bytes를 확인한 시간이 새 실제 집계보다 앞서야 한다.

새 소스 고정 목록은 20개다. 부모 증거 고정 목록은 12개이며 이전 장부의 원자료와
원 학습의 `results/gated_learning_v1/arrays.npz`를 직접 포함한다. 이전 원 학습의
전체 행동·최적화 검산을 새로 실행했다는 주장 대신 동결된 통과 증거를 참조한다.

새 숫자 파일은 정확히 14배열을 갖는다. 실제 확률·정답 정렬 점수 변화, 공통 후반,
두 실제 행동의 경우, 교차 대상 mask, 8셀, 순효과·양수 질량·음수 질량의 세 배분,
두 경로의 여덟 진단, 최초 공통 후반 시행, 시드·입력 순서·목표다. 비대상 셀·배분·진단은

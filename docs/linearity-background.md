# 선형 참조 함수의 수학적 의미

2026-10-14, Asia/Seoul. 아래는 현재 코드와 새 설계에서 도출한 사실이며 새로운 생물학적 관찰이 아니다.

현재 모델의 후보 점수는 `s(x)=Σ_k g_k ReLU(e_k·x+b_k)`로 쓸 수 있다. encoder와 bias는 고정되고 g는 KC→MBON 가중치와 마지막 선택 가중치의 곱을 합친 값이다. 따라서 입력의 활성 구간 안에서는 점수가 affine 함수이지만, 모든 입력에서 같은 직선이라는 보장은 없다. 배선과 내부 학습으로 계수도 달라진다. 이번 검사는 그 알려진 계산 구조가 수량·nuisance 범위에서 얼마나 간단하게 요약되는지를 묻는다.

주 affine 참조는 `r(x)=a+βq+Σ_j η_j u_j`다. q는 수량 코드/8, u는 기존6개 인공 nuisance 입력이다. intercept 포함8계수는 독립 calibration 자료의 **2·4에 대한 모델 후보 점수만** 최소제곱으로 맞춘다. design의8열이 독립인지 확인하며, 순위를 잃으면 실패로 남기고 ridge·추가 자료·특수 시드로 교체하지 않는다.

보조 scalar 참조는 nuisance를 보지 않는다. 같은 nuisance 분포를 교차 제시한 q=.25/.5의 평균 모델 점수를 m2,m4라 할 때 `β=(m4−m2)/.25`, `a=m2−.25β`다. 새 수량 점수를 맞추지 않고 같은 직선을 적용한다. 두 참조는 **이미 학습한 모델의 출력을 제공받는 근사 함수**이며 보상만으로 수량 규칙을 독립 습득한 모델이 아니다.

참조의 점수 차이에도 원래 모델과 같은 `sigmoid(clip(r_right−r_left,−40,40))`를 적용한다. sigmoid의 변화율은 최대1/4이므로 작은 점수 차이 오차는 확률에서도 작다. 반대로 포화 구간에서는 큰 점수 오차도 확률에서 거의 보이지 않을 수 있다. 공통 intercept는 두 후보의 차이에서 소거되므로 절대 점수 오차와 선택 확률 오차도 다르다. **낮은 확률 MAE가 모든 점수 함수의 정확한 선형성이나 동일 내부 기작을 증명하지 않는다.** 따라서 절대 점수 RMSE, clipping 전 점수 차이의 MAE/RMSE, 확률 MAE와 greedy 불일치를 함께 보존한다.

calibration의 두 수량에서 잘 맞는 것은 새 사례에 대한 검증이 아니다. 주 오차는 두 수량 모두 연습하지 않은15쌍과 사전4코드에서 계산한다. 12개 anchor 포함 쌍, 전체27쌍과 주 예시5대7은 보조로 구분한다. 처음 상태의 오차도 기록하며, 학습 후 fidelity 기준을 통과했다고 학습이 압축 가능성을 새로 만들었다고 가정하지 않는다. 인간의 수량 표상·주관적 확신·Weber 법칙과는 다른 계산적 검사다.

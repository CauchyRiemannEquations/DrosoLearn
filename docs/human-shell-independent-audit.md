# 공개 조개 과제 비교: 독립 검산 계획과 해석 경계

작성일: 2026-10-19 (Asia/Seoul). 실행 전 초안이다. 이 문서는 새 분석 결과나 유사성 지지 판정이 아니다. 주 프로토콜·설정의 최종 계약과 함께 동결하며, 아래 계약이 충족되지 않으면 실제 비교를 시작하지 않는다.

## 쉽게 설명하면

사람과 모델 모두 조개를 가져갈지 그냥 보낼지 고른다. 가져가야 안에 든 진주·흙·빈 공간을 볼 수 있다. 원자료에는 그냥 보낸 조개의 내용까지 적혀 있지만, 이것을 모델에게 알려 주면 사람보다 많은 정보를 가진 채 시험을 치르게 된다. 독립 검산은 이런 정보 누출과 계산 순서의 오류를 먼저 잡는다. 비슷한 선택 기록이 나와도 같은 뇌 기작이나 수량 이해를 입증하지 않는다.

## 원자료와 분석 대상

후보 자료는 [TNU 공개 자료, Zenodo 10066829](https://zenodo.org/records/10066829)다. 제공된 설명서 전체는 연구를 위한 외부 캐시의 `readme.pdf`로 확인했다. 설명서는 자료에 CC BY-NC 4.0을 명시한다. 정확한 다운로드 URL·버전·해시·출처·라이선스는 별도 원자료 manifest에 보존하고, 실제 등록은 그 manifest와 원 ZIP의 바이트를 고정해야 한다.

설명서는 `VerumPlacebo`의 0을 위약, 1을 약물로 정의하지만, 수령 자료의 표기와 농도 열 사이에 해석이 필요한 불일치가 보고됐다. 이를 임의로 역코딩하거나 농도값으로 집단을 다시 만들지 않는다. 분석 대상은 성과를 보지 않고 정한 **공개 자료의 전체 ID**이며, 위약군·약물군 효과나 일반적인 건강인 집단의 대표값을 추론하지 않는다. 인구통계·농도·설문 변수는 모델 입력·개인별 가중치·분할 기준에 사용하지 않는다. 약물 메타데이터의 불확실성과 시행 기록의 의미·일치 여부는 서로 다른 검증 항목이다.

자료 구조 검토에서 메타데이터 50명 중 `A0016`의 로그가 잘린 점을 보존하고, 완전한 대응 시행을 가진 49명을 분석 대상으로 고정한다. 사람의 선택 성과나 약물 표기에 따라 제외·분할하지 않는다. ID는 `A0004`와 같은 원래 문자열을 사용하고, `SHA-256('drosolearn-shell-v1:'+ID)`의 16진수 순서에서 앞 20명을 보정용, 나머지 29명을 최종 평가용으로 고정한다. 구체적인 두 명단과 제외 근거를 등록 전에 보존한다. 추가 구조·결측 문제가 발견되면 미리 정한 무결성 실패 규칙에 따라 중단하며, 성과를 본 뒤 새 제외 규칙을 만들지 않는다.

## 공개 필드의 의미와 관측 정보

설명서에 따르면 `GONOGO_trace_AXXXX.csv`는 매 시행의 입력 세 열을 가진다. 첫 열은 조개 종류 1–6, 둘째는 그 조개의 초기/다른 숨은 상태 1/2, 셋째는 잠재 내용 0=빈 조개·1=진주·2=흙이다. 상태 1은 항상 보상 상태를 뜻하지 않는다. 조개별 초기 순서는 1=RNRN, 2=NRNR, 3=RPRP, 4=PRPR, 5=PNPN, 6=NPNP다.

`GONOGO_shortlog_AXXXX.txt`는 시행 번호, 조개 종류, 잠재 내용, 관측 행동(Go=1·NoGo=0), RT를 기록한다. 설명서는 shortlog의 종류·내용이 trace의 대응 열과 같다고 명시한다. NoGo의 잠재 내용이 파일에 있다는 사실은 참가자가 그것을 봤다는 뜻이 아니다. Go에서는 진주 +1·흙 -1·빈 조개 0, NoGo에서는 보상 0이며 내용이 숨겨진다. RT 0은 설명서상 NoGo의 기록값으로, 빠른 반응시간이라고 해석하지 않는다.

독립 검산은 등록된 원 ZIP에서 직접 CSV/TXT를 읽고 모든 참가자·원 시행의 순서·길이·종류·내용 대응·허용 코드·RT 역할을 확인한다. 임의로 행을 정렬하거나 결측 시행을 건너뛰어 인접하게 연결하지 않는다. 상태·잠재 내용의 관계는 자료 의미 확인에만 사용하며, 숨은 상태와 R/P/N 라벨을 모델 입력·보상 전 예측·중간 재설정·학습률 선택에 사용하지 않는다.

## 비교할 두 실행 경로

1. **사람의 다음 선택 예측:** 각 시행에서 현재 조개와 과거에 실제로 관측 가능한 사람의 경험만으로 Go 확률을 먼저 계산한다. 확률을 기록한 뒤 실제 사람의 행동·그 행동으로 관측한 보상만 모델에 전달한다. 같은 시행의 행동·내용으로 가중치를 바꾼 뒤 그 행동을 예측하는 것은 금지한다. 이 경로의 평균 음의 로그우도와 Brier 점수는 사람 행동을 얼마나 잘 예측하는지 평가하며, 모델이 스스로 플레이한 성과가 아니다.
2. **모델의 독립 선택:** 새 고정 시드의 모델이 원 trace의 조개 순서를 따라 스스로 행동한다. Go면 그 시행에 고정된 잠재 내용을 드러내고, NoGo면 내용이 없는 관측과 보상 0만 전달한다. 사람의 행동·보상 기록으로 모델 행동을 바꾸지 않는다. 학습 상태는 한 참가자 trace 안의 숨은 반전에서 초기화하지 않고, 참가자 trace를 시작할 때만 새로 초기화한다. 고정 입력 trace를 쓰는 이 비교는 사람의 반응시간·실제 상호작용 시간·약물 상태를 재현하지 않는다.

두 실행 경로의 모델 상태·시드·기록·결과를 분리한다. 학습률 보정은 보정 참가자에 한정하며, 각 학습 계열에서 사전에 정한 후보 `.03, .1, .3`과 보정 시드 `13001–13003` 모두의 참가자 평균 음의 로그우도로 선택한다. 동률이면 더 작은 학습률을 선택한다. 내부 학습률은 출력 학습률의 `.1`배, Q-learning의 학습률 후보도 같은 셋이며 역온도는 4다. 최종 평가 시드는 `13101–13105`다. 최종 평가 참가자의 점수로 학습률·시드·예산·지표를 변경하지 않는다.

## 독립 검산의 최소 요건

- 검산기는 주 산출물의 요약 수치를 입력 정답으로 삼거나 주 생성기의 지표·업데이트 함수를 호출하지 않는다. 원자료·설정·동결된 초기값·행동 기록에서 직접 다시 계산한다.
- 모든 사람 조건부 예측의 시점이 업데이트 전인지 확인한다. 최초 시행과 손으로 계산 가능한 짧은 합성 시행열에서 이를 검증한다.
- 입력은 새 인공 조개 표현이다. 현재 제안은 7차원 중 앞 6차원의 Go 조개 one-hot과 NoGo의 영벡터이며, 일곱째 차원의 역할·출력 bias·입력 가중치 고정 여부를 최종 계약에서 확정한다. 실제 시각·행동 억제 회로를 구현했다는 주장을 하지 않는다.
- 관측이 같은 두 시행열의 숨은 NoGo 잠재 내용만 바꿔도 이후 사람 조건부 예측·내부/출력 가중치가 바뀌지 않아야 한다. 모델 독립 선택에서도 NoGo인 순간의 숨은 내용을 바꿨을 때 동일 관측까지의 상태가 같아야 한다. 이후 모델이 Go한 순간에는 새 관측이 달라질 수 있다.
- 양·음·0 보상, Go·NoGo, 두 행동의 확률과 부호를 별도 합성 예에서 검증한다. 제한된 내부 학습은 해당 시행 업데이트 전의 출력 가중치로 적격도를 계산하는지 확인한다. 가중치 clipping·정규화·샘플링·출력 안정화가 있으면 모두 계약과 검산에 포함한다.
- 각 계열·학습률·시드의 전체 실행을 보존한다. 보정 후보 전부와 최종 선택, 평가 참가자 전부와 고정 평가 시드를 빠짐없이 기록한다. 학습 실패를 좋은 시드로 바꾸지 않는다.
- 시행별 확률·실제 행동·관측 보상·가중치 변경량을 구분한다. 고정 모델의 내부 변화는 0이어야 하며, 가소성 모델의 선택된 내부 연결 외 변경도 0이어야 한다. 내부/출력 변화와 단순 활성 변화를 섞어 세지 않는다.
- 평균 음의 로그우도와 Brier 점수는 확률의 사전 clipping 규칙까지 독립 계산한다. 참가자별 평균과 참가자 사이 평균을 구분하고, 계산 시드를 사람 개체 수로 더하지 않는다. 동일 참가자의 여러 반전·조개·시행은 독립 사람 표본이 아니다.
- R/P 상태의 기대 보상에 따른 적절한 선택과 N 상태의 선택을 구분한다. N에서는 Go·NoGo의 기대 보상이 모두 0이므로 임의의 정답 행동을 만들지 않는다. N에서의 Go 빈도는 선택 성향으로 따로 제시할 수 있다.
- 반전 분석은 조개별 노출 횟수로 맞추고, 전체 게임 시행 수와 구분한다. 반전 앞뒤의 고정 창·중복 창 처리·최소 분모·빈 셀 null 규칙을 등록한다. 지표를 정의한 뒤 인간 자료의 유리한 반전만 고르지 않는다.
- 무학습 확률·단순 지속·일반 신경망·재배선·단순 가치 학습 대조와 실제 부분 배선 모델의 지표를 같은 단위로 계산한다. 자원·학습 규칙·입력 차이가 완전히 통제되지 않았다면 그 차이도 결과와 함께 명시한다.
- 파일 해시·코드 커밋·등록 시각·실제 실행 시각·독립 검산 시각을 확인한다. 새 등록과 결과는 별도 경로에 보존하고, 이전 Marković 비교의 닫힌 문턱이나 기존 완료 결과는 변경하지 않는다.

## 실패와 유사성의 판정

무결성 오류, 학습 실패, 행동 유사성 미지지는 별도 상태다. 원자료·시점·정보 차단·산술 일치가 깨지면 유사성 검정을 수행한 것으로 세지 않는다. 유효하게 실행했지만 정한 차이 허용 범위를 벗어나면 그 행동 유사성을 지지하지 않는 결과로 남긴다. 차이가 유의하지 않다는 사실만으로 동등하거나 닮았다고 판정하지 않는다. 허용 차이·평가 지표·불확실성 계산법·학습 성립 조건이 동결되기 전에는 유사성 성공 판정을 만들지 않는다.

사람의 행동을 더 잘 예측하는 결과와 사람·모델 간 학습 곡선의 동등성은 서로 다른 주장이다. 전자는 NLL/Brier와 대조 모델로 평가할 수 있지만, 후자는 어떤 행동 범위에서 어느 정도의 차이를 허용할지 별도의 사전 기준이 필요하다. 사람이 경험한 금전적 결과와 모델의 signed reward도 같은 주관적 가치라고 가정하지 않는다.

행동 유사성의 일차 모델은 실제 부분 배선 가소성 조건 `plastic`이다. 조개 3/4 초기 단계의 마지막 3회−첫 3회 적절한 행동률, 여섯 반전 직후 3회 적절한 행동률, 여섯 반전 단계의 마지막 3회−첫 3회 회복량을 사용한다. N을 포함하지 않는 R/P의 기대 보상상 유리한 행동을 채점한다. 세 평균 차이의 90% 구간이 모두 ±.10 안에 있을 때 해당 세 행동 지표의 제한된 동등성을 지지한다. 같은 ID 추출을 사람과 모델에 적용하고 모든 참가자에 공유되는 모델 시드 축은 따로 추출하는 교차 재표집을 2,000회 수행한다. 여러 조건 중 통과한 조건만 골라 일차 성공으로 바꾸지 않는다.

조건부 예측은 `plastic`과 uniform·보정 집단의 고정 Go 편향·동일 조개 직전 행동 지속 대조를 비교한다. 모든 세 대조에 대한 참가자 평균 NLL 개선의 90% 구간 하한이 `.01`을 넘는지 따로 판정한다. 이는 예측 유용성 기준이며, 단순한 예측 정확도를 학습 기작의 증거로 바꾸지 않는다. 지속 대조가 사용하는 동일 조개의 이전 노출은 게임 전체의 직전 시행과 구분한다.

두 체계의 향상량이 모두 0인 경우에도 동등성은 성립할 수 있다. 따라서 행동 동등성 통과만으로 두 체계에 실제 학습이 성립했다거나 학습 메커니즘이 닮았다고 쓰지 않는다. 학습 변화·대조 비교·일차 행동 동등성의 판정을 각각 보존한다.

현재 사용될 커넥톰은 제한된 KC→MBON 부분 배선이며 입력과 행동 출력은 인공적이다. 이 조개 과제는 수량 비교·수학 규칙·고등 수학 학습이 아니다. 따라서 지지 가능한 최대 주장은 등록한 보상 학습 과제의 특정 행동 지표에 대한 제한된 인간·모델 비교이며, 실제 초파리 학습·공통 신경 기작·교육 효과는 이 연구만으로 판정하지 않는다.

# 단순 참조 함수의 설명 범위 — 사전 프로토콜 v1

작성일: 2026-10-14 (Asia/Seoul). 앞선 [입력 간격 진단](spacing-findings.md)을 본 뒤 **새 시드 5001–5010의 연구 실행 전에 정한 후속 계획**이다. 기존 smoke·보상 반전·입력 표현·입력 간격 연구의 프로토콜, 설정, 코드, 결과와 실패를 보존한다. 이번 연구는 새 모듈·문서·설정·등록·결과 경로를 사용하며 원자료와 공유 코드까지 해시로 동결한다. 비공개 Git 원격에 실행 전 동결을 확인하지만, 이를 외부 공인 공개 사전등록 또는 완전한 눈가림 확증으로 표현하지 않는다.

## 비전공자를 위한 설명

지난 실험에서는 같은 5개와 7개 문제라도 모델에 알려 주는 숫자 사이의 거리가 좁으면 정답 선택 확률이 낮아졌다. 그런데 확률이 큰 쪽만 고르면 정답 방향은 유지됐다. 간단한 직선도 이런 반응을 낼 수 있다. **복잡한 배선 모델이 보인 반응을 단순한 계산식으로 어디까지 설명할 수 있는지**가 이번 질문이다.

모델은 먼저 2개와 4개 중 큰 쪽을 고르는 연습을 한다. 그 뒤 연습과 별도로 준비한 2개·4개 입력에 대한 모델의 점수만 보고 두 가지 간단한 참조 함수를 맞춘다. 하나는 수량 숫자와 나머지 여섯 입력을 더한 식이고, 다른 하나는 수량 숫자만 보는 직선이다. 참조 함수는 새 수량의 정답이나 점수를 보고 다시 맞추지 않는다. 연습하지 않은 수량에서 참조와 원래 모델이 얼마나 같은 선택 확률을 내는지 검사한다.

참조가 원래 모델을 잘 따라가도 참조가 같은 보상 경험으로 독립 학습했다는 뜻은 아니다. 참조는 **원래 모델의 점수를 제공받은 요약식**이다. 또한 두 함수가 서로 같게 반응하는 것과 둘 다 정답을 잘 맞히는 것은 다르다. 학습 전의 약 50% 반응도 간단한 식이 잘 따라갈 수 있으므로 학습 전후를 함께 남긴다.

## 연구 질문과 사전 판정

주 질문 H-L: 훈련 수량 2·4의 별도 calibration 입력만으로 맞춘 affine 참조 함수가, 학습 후 네 입력 코드와 완전 미학습 15수량쌍에서 원래 모델의 오른쪽 선택 확률을 얼마나 정확히 예측하는가? affine는 입력값들을 계수로 곱해 더하고 상수 하나를 붙인 함수다. 수량의 의미를 발견했는지나 생물학적 학습 법칙이 같은지를 묻는 검사가 아니다.

각 시드·모델 조건에서 원래 모델과 주 affine 참조의 `p_right` 차이 절댓값을 `4코드×15쌍×128행=7,680`개 평가 사례에 동일하게 평균한 **MAE**를 주 지표로 쓴다. MAE는 평균 절대 오차이며, `0.02`는 선택 확률의 평균 2%포인트 차이다. 각 쌍의 평가 행 수가 같으므로 코드·쌍 macro 평균과 같은 가중치를 준다. 여섯 모델 조건마다 **전체 10시드 평균 MAE≤0.02 및 개별 MAE≤0.02인 시드≥8/10**을 모두 만족하면 해당 조건의 H-L 계산 기준 통과다. 0.02는 사전 지정 연구용 실용 기준이며 생물학적 임계값, 유의성 검정 또는 신뢰구간이 아니다.

주 판정에는 습득 실패 시드를 포함해 모든 10시드를 사용한다. 별도의 **습득 gate**는 원래 모델의 훈련 수량쌍 2 대 4 최종 IID `p_correct≥0.75` 및 학습 전 대비 향상 `≥0.15`를 모두 만족하는 것이다. `습득 gate 및 개별 H-L 오차 기준`을 함께 통과한 시드 수를 qualified fidelity로 별도 보고한다. 그 수에 사후 조건 성공 임계값을 붙이지 않으며 전체 시드의 주 판정을 대체하지 않는다. 실패한 시드를 삭제·교체하거나 시행을 늘리지 않는다.

JSON의 `qualified_mean_affine_probability_mae`는 **습득 gate를 통과한 모든 시드**의 평균이며 분모는 `acquisition_count`다. `qualified_count`는 습득과 개별 오차 기준을 모두 통과한 수이므로 두 필드의 분모를 혼동하지 않는다. 코드별·시드별 오차와 두 gate의 원값도 보존한다.

다음은 사전 보조 지표이며 별도 주 가설 또는 사후 성공 기준으로 추가하지 않는다.

- 학습 전 동일한 affine MAE와 학습 후 대비: 낮은 오차가 이미 초기 상태에도 있는가.
- 수량만 사용하는 scalar 직선의 MAE: 여섯 nuisance 좌표를 포함한 주 참조와의 설명 범위 차이.
- 완전 미학습 15쌍, 학습 anchor를 하나 포함한 12쌍, 미학습 전체 27쌍 및 5 대 7의 각각의 오차와 정답 선택 확률.
- 네 코드별 5 대 7 반응 곡선, 원래 모델·두 참조의 `p_correct` 및 greedy 정확도.
- 오른쪽−왼쪽의 **clipping 전 원시 점수 차이**에 대한 MAE·RMSE와 greedy 선택의 불일치. RMSE는 제곱 오차 평균의 제곱근이다.
- calibration 입력의 rank, 특이값, 계수와 calibration 오차. 이 자료로 사후 참조식을 고르거나 기준을 바꾸지 않는다.

sigmoid와 clipping은 큰 점수 차이를 거의 0 또는 1의 확률로 압축한다. 따라서 작은 확률 MAE만으로 원래 점수 함수가 정확한 직선이라고 판정할 수 없다. 원시 점수 차이 오차와 선택 불일치를 함께 해석하며, MAE의 변화가 원래 함수의 학습 변화인지 참조 적합 자체의 차이인지 구별한다. 참조가 틀린 모델을 잘 따라가는 경우도 fidelity 기준을 통과할 수 있다.

## 참조 함수: 적합 자료와 수학적 정의

원래 학습 모델의 후보별 점수는 다음과 같다.

`s(x) = MBON(ReLU(x @ encoder.T + bias)) @ head`

KC 활성은 고정된 ReLU 특징이고, MBON 합산과 출력 점수는 선형이다. 따라서 현재 모델의 점수 함수는 입력에 대해 **구간마다 affine인 함수**이며 내부·출력 가중치 학습이 합산 계수를 바꾼다. 구간 전체가 하나의 직선에 가깝다는 것은 자동으로 보장되지 않으며 KC 활성 구간의 경계와 nuisance 상호작용 때문에 참조 오차가 날 수 있다. 이 알려진 계산 구조의 압축 가능성을 검사하는 것으로, 실제 초파리 뇌의 선형성을 검증하는 실험은 아니다.

각 시드에 2 대 4의 별도 IID calibration 128행을 생성한다. 후보별로 두 입력이 있으므로 주 적합에는 `256×8` 설계 행렬을 쓴다. 각 행은 **실제 7차원 입력 앞에 상수 1을 붙인 벡터**이며 계수 순서는 `[intercept, q, nuisance1,…,nuisance6]`이다. 수량 입력은 원래대로 `2/8=0.25` 또는 `4/8=0.5`, 나머지 여섯 좌표는 `0.1×(u−0.5)`다. calibration 목표는 원래 모델의 후보별 원시 점수이며 정답 라벨, 선택 보상, 확률이나 새 수량의 점수가 아니다.

주 참조의 8개 계수 `beta`는 `np.linalg.lstsq(X, model_candidate_scores, rcond=None)`의 보통 최소제곱으로 한 번 적합한다. 반환 rank는 반드시 8이어야 한다. full rank를 만족하지 않으면 검증 실패로 기록하고 다른 적합법·regularization·추가 calibration 자료로 바꾸지 않는다. 동일한 점수에 상수를 더해도 후보 차이는 같지만, 여기서는 저장한 모델 점수를 그대로 사용하고 intercept와 후보별 예측을 모두 보존한다.

보조 scalar 참조는 calibration 후보 중 수량 2와 4의 모델 점수 평균을 각각 `mean_s2`, `mean_s4`로 구한다.

`slope = (mean_s4 − mean_s2) / (0.5 − 0.25)`

`intercept = mean_s2 − slope×0.25`

`s_scalar(x) = slope×x[0] + intercept`, 저장 계수 순서는 `[intercept, slope]`다.

scalar 참조에는 여섯 nuisance 입력이 직접 들어가지 않는다. nuisance를 평균한 두 anchor 점수로 만든 기준선이며, 서로 다른 수량 구간의 KC 활성이나 nuisance 효과를 정확히 재현한다고 가정하지 않는다.

원래 모델·두 참조 모두 오른쪽−왼쪽 점수 차이 `d`에서 `p_right = 1/(1+exp(−clip(d,−40,40)))`를 계산한다. 참조에만 확률 온도나 clipping 범위를 조정하지 않는다. raw margin 지표는 `clip` 이전 `d`끼리 비교한다. greedy 평가는 `|p_right−0.5|<1e−12`를 동률로 처리한다. 정답 평가에서 동률은 0.5점이며, 원래 모델과 참조의 오른쪽 greedy 선택을 각각 `g∈{0,0.5,1}`로 두고 `|g_model−g_reference|` 평균을 선택 불일치로 기록한다. 같은 방향은 0, 반대 방향은 1, 한쪽만 동률이면 0.5다.

학습 전과 400시행 후 각각 같은 calibration 입력에 대한 **해당 시점 모델 점수**로 참조를 별도 적합한다. 두 시점의 참조 계수와 오차를 보존한다. 중간 checkpoint에서는 원래 모델을 기록하되 참조를 재적합하지 않는다. 27쌍·네 코드의 평가 입력과 정답은 적합 자료로 사용하지 않고, 평가 이후 계수 수정·모형 선택·추가 보상·학습을 금지한다.

## 입력 코드, 학습과 자원

앞선 spacing 연구와 같은 네 코드를 사용한다.

`code_alpha = [1, 2, 3, 4, 6−alpha, 6, 6+alpha, 8]`, `alpha∈{0.25,0.5,1,1.5}`

첫 입력 좌표는 `code_alpha(n)/8`이고 여섯 nuisance 좌표는 동일하다. 네 코드는 순서, 훈련 anchor 2·4, 양 끝 1·8, 전체 입력 범위 `[1/8,1]`를 고정한다. 5 대 7에서는 입력 중간값 0.75를 고정하고 입력 간격을 `2×alpha/8`로 바꾼다. 다른 쌍에는 중간값과 간격이 함께 달라질 수 있다. 실제 수량의 비율·차이와 입력 코드의 간격·중간값을 별도 저장한다. 실제 수량 비율이나 실제 그림의 단서 통제를 조작한 과제로 해석하지 않는다.

모든 시드·조건은 2 대 4를 400회 연습하며 큰 수량 선택에 보상 1, 다른 선택에 보상 0을 받는다. 알고리즘에 선택 행동과 scalar 보상만 전달한다. 네 코드의 훈련·IID·OOD·calibration 입력은 byte 수준에서 같으며 **시드·모델 조건당 원래 모델을 한 번만 학습**한다. 두 시점의 참조 적합은 해당 모델의 관찰 요약이지 추가 보상 학습이 아니다. 실제 보상 학습량은 `10시드×6조건×400시행=24,000`이다. 네 코드·두 참조·두 평가 시점을 새로운 학습자 수나 생물학적 개체 수로 세지 않는다.

원래 `Learner`의 encoder, 활성 함수, 연결 합산, 선택 확률, 갱신식과 clipping을 변경하지 않는다. 모델 조건은 `fixed`, `plastic`, `rewired_fixed`, `rewired_plastic`, `ann_fixed`, `ann_plastic`이다. 실제 KC→MBON 부분집합, 차수 보존 재배선, 무작위 희소 일반망을 각각 출력 전용 또는 내부·출력 학습으로 비교한다. 조건 전체에 같은 7차원 입력, nominal 512 KC·48 MBON, 400 학습 시행, 출력 학습률 0.1과 내부 학습률 0.01을 사용한다.

실제 부분집합은 FlyWire v783의 KC→MBON 1,474개 연결이며 489 KC·29 MBON에 연결이 있다. 내부 가소성은 확보한 mask 안에서만 허용하고 각 가중치를 초기값의 `[0,2배]`로 제한한다. 고정 모델은 출력 48개만, 가소성 모델은 내부 1,474개를 추가로 학습하므로 학습 자원이 같다고 주장하지 않는다. 재배선은 KC outdegree·MBON indegree·MBON별 incoming weight multiset을 보존하고, ANN은 뒤의 두 특성을 보존하며 KC outdegree까지 같다고 가정하지 않는다.

참조 함수는 8개 또는 2개 계수만으로 원래 모델의 점수를 제공받아 맞춘다. **같은 정보·보상·학습 자원으로 독립 학습한 일반 신경망과의 우열 비교가 아니다.** 기존 여섯 모델 조건을 유지하는 이유는 배선에 따른 설명 오차 차이를 관찰하기 위해서이며 실제 배선의 우위를 성공 목표로 정하지 않는다.

## 자료 분할, 새 시드와 checkpoint

연구 시드는 **5001–5010**이다. 자료 난수는 `seed*100+31`(train), `+32`(IID), `+33`(nuisance OOD), **`+34`(calibration)**, `+40+i`(사전식 미학습 27쌍의 index i=0,…,26)를 사용한다. 행동 uniform은 `seed+280000`, encoder·초기 head는 `seed+70000`, 재배선은 `seed+50000`, ANN은 `seed+60000`이다. 구현 fixture는 71/72 등의 별도 시드, 학습 8행, 평가 8행, calibration 32행을 사용해 full rank를 확인한다. 계획 시드 5001–5010으로 구현·오차 기준·예산을 튜닝하지 않는다.

훈련은 2 대 4의 400행이다. 학습과 분리한 2 대 4 IID·nuisance OOD·calibration은 각각 128행이며 미학습 27수량쌍은 쌍마다 128행이다. nuisance OOD는 인공 비수량 좌표의 분포 변화이며 실제 시각 수량 일반화가 아니다. 모든 조건·코드는 원래 평가 행을 공유한다.

각 nuisance family의 네 행 교차 설계로 후보 위치와 nuisance 벡터가 정답 수량에 균형 있게 대응한다. orientation에 독립적인 자극 fingerprint로 train·IID·OOD·calibration·27쌍 전체의 중복을 확인한다. calibration은 train과 같지 않으며 평가 문제와도 겹치지 않는다. 독립 난수 생성만으로 누출 방지가 보장됐다고 표현하지 않는다. counts·nuisance·family ID·행동 uniform·코드 벡터를 원자료로 저장한다.

| 평가 범위 | 쌍 수 | 역할 |
|---|---:|---|
| `{1,3,5,6,7,8}`의 모든 조합 | 15 | 주 H-L 확률 MAE; 두 수량 모두 훈련에서 제외 |
| 2 또는 4와 위 여섯 수량의 조합 | 12 | 학습 anchor 포함 보조 오차·수행 |
| 위 두 범위의 합 | 27 | 전체 미학습 보조 요약; 훈련 2 대 4 제외 |
| 5 대 7 | 1 | 네 간격의 반응 곡선과 보조 오차; 15쌍에 포함 |

27쌍은 1–8에서 서로 다른 두 수량의 사전식 조합에서 2 대 4만 제외한다. 각 범위를 별도로 보고하며 주 결과를 유리한 쌍·코드·모델 조건으로 대체하지 않는다. 같은 함수가 여러 입력에 낸 반응이지 여러 학습 규칙을 발견한 결과가 아니다.

checkpoint는 시행 `0·100·200·300·400`이다. 원래 모델의 2 대 4 IID/OOD 학습 곡선을 기록하고 네 코드의 입력·출력이 동일함을 확인한다. 고정 probe는 IID의 첫 8행이며 내부 가중치·출력 가중치·KC/MBON 활성·선택 확률을 구분해 저장한다. 참조·27쌍 평가와 적합은 학습 전·학습 후 두 시점에서만 한다. 평가와 적합은 모델 가중치, 갱신 counter 또는 행동 난수 상태를 바꾸지 않는다.

## 분석적 확인과 해석 범위

순서를 제공하는 네 코드에서 큰 입력값을 고르는 code-ranking oracle은 모든 쌍에서 1.0이다. 이는 정답을 낼 정보가 입력에 있다는 설계 확인이며 이번 참조와 다른 목적의 privileged 기준이다. nuisance-only 고정 정책의 평균 정답 선택 확률 0.5는 교차 자료의 대칭 성질이다. 반면 원래 모델과 두 참조가 같은 반응을 내거나 H-L 기준을 통과해야 하는 항등식은 없다.

원래 모델의 score는 KC ReLU 특징의 가중 합이지만 전체 입력 범위에 하나의 affine 함수가 보장되지는 않는다. full rank calibration은 anchor 영역의 8개 affine 계수를 정할 수 있다는 뜻이며 처음 보는 수량에서의 정확도를 보장하지 않는다. 5·7은 모든 네 코드에서 훈련 입력 구간 `[0.25,0.5]` 밖이다. 따라서 낮은 새 입력 오차가 나오면 이 인공 입력 범위에서의 제한된 외삽 설명 가능성으로 기록한다. 원시 점수 차이 오차가 큰데 확률 오차만 작으면 확률 압축 효과를 먼저 검토한다.

계산 시드별 전체 값, 조건별 평균·계산 시드 표본 표준편차, H-L 통과 시드 수, 습득 gate·qualified fidelity 수, 학습 전후와 두 참조의 결과를 보존한다. 평가 행·수량쌍·코드를 생물학적 표본 수로 부풀리지 않는다. 사전 실용 기준을 p값 또는 여섯 조건의 다중 비교를 통과한 유의성 결과로 표현하지 않는다.

관찰·평가 대상인 원래 모델의 경험 의존 변화는 Level 2, 습득 확인 뒤 인공 표현의 미학습 입력에 대한 반응은 제한된 Level 3다. **참조식의 높은 fidelity 자체는 별도 학습 경험에 의한 Level 2 또는 독립 일반화 학습의 증거가 아니다.** 현재 자료에는 실제 물체 세기·LC11·DAN·APL·재귀 상태·생물학적 시냅스 법칙이 없다. 수학 기호 의미 이해·일반 규칙 발견·인간 행동과의 정량적 유사성(Level 4)·관련 신경 기작(Level 5)을 주장하지 않는다. 기존 M11과 보상 반전의 실패도 계속 보존한다.

## 기록·독립 검산·중단

학습의 시행별 입력 식별자·좌우 수량·action·reward·p_right·갱신 계수·내부 및 출력 가중치 변화 norm을 저장한다. 원자료와 초기 상태, 행동 uniform을 이용해 모든 실제 갱신을 replay할 수 있어야 한다. 각 checkpoint의 encoder/bias·연결 인덱스·내부/출력 가중치·probe 활성·확률을 저장한다. encoder와 KC 함수는 학습하지 않으며 가중치 변화, 출력 변화와 활성 상태 차이를 같은 현상으로 합치지 않는다.

학습 전후 원래 모델의 calibration 후보별 점수·설계 행렬 또는 재구성 가능한 입력·최소제곱 rank/특이값·두 참조 계수를 남긴다. 네 코드·27쌍의 모델/참조 후보별 점수, 원시 점수 차이와 선택 확률은 원자료로 재계산 가능해야 한다. 효율을 위해 코드값별 모델 score cache를 사용할 수 있지만 직접 순전파와 일치해야 한다. 부동소수점 코드값을 정수 인덱스로 오인하지 않는다.

독립 auditor는 기존 학습 update 또는 새 연구의 적합·평가·요약 함수를 호출하지 않고 별도 산술로 확인한다. 전체 24,000갱신, action/reward/uniform, 내부 mask와 clipping, 고정 조건 내부 불변성, 자료 교차·분할 fingerprint·calibration rank, 두 참조 계수, 모든 평가 후보 점수·확률·오차·gate·요약·해시를 검산한다. 모든 seed·condition·trial coverage와 네 코드의 anchor 동등성을 확인하고, 평가에 따른 모델 상태 변화가 없는지 검사한다. 선형 대수 라이브러리를 사용하더라도 모델 score와 설계 행렬·계수 적합·잔차 계산은 연구 함수와 독립적으로 구성한다.

등록 후 source/config/protocol drift, NaN, full rank 실패, 누락·중복, 자료 교차 또는 누출, 허용되지 않은 내부 변화, 독립 산술 불일치는 검증 실패다. 부분 실행과 원인을 보존하고 과학적 결과를 승인하지 않는다. 같은 결과 경로를 덮어쓰지 않으며 구현 수정은 이유와 변경을 기록하고 새 전향적 동결·결과 경로로 진행한다. 좋은 결과를 얻기 위한 모델 확대·학습률 탐색·시드 교체·사후 기준 변경·400시행 예산 연장을 금지한다.

## 인간 학습과 연결할 다음 질문

인간 학습과의 연결은 장기 핵심 목표로 유지한다. 이번 검사는 복잡한 계산 모델의 행동을 더 간단한 입력·점수·선택 모형으로 설명할 수 있는가를 묻는다. 인간 자료에서도 수량 표현에 이미 제공된 정보와 선택 규칙의 기여를 구분하고, 정답률뿐 아니라 확률·오류·학습 전후 변화를 같은 측정 의미로 비교할 수 있는지를 후속 질문으로 남긴다.

[인간 비교 체계](human-learning-comparison.md)와 [확보한 공개자료의 범위](human-data-readiness.md)를 따른다. 그 자료에 이번의 후보별 모델 점수, 코드 간격 조작 또는 시행별 확률이 있다고 가정하지 않는다. 이번 참조의 계수나 확률을 인간의 수량 표상·주관적 확신·학습 기작과 바로 동일시하지 않는다. 실제 비교 지표와 자료 가용성이 확인되기 전에는 인간이나 학교 수학교육에 대한 효용을 주장하지 않는다.

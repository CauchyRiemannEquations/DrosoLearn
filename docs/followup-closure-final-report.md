# DrosoLearn 최종 후속 종합 — 현재 연구 범위 완료

**Exploring the Foundations of Mathematical Learning Through a Drosophila Connectome**
2026-10-21, Asia/Seoul. 사용자가 요청한 후속 결과 종합·한계 정리·재현 확인을 마쳤다.

**현재 승인된 로컬 계산 연구 범위는 완료했다.** 첫 Phase 5와 이후 17개 후속 등록을 보존하고, 새로운 학습 성공이나 생물학적 공통 기작을 선언하지 않은 채 연구를 닫는다. 새 실험·후보 탐색·시드 교체·예산 연장을 시작하지 않는다.

비전공자는 [쉽게 읽는 결론](followup-closure-plain-language.md)부터 읽으면 된다. 근거의 정확한 값은 [24개 주장과 원값 부록](followup-closure-evidence-appendix.md), 해석 범위는 [별도 한계 문서](followup-closure-limitations.md), 실행 범위는 [재현 안내](followup-closure-reproduction.md)에 있다. 원 [첫 Phase 5 보고서](phase5-final-report.md)와 [LIMITATIONS.md](../LIMITATIONS.md)는 수정하지 않았다.

## 이 연구가 남긴 결론

**문제를 구별할 정보가 있다는 것과, 그 정보를 경험으로 잘 배우는 것은 달랐다.** 네 인공 연습 문자열의 고정 특징에는 구별 가능한 정보가 있었지만, 한 문제의 출력 수정이 다른 문제의 출력에 미치는 영향과 그 영향을 통제하는 자원이 학습 결과에 중요했다.

자기 문제의 점수 수정 폭을 맞춘 투영 조건은 원 입력에서 정답 선택 확률 50.29%→86.54%, 습득 10/10으로 개선됐다. 다만 더 큰 가중치 이동과 추가 계산을 사용했다. 별도 코호트에서 한 번 수정 길이의 상한을 맞춘 조건은 57.47%, 습득 0/10이었다. 서로 다른 등록의 숫자를 같은 시드의 비용 개입 효과로 빼거나 공정한 성능 순위로 합치지 않는다. [표현·갱신 분리](representation-update-findings.md), [수정량 제한](update-budget-findings.md).

**다른 답을 보호하는 것과 충분히 배우는 것도 달랐다.** 도움과 방해를 나누고 관측한 보상만으로 방해를 줄이는 규칙을 구현했다. 처음에는 번짐을 막고 네 답의 보상 부호를 모두 확인한 뒤 균형 목표를 쓰면 아직 보상을 모르는 다른 연습 입력의 방해를 막는 동작은 확인됐다. 충분한 개선·습득 기준까지 충족한 것은 아니었다. 완전 관측 뒤에는 미관측 입력이 없다는 설계도 포함된 운영 검사이며 새로운 보호 기작이나 새 문제 일반화가 아니다. [초반 보호](gated-learning-findings.md), [선택 억제](selective-spillover-findings.md).

**한 번 유리한 수정은 실제 학습 전체의 우위를 보장하지 않았다.** 같은 저장 상태에서 전체 목표 U와 현재 확률 P의 작은 이득을 확인한 뒤, 새 등록과 새 시드로 실제 학습을 실행했다. 같은 연구 안의 주 조건은 다음과 같다.

| 방법 | 최종 네 연습 입력의 정답 선택 확률 | 충분한 습득 | 미관측 다른 연습 입력 방해 |
|---|---:|---:|---:|
| 기존 전환형 균형 B | 58.4542% | 0/10 | 0 |
| 네 문제 전체 목표 U | 58.2672% | 0/10 | 0 |
| 현재 확률 반영 P | 58.5224% | 0/10 | 0 |

U의 기존 B 대비 −0.1871%p, P의 +0.0682%p는 미리 정한 실용 개선 기준에 못 미쳤다. 같은 수정 상한을 적용했지만 실제 누적 이동과 처리 비용은 달랐다. 저장 경로에서는 자기 수정 감소와 다른 문제 도움 증가가 서로 상쇄됐고, 상태·실제 크기·선택과 보상 경로까지 더해져 작은 차이가 남았다. 방향 전체의 순몫은 양수였고, 음수 상태 몫이 당시 상태가 더 나빴다는 뜻은 아니다. 대칭 배분은 유일한 인과 원인이나 다음 학습의 성적 예측이 아니다. [단일 수정 진단](probability-alignment-findings.md), [실제 학습](objective-learning-findings.md), [경로 분해](objective-pathways-findings.md).

## 한계와 해석 수준

이번 후속 입력은 ABAB/BABA/ABBA/BAAB의 네 전체 문자열이다. 입력의 정체성을 외우는 것으로 풀 수 있어 수학적 규칙 이해가 필수인 과제가 아니다. 주로 변한 것은 출력 계수와 별도 획득 보상 기억이며, 고정 내부 KC→MBON 가중치와 같은 입력의 내부 반응을 구별했다. 계산 시드는 사람이나 초파리 개체가 아니다.

실제 LC11 시각 입력 회로·DAN 생리 동역학·독립 커넥톰 반복·새 규칙 계열·대응 인간 과제의 양성 유사성은 추가 근거가 필요하다. 정량 행동 유사성(Level 4)이 성립해도 같은 신경 기작(Level 5)이 자동으로 성립하지 않는다. 이번 종료는 새 양성 Level 3·4·5를 추가하지 않았다. 24개 장부의 Level은 주장 범위를 표시하며 음성/미검증 수준을 양성 성과로 세지 않는다.

독립 프로젝트 DrosoMem의 고정 버전·라이선스·원 결과와 M11 습득/전이 미달을 보존했다. 실제 배선이 모든 대조보다 우수하다는 근거를 새로 얻었다고 주장하지 않는다. 문헌의 실제 관찰과 모델 가정, 기존 접근 제한은 원 [문헌 검토](literature-review.md)와 [DrosoMem 감사](drosomem-audit.md)를 그대로 따른다. 이번 종합은 새로운 최신 문헌 고찰이나 인간 대상 연구가 아니다.

## 실제로 확인한 재현 범위

기존 **19,206파일·2,528,410,365바이트**의 Git blob 해시 보존을 확인했고, 이후 세 상태 인덱스 외 기존 완료 자료를 바꾸지 않았다. 소스 35개와 직접 원 입력 253개를 고정한 뒤 비공개 원격의 등록 bytes를 확인했다. 원 연구의 설정·등록·태그·소스/입력 해시·다섯 원 산출물·독립 검산·실행 순서와 과거 실패 원문을 다시 연결했다.

최신 저장 분석의 독립 산술 검산은 **한 번 실제로 재실행**했다. 원 192,000선택 기록·16배열·2,160행·480경로·34,560선택/보상 칸을 확인한 수와 요약 SHA-256이 원 영수증과 일치했다. 새 영수증 시각은 `2026-10-21T04:00:25.230015+00:00`다. 이는 원 학습과 방향 최적화를 새로 실행한 것이 아니다.

그 뒤 종합 생산 코드와 별도 독립 검산자가 17개 연구·24개 주장·80개 원 JSON 참조와 연구별 원 판정 66개, 보존 앵커 여섯 묶음을 확인했다. 2개 정수/불리언 배열과 24행10열 장부를 남겼다. 이번 실행의 자동검사 **267개(종합 신규146·관련 기존121)**가 통과했다. 이것은 이번 고유 시험 수이며 원 연구 시험들의 단순 합계가 아니다.

최초 독립 종합 검산은 원 인간 요약에 존재하지 않는 `study_id`를 요구하여 실패했다. 원 소스와 실패 출력·당시 결과를 JSON/ZIP에 보존했다. 원 요약을 바꾸지 않고, 별도 네 소스·54입력·등록·비공개 게시를 거친 엄격한 원 스키마 소비자 v2로 전체 독립 검사를 통과했다. 원 267시험과 별도 추가 소비자 84시험을 구분한다. 이는 새 학습 성공이나 과학 기준 완화가 아니다. [수정 규격](followup-closure-consumer-v2-protocol.md).

소스 commit `2b9cef9fb475846b71cc63ea0629ce4e36b790ac`, 등록 게시 `16a0643017141d521df1e4548180ccb72c87ad2a`를 보존한다. 원 산출물의 과학 기준 미달, 개발 오류와 별도 수정, 표시·소비자 검사·EOF 형식 알림은 서로 다른 이력으로 남겼다. 이번 마무리의 모든 새 문서에는 QA 봉인 전에 끝줄·공백·링크·원값 검사를 적용했다. [재현 명령과 정확한 확인 범위](followup-closure-reproduction.md).

## 이번 범위의 종료

결과·지지되지 않은 가설·판정 보류·한계·재현 명령·해시·독립 영수증을 보존한 것으로 현재 프로젝트 범위를 마친다. 원 Phase 5를 덮어쓰지 않고 별도 후속 종합으로 남겼다. 현재 자동 반복은 PAUSED이며 새로운 학습·연구를 자동 대기열에 넣지 않는다.

장기 질문인 시각 수량 회로, 생리학적 가소성, 독립 배선 반복, 습득이 성립한 새 규칙 일반화·간섭, 더 잘 대응하는 인간 공개 과제는 미해결인 채 남는다. 이를 이번 완료의 숨은 미완료 작업으로 취급하거나, 성공할 때까지 같은 등록의 시드·예산을 바꾸어 반복하지 않는다. 다시 연구할 때에는 별도 목표·자료·자원·사전 기준을 정해야 한다.

완료 표식은 `followup-closure-v1`과 `drosolearn-bounded-complete-v1`이다. 이 표식은 **현재 승인한 계산 연구와 보고의 완료**를 뜻한다.

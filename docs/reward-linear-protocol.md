# 독립 보상 선형 학습 — 사전 프로토콜 v1

작성일: 2026-10-14 (Asia/Seoul). [선형 참조 진단](linearity-findings.md)을 본 뒤 새 시드 6001–6010의 연구 실행 전에 정한 후속 계획이다. 이전 연구의 소스·자료·설정·등록·결과와 실패를 수정하지 않는다. 이번 연구는 새 모듈·문서·설정·등록·결과 경로와 전향적 해시 동결을 사용한다. 비공개 Git 원격에 실행 전에 보존하지만 외부 공인 공개 사전등록이나 완전히 눈가림한 확증 연구로 표현하지 않는다.

## 비전공자를 위한 설명

지난번에는 복잡한 모델의 계산 점수를 읽어 간단한 설명식을 만들었다. 이번에는 **그 점수를 주지 않고, 간단한 모델도 선택하고 보상을 받는 연습만으로 배울 수 있는지** 검사한다. 처음에는 모든 모델이 어느 쪽이든 50% 확률로 고른다. 2개와 4개를 400번 연습한 뒤, 연습하지 않은 수량에서도 큰 쪽을 고르는지 따로 본다.

단순한 모델은 이미 숫자로 제공한 수량값과 나머지 여섯 입력을 각각 계수로 곱해 더한다. 숫자 순서는 처음부터 입력에 있다. 물체를 세는 시각 능력을 배우는 실험은 아니다. 무작위로 보상을 주는 모델도 함께 돌려, 향상이 연습과 관련된 보상 정보에 의존했는지 확인한다.

같은 학습률을 써도 입력값 크기 때문에 한 번의 변화가 다를 수 있다. 그래서 초기 입력·활성 차이의 전체 크기를 맞춘 조건을 주 비교에 쓰고, 원시 입력을 그대로 쓰는 선형 조건도 보조로 남긴다. 척도를 맞춰도 모델의 파라미터 수와 내부 학습 자원이 모두 같아지는 것은 아니다.

## 주 질문과 판정 기준

주 질문 **H-R**: `linear_normalized`는 독립 선택·보상 경험으로 훈련 2대4를 습득하고, 선택과 무관한 무작위 보상 대조보다 향상하는가?

시드별 습득 gate는 최종 2대4 IID 정답 선택 확률 `p_correct≥0.75` 및 처음 대비 향상 `≥0.15`를 모두 만족하는 것이다. 처음 head가 모두 0이므로 초기 확률은 정확히 0.5다. 기준을 약간 못 미친 경우도 실패로 남긴다. **H-R은 다음 세 조건을 모두 요구한다.**

1. `linear_normalized` 습득 시드가 8/10 이상이다.
2. 같은 시드의 최종 IID `linear_normalized − linear_random_reward` 정답 선택 확률 차이를 전체 10시드에서 평균하여 `≥0.15`다.
3. 위 쌍 차이가 엄격히 `>0`인 시드가 8/10 이상이다. 정확히 0은 양수로 세지 않는다.

0.15는 15%포인트 차이다. 조건 2·3에는 습득 실패 시드도 포함하며 일부 시드만 골라 평균하지 않는다. 무작위 보상 모델의 습득 또는 일반화 판정도 동일한 기준으로 별도 보존하되, 주 가설의 대조 역할을 바꾸지 않는다.

주 질문 **H-G**: 습득이 확인된 `linear_normalized`가 두 수량 모두 연습하지 않은 사례에 같은 선택 방향을 적용하는가?

identity 코드에서 완전 미학습 15수량쌍의 최종 `p_correct`를 사례별로 평균한다. 각 쌍은 128행이므로 시드별 지표는 `15×128=1,920`개 사례에 동일 가중치를 준다. **시드별 습득 gate와 이 평균 `≥0.75`를 동시에 통과한 시드가 8/10 이상일 때 H-G 기준 통과다.** 습득하지 않은 모델의 높은 새 입력 수행을 ‘습득 후 일반화’로 세지 않는다. H-G가 통과해도 새로운 규칙에 대한 전이, 수학 기호 이해 또는 입력 순서의 발견을 뜻하지 않는다.

H-R과 H-G는 서로 다른 사전 가설이다. 어느 하나의 성공으로 다른 실패를 대체하지 않는다. 75%, 15%포인트, 8/10은 연구용 실용 기준이며 생물학적 임계값 또는 유의성 검정이 아니다. 가설별 원값·개별 판정·전체 10시드 평균·표본 표준편차와 실패를 모두 남긴다. 선택 확률을 높이는 것과 greedy 정답 방향은 별도 평가한다.

다른 여섯 네트워크와 `linear_raw`에도 같은 습득·identity 일반화 gate를 적용해 사전 비교 표로 보고한다. 이 보조 비교에서 유리한 조건을 골라 H-R/H-G 주 대상을 변경하지 않는다. 실제 배선이 모든 대조보다 뛰어남을 성공 목표로 정하지 않는다. 다중 가설 유의성 검정이나 공통 신경 기작 판정을 하지 않는다.

## 조건과 자원

| 조건 | 후보 특징 | 학습 계수·연결 | 보상 | 척도 |
|---|---|---|---|---|
| `linear_raw` | 원래 7차원 입력 | 7 출력 계수 | 큰 수량 선택 1/그 외 0 | 그대로 |
| `linear_normalized` | 같은 7차원 입력 | 7 출력 계수 | 같은 정답 선택 보상 | 초기 훈련 특징 차이 RMS로 나눔 |
| `linear_random_reward` | 같은 7차원 입력 | 7 출력 계수 | 선택과 무관한 독립 0/1 | 같은 초기 선형 RMS |
| `fixed` / `plastic` | 실제 KC→MBON 부분집합의 48차원 MBON | 48 출력 / 출력+1,474 내부 연결 | 같은 정답 선택 보상 | 각 초기 훈련 MBON 차이 RMS |
| `rewired_fixed` / `rewired_plastic` | 차수 보존 재배선의 48차원 MBON | 48 출력 / 출력+1,474 내부 연결 | 같은 정답 선택 보상 | 각 초기 훈련 MBON 차이 RMS |
| `ann_fixed` / `ann_plastic` | 무작위 희소 일반망의 48차원 MBON | 48 출력 / 출력+1,474 내부 연결 | 같은 정답 선택 보상 | 각 초기 훈련 MBON 차이 RMS |

모든 조건은 같은 7차원 원입력, 400 학습 시행, 출력 학습률 0.1, 내부 학습률 0.01을 사용한다. head는 모두 정확히 0에서 시작한다. 선형 조건에는 KC·MBON과 내부 학습이 없다. 여섯 네트워크는 nominal 512 KC·48 MBON을 쓰되 실제 부분집합의 연결은 489 KC·29 MBON에 존재하며 19 MBON은 연결이 없다. 따라서 48개 head 슬롯이 모두 유효한 특징이라고 주장하지 않는다. 재배선은 KC outdegree·MBON indegree·MBON incoming weight multiset을 보존하고 ANN은 뒤 두 특성만 보존한다.

400 시행을 각 조건에 한 번씩 실행하므로 실제 학습 갱신 호출은 `10시드×9조건×400=36,000`이다. 네 코드로 평가하는 것을 학습 횟수로 추가 집계하지 않는다. 내부도 학습하는 네트워크는 추가 1,474개 가중치를 사용하므로 모든 조건의 학습 자원이 동등하지 않다. 선형 7개와 네트워크 48개 출력 계수의 수, 활성 규모, 제약과 갱신량도 별도 남긴다.

이번 새 wrapper의 초기 head와 출력 특징 척도는 이전 Learner 연구와 다르다. 새 시드와 새 설정을 사용한 진단이며 옛 결과보다 개선한 동일 실험으로 표현하지 않는다. 기존 shared 소스는 수정하지 않는다.

## 초기 정규화와 갱신식

훈련 입력만으로 초기 raw 특징 차이 `Δz_i`를 계산해 `g=sqrt(mean_i sum_j Δz_ij²)`를 구한다. `g`가 양의 유한값이 아니면 구현·검증 실패로 중단하고 임의 상수나 다른 자료로 대체하지 않는다. 각 모델의 `initial_feature_gap_rms=g`와 실제 나눗값 `feature_scale`을 저장한다. `linear_raw`의 `feature_scale=1`; 나머지는 해당 `g`다. 두 normalized 선형 조건은 같은 입력을 쓰므로 `g`가 같아야 한다. 각 고정·가소성 네트워크 쌍도 초기 내부 구조가 같으므로 같은 `g`를 가져야 한다.

전체 훈련 입력 400개를 선택·보상 전에 관찰하는 무보상 batch 전처리다. 정답 라벨·보상·teacher 점수·평가 입력·이전 연구의 학습 가중치를 쓰지 않는다. 이후 어떤 학습 시점에도 `g`를 재추정하지 않는다. 초기 특징 차이 RMS를 맞추는 것은 특징 상관과 모든 학습 방향, 내부 변화 후의 척도까지 같게 만들지는 않는다.

정규화된 후보 특징을 `φ=z/feature_scale`, 점수 차이를 `d=(φ_right−φ_left)·head`, 오른쪽 선택 확률을 `p=sigmoid(clip(d,−40,40))`로 정의한다. 공통 행동 uniform으로 `a=1[u<p]`를 선택하고 환경이 scalar 보상만 반환한다. `f=(a−p)(r−0.5)`를 사용해 `head←head+0.1 f (φ_right−φ_left)`다. 정답 라벨을 optimizer에 전달하지 않는다. 다만 두 선택의 결정적 보상 자체가 정답과 동등한 정보를 제공함은 [계산적 배경](reward-linear-background.md)에 명시한다.

가소성 네트워크의 내부 가중치는 갱신 전 head로 `eligibility=old_head[post]*(KC_right−KC_left)[pre]/feature_scale`을 계산하고 `weights←clip(weights+0.01 f eligibility, 0, 2*initial_weights)`로 갱신한다. head가 0인 첫 시행에는 내부 변화량이 0이지만 호출·counter는 시행대로 기록한다. 고정 encoder와 KC ReLU는 학습하지 않는다. LC11·DAN·APL·재귀 회로와 생리학적 시간은 구현하지 않는다. 실제 dopamine 규칙과 동일하다고 주장하지 않는다.

`linear_random_reward`는 `seed+290000`으로 400개 reward uniform을 미리 생성하고 `r=1[u_reward<0.5]`를 받는다. 모든 보상 uniform과 실제 보상을 저장한다. 보상은 선택·수량·nuisance와 독립인 난수 생성 규칙이며 유한 표본의 보상률이 정확히 0.5가 되도록 균형화하지 않는다. 모든 조건은 같은 행동 uniform을 쓰지만 학습 정책이 달라지면 실제 행동·보상 경로는 달라질 수 있다. 정답 선택 보상 조건의 실제 보상을 무작위 보상 대조에 복사하지 않는다.

## 자료, 시드와 누출 검사

새 연구 시드는 **6001–6010**이다. 자료 난수는 `seed*100+31`(train), `+32`(2대4 IID), `+33`(2대4 nuisance OOD), `+40+i`(사전식 미학습 27쌍의 index i=0,…,26)를 사용한다. 행동 uniform은 `seed+280000`, 독립 무작위 보상 uniform은 `seed+290000`, encoder 초기화는 `seed+70000`, 재배선은 `seed+50000`, ANN은 `seed+60000`이다. 네트워크 encoder를 재생성할 때 기존 RNG 소비 순서를 유지하고 출력 head만 0으로 설정한다. 구현 fixture는 81/82 등 별도 시드와 작은 예산을 사용한다. 계획 시드로 구현·척도 규칙·기준·예산을 튜닝하지 않는다.

train은 2대4 400행, IID·OOD는 각각 128행, 미학습 27쌍은 쌍마다 128행이다. 별도 calibration은 만들지 않고 teacher 출력도 적합하지 않는다. nuisance는 기존 여섯 인공 좌표이며 네 행 교차 설계로 후보 위치·nuisance와 정답 수량을 균형화한다. 훈련·평가·27쌍의 orientation 독립 자극 fingerprint를 비교해 중복을 검사하고 counts·nuisance·family ID·행동·보상 uniform을 저장한다. 독립 난수라는 이유만으로 누출이 없다고 가정하지 않는다.

주 완전 미학습 15쌍은 `{1,3,5,6,7,8}`의 모든 서로 다른 조합이다. 하나의 훈련 anchor 2 또는 4를 포함하는 12쌍과 합쳐 27쌍을 별도 보조 보고한다. 2대4는 미학습 집합에서 제외한다. IID 습득과 nuisance OOD도 서로 구분하며 OOD는 실제 시각 일반화가 아니라 인공 좌표 분포 이동이다.

## 평가 코드와 보조 분석

코드는 `code_alpha=[1,2,3,4,6−alpha,6,6+alpha,8]`, `alpha∈{0.25,0.5,1,1.5}`다. 첫 입력 좌표는 `code_alpha(n)/8`이며 여섯 nuisance는 그대로다. 훈련 anchor 2·4, 순서, 양 끝 1·8과 입력 범위는 고정한다. **주 H-G는 alpha=1 identity 코드만** 사용한다. 나머지 세 코드와 전체 네 코드의 결과는 보조다. 같은 모델을 다시 학습하거나 평가 점수를 보고 계수를 변경하지 않는다.

사전 보조 지표는 다음과 같다.

- 0·100·200·300·400 시행의 IID/OOD `p_correct`와 greedy 정확도, 최종 습득 여부.
- 최초 저장 checkpoint의 습득 gate 충족 시행. checkpoint 간 정확한 최초 학습 시점이나 시행 중 지속 충족을 추정하지 않는다. 통과가 없으면 null로 남긴다.
- 학습 전·후 네 코드의 완전 미학습15·anchor 포함12·전체27쌍과 5대7 반응. 실제 수량 비율·차이와 입력 코드 간격·중간값을 별도 저장한다.
- `linear_normalized − linear_raw` 최종 IID 및 identity 완전 미학습15의 시드별 쌍 차이: 고정 예산에서 초기 척도의 영향. 추가 주 가설·사후 기준으로 변경하지 않는다.
- 다른 모델과 normalized linear의 학습 곡선·새 입력 반응 차이. 같은 시행·초기 RMS가 같은 계산 자원·우수성 근거는 아니다.
- 각 시드의 `g`, `feature_scale`, 출력 계수 변화, 내부 가중치 변화, KC·raw MBON·정규화 특징 활성 변화와 원시 점수 차이. 선택 확률의 포화가 내부 변화 크기를 숨길 수 있다.
- 선형 모델의 일곱 최종 계수, 수량 계수와 nuisance 계수. 이 값으로 조건을 다시 선택하거나 평가 자료에 재적합하지 않는다.

greedy 평가는 `|p_right−0.5|<1e−12`이면 동률 0.5점, 그 밖에는 더 큰 확률의 선택이 정답인지 0/1로 계산한다. 학습 전 head=0이므로 모든 사례에서 동률이다. 연습한 쌍 또는 새 쌍의 평균 확률과 개별 greedy 방향은 같은 지표가 아니다. 학습 곡선·모델 조건별 비교 그림과 시행별 기록을 자동 생성한다.

## 구조적 해결 가능성과 반증

순서를 이미 제공한 코드에서 큰 입력을 고르는 code-ranking oracle은 27쌍 모두 정답을 낼 수 있다. 이는 과제에 필요한 정보가 주어졌다는 구조 확인이며 보상 학습자의 성능이나 생물학적 수량 능력이 아니다. nuisance-only 기준은 교차 자료에서 평균 0.5이며, 입력의 순서 정보를 숨기는 실험은 이번 범위가 아니다.

H-R 미달이면 이 입력·척도·갱신·400시행에서 독립 선형 보상 학습 기준에 도달하지 못한 결과다. 모든 선형 알고리즘의 불가능성이나 초파리 커넥톰의 필수성을 뜻하지 않는다. H-G 미달이면 습득 후 사전 새 입력 기준을 만족하지 못한 결과이며 습득과 일반화 실패를 각각 남긴다. 무작위 보상에서도 높은 성능이 나면 우연 편향·보상 경로와 평가 구조를 기록하고 주 차이 기준을 그대로 적용한다. 실패를 해소하려고 학습률·시드·시행을 바꾸지 않는다.

성공하면 모델 점수를 받는 참조뿐 아니라 **독립적인 단순 보상 정책도 이 순서 제공 과제에서 학습할 수 있음**을 보여준다. 커넥톰의 실제 배선만의 수학적 원리, 물체 수 세기, 새로운 규칙 발견, 인간의 수학 이해 또는 같은 신경 기작을 증명하지 않는다. 내부 가소성과 파라미터 수 차이를 통제한 우열 실험이라고 부르지 않는다.

## 실행 전 동결과 독립 검산

이번 설정, 새 프로토콜·배경, 전체 Python 소스, 원자료 projection·manifest·license와 환경 잠금 파일의 해시를 새 registration에 기록한다. 소스 commit과 등록 commit을 비공개 원격에 먼저 보존하고 원격 byte 해시·시간을 확인한 뒤 주요 실행을 시작한다. 결과 디렉터리는 새 경로로 배타 생성하며 기존 연구를 덮어쓰지 않는다.

새 자동 테스트는 특징 정규화 자료범위·0 head·보상 API·random reward 독립 생성·7계수 갱신·normalized 내부 gradient·상태 비변경 평가·누출·주 gate의 경계와 실패 보존을 확인한다. 독립 검산은 producer 학습자·정규화 함수·요약 함수를 호출하지 않고 원자료에서 `g`, 모든 행동·보상·갱신, checkpoint, 새 입력 확률·raw margin·summary 판정을 별도 산술로 재구성한다. 원시 입력·수량 순서 정보·처리 자원과 zero head 변경이 기록됐는지도 검사한다.

재현 명령은 별도 태그 checkout에서 같은 잠금 환경을 준비한 뒤 실행한다. 결과 경로는 존재하지 않는 새 경로를 지정한다.

```powershell
.\.venv\Scripts\python.exe -m drosolearn.reward_linear register --config configs/reward_linear_diagnostic.json --out results/registration_reward_linear_v1.json
.\.venv\Scripts\python.exe -m drosolearn.reward_linear run --config configs/reward_linear_diagnostic.json --registration results/registration_reward_linear_v1.json --out results/MY_REWARD_LINEAR_REPLAY
.\.venv\Scripts\python.exe -m drosolearn.reward_linear verify --out results/MY_REWARD_LINEAR_REPLAY
```

연구 실행은 최초 등록과 동결 증거를 보존한다. 과거 태그의 결과를 재현할 때 최신 소스 목록에 맞춰 옛 registration을 변경하지 않는다. 계산 시드는 독립 초파리 개체 또는 인간 참가자가 아니다. 사후 실패·해석도 별도 보고하고 실행 전 기준은 고치지 않는다.

## 인간 학습 비교와 해석 수준

경험에 따른 모델 출력·가중치 변화는 Level 2, 습득과 joint gate를 통과한 인공 입력의 새 사례 반응은 제한된 Level 3 후보로 해석한다. 코드 순서가 이미 제공된 사실을 함께 밝힌다. 이번에는 실제 초파리 또는 인간 행동 자료와 같은 측정 구조로 정량 비교하지 않으므로 Level 4 결과가 아니다. 공통 신경 기작의 Level 5도 주장하지 않는다.

장기 목표는 학습 곡선, 정답 선택률, 보상 규칙 수정, 일반화와 간섭에서 인간과 비교 가능한 가설을 만드는 것이다. 현재 확보한 인간 공개 자료는 참가자별 전후 요약이며 이번의 시행별 보상·입력 코드 조작 기록이 없다. 새 인간 실험을 시작하지 않고, 비교 가능한 기존 원자료와 측정 정의를 확인한 뒤 별도 계획으로 진행한다. 이번 성공·실패가 인간의 수학 교육 효과를 알려준다고 주장하지 않는다.

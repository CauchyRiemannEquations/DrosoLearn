# 조개별 학습의 공유 출력 간섭: 실행 전 제한된 계산 진단

작성일: 2026-10-19 (Asia/Seoul). 새 연구 `shell_credit_v1`이다. 설정·입력 그래프·의존 소스·이 계획·부모 결과를 별도로 동결하고 등록을 원격 확인한 뒤 실제 과학 시행을 한 번 실행한다. 기존 `human_shell_v1`·`human_shell_rng_v2`와 모든 완료 소스·설정·등록·결과를 바꾸지 않는다.

## 쉽게 설명하면

기존 조개 비교에서 모델의 수치는 바뀌었지만 행동은 거의 개선되지 않았다. 이번에는 “한 조개를 배울 때 다른 조개의 답까지 같이 바뀌는가?”를 좁혀 본다. 원래처럼 답을 공유하는 모델, 현재 조개의 답만 바꾸도록 계산적으로 분리한 모델, 아무것도 배우지 않는 모델을 같은 작은 시험에 놓는다.

이것은 사람에게 다시 같은 시험을 시키거나, 과거 실패의 학습 횟수를 늘려 성공으로 바꾸는 작업이 아니다. **규칙이 바뀌지 않는 별도의 정지 과제**에서 갱신 간섭을 조사한다. 720시행을 원래 사람의 216시행과 대응한다고 부르지 않는다. 새 결과가 좋아도 과거 인간 유사성 실패는 그대로 남는다.

## 근거·가설·반증 조건

[조개 비교](human-shell-findings.md)는 출력·내부 변화와 행동 습득을 구분했다. 여섯 조개가 같은 출력 계수를 공유하는 네트워크와 조개별 계수를 쓰는 단순 모델의 평균 차이는 간섭 가능성을 제안하지만 원인을 증명하지 않았다. Q와 actor는 갱신 규칙·척도도 다르다. 기존 수량 과제의 ablation·상태 분해 결과를 새 조개 과제의 원인으로 그대로 옮기지 않는다.

주 가설 H_credit: 현재 조개에 대한 국소 점수 수정 폭을 맞춘 상태에서, 다른 조개로 번지는 출력을 차단한 조건이 공유 조건보다 정지 과제의 최종 유리한 선택 확률을 높인다. 평균 차이 ≥.10, 차이가 양수인 seed가 4/5 이상이어야 효과 기준 통과다. 또한 분리 조건의 습득 기준을 4/5 이상이 통과해야 가설 지지다. 이 실용 기준은 통계적 유의성·생물학적 경계가 아니다.

분리 조건이 습득하지 못하거나 차이가 기준보다 작으면 가설은 미지지다. 간섭이 실제로 작거나, 차이가 없어도 이를 실패로 보존한다. 더 좋은 seed·학습률·시행 예산으로 같은 등록을 재시도하지 않는다. 원래 사람 과제 실패의 원인이 이 간섭이라고 확정하는 검정은 아니다.

## 세 조건과 정적 영향 행렬

세 조건은 `shared`, `isolated`, `uniform`이다. 실제 부분 배선의 입력·KC 반응·KC→MBON 가중치는 모두 고정하고 출력 계수만 학습한다. 배선 우위 비교나 내부 가소성 실험은 이번 범위에 포함하지 않는다.

여섯 조개의 인공 입력은 기존과 같은 7차원이다. NoGo는 영벡터, Go는 조개별 앞 여섯 좌표의 one-hot이고 마지막 좌표는 0이다. 고정 encoder seed는 새 계산 seed +100000이다. 입력을 점 그림·수량 추출·실제 시각 회로로 해석하지 않는다.

초기 MBON의 Go−NoGo 차이를 여섯 조개의 RMS로 나눈 행벡터를 d_s, 이 여섯 행을 모은 행렬을 D, Gram 행렬을 G=D Dᵀ라 한다. 출력 h는 0으로 시작하고 Go 확률은 logistic(d_s·h), 점수 clipping은 ±40이다. `shared`의 출력 변화는 `eta × (action−p) × obtained_reward × d_s`다. eta=.1이며 NoGo는 보상 0이므로 변화가 없다.

`isolated`는 U=solve(G,D)의 s번째 행 u_s를 이용해 `eta × (action−p) × obtained_reward × ||d_s||² × u_s`만큼 바꾼다. 동일 p·행동·보상인 같은 상태에서 자기 조개 점수 변화는 공유 갱신과 같고 다른 조개 점수 변화는 0이 된다. 이 일치가 실제로 갈라진 두 자율 경로의 매 시행 변화까지 같다는 뜻은 아니다. 이후 선택·보상 경험도 달라질 수 있으며 전체 계산 경로의 효과를 비교한다.

U는 추가 학습된 해부 연결이 아닌 고정된 계산 대조다. 두 학습 조건의 출력 좌표 수는 같지만 분리 조건에는 6×출력 차원의 추가 고정 계수와 6×6 행렬 풀이가 필요하다. 실제 갱신 L2 크기도 같다고 주장하지 않고 별도로 기록한다. 실제/생물학적 학습 법칙의 우수성을 주장하지 않는다.

초기 확률 .5에서 단일 Go와 보상 −1/+1의 정적 점수 영향 행렬을 각각 계산한다. 행은 학습한 조개, 열은 평가한 조개다. 공유·분리의 대각선 일치와 분리 조건의 비대각선 0을 확인한다. Q의 alpha=.1·beta=4라면 첫 Go의 자기 logit 변화가 ±.4라는 산술 참조도 대각선으로 남긴다. 이는 추가 Q 학습 경로나 경험 수가 아니다. actor의 평균 초기 자기 변화는 ±.05여서 같은 학습률 숫자가 같은 행동 수정 폭을 뜻하지 않음을 구분한다.

## 수치 gate와 중단

모든 과학 seed에서 D의 수치 rank=6, G의 조건수 ≤1e8, D Uᵀ−I의 최대 절댓값 ≤1e−9를 요구한다. 단일 갱신의 자기 점수 차이도 ≤1e−9여야 한다. 어느 seed든 실패하면 과학 선택 시행을 시작하지 않고 gate 실패를 보존한다. 사후 정규화·정칙화·다른 whitening·seed 교체를 도입하지 않는다. 실제 기하를 보기 전 고정한 수치 기준이다.

## 고정 과제·예산·난수

새 계산 seed는 15001–15005다. 각 seed의 여섯 조개 중 세 개는 Go에서 +1을, 나머지 세 개는 −1을 80% 확률로 준다. 나머지 20%는 0이다. NoGo는 항상 0이고 숨은 Go 내용은 학습자에게 주지 않는다. R/N의 동률 상태나 규칙 반전은 이번 과제에 없다.

각 조개를 120회, 총 720회 제시한다. 매 여섯 시행 block에 모든 조개가 한 번씩 나오고 그 안의 순서를 섞는다. 사전에 고정한 세 조건 × 다섯 seed × 720 = **10,800회** 실제 선택·피드백이다. 보상과 행동의 확률 추출은 다른 스트림이고 조건 간에는 같은 잠재 결과·행동 uniform을 공유한다. 모델이 실제 받는 보상은 자신의 선택에 따라 달라진다.

모든 스트림은 `SeedSequence([202610191, seed, component])`다. component=0은 조개 표지 permutation(앞 세 개 양의 보상), 1은 block별 제시 순서, 2는 잠재 결과 uniform, 3은 행동 uniform이다. 순서·양/음 표지·잠재 결과·두 uniform을 결과 배열에 모두 남긴다. 동일 조건 내 seed를 생물학적 개체로 세지 않는다.

120 노출은 등록 전에 정한 제한된 정지 과제 예산이다. .1의 actor 수정 크기에서 40 노출만으로는 습득 기준과 간섭을 혼동할 수 있어, 실제 과학 결과를 보기 전에 별도 과제의 예산을 고정했다. 사람 데이터에 맞춰 학습률을 다시 선정하지 않는다. 기존 선정 목적이 다음 인간 선택의 NLL이었다는 사실과, 자율 과제의 습득은 다른 목적이라는 점도 보존한다. 이 목적 차이의 인과 효과를 이번에 검정했다고 부르지 않는다.

## 지표·자원·검산

노출 0,10,…,120회(전역 0,60,…,720시행)에 고정 여섯 조개의 선택 확률·출력 계수를 저장한다. 주 성능은 여섯 조개에서 점수상 유리한 행동을 고를 확률의 평균이다. 실제 받은 보상률이나 표본 행동 정답률과 구분한다. seed별 습득 기준은 최종 확률 ≥.75와 초기 대비 증가 ≥.15의 동시 충족이다. 조건별 4/5 이상이면 습득 gate 통과다.

모든 시행의 조개·현재 노출 수·예측 확률·선택·획득 보상·출력/내부 갱신 호출과 실제 L2 변화를 저장한다. 내부 가중치와 KC/MBON/정규화된 특징 probe는 고정이므로 변화 0을 확인한다. 출력 점수·확률 변화는 이 특징 활성과 별도다. 초기/최종 encoder·bias·배선·내부 가중치·probe와 출력 checkpoint를 함께 보존한다.

독립 검산은 원 그래프·고정 설정에서 초기 신경 특징, Gram/dual, 두 부호의 영향 행렬, 세 난수/순서·표지 스트림, 모든 실제 선택·보상·출력 갱신, checkpoint·습득·가설 판정을 별도로 계산한다. 원 소스와 새 소스를 덮어쓰지 않는다. 실제 실행 전에 합성 fixture로 수치 gate·숨은 보상 차단·자기 변화 일치·다른 조개 차단·균등 정책 불변·예산/순서·미지지 판정을 검사한다.

이번 성공이나 실패를 확인한 뒤에만 후속 측정 검증·최소 규칙 과제·간섭/순서 연구의 조건을 결정한다. 습득하지 못한 조건의 규칙 전이를 성공으로 읽지 않는다. 사람과의 유사성·실제 초파리의 학습·공통 신경 기작·수학교육 효과는 이번 연구의 검정 대상이 아니다.

# 입력 표현 진단 — 쉬운 설명과 결과

2026-10-14, Asia/Seoul. 실행 뒤 작성한 해석 문서다. [사전 계획](encoding-protocol.md)·설정·학습 규칙·성공 기준은 바꾸지 않았다. [자동 보고서](../results/encoding_v1/report.md), [모든 시드 판정](../results/encoding_v1/summary.json), [학습 전후 숫자](../results/encoding_v1/analysis_summary.json)를 함께 보존한다.

## 이번에 확인한 질문

이전 모델에는 물체 그림을 보여준 것이 아니라, 이미 계산한 수량을 숫자로 전달했다. 예를 들어 2개는 2/8, 4개는 4/8이었다. 모델이 입력을 받기 전에 **큰 수량에는 큰 입력값을 주는 힌트**가 들어 있다. 그래서 처음 보는 수량에서도 높은 성적을 냈다는 사실을 수학 규칙을 스스로 발견했다는 뜻으로 해석하면 안 된다.

이번에는 2개와 4개를 구별하는 연습은 그대로 두었다. 연습하지 않은 1·3·5·6·7·8의 입력은 두 방법으로 검사했다. 하나는 원래의 크기 순서를 유지하는 방법이고, 다른 하나는 수량에 임의의 이름표를 붙이는 방법이다. 이름표의 숫자가 커도 물체 수는 적을 수 있다. 같은 학습된 모델을 사용하며, 검사 때 새 정답을 가르치지 않는다.

이 조작은 실제 수량과 코드의 순서 대응뿐 아니라 수량쌍별 입력 간격도 바꾼다. **순서만 독립적으로 바꾼 실험이라고 표현하지 않는다.** 이름표는 수량의 고유한 정체성과 인공적인 숫자 간격을 남긴다. 첫 입력값을 모두 0으로 만드는 ‘수량 정보 제거’ 모델은 이와 구분해 별도로 학습했다.

## 실제로 학습한 변화

아래 성적은 ‘정답을 고를 확률’의 평균이다. 10개 계산 시드, 즉 서로 다른 초기 난수 조건을 모두 포함한다. 실제 배선은 공개 초파리 자료의 일부 연결을 사용한 계산 모델이며, 살아 있는 초파리가 아니다.

| 모델 | 연습한 2대4의 최종 성적 | 두 수량 모두 새로 나온 15쌍: 순서 코드 학습 전→후 | 연습 습득 통과 | 습득 후 새 수량 기준 통과 |
|---|---:|---:|---:|---:|
| 실제 배선·출력만 학습 | 80.4% | 50.1%→86.1% | 10/10 | 10/10 |
| 실제 배선·내부도 학습 | 93.5% | 50.1%→94.0% | 10/10 | 10/10 |
| 재배선·출력만 학습 | 80.4% | 50.0%→86.0% | 10/10 | 10/10 |
| 재배선·내부도 학습 | 93.4% | 50.0%→93.9% | 10/10 | 10/10 |
| 일반 신경망·출력만 학습 | 80.3% | 50.0%→85.8% | 8/10 | 8/10 |
| 일반 신경망·내부도 학습 | 93.2% | 50.0%→93.9% | 10/10 | 10/10 |

학습 전후 차이가 있으므로, 순서 입력의 높은 성적이 입력 힌트 하나만으로 처음부터 생겼다는 뜻도 아니다. **힌트가 있는 표현에서 보상 경험으로 선택 함수가 바뀌었고, 그 함수가 새 입력에도 반응했다**는 범위의 결과다. 물체를 세거나 수량의 의미를 발견한 증거는 아니다.

새 15쌍의 평균 수량 차이는 3.2이고, 연습한 2대4의 차이는 2다. 큰 차이의 쌍이 포함되어 새 문제 평균 성적이 더 높을 수 있으므로, ‘더 어려운 문제에서도 더 잘했다’고 해석하지 않는다. [쌍별 성적](../results/encoding_v1/pair_summary.csv)을 별도로 남겼다. 두 일반 신경망 출력 전용 시드 3008·3009는 연습 성적 74.84%·70.83%로 사전 75% 기준에 못 미쳤다. 새 수량 성적이 높아도 연습 습득 실패를 구제하지 않았다.

내부도 바꾸는 모델의 성적이 수치상 높았지만, 이 조건에는 추가로 학습 가능한 내부 가중치 1,474개가 있다. 출력만 배우는 조건과 같은 학습 자원을 썼다고 주장하지 않는다. 재배선·일반 신경망에도 같은 가소성 규칙과 예산을 적용했다. 이 차이는 단순화된 계산 규칙의 효과이며 실제 DAN 신경세포의 기억 작용을 검증한 결과가 아니다.

## 임의 이름표의 50%는 무엇을 뜻하는가

720가지 이름표 배치를 모두 평가하면, 두 새 수량의 이름표를 서로 바꾼 경우가 같은 수만큼 들어간다. 같은 입력에 반대 정답이 대응하는 경우를 공평하게 평균하므로, 이번 설계에서는 **새 수량의 대응표를 받지 않고 같은 코드 입력만 보는 어떤 고정된 모델도 두 수량 모두 새로 나온 15쌍에서 평균 50%**다. 이는 실행 전에 증명해 둔 검사 조건이다.

실제로 모든 모델에서 이름표 평균은 50%였고, 수량 정보를 제거한 대조도 50%였다. 이것을 새로운 학습 실패, 초파리의 수학 능력 한계, 임의 이름표 학습 자체의 불가능성으로 보고하지 않는다. 이름표와 참 수량의 대응표를 전부 제공받은 특권적 기준 모델은 100%를 낼 수 있다. 실제 학습 모델은 새 수량의 대응표를 받지 않았다.

순서 코드와 이름표 평균의 차이는 실제 출력 전용 36.06±1.13%포인트, 내부 학습 44.00±0.45%포인트였다. 평균 차이 10%포인트 이상·양수 시드 8/10 이상이라는 사전 기준은 6모델 모두 통과했고, 각 모델의 10시드 모두 양수였다. ±는 계산 시드의 표본 표준편차이며 생물학적 표본의 신뢰구간이나 유의성 검정이 아니다. 이 대비는 순서 제공 표현과 임의 표현에서 같은 함수의 반응이 달라지는 진단이다. 50%를 실험으로 발견한 성과로 세지 않는다.

2나4 중 하나를 연습에서 본 나머지 12쌍에는 일부 정보가 남는다. 임의 이름표에서도 실제 출력 전용 모델 62.4%, 내부 학습 모델 63.8%였다. 전체 27쌍 평균은 각각 55.5%, 56.1%다. 단순히 큰 이름표를 고르는 기준 모델도 그 두 범위에서 63.89%, 56.17%를 낼 수 있다. 따라서 50%보다 높다는 사실을 새 수학 규칙의 학습으로 해석하지 않는다.

## 검증과 해석 범위

실제 학습은 6모델×10시드×2입력 조건×400시행, 총 48,000번이다. 720은 같은 모델을 검사하는 이름표 배치 수이며 추가 학습 수나 초파리 개체 수가 아니다. 연습 입력과 연습 수량의 평가 입력은 모든 이름표에서 완전히 같았다. 모든 시행·선택 난수·보상·checkpoint·입력 코드별 점수와 판정을 보존한다.

자동 테스트 229개와 [독립 검산](../results/encoding_v1/verification.json)이 모두 통과했다. 별도 식으로 48,000번의 갱신, 600개 checkpoint, 240개 평가 파일과 2,336,040개 평가 확률 항목을 재계산했다. [보존 확인](../results/encoding_archive_validation.json)에서 동결한 소스·자료·프로토콜 24개와 주요 결과 898개의 해시가 그대로임을 확인했다. 앞선 실험 파일 3,488개도 바이트 기준으로 보존했다. README·현재 상태·로드맵은 새 결과를 반영해 갱신했다. [실행 전 원격 고정 확인](../results/encoding_prefreeze_evidence.json)은 비공개 Git 기록이며 공인된 공개 사전등록은 아니다.

현재 근거는 인공 입력에서의 경험 의존적 변화(Level 2), 습득 확인 후 그 표현 안에서 새 수량에 반응한 제한된 일반화(Level 3)다. 실제 시각 수량 지각, LC11 회로, 수학 기호 이해, 인간과의 정량적 유사성(Level 4), 같은 신경 기작(Level 5)은 검증하지 않았다. 재배선·일반 신경망에도 비슷한 결과가 있어 초파리 원래 배선의 고유한 우수성을 뒷받침하지 않는다.

## 다음 연구로 남기는 질문

다음 후보는 **크기 순서는 유지하되 입력값 사이의 간격만 바꾸면 새 수량 성적이 어떻게 변하는가**다. 연습한 두 입력값을 고정한 채 비교하면 순서와 거리 효과를 더 좁힐 수 있다. 비율 효과를 인간의 수량 감각과 연결하기 전에, 모델 반응이 이미 제공한 입력 간격으로 설명되는지 먼저 검사해야 한다. 아직 실행하지 않은 가설이며 새 프로토콜을 먼저 고정한다.

인간 학습과 연결되는 질문은 ‘어떤 표현을 보여줬는가’와 ‘어떤 경험으로 변화했는가’를 분리해서 비교할 수 있는가다. [확보한 인간 공개 자료](human-data-readiness.md)는 아동 56명의 연습 전후 요약 점수이며 이번 이름표 조작이나 시행별 학습과 같은 자료가 아니다. 이번에 인간과의 직접 비교를 수행하거나 학교 수학교육 효과를 주장하지 않는다. 인간 비교는 장기 핵심 목표로 유지한다.

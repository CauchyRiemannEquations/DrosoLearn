# 공식 원본에서 가공 기록을 다시 만든 결과

작성일: 2026-10-15 (Asia/Seoul). 보존 태그: `human-osf-origin-v1`.

## 먼저 쉽게 설명하면

**공식 원본 25개에서 기존 가공 기록의 75,000개 항목을 다시 계산했고, 결측 위치까지 모두 일치했다.** 저자가 공개한 변환 규칙을 읽어 새 Python 도구로 재현한 결과다. 원 저자의 프로그램 자체를 실행하지 않았고, 사람의 성적이나 학습 곡선을 계산하지도 않았다.

쉽게 말하면, 연구에 쓸 표가 원래 기록에서 어떻게 만들어졌는지를 확인했다. 이 확인은 중요하지만 사람이 모델과 같은 방식으로 배운다는 증거는 아니다. 전체 74행 중 이번에 원본을 찾지 못한 **49행은 미검증**으로 남겼다.

## 자료를 고른 기준과 실제 범위

출처는 [Marković, Reiter & Kiebel (2022)](https://doi.org/10.3389/fnbeh.2022.962494)이 연결하는 [공식 OSF 프로젝트](https://osf.io/h526v/)의 [행동 자료 component](https://osf.io/75jrf/), 가공 자료는 저자 pybefit 저장소의 고정 커밋 `813aeb5ad2c7bbed90ecd7d947bce9fe981c9702`다. 파일별 버전·URL·바이트·SHA-256과 가용성은 [동결 manifest](../configs/human_osf_origin_manifest.json)에 있다.

공식 `Main` 폴더의 목록은 이번 접근에서 0개, `Pilot`이라는 폴더에는 154개 항목이 있었다. 하지만 파일명을 저자 변환 코드의 전체 명단과 정확히 대조하니, `Pilot` 폴더에서 **가공 main 50행 중 25행**의 원본이 발견됐다. 가공 pilot 24행의 원본은 이 목록에서 찾지 못했다. **폴더 이름으로 실험 집단을 결정하지 않았다.**

| 가공 자료 구획 | 전체 행 | 정확한 이름 대응 원본 | 미검증 |
|---|---:|---:|---:|
| main | 50 | 25 | 25 |
| pilot | 24 | 0 | 24 |
| 합계 | 74 | 25 | 49 |

선정은 성적을 계산하기 전에 파일명의 정확 일치와 공개 가용성만으로 고정했다. 찾은 25개를 전부 사용했다. 이 중 formatter 순서상 regular 15행·irregular 10행이며 조건 표시도 일치했다. 대표 표본이거나 서로 독립된 사람 25명이라는 새 판정을 내리지 않는다. pilot의 중복 행 두 쌍도 명단에서 삭제하지 않았다.

원본 25개는 총 2,182,734바이트다. 공식 API가 제공한 `revision=1` URL에서 받아 서버의 크기·SHA-256과 대조했다. 원본 MAT와 가공 CSV·저자 formatter는 저장소 밖 캐시에 유지한다. 공식 목록·권한 JSON 5개는 [별도 폴더](../data/human/osf_origin_evidence_20261015/)에 원바이트로 보존했다. 이 메타데이터에는 공개된 익명 코드 파일명·시각이 있지만, 새 행별 대조 보고서는 파일 ID와 이름 토큰의 SHA-256만 사용한다. 실제 개인의 이름과 연결하지 않았다.

## 사전에 고정한 변환과 판정

[별도 프로토콜](human-osf-origin-protocol.md)에 변환·성공 기준을 먼저 고정했다. 원 formatter는 AST로 문자 목록과 순서를 정적으로 읽었으며 실행하지 않았다.

| 가공 열 | 재현한 원 규칙 | 주의점 |
|---|---|---|
| responses | 원 `A − 1` | 0/1 카드 선택, 2 정보 요청, 결측은 그대로 |
| outcomes | 카드 선택은 해당 `R`의 `(값+1)/2`; 정보 요청은 `S+1`; 무응답은 NaN | 2/3은 정보 요청 결과의 상태 코드이며 금전 보상 크기가 아님 |
| correct_responses | 원 `C`를 그대로 복사 | 정답 카드 번호로 바꾸거나 결과를 새로 계산하지 않음 |

각 원본은 1,000개 시행 위치를 가진다. 선택·결과·정오의 세 배열을 모두 대조했다. `NaN`은 빈 기록이며 0으로 채우지 않았다. 값이 잘 맞도록 배열을 정렬하거나 일부 시행을 빼지 않았다.

| 검사 항목 | 실제 결과 |
|---|---:|
| 원본 재현 행 | 25 |
| 행마다 대조한 배열 | 3 |
| 배열마다 위치 수 | 1,000 |
| 전체 대조 항목, 결측 포함 | 75,000 |
| 값 또는 결측 위치 불일치 | 0 |
| 조건 표시 일치 | 25행 모두 |
| 이번 부분 게이트 | 통과 |

이 통과 범위는 **선정된 25개 원본과 세 가공 배열**이다. 49행은 비교하지 않았으므로 ‘0불일치’에 포함하지 않는다. 25개 원본의 모든 변수, 자극·반응 시간, 전체 연구의 분석 또는 자료 독립성을 검증한 결과도 아니다.

## 권한과 해석의 경계

공식 데이터 component는 CC BY 4.0을 직접 명시했다. 소프트웨어의 MIT 선언과 구분하고 원 출처·버전·변환을 기록했다. 이번 값 재현이 별도 호스팅된 가공 CSV 전체에 포괄적인 재배포 권한을 자동 부여하는 것은 아니다. 원본과 가공 파일의 재배포 정책은 그대로 유지했다.

OpenNeuro의 기대·도형 코드 의미 문제는 이 다른 자료의 통과로 해결되지 않는다. [앞 단계 결과](human-semantics-findings.md)는 미해결 상태로 보존했다. 이번에도 인간의 정확도·보상률·학습 곡선·반전 비용·모형 적합·인간/초파리 모델 유사성은 계산하지 않았다. Level 4 또는 Level 5의 근거가 아니다.

다음 행동 비교를 설계하려면 원 과제의 두 카드와 정보 요청 선택, 관측 선택과 모델 확률, 확률적 피드백, 시행 구획·반전 상태의 뜻을 먼저 맞춰야 한다. 이번 확인 범위의 자료에서 어떤 공통 지표가 가능한지를 검토하고, 별도 계획으로 지표·분모·성공/실패 조건을 고정한 다음 계산한다. 단순히 같은 수의 시행이 같은 학습 경험을 뜻한다고 가정하지 않는다.

## 재현·독립 검증

합성 자료 자동 테스트 **52개가 3.99초에 통과**했다. 이 중 본체·동결 검사 33개, 독립 변환·손상 검사 19개다. 사람 원본의 실제 값 대조를 테스트에 쓰지 않았다. [테스트 기록](../results/test-validation-human-osf-origin.json)을 보존했다.

실제 실행 뒤 주 변환 함수를 호출하지 않는 독립 검증기가 입력 파일 39개와 동결 파일 15개, 74행의 전체 가용성, 25개 원본의 75,000항목을 다시 계산해 통과했다. [주 결과](../results/human_osf_origin_v1/comparison.json), [독립 검증](../results/human_osf_origin_v1/verification.json)을 함께 남긴다. 독립 검증의 통과와 원본 재현 게이트의 통과를 별도 필드로 기록했다.

소스 커밋은 `93eea32f0ef18466142657ee978afc7694bcc5db`다. 2026-10-15 UTC 등록 02:54:14 → 원격 원바이트 확인 02:54:30.647 → 값 대조 02:54:31.328–31.450 → 독립 검증 02:54:32 순이다. [등록](../results/registration_human_osf_origin_v1.json), [원격 확인](../results/human_osf_origin_prefreeze_evidence.json)에 원본·코드·설정과 당시 가용성의 해시를 묶었다. 자료 구조와 가용성을 먼저 본 부분 출처 감사이며 눈가림 행동 가설 사전등록은 아니다.

`human-osf-origin-v1`의 별도 checkout에서 프로토콜의 `register --fetch`, `run`, 독립 검증 명령으로 새 경로에 재현한다. 공식 메타데이터는 보존본을 복사하고 원본은 고정 버전·가공 파일은 고정 커밋 URL에서 복구하며 모두 해시를 검사한다. 후속 서버 접근 실패나 해시 차이는 숨기지 않고 기록한다. 기존 연구·실패·등록·결과는 바꾸지 않았다.
